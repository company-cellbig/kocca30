> 2026-08-07 사용자 재규정(덧뵈기는 탈춤이 아니라 가면극에 가까움)에 따라 Step 3 재설계를 원점부터 다시 검토한 기록. 같은 과제를 Claude Code와 Codex가 독립 수행한 두 결과와 비교, 미결을 담음. 구성 방향은 사용자 결정 대기.

# 1. 배경과 재규정

- **사용자 문제 제기 경과**: 2026-08-06 논의(마당 한 판은 대부분 대화고 춤은 막간이라 춤 따라추기 기획으로는 유저가 수동적)에 이어, 2026-08-07 사용자가 원점 재검토를 지시함. 핵심 재규정: 덧뵈기를 탈춤(춤 중심)으로 본 것이 오판이었고, 덧뵈기는 가면극(연극 중심)에 가까움
- **검토 과제**: ① 가면극으로서 덧뵈기 전승에 필요한 내용(기예와 지식 요소) 검토 ② 그중 키오스크 디바이스에서 콘텐츠화할 수 있는 것 확인. 같은 과제를 Claude Code와 Codex 양쪽에서 독립 수행해 결과를 비교함
- **원전 뒷받침**: 전사본([[남사당놀이 - 덧뵈기]], L2)은 덧뵈기를 "사회극"으로 규정하고(특징 절), 춤사위 서술은 3종 몇 줄뿐인 반면 연회본(대본)이 문서의 3분의 2를 차지함. [[덧뵈기]] 페이지도 "춤사위보다 마임과 재담, 사회 풍자가 두드러짐"으로 정리되어 있음
- **디바이스 제약 기준**: 65인치 가로 터치, 뎁스 카메라 전신 인식(손가락 불가, 손목까지), 바닥 프로젝션 2x2m, 마이크/STT, 스피커, QR 웹 반출, 모바일 앱 없음, 3D 지양, 1인 플레이 ([[디바이스 사양]])

## 3.2 콘텐츠 후보 5개

모두 원전 대목이 이미 게임 구조를 내장한 지점을 고른 것임(2026-08-06 발견의 연장).

- **후보 A. 「절 배우기」 시늉 게임** (셋째 마당 556~608행)
	- 흐름: 샌님이 "번쩍 들어라, 꾸부려라" 지시 → 유저(말뚝이 역)가 몸으로 수행 → 원전대로 말뚝이식 되받기 반전으로 마무리
	- 입출력: 뎁스 카메라(동작 판정), 스피커(샌님 음성), 터치(대사 선택)
	- 학습 요소: 마임, 주고받기 구조, 신분 풍자의 핵심 대목
	- 리스크: 낮음. 원전이 이미 지시-수행 게임이라 각색이 거의 불필요
- **후보 B. 「말뚝이 대거리」 재담 응수** (셋째 마당 480~554행)
	- 흐름: 샌님이 재담을 걸면 유저가 응수 대사를 터치로 고르고 마이크에 크게 외침 → 음량과 타이밍(판정 구간) 채점 + 결정 몸짓
	- 입출력: 터치, 마이크(음량), 뎁스 카메라
	- 학습 요소: 재담의 맞받기 구조, 말뚝이 전형, 풍자 정신
	- 리스크: 공공장소 발화 부끄러움, 소음 오검출
- **후보 C. 「춤 대결」 취발이 대 먹중** (넷째 마당 666~672행)
	- 흐름: 먹중을 춤으로 눌러 이기는 원전 대목을 대결 연출로 옮김. 코치를 따라 추되 진폭이 클수록 상대 게이지를 깎음
	- 입출력: 뎁스 카메라(포즈 매칭과 진폭), 바닥 프로젝션(대결 연출)
	- 학습 요소: 극 안에서 춤이 하는 기능(겨루기), 덩덕궁이 장단
	- 리스크: 낮음. 기존 Step 3 포즈 매칭 자산 재활용도가 가장 높음
- **후보 D. 「탈이 말한다」 인물 연기 교실**
	- 흐름: 탈 도상 읽기(점과 혹의 의미) → 그 인물의 전형 몸짓 3~4개 수행(과장/맺음 관대 판정) → 결정 포즈
	- 입출력: 터치(탈 선택), 뎁스 카메라
	- 학습 요소: 탈 기호 체계, 배역 전형
	- 리스크: 자유 표현 판정 기준이 모호(2026-08-06 B안의 머뭇거림 리스크와 동일)
- **후보 E. 「덧뵈기 한 판」 4마당 압축 종합 (Claude Code 추천)**
	- 흐름: 비나리 외치기(첫째) → 옴탈 흉내 맞받기(둘째) → 절 배우기(셋째) → 춤 대결(넷째), 마당당 60~90초 미니게임
	- 학습 요소: 극 구조 전체 + 마당별 핵심 기예를 한 세션에. 가면극으로서의 덧뵈기를 가장 온전히 전달
	- 리스크: 세션 길이와 회전율. 한 세션 한 배역 결정(2026-07-24, [[덧뵈기 나만의 탈춤 대수정 방향]])과의 조율 필요(유저를 말뚝이/꺽쇠 시점으로 고정하면 양립 가능)
- **축소 대안**: 개발 리스크를 낮추려면 후보 A+C 2장 구성(절 배우기 → 춤 대결)이 최소 성립선임. 어느 쪽이든 기존 포즈 매칭 엔진과 배역 선택 Step은 재활용됨

| 장단/소리 | 사물과 날라리, 염불, 타령, 굿거리, 덩덕궁이, 칠채가락. 마당씻이에서 꺽쇠가 꽹과리 자진가락을 치며 비나리를 외움 | 배경음이 아니라 말, 춤, 등퇴장, 판 열기의 리듬 규칙임. 키오스크에서는 장단 타이밍을 대사/행동 큐와 연결해야 함 |
| 극 구조/놀이판 | 네 마당. 덜미 포장막이 탈막 구실, 큰 멍석 약 4평이 관중 시선을 잡음 | 단일 동작 루프보다 "들어옴-대거리-뒤집힘-춤/퇴장"의 미니 장면 구조가 필요함 |

## 4.2 콘텐츠화 가능성 평가 (Codex)

| 요소 | 판정 | 근거와 제약 |
|---|---|---|
| 극/재담 | 가능 | 터치 선택, 마이크/STT, 스피커/TTS로 짧은 대사 선택, 낭독, 응답이 가능함. 긴 원문 전체 암송은 전시장 회전율상 제한적임 |
| 마임/연기 | 가능 | 절하기, 꾸부리기, 쫓기기, 얼굴 가리기 같은 큰 몸짓은 가능함. 손가락 세부 연기와 탈 표정 연기는 불가 |
| 배역 전형 | 가능 | 터치 화면에서 탈/배역 선택과 배역 기능 설명 가능. 단 10개 전 배역 체험은 제작량이 커져 1차연도는 제한 필요 |

| 4. 취발이 vs 먹중 장면 선택극 | 먹중, 피조리, 취발이 관계 제시 → 유저가 취발이 대사/행동 선택 → 선택에 따라 먹중을 춤으로 겨루거나 풍자하는 짧은 분기 → 마지막 굿거리 춤 한 동작 | 터치, 선택 UI, 스피커/TTS, 뎁스 카메라 | 먹중잡이, 배역 전형, 파계승 풍자, 장단 전환 | 원문에 성적 표현과 여성 비하로 읽힐 수 있는 대목이 있어 가족형 전시용 각색과 고증 자문 필요 |

## 4.4 Codex 핵심 결론

Step 3를 "배역 동작 따라하기"에서 "배역 장면 연기하기"로 바꾸는 쪽임. 춤 채점은 남겨도 되지만, 가면극 관점에서는 대사, 몸짓, 배역 관계, 장단 큐가 함께 판정되는 짧은 마당 장면이 더 맞음.

# 5. 두 결과 비교

## 5.1 수렴하는 결론

양쪽이 독립적으로 같은 곳에 도달한 지점임.

- **Step 3의 정체성 전환**: 배역 동작 따라하기(춤 채점)에서 배역 장면 연기하기(대사, 몸짓, 장단 큐 통합 판정)로. Claude Code의 대목 수행형과 Codex의 미니 장면 구조(들어옴-대거리-뒤집힘-춤/퇴장)는 같은 방향임
- **핵심 대목 일치**: 절 배우기(샌님잡이), 옴탈잡이 실랑이, 취발이 대 먹중을 양쪽 모두 1급 소재로 꼽음. 원전이 이미 게임 구조를 내장한 대목임
- **춤의 재배치**: 삭제가 아니라 극 안의 기능(겨루기, 마무리)으로 이동. 기존 포즈 매칭 엔진은 재활용함
- **재담 처리 방식**: 자유 발화 STT 대신 터치 대사 선택 + 외침(음량/타이밍) 조합이 현실적이라는 판단이 동일함

## 5.2 갈리는 지점

| 쟁점 | Claude Code | Codex |
|---|---|---|
| 권장 구성 | 4마당 압축 종합(후보 E), 축소 시 절 배우기+춤 대결 2장 | 단일 후보 추천 없이 5안 병렬 제시, 방향 전환 원칙만 결론 |
| 마당씻이/비나리 | 종합형의 첫 장으로만 포함 | 독립 후보로 제시(바닥 프로젝션을 멍석으로 쓰는 아이디어) |
| 결과물(반출) | 언급 없음(현행 5 Step 유지 전제) | 네 마당 카드 만들기로 QR 반출 부활 안 제시 |

Codex가 지적한 넷째 마당 각색 문제는 Claude Code 분석이 놓친 유효한 발견임. 취발이 대 먹중 대목을 쓰려면 피조리 관련 재담을 덜어내는 각색이 필요함.
