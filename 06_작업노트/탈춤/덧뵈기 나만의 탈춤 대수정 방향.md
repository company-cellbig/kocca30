# 1. 배경

- 2026-07-23 개발 리뷰에서 탈춤 콘텐츠의 상호작용 모델을 재설계하기로 함. 사용자 결정을 2026-07-24 대화에서 확정함
- 재설계 핵심: 탈을 유저가 그리는 창작에서 프리셋 선택으로 바꾸고, 춤 체험을 배역 연기형으로 좁히며, 별도 촬영을 없애고 체험 중 베스트샷을 자동 선별함
- 사전 조사(2026-07-24, 이 대화)로 타당성과 기술 가능성을 확인함. 근거는 아래 4절

# 2. 확정된 결정 (사용자)

- **탈 디자인 삭제, 탈 선택으로 대체**: 유저가 프리셋 배역 탈 목록에서 하나를 고름. 탈 디자인(생성 AI)은 이 콘텐츠의 필수 쇼케이스가 아님을 사용자가 확정함
- **3D 변환 단계 삭제**: 프리셋 배역 탈은 AR용 3D 에셋을 사전 제작해 배포함. 런타임 2D→3D 변환이 사라짐
- **핵심 체험 = B1 배역 상징 동작 따라하기**: 선택한 배역의 대표 몸짓과 춤(취발이 깨끼춤, 말뚝이 두어춤, 샌님 거드름 등)을 따라 하며 "그 인물이 되어 보기". 채점은 기존 포즈 매칭 그대로. 재담과 풍자는 말뚝이 호스트가 연출로 얹음
- **한 세션에 배역 하나만 체험**: 여러 배역 순회 대신 몰입과 회전율 우선
- **기념 촬영 단계 삭제, 베스트샷 자동 선별로 대체**: 별도 촬영 화면 없이 배역 동작 체험 중 프레임을 자동 캡처해 선별함
- **베스트샷 촬영 방식 (2026-07-24 확정)**: 상시 스트림이 아니라 배역 동작의 주요 지점(특정할 수 있는 대표 동작)마다 사진을 찍고, 각 캡처를 순위 매겨 상위 4컷만 기념 사진으로 남김. 지점 기반이라 어떤 동작이 담겼는지 특정됨. 주요 지점을 하나도 지나지 않고 이탈하면 캡처가 없어 이탈 종료(기념물 없음)
- **베스트샷 4컷**: 세션당 상위 4컷 제공(6컷 검토했으나 4컷 확정)
- **베스트샷 순위 기준**: 자세 일치도 높음 + 동작이 큰 순간(팔 뻗음, 도약) + 프레이밍 양호(전신과 탈이 보이고 흔들림 적음)의 가중 순위
- **기본 배역 (2026-07-24 확정)**: 탈 선택 진입 시 사전 선택되는 기본 배역은 취발이(잠정)
- **「나만의」 개념 삭제**: 개인화를 별도 강조하지 않음. 개인화는 탈 선택과 유저 자신의 춤, 베스트샷에서 자연히 나옴
- **라이브 AR 제거, 탈은 기념 사진에만 (2026-07-24 확정)**: 라이브 체험에 AR 탈 착용을 두지 않음. 배역 탈은 기념 사진 생성 단계에서만 합성함. 이로써 "AR 얼굴(근거리 구도) + 전신 채점(원거리 구도) 동시성" 개발 선결 난제가 해소됨(라이브는 전신 포즈 단일 구도)
- **저스트 댄스형 레이아웃 (2026-07-24 확정)**: 화면 중앙에 가이드 코치(전신), 그 아래 다음 동작 픽토그램. 유저 셀피는 표시하지 않고 카메라는 채점과 베스트샷 캡처 입력 전용. 1인 플레이 가정
- **미러 규약 (거울 방식, 2026-07-24 확정)**: 코치를 좌우 반전해 유저가 보이는 대로 따라 하게 함. 카메라 피드(셀피용), 코치, 채점 기준 스켈레톤을 한 미러 프레임으로 일관되게 두고 엄격 채점(좌우 관용 없음). 반전은 표시 규약이라 고증 자문 사안이 아님
- **AR은 RFP 요건 아님 (2026-07-24 확인)**: RFP(`03_References/_locked/rfp_제안요청서.md`)는 AI 기반 4D 콘텐츠와 교육/체험을 요구하고 "AR/증강현실"을 특정하지 않음. "AR"은 우리 설계 프레이밍(L3)이라 조정 가능. 지켜야 할 기둥은 AI, 4D, 교육/체험
- **용어 (2026-07-24)**: 카메라 입력=카메라 피드, 화면 표시=셀피 프리뷰(현재 설계는 미표시). "AR 카메라 뷰" 폐기

# 3. 새 세션 흐름 (7 Step → 6 Step)

기존 흐름과 새 흐름을 나란히 둠. 삭제는 3D 변환과 기념 촬영, 통합은 촬영이 핵심 체험 안으로 들어감.

| 새 Step | 내용 | 기존 대응 |
|---|---|---|
| Step 1 인트로 | 시작(언어 선택), 가이드, 이용 동의 | 기존 Step 1 유지 |
| Step 2 탈 선택 | 프리셋 배역 탈에서 하나 선택 → 확정. 그 배역의 3D 탈 에셋과 동작 세트를 세션에 로드 | 기존 Step 2 탈 디자인을 대체 |
| Step 3 배역 동작 따라하기 (핵심) | 가이드 코치 따라 하기(B1, 거울 방식), 포즈 매칭과 장단 타이밍 채점, 신명 게이지. 체험 중 베스트샷 자동 캡처. 탈은 라이브에 안 씌우고 기념 사진에만 합성. 말뚝이 재담 연출 | 기존 Step 4를 대체, 촬영을 흡수 |
| Step 4 기념 사진 생성과 대기 (병행) | 선별 베스트샷 4컷에 배역 탈 고품질 재합성 + 프레임 + 등급 스탬프 + 출력 가드레일 + 호스팅 | 기존 Step 5 생성을 대체, 촬영 화면 삭제 |
| Step 5 결과물 감상 | 기념 사진(통과분 최대 4장) 감상 | 기존 Step 6 |
| Step 6 종료와 리셋 | 완주/비완주, QR 다운로드, 파기, 리셋 | 기존 Step 7 |

**삭제됨**: 기존 Step 3(3D 변환과 대기), 기존 Step 5의 별도 기념 촬영 화면.

# 4. 삭제, 변경, 유지 대상 (기획서 절 단위)

수정할 때 놓치지 않도록 절 단위로 추적함.

## 4.1 삭제

- **탈 디자인 도구** 일체(기존 4.2.1 도구, 드로잉, 오방색 팔레트, 문양 스탬프)
- **입력 도안 가드레일**(기존 4.2.2, 3.5.2 4항, 3.8 런타임 입력 검사): 유저 생성 이미지가 사라져 입력 검사가 불필요
- **3D 변환**(기존 4.3 전체, 3D 탈 모델 데이터, 3D 출력 가드레일)
- **기념 촬영 화면**(기존 4.5.1): 촬영 카운트다운, 컷 간 포즈 전환 간격
- 관련 운영 파라미터: 창작 화면 타임아웃, 3D 변환 타임아웃, 입력 도안 가드레일 위반 한도, 촬영 카운트다운과 컷 간격

## 4.2 변경

- **개요(1)**: 목표 경험, 핵심 메커닉, 산출물을 선택/배역 동작/베스트샷 기준으로 다시 씀. "자기가 디자인한 탈", "자기만의" 문구 제거
- **세션 데이터(3.1)**: 탈 디자인(2D), 3D 탈 모델 행 삭제. 대신 선택 배역 항목 추가. 기념 사진 행을 베스트샷 선별본 기준으로. 영상 피드에서 별도 기념 촬영 입력 제거
- **말뚝이 호스트(3.4)**: 진행 범위를 탈 선택→배역 동작→베스트샷으로. 배역 성격과 풍자 맥락을 재담으로 얹는 연출 기능 명시(B2 정수의 우회 흡수)
- **AI 가드레일(3.8)**: 사전 자산 검수 + 기념 사진(베스트샷) 출력 검사만 남김. 입력 도안, 3D 모델 검사 삭제
- **탈과 춤사위 고증(3.11)**: 탈은 프리셋 배역 탈, 춤사위는 배역별 상징 동작 세트로 매핑(B1). 소재는 변환본 `03_References/converted/남사당놀이/남사당놀이 - 덧뵈기.md`
- **각종 참조**: 화면 타임아웃(3.6), 터치 미입력(3.7), 진행 중 종료(3.5) 적용 화면 목록, 실패 처리(3.10), 에러 케이스(5.2), 운영 파라미터(5.1)에서 삭제 항목 반영과 Step 번호 재정렬

## 4.3 유지 (구조와 스키마)

- 정본 스키마(세션 진행 H1, Step H2, 진행 단위 H3, 진행과 엔진 H4, 엔진 명세 H5)는 그대로 지킴. 콘텐츠만 바뀌고 문서 골격은 유지함([[콘텐츠 기획서 작성 양식]] 모델, [[반복 결함 카탈로그]] STRUCT-010)
- 언어 선택(3.3), 진행 중 종료 일반 규칙(3.5), 외부 서비스 호출 래퍼(3.9), 실패 처리 갈래(3.10) 골격은 유지하되 삭제 항목만 반영
- 결과물 전달(QR, 48시간 다운로드), 개인정보 최소 보관 원칙은 유지

# 5. 결정 근거 (2026-07-24 조사)

- **타당성**: 덧뵈기는 춤이 적고 재담과 마임이 중심이라 "탈마다 고유한 춤"은 덧뵈기 고증만으로 성립하지 않음. 다만 한국 탈춤 전체가 "춤대사"(움직임으로 인물 성격을 말함) 전통을 가지고, 산대계 자매 전통(봉산탈춤 등)에 배역별 상징 동작(취발이 깨끼춤, 말뚝이 두어춤, 미얄 궁둥이춤, 먹중 뭇동춤)이 뚜렷함. 덧뵈기도 취발이/먹중/말뚝이/샌님을 공유하므로 배역-동작 매핑을 고증 자문으로 세우면 문화적으로 성립함
- **가능성**: BlazePose로 한국 전통무용 동작을 실시간 인식하는 연구가 동작 인식률 92.6%로 나와 있어 포즈 매칭 채점은 검증된 문제임. 기준 동작은 국가유산청 공식 기록영상(2000년 남사당놀이보존회 실연)으로 확보 가능. 덧뵈기 춤이 팔 중심이라 단일 카메라 스켈레톤에 유리함
- **동시성 리스크 해소 (2026-07-24)**: 앞서 유일한 실측 리스크였던 "AR 탈 얼굴(근거리) + 전신 포즈 채점(원거리) 동시 성립"은, 라이브 AR을 없애고 탈을 기념 사진 생성에만 합성하기로 해 사라짐. 라이브는 전신 포즈 단일 구도만 씀. 남는 검증은 표준 포즈 채점 정확도와 베스트샷(원본 프레임) 사진 품질임([[덧뵈기 - 나만의 탈춤 기획서#4.3.1 클라이언트: 배역 동작 체험 화면]] (4) 기술 요건)
- 조사 출처: 한국민속대백과사전 남사당덧뵈기춤, 위키백과 덧뵈기와 탈춤, 위키문헌 한국 가면극의 무용과 음악, Applied Sciences 2025(BlazePose 한국 전통무용), 무형유산 디지털 아카이브

# 6. 미결과 확인 필요

- **베스트샷 탈 합성 (해소 2026-07-24)**: 라이브 AR을 없애 라이브에는 탈이 없으므로, 기념 사진 생성 단계에서 배역 탈을 고품질로 합성함(프레임/스탬프만 얹는 안은 폐기). 합성 품질 목표값만 개발 단계 확정
- **프리셋 탈 종수**: 변환본 기준 탈 10종(샌님, 노친네, 취발이, 말뚝이, 먹중, 옴중, 피조리 甲乙, 꺽쇠, 장쇠) 중 실제 제공할 배역 수와 각 배역의 동작 세트 범위. 고증 자문 연계
- **배역별 동작 세트**: 덧뵈기 3종(나비춤, 닭이똥 사위, 피조리춤)을 코어로, 배역 특색은 산대계 배역 동작 차용. 고증 자문으로 확정(기획서 3.11 채울 칸)
- **채점 튜닝값**: 자세 일치도 임계, 자세 대 타이밍 가중치, 게이지 임계, 난이도 곡선은 개발 단계 실측으로 확정(정량 미정 유지)
