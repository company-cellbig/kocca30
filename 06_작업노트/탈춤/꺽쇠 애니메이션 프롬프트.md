# 5. 프롬프트 작성 규칙

다른 배역(말뚝이, 취발이)으로 넘어갈 때 그대로 적용함.

- 동작 지시를 앞에, 제약을 마지막 한 문단에 둠. 제약을 앞에 깔면 모델이 몸을 사려 동작이 작아짐
- 동작마다 **방향과 높이**를 못 박음. 안 적으면 매번 다르게 나오고 판정 레퍼런스를 만들 때 갈림
- 옷의 특정 부위는 "그대로 유지"만 쓰고 움직임을 붙이지 않음. 언급한 부위가 주인공이 됨
- 금지는 구체적으로 씀. "방정맞지 않게"가 아니라 "뛰지 않는다, 무릎을 굽히지 않는다"
- 2D 정면 캐릭터라 카메라 쪽으로 뻗는 동작은 원근이 안 생김. 화면과 나란한 방향으로 각색함
- 모든 클립은 시작 자세로 돌아와 마지막 1초를 정지로 끝냄

# 6. 재생 규칙

- 클립은 **반전하지 않은 원본**으로 보관함. 시범 클립의 좌우 반전은 재생 시점에 처리함(HTML은 `transform: scaleX(-1)`, Unity는 스케일 X를 -1로)
- 판정 레퍼런스도 반전 전 원본에서 뽑음
