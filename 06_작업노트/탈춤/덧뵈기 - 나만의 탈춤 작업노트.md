# 1. 개발 선결 미결

주관 기관 Qlab 「댄스 마스터」(qlab.co.kr/page/prd01.php, 외부 참고 L4) 사례를 4.3.1 배역 동작 채점에 반영(2026-07-23, `review`)하면서 열어 둔 결정 대기 항목임. 기획서 본문([[덧뵈기 - 나만의 탈춤 기획서#4.3.1 클라이언트: 배역 동작 체험 화면]] (4) 기술 요건)에 조건으로 남아 있고, 아래로 추적함.

- **엔진 재사용 여부 (사용자와 Qlab 결정)**: 「댄스 마스터」의 스켈레톤 실시간 비교 엔진을 재사용하거나 라이선스할지, 접근만 참고해 자체 구현할지가 개발 규모를 가름. 기획서는 양쪽 병기로 열어 둠([[덧뵈기 - 나만의 탈춤 기획서#4.3.1 클라이언트: 배역 동작 체험 화면]] (4) 모델 확보 항목)
	- 결정 입력: Qlab 자산 제공 조건, 라이선스 비용, 우리 요건과의 격차
	- 후속: 재사용 확정 시 채점 방법 서술을 그 엔진 방식에 맞춤. 자체 구현 확정 시 사전학습 포즈 모델과 SDK 후보 조사
- **AR 얼굴과 전신 포즈 동시성 검증 (해소, 2026-07-24)**: 라이브 AR 탈 착용을 없애고 탈을 기념 사진 생성에만 합성하기로 확정해, 근거리 얼굴 구도와 원거리 전신 구도의 동시 성립 난제가 사라짐. 라이브는 전신 포즈 단일 구도만 씀. 남는 검증은 표준 포즈 채점 정확도이며 위 엔진 재사용 결정과 함께 진행함
