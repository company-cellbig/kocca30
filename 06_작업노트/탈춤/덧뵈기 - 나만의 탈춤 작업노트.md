# 9. "큐" → "동작 신호" 용어 변경의 자매 문서 잔여 (2026-08-10)

기획서에서 "큐"(무대 큐 사인 뜻)를 "동작 신호"로 전수 변경함(3.3.0). 기획서 반영을 먼저 끝내라는 사용자 결정에 따라, 자매 문서의 옛 표기 정비는 뒤로 미뤘음.

- **변경 사유**: 시범콘텐츠 5종 안에서 "큐"가 대기열(queue) 뜻으로 이미 쓰여 오독이 실제로 생김([[시범콘텐츠 공통 사양]] 97행 지속(durable) 큐, [[살판 - 발장단 한 판 기획서]] 243행 등 로컬 큐, [[덜미 - 나만의 꼭두각시 기획서]] 376행 작업 큐). 특히 "동작 큐"는 "동작을 위한 신호"와 "동작들의 대기열" 양쪽으로 읽혀 구현자가 오해할 소지가 큼
- **확정 대응표**: 옛 표기와 새 표기의 짝임

| 옛 표기 | 새 표기 |
|---|---|
| 동작 큐 | 동작 신호 (둘째 등장부터 "신호"로 줄임) |
| 큐 판정 | 동작 판정 |
| 큐 이벤트 | 동작 신호 이벤트 |
| 큐별 | 신호별 |
| 폐쇄형 큐 원칙 | 지정 동작 판정 원칙 |
| 큐 성공 | 동작 성공 |
| 큐 시퀀스 | 신호 시퀀스 |
| 연속 큐, 연타 큐 | 연속 신호, 연타 신호 |
| 수업 큐, 장면 큐, 장단 큐 | 수업 신호, 장면 신호, 장단 신호 |

# 10. 대사 대행 폐지와 화자 배정 확정 (2026-08-10, 기획서 3.4.0)

"대사 대행"을 별도 항목으로 두던 것을 폐지하고 3.4.2 「화자 배정」 규칙으로 흡수함. 사용자 질의("왜 굳이 대사 대행이라는 시스템을 추가했나, 공용 보이스면 되지 않나")에서 출발한 정비임.

- **폐지 근거**: 이 항목에는 메커니즘이 없었음. 새 상태, 입출력, 실패 모드를 하나도 더하지 않고 전부 기존 장쇠 발화 경로를 씀. 문서 자신도 그렇게 취급하고 있었음(3.4.2 대사 적용의 레퍼토리 열거와 3.4.3 리소스의 대사 목록에 대사 대행이 빠져 있었고, 정작 4.3.2 리소스에는 "대사 대행 문안"이 있어 소유 위치가 어긋남)
- **화자 배정 확정 (사용자 결정)**: 장쇠 보이스 1종이 유저 배역 대사까지 읽음. 괄호에 숨어 있던 "배역 전용 보이스, 잠정" 분기는 폐기함. 근거는 자매 5종의 호스트 보이스 1종 원칙([[덜미 - 나만의 유람기 기획서]]의 박첨지 1종이 호스트 대사와 낭독을 겸함), 리액션 클립을 리소스 부담으로 제외한 3.2.0 결정과의 일관성, 대거리 턴 교환은 상대 배역 보이스가 이미 갈라 준다는 점
- **대잡이 동형 근거 제거**: "덜미 대잡이가 인형 목소리를 대신 내는 전통 구조와 동형"은 종목을 건너뛴 유비라 고증 근거가 아니라 각색 사유임. 3.10.3이 동작 세트에 "근거 없으면 각색임을 병기" 기준을 적용하는 것과 어긋나 본문에서 뺌. 결정 경위는 [[덧뵈기 가면극 재규정 검토]] 151행과 log에 이력으로 남아 있음
- **함께 메운 공백**: 상대 배역 TTS 보이스 3종이 어느 리소스 목록에도 없었음(3.3 현지화 범위는 상대 배역 TTS를 규정하고 4.3.2 대본에는 샌님 호통이 들어 있는데도). 4.3.2 필요 리소스에 한 줄, 실패와 복구에 음성 실패 경로 한 줄, 5.2 에러 케이스 표의 대상 확장으로 닫음
- **범위 밖으로 미룬 잔여**
	- 상대 배역 발화의 시스템 명세: 발화 여부, 스킵과 타임아웃 연동, 화면 상태 모델 연동이 문서에 없음. 절 신설 규모라 별건으로 둠
	- 상대 배역 보이스 3종의 실제 확보 방식: 예산과 발주 사안이라 "확보 필요" 표기까지만 함. 축소 대안(전부 장쇠 1보이스로 처리)도 열려 있음
