> [완료] 자매 기획서 6종의 역할과 목적 절 90개를 CONTENT-004 기준으로 전수 점검함(2026-08-05, 사용자 지시로 착수). 위반 20건 정정(+ 마당 가드레일 역할 절의 의미 stale 1건), 경계 14건은 판정 유보로 존치. 정정문은 맥락 독립 검토를 거쳐 6건 추가 정정함. 상세는 log 2026-08-05 항목 참조.

# 1. 배경

2026-08-04 [[덧뵈기 - 나만의 탈춤 기획서]]에서 베스트샷 자동 선별의 역할과 목적이 동작 요약 재서술인 것을 사용자가 지적함. 같은 결함류를 그 문서의 역할과 목적 16개 절에서 전수 점검해 7절을 정정함(log 2026-08-04 「탈춤 역할과 목적 절 전수 정정」). 재발 원인은 검수가 편집한 절만 보고 기존 절을 스코프에 넣지 않은 것임. 자매 기획서는 이때 점검하지 않았고, 사용자가 추후 진행으로 확정함.

# 2. 대상과 기준

- **대상 문서 6종**: [[덜미 - 나만의 유람기 기획서]], [[덜미 - 나만의 꼭두각시 기획서]], [[버나 - 버나잡이 한 판 기획서]], [[덧뵈기 - 양반 놀리기 4컷 기획서]], 덧뵈기 - 양반 놀리기 마당 기획서(점검 후 2026-08-05 문서 삭제, 링크 해제), [[살판 - 발장단 한 판 기획서]]
- **점검 기준** ([[반복 결함 카탈로그]] CONTENT-004, [[콘텐츠 기획서 작성 양식]]): 각 역할과 목적 절이
	- 2문장 내외(첫 문장 역할, 둘째 문장 목적)인가
	- 다른 절이 소유한 동작/절차/범위의 재서술이 없는가
	- 앞 문장이 이미 함의한 경계 단서("~만 맡음", "~하지 않음" 류 사족)가 없는가
	- 동어반복과 비문이 없는가
- **절차**: 문서별로 역할과 목적 절 전체를 grep으로 모아 일괄 판정 → 정정 → 정정문 맥락 독립 검토 1회 → G1 보고. 탈춤 정정분(커밋 `7bb6897`)을 기준 예시로 삼음
