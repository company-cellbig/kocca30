> [[시범콘텐츠 공통 사양#2. 세션]]나에 세션 데이터 분류 값 3종 정본을 세운(2026-07-08) 뒤 남은 **개별 기획서 마이그레이션 백로그**. 유람기와 양반 놀리기 4컷은 정정 완료, 꼭두각시와 탈춤과 버나 3종은 정본에 없는 분류 값을 쓰는 상태임. 각 기획서 검수 사이클에서 처리함.

# 1. 정본 (적용 기준)

[[시범콘텐츠 공통 사양#2.2 세션 저장 데이터 (공통 항목)]]이 정본임. 분류 열은 아래 3종만 씀.

| 분류 값 | 정의 |
|---|---|
| 시스템 | 세션 운영과 관측에 쓰는 관리 데이터. 콘텐츠 내용이 아님 |
| 콘텐츠 입력 | 유저가 직접 넣거나 고른 값, 유저를 촬영하거나 측정해 받은 값 |
| 콘텐츠 생성 | 시스템이 콘텐츠 내용으로 만들어 낸 값 |

부칙 3건을 함께 적용함.

- **결과물은 콘텐츠 생성**: 유저 입력을 재료로 써도 시스템 산출물이라 입력이 아님
- **한 행은 한 분류만**: 유저 선택과 시스템 배정이 한 값에 섞이면 행을 나눔
- **개인정보는 분류 값이 아님**: 분류와 별개 기준이라 표 비고와 각 기획서의 개인정보 처리 절에 적음

# 2. 대상 문서와 정정 항목

# 3. 함께 볼 것

- **stale 문장**: 꼭두각시 기획서 `:388`, 탈춤 기획서 `:67`의 "분류는 콘텐츠지만 ..." 서술이 3분류에 없는 값을 가리킴. 표 정정과 함께 갱신함
- **기념 사진의 개인정보 표기 소실 주의**: 꼭두각시와 탈춤의 기념 사진은 유저 얼굴을 담음. 분류를 `콘텐츠 생성`으로 옮길 때 개인정보 표기가 사라지지 않도록 비고와 개인정보 처리 절에 반드시 남김
- **표 앞 길잡이 문장 점검**: 분류 값에서 개인정보 여부를 도출하는 문장(예: "콘텐츠 입력은 개인정보가 아님")이 있으면 실제 근거(카메라 사용 여부, 연락처 수집 여부)로 바꿈. 유람기와 양반 놀리기에서 같은 결함을 정정함
- **유저 응답 중복 저장**: 유람기와 양반 놀리기는 응답 행과 대화 로그 행의 중복을 단일 행으로 통합함(2026-07-08). 다른 콘텐츠에 같은 구조가 생기면 같은 방식으로 통합함

# 4. 함께 정리할 다른 결함 (2026-07-08 추가)

세션 데이터 표를 열 때 같이 볼 것. 유람기와 양반 놀리기는 정정 완료임.

- **근거 없는 보관 기간**: 동의 기록 5년은 작성자가 통상치로 지어낸 값이었음(`git log -S`로 확인, 2026-06-26 커밋 d75d91f). 유람기와 양반 놀리기는 "기간 미정, 규정 검토 후 확정"으로 되돌림. 다른 3종 표에 같은 값이 있으면 함께 정정함. 대화 로그 14일과 결과물 호스팅 30일도 출처가 없어 규정 검토 대상임
- **사전 가드레일 검수 서술**: 사전 배치 플롯은 사람이 검수해 확정하므로 자동 가드레일 검수와 재생성 한도, 폐기 루프는 실체가 없음(작성자 추정이었음). 유람기는 사람 검수로 정정하고 [[덜미 - 나만의 유람기 기획서#3.9 AI 가드레일]]의 적용 지점에서 사전 항목을 제거함. [[덧뵈기 - 양반 놀리기 4컷 기획서#3.13 풍자 플롯 생성 LLM]]과 운영 파라미터 표의 "AI 가드레일 재생성 한도 3회 (사전)"에 같은 서술이 남아 있음
- **동의 약관의 성격**: 개인정보를 수집하지 않는 콘텐츠(유람기, 양반 놀리기, 버나)의 동의는 개인정보 수집 동의가 아니라 AI 생성물 책임 범위 등 이용 조건 동의임(사용자 확정). 약관 항목은 규정 검토에서 확정하며 가드레일 소관이 아님
