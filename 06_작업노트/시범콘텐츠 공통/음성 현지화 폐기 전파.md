> 언어별 AI 음성 생성이 무리라 **글자만 현지화하고 음성은 한국어로 고정**하기로 함(2026-08-12 사용자 결정, 시범콘텐츠 5종 전체). 탈춤 기획서에는 반영했고, 공통 사양과 나머지 4종 기획서 전파는 **사용자 지시로 보류 중**임. 착수 시점은 사용자가 정함.

# 1. 결정

- **적용 범위**: 시범콘텐츠 5종 전체
- **바뀌는 것**: 현지화 대상은 UI 카피, 자막, 안내 문구 등 글자뿐임. 음성은 세션 언어와 상관없이 한국어로 재생하고, 비한국어 세션은 한국어 음성에 현재 언어 자막을 얹음
- **사유**: 언어별 음성 확보와 합성이 1차연도 범위를 넘음

# 2. 반영 완료

- [[덧뵈기 - 나만의 탈춤 기획서]]: 3.3.1 역할과 목적, 3.3.3 현지화 범위(「음성 제외」 신설), 3.5.2 발화 방식. 프로토타입은 `u.lang="ko-KR"` 고정이라 손댈 것 없었음

# 3. 남은 작업

- **정본 수정**: [[시범콘텐츠 공통 사양]] 1.2가 "현지화 범위는 UI 카피뿐 아니라 AI 생성물(서사, 음성 등)까지"라 새 결정과 어긋남. 이 문장이 5종 공통 정본이라 여기부터 고쳐야 함
- **자매 기획서 4종 전파**: 덜미 - 나만의 유람기, 덧뵈기 - 양반 놀리기 4컷, 덜미 나만의 꼭두각시, 버나 콘텐츠. 각 기획서의 현지화 범위 절과 음성 관련 서술, 리소스의 "지원 언어별 확보" 문구를 훑음
- **점검 키워드**: `현지화`, `언어별`, `지원 언어`, `TTS`, `음성`
- **주의**: 현지화 데이터 파일(`05_클라이언트 데이터/공통/localization.json`)은 사용자가 직접 관리함. 에이전트가 자동 반영하지 않음
