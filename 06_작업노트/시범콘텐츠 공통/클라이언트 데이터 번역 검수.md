# 1. 검수 범위와 기준

- **대상**: `05_클라이언트 데이터/공통/localization.json`(UI 텍스트), `05_클라이언트 데이터/유람기/character_name_pool.json`(이름 풀)
- **방향**: 한국어(`ko`) 원문 기준 영어(`en`) 검수
- **기준**: 의미 일치(오역/누락/드리프트), 용어 일관성, 표기 규범(대소문자, 문장 부호, 공백), UI 적합성
- **반영 규칙**: 아래 제안 en은 초안임. 사용자가 항목별 승인한 것만 JSON에 반영. 반영 후 `_meta` 없는 평면 맵 구조 유지

# 4. 표기 일관성 (정책 결정 필요)

개별 오류가 아니라 파일 전체에 걸친 스타일 불일치. 아래 각 절에 사용자 결정 반영(2026-07-22).

## 4.1 문장 Title Case

- **현상**: 완결 문장까지 모든 어절을 대문자로 시작함. 예: `1_2_inactivity_timeout_desc`(`localization.json:44`) "Please Touch The Screen To Continue. This Session Will End If There Is No Input."
- **문제**: 영어에서 문장은 문장 케이스(첫 글자만 대문자)가 표준. 버튼/짧은 명사 라벨과 달리 서술문의 전면 Title Case는 어색함
- **결정(2026-07-22)**: 서술문을 문장 케이스로 전환. 사용자가 직접 수정하며 아래 키 목록을 제공함
- **전환 규칙**: 문장 첫 글자만 대문자. 고유명사는 대문자 유지(Park Cheomji, Malttugi, Deolmi, Deotboegi, Pungmul, AI, QR, E-Book)와 대명사 "I". 기존 공백은 유지(줄바꿈 의도, [[#4.2 이중 공백]])
- **전환 대상 (완결 서술문, 48키. 신규 9키는 2026-08-06 탈춤 재편 반영으로 추가, [[#8. 신규 키 검수 (2026-08-06, 탈춤 재설계 반영분)]])**:
	- guide (8): `3_2_guide_0`~`3_2_guide_3`, `5_2_guide_0`~`5_2_guide_3`
	- dialogue (13): `3_2_dialogue`, `3_3_dialogue`, `3_6_dialogue`, `3_8_dialogue`, `3_10_dialogue`, `5_2_dialogue`, `5_3_dialogue`, `5_4_dialogue`, `5_6_dialogue_0`~`5_6_dialogue_4` (`5_5_dialogue`는 [[#2. 치명 결함: en 플레이스홀더 오류 (7건)]] 정정 시 문장 케이스로 입력했고, 2026-08-06 탈춤 재편으로 키 자체가 삭제됨)
	- role desc (3): `5_0_role_0_desc`~`5_0_role_2_desc`
	- desc (20): `1_2_inactivity_timeout_desc`, `1_2_screen_timeout_desc`, `3_1_desc`, `3_10_desc`, `5_1_desc`, `13_1_desc`, `13_2_desc`, `14_1_desc`, `14_2_desc`, `14_3_desc`, `14_4_desc`, `14_7_desc`, `14_8_desc`, `14_9_desc`, `14_10_desc`, `14_11_desc`, `14_12_desc`, `14_13_desc`, `14_14_desc`, `14_15_desc`
	- placehold (2): `3_6_placehold`, `3_7_placehold`
	- 기타 문장 (2): `1_2_timeout_quit`, `1_2_inactivity_timeout_title`("No Input Detected." 문장형)
- **경계 (제목이나 문장형, 사용자 판단)**: 팝업 제목이 절/질문 형태라 전환/유지는 스타일 결정에 맡김

- **유지 (버튼/짧은 명사 라벨)**: 버튼 `1_1_*`, 서식 `1_2_percentage`/`1_2_min_max`, 명사형 제목과 부제(`3_1_subtitle`, `5_1_subtitle`, `3_2_title`, `3_3_title`, `3_5_title`, `3_7_title`, `3_8_title`, `3_10_title`, `5_2_title`~`5_10_title`), 라벨(`3_4_plot_*`, `3_5_card_*`, `3_7_phase_*`, `3_3_terms`/`5_3_terms`)

## 4.2 이중 공백

- **현상**: ko와 en 곳곳에 어절 사이 공백 2칸. en 예 `localization.json:44`("Continue.  This"), `192`("Code  To"). ko 예 `:75`, `:79` 등
- **결정(2026-07-22)**: 줄바꿈(개행) 의도로 넣은 공백임. 오류 아님, 유지. 문장 케이스 전환 시에도 공백은 건드리지 않음

## 4.3 아포스트로피 혼용

- 곱슬(`’`)과 곧은(`'`)이 섞임. 예: 곱슬 `3_2_guide_1`(`:80` Cheomji’s), 곧은 `3_10_dialogue`(`:188` Let's)
- **제안**: 하나로 통일. 폰트 렌더링 확인해 곧은(`'`) 권장(키오스크 폰트 호환 안전)

# 7. 이름 풀 검수 (character_name_pool.json)

- **성격**: en이 로마자 음역이 아니라 **뜻을 살린 창작 영문명**임. 예: 김두리→Merry Rowan, 한재담→Tale Weaver, 진바우→Rocky Flint
- **결정(2026-07-22)**: 영어권 사용자용 창작 영문명이 의도임. 로마자 음역으로 재작성하지 않음
- **잔여(선택, 사용자 판단)**:
	- 중복 어휘: `Reed`가 장버들(`:27` Willow Reed)과 류가람(`:71` River Reed) 둘에 쓰임. 랜덤 노출 시 겹칠 수 있어 하나 교체 여지
	- 표기 확인: 최한결→True Hart(`:19`). "Hart"는 수사슴 뜻 고어(heart 아님). 의도면 유지

# 8. 신규 키 검수 (2026-08-06, 탈춤 재설계 반영분)

탈춤 재설계 후속으로 들어온 5_x 재편 키와 처음으로 버튼 키(커밋 `1a449ad`)의 en 검수. 사용자 승인(2026-08-06)으로 제안 3건을 반영 완료함. 경미 2건은 확인 대기.

- **정상 확인**
	- `1_1_restart`(`:10`) "BACK TO START"는 버튼 전면 대문자 관례(`1_1_next` "NEXT")와 일치함
	- `5_0_grade_0`~`5_0_grade_3`(`:226`~`:238`) X/OK/GOOD/PERFECT는 탈춤 기획서 판정 등급 표기와 일치함
	- 배역명 로마자(`:202`~`:218` Kkeoksoe, Saennim, Chwibari)는 표준 로마자 표기와 일치함
	- 신규 desc의 이중 공백은 줄바꿈 의도([[#4.2 이중 공백]] 결정)와 일치함
- **명령형 문형 불일치**: `5_2_guide_0`(`:258`) "Please Select The Mask..."만 Please가 붙고, `5_2_guide_1`(`:262`) "Follow The Movements..."는 명령형임. **반영 완료(2026-08-06)**: Please를 빼고 "Select The Mask For The Role You Will Play."로 통일
- **전통 감탄사 처리 불일치**: `5_6_dialogue_4`(`:314`)는 "얼쑤!"를 "Hurray!"로 번역했는데, `5_6_dialogue_3`(`:310`)는 "덩실덩실"을 "Deongsil-Deongsil!"로 음역함. **반영 완료(2026-08-06)**: "Eolssu!" 음역으로 통일
- **문장 케이스 전환 대상 추가**: 신규 서술문 키가 기존 전면 Title Case 스타일로 들어옴. **반영 완료(2026-08-06)**: `5_0_role_0_desc`~`5_0_role_2_desc`(`:206`~`:222`), `5_4_dialogue`(`:290`), `5_6_dialogue_0`~`5_6_dialogue_4`(`:298`~`:314`)를 [[#4.1 문장 Title Case]] 전환 대상 목록에 등재함(`5_2_guide_0`~`5_2_guide_1`은 기존 목록에 이미 포함). 문장 케이스 전환 자체는 4.1 결정대로 사용자가 직접 수행함
- **경미 (확인 권장)**
	- `5_0_role_2_desc`(`:222`): "먹중"을 "The Troublemaker Monk"로 의역함. 전통 배역명 보존이 필요하면 "Meokjung" 음역 병기 검토
	- `5_6_dialogue_1`(`:302`): ko "괜찮네"(다독임)보다 en "That's Good."이 칭찬 쪽으로 강함. 등급 톤을 살리려면 다른 표현 검토(`5_6_dialogue_3` "Not Bad At All"과 겹치지 않게)

# 9. 미해결 / 확인 필요

- **키 번호 공백**: `3_9`, `14_5`, `14_6` 등 결번. **결정(2026-07-22)**: 의도적 결번(누락 아님)
