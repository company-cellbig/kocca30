> 결과물 전달을 SMS(전화번호) → 화면 QR + 스캔 다운로드로 바꾼 공유 정본 개정(2026-07-07)의 **개별 문서 후속 동기화 백로그**. 공유 정본 5개는 개정 완료, 개별 기획서 5 + UI 5(총 10개)의 하드코딩 서술은 아직 SMS/휴대폰 번호 상태라 동기화 필요.

> [완료] 2026-07-07 개별 문서 10개 동기화 완료(lint 0, 금지 패턴 0). 본 문서는 이력 기록으로 보존함. 아래 [[#2. 전환 규칙 (개별 문서 적용 기준)]]과 [[#3. 대상 문서와 하드코딩 지점]] 표는 실제 적용된 내용이며, 재발이나 신규 콘텐츠 시 참고용으로 남김.

# 1. 배경

공유 정본(시범콘텐츠 공통 사양, 플랫폼 사양, 디바이스 사양, 공통 UI 컴포넌트, 콘텐츠 기획서 작성 양식)은 QR 모델로 개정 완료함([[시범콘텐츠 공통 사양#5.4 결과물 감상과 받기]], [[플랫폼 사양#4. 결과물 전송과 호스팅]]). 임베드 블록(`^step-common-funcs`, `^common-params`, `^step-def`)은 개별 기획서에 자동 전파되나, 각 문서가 **본문에 직접 하드코딩한 SMS/휴대폰 번호/연락처 입력 서술은 스테일로 남음**. 사용자 지시로 이번엔 개별 문서 미수정, 별도 후속 사이클로 처리.

# 2. 전환 규칙 (개별 문서 적용 기준)

- **세션 데이터 표**: "휴대폰 번호 | 개인정보 | 유저 연락처(SMS 발송용) | 발송 후 즉시 파기" 행 삭제. 결과물 행의 파기를 "다운로드 만료 시 파기"로 정합
- **Step 6 결과물 전송 흐름**: "외부 서비스(SMS): 연락처 임시 저장 → 링크 발송 → 즉시 파기" → "백엔드: 결과물 호스팅 + 만료형 다운로드 URL 발급 → UI: 화면에 QR 표시 → 유저가 본인 휴대폰으로 스캔해 다운로드". 연락처 입력, 전송 동의/받지 않기 분기, 수신처 영구 실패 재입력 제거
- **개인정보 절**: 개인정보 범위에서 "휴대폰 번호" 제거. 전송 동의 항목 제거. 남는 개인정보는 콘텐츠 고유(얼굴, 영상 등)뿐
- **전송 수단별 파기표**: SMS 발송 성공/전송 거부/영구 실패/타임아웃 상태 구분 → QR 다운로드 단일 경로(결과 페이지 다운로드 만료 파기)로 단순화
- **UI 문서**: 전송 화면(전화번호 입력 필드, 숫자 키패드, 전송/받지 않기, 개인정보 고지) → 결과물 QR 화면(QR 코드 + 스캔 안내 + 다운로드 기간, 마침 버튼). UI 문서의 전송 프롬프트 복제분을 QR 프롬프트로 교체(정본은 [[시범콘텐츠 공통 사양#12. 공용 화면 예시 이미지]])
- **헤딩 리네이밍(선택)**: 개별 문서 동기화 시 "결과물 전송" 헤딩을 QR 성격에 맞게 함께 검토 가능(이번엔 anchor 안정성 위해 공유 정본 헤딩 유지)

# 4. 검증

- 동기화 후 `node scripts/wiki_lint.mjs` 0건
- `grep "SMS\|휴대폰 번호\|전화번호"` 전 저장소 0건(2차연도 학습 토큰 QR 스캔은 별개라 잔류 정상)
- 각 문서 Step 6과 UI 전송 화면이 QR 모델로 일관되는지 자매 문서 대조

# 5. 후속 백로그: 감상과 받기 화면 통합 (2026-07-08 추가)

[[덜미 - 나만의 유람기 기획서]]는 결과물 감상 화면과 결과물 QR 화면을 한 화면으로 합쳐 Step을 7개에서 6개로 줄임. 호스팅과 다운로드 URL 발급을 Step 4 생성 파이프라인 끝으로 옮겨, 유저가 감상을 마친 뒤에야 호스팅 실패를 만나던 순서를 뒤집음. 두 화면 분리는 SMS 전송 시절 전화번호 입력 단계가 남긴 흔적이었음.

- **적용 완료**: 덜미 나만의 유람기 (참조 구현)
- **미적용 (각 콘텐츠 검수 사이클에서 판단)**: 나만의 꼭두각시, 나만의 탈춤, 양반 놀리기 4컷, 버나잡이 한 판
- **통합 조건**: 결과 감상 화면에 QR을 함께 둘 공간이 있고, 유저가 감상 도중 받아 가도 흐름이 깨지지 않는 콘텐츠. 기념 사진처럼 결과물이 한 장이면 감상 화면 자체가 짧아 통합 이득이 작을 수 있음
- **통합 시 함께 볼 것**: 호스팅을 생성 파이프라인으로 옮기면 상태 머신 `completed`의 뜻이 "호스팅과 URL 발급까지 끝난 상태"로 바뀜. 세션 데이터에 다운로드 URL 행이 필요함. 화면 타임아웃은 감상과 스캔을 겸하므로 늘리고, 재생 중 정지와 조작 시 리셋 규칙을 둠
- **공통 사양**: [[시범콘텐츠 공통 사양#5.4 결과물 감상과 받기]] 전송 공용 화면은 미통합 콘텐츠용으로 유지하며, 적용 범위 문구에 통합 콘텐츠 예외를 명시해 둠
