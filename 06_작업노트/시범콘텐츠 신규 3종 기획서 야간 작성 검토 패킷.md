# 2. 사용자 결정 필요 미결 (G1 우선)

콘셉트에 없거나 콘셉트가 안 밝힌 지점을 합리적 기본값으로 채우고 플래그한 것임. 각 항목의 현재 기본값과 대안을 제시함.

## 2.1 버나 결과물 범위 (매력도 대 콘셉트 충실, 중요)

- **상황**: 콘셉트 §4.나 1) 버나 진행이 마무리에서 끝남. 자매 두 체험(탈춤, 꼭두각시)과 달리 영구 산출물(기념 사진)과 결과물 전송이 없음
- **현재 기본값**: 콘셉트에 충실하게 산출물 없는 5 Step 체험으로 작성함. 개인정보(연락처, 얼굴) 미수집
- **대안(매력도)**: 자매 일관성과 키오스크 기념성을 위해 기념 결과물(한 판 성적표나 리플레이 영상) + SMS 전송 추가. 채택 시 생성/전송/출력 가드레일/연락처 개인정보 처리가 더해짐([[버나 - 버나잡이 한 판 기획서#1. 개요]], [[시범콘텐츠 공통 사양#8. 개인정보와 가드레일 원칙]])
- **결정 요청**: 산출물 없이 둘지, 기념 결과물을 추가할지

## 2.2 버나 가드레일 3지점 정합 (정본 정합, 중요)

- **상황**: 버나는 런타임 AI 생성과 자유 입력이 없음(대거리는 선택지 택1, 재담은 사전 제작). [[시범콘텐츠 공통 사양#8.2 가드레일 적용 3지점]]은 3지점 모두 필수로 규정하나, 버나는 런타임 두 지점(입력/출력)에 검사 대상이 없음
- **현재 처리**: 사전 지점 중심으로 기술하고, 정합 문제를 [[버나 - 버나잡이 한 판 기획서#3.7 AI 가드레일]]와 [[시범콘텐츠 공통 사양#8. 개인정보와 가드레일 원칙]]에 명시
- **결정 요청**: 공통 사양에 "생성 없는 체험형" 예외 표기를 둘지, 아니면 버나 가드레일 기술을 조정할지. 공통 사양 정본 변경이라 사용자 결정 필요

## 2.3 4컷 유저 탈 캐릭터 해석

- **상황**: 콘셉트 §4.다 2) 개요는 "사용자 탈을 쓴 캐릭터"라 하나, 진행에 탈 디자인 단계가 없음(캐릭터 카드 6조합만)
- **현재 기본값**: 별도 탈 디자인이 아니라 캐릭터 정보로 개인화된 배역 탈 양식 캐릭터로 해석([[덧뵈기 - 양반 놀리기 4컷 기획서#4) 유저 탈 캐릭터]]
- **대안**: 별도 탈 디자인 단계 추가([[덧뵈기 - 나만의 탈춤 기획서]]의 탈 디자인 도구 차용). 채택 시 Step과 구성 요소가 늘어남
- **결정 요청**: 현재 해석 유지 여부

## 2.4 4컷 풍자 템플릿 로스터

- **상황**: 콘셉트가 "양반 놀리기 등"만 명시, 1차연도 풍자 템플릿 종류와 수 미정
- **현재 처리**: 양반 놀리기를 대표로 두고 N종 지원 구조로 작성, 로스터는 미결
- **결정 요청**: 1차연도 정의 템플릿 목록

## 2.5 꼭두각시 양손 조작 입력 수단

- **상황**: 콘셉트 "양손 조작"의 구체 입력 수단 미명시
- **현재 기본값**: 멀티터치(화면 양손 조작) 기본. 카메라 핸드 트래킹 병행은 확인 필요([[덜미 - 나만의 꼭두각시 기획서#2) 양손 조작과 장단 채점]])
- **결정 요청**: 입력 수단 확정(하드웨어 요건과 채점 설계를 가름)

## 2.6 공통 확인 필요 (구현/규정 단계)

- **목표 플레이타임**: 3종 모두 콘셉트와 로드맵 원문 미명시라 미기재(임의 추정 금지)
- **데이터 수명 정합**: 생성형 2종(4컷, 유람기 공통)의 콘텐츠 입력 3종 파기 시점이 공통 사양 정본과 미정합("확인 필요" 표기)
- **버나 센서 막대 주변기기**: 센서 종류, 폼팩터, 무선/유선, 내구성, 보정 방식 미정. 핵심 메커닉을 가름
- **모델 확보, 정량 임계**: 3종 모두 AI 모델 후보와 채점/가드레일 정량값은 "확인 필요"로 유보

# 3. 독립 검토 발견 (G2 참고)

## 3.1 즉시 정정 완료 (이미 반영, 확인용)

- **꼭두각시**: TL;DR "AR" 과대 표기 제거(본문에 AR 없음), Step 6 dangling 참조 정리, [[시범콘텐츠 공통 사양#4.3 중단 공통 처리]] 입력 수단 괄호 두 겹 해소
- **4컷**: [[시범콘텐츠 공통 사양#3.3 진행 중 종료]] Step 2 참조를 "§4.가 5) 변주"로 좁힘(정밀도)
- **버나**: 기획서 전체 플로우 절의 "미동의" 복붙 잔재 제거(버나엔 동의 절차 없음), Step 4 괄호 두 겹 해소, [[시범콘텐츠 공통 사양#4.3 중단 공통 처리]] 범위 태그 "Step 2~3"로 정정, 핸드 트래킹↔개인정보 없음 충돌 caveat 추가([[시범콘텐츠 공통 사양#5.3 생성과 변환 대기]], [[시범콘텐츠 공통 사양#8. 개인정보와 가드레일 원칙]])
- **공통**: Step 6 dangling 참조 류를 꼭두각시/4컷 양쪽에서 전수 정정

## 3.2 보류 (저~매우저, 사용자 판단)

- **[구조, 자매 공통] 기획서 세션 진행 절 도입부 "서술형" 자기선언 대 라벨 형식 불일치**: 생성형(4컷, 유람기)의 세션 진행 절 도입부가 진행 호스트를 "서술형으로 적음"이라 선언하나 실제 [[#4. Codex 외부 검토 상태]]바는 엔진과 같은 라벨(역할/동작/자산/의존)로 작성됨. 유람기에서 상속된 불일치. 자매 일관성 때문에 미정정. 유람기와 함께 정비할지 판단 필요
- **[스타일] § 참조 헤더 이름 정밀도**:
	- 꼭두각시/4컷: 자산 참조가 "§4.사 콘텐츠 자산"으로 항목 번호 없음(자매 탈춤은 "§4.사 1/2/3"). 정밀도 낮음
	- 버나: "[[시범콘텐츠 공통 사양#4.3 중단 공통 처리]] 묘기와 재담 채점"이 실제 헤더 "묘기와 재담 채점, 신명 게이지"의 약칭. 자매는 전체명 사용
- **[스타일] 버나 행위자 라벨**: Step 2 "AI 묘기 채점" 대 Step 3 "AI 채점"(범위 차이 반영이나 병렬성 약함)
- **[콘셉트, 저] 4컷 템플릿 선택 단계 추가**: 콘셉트 진행이 사용자 템플릿 선택을 명시 안 하나 기획서가 "풍자 템플릿 선택 화면"을 둠. 콘셉트 개요의 복수 템플릿 전제와 자매 유형 선택 골격으로 방어 가능, [[시범콘텐츠 공통 사양#8. 개인정보와 가드레일 원칙]]에 로스터 미결로 플래그
- **[표기, 매우저] 연령대 라벨**: 기획서 3종이 "아이"(유람기 상속) 사용, 콘셉트는 "유아". 자매 일관성으로 "아이" 유지

# 4. Codex 외부 검토 상태

- **상황**: Codex CLI는 설치돼 있음(v0.129.0). 다만 `/codex:adversarial-review`는 발췌 첨부가 필요한 대화형 흐름이라, 무인 야간 세션에서 강행하지 않음(헤드리스 인증과 승인 프롬프트 위험)
