# 2. 설계 근거 (전통 재창조 취사 기준)

[[덜미 - 나만의 유람기 기획서]] 설계의 근거가 된 전통 재창조 취사 기준임(에이전트 설계 참고). 기획서 §3~4 시스템이 이를 적용하고, 아래 [[#4. 정체성 매핑 (전통 정합 검증)]]이 반영 여부를 추적함. 개발 전 결정(시각 정체성, 가드레일, 4D 미연계)은 기획서 시스템 절(§3 공용 시스템, [[#4. 정체성 매핑 (전통 정합 검증)]] 개별 시스템)에 직접 반영돼 있어 여기 두지 않음.

유저 입력으로 극을 구성할 때 무엇을 가져가고 버릴지의 잣대는 "덜미를 덜미이게 하는 문법(뼈대)인가, 아니면 특정 대본이나 시대나 연행 매체에 묶인 곁가지(우연한 살)인가"임. 뼈대는 가져가고, 곁가지는 버리고, 매체에 묶인 것은 바꿔서 가져감. 그 "바꿔 가져가기"가 곧 재창조임.

**가져갈 것 (덜미의 정체성, 문법)**

- 박첨지: 떠돌이 노인 해설자, 거리를 잇는 목소리. 이 해설자 정체성을 가져감
	- AI 버전에선 유저가 사건 주인공이 되고, 박첨지는 그 여정을 잇는 해설자와 길잡이로 둠 (전통의 "해설자 겸 주역" 중 해설자 기능 계승, 주인공 자리는 유저에게 재배치)
- 재담과 메타연극성: 인형이 무대 밖(산받이, 관객)에 말을 거는 구조. 인터랙티브 콘텐츠와 맞물려 유저가 곧 재담 상대가 됨
- 풍자 정신: 권위, 위선, 허세를 비트는 태도. 특정 대상이 아니라 태도 자체를 가져감
- 홍동지의 응징이 주는 카타르시스: 민중의 힘이 위협과 위선을 처치하는 통쾌함
- 에피소드(거리)식 구성: 느슨하고 빠르고 모듈적. 유저 입력으로 재조합이 가능한 이유가 이 구조
- 골계적 반전: 권위의 갑작스럽고 허망한 추락
- 인형극 시각 양식: 나무 인형, 포장, 과장된 형상. 무엇을 그리든 이 양식으로 렌더링

**버릴 것 (재창조를 막거나 매체와 시대에 묶인 것)**

- 고정된 특정 줄거리: 박첨지의 첩, 평안감사 사건 등 특정 사건. 채록본마다 달라 정전도 아니며, 고정하면 결과물이 대동소이해짐
- 시대적으로 낡은 내용: 처첩 삼각관계를 갈등의 기본값으로 쓰는 것, 여성 인물을 도구적이고 비하적으로 다루는 것
- 연행 규모: 2시간 7거리. 짧은 플레이타임 제약과 맞지 않음
- 현장 즉흥성(라이브 의존): 실연자가 실제 관객을 읽으며 치는 애드리브. AI 콘텐츠에는 실연자가 없음

**바꿔서 가져갈 것 (재창조의 핵심)**

| 전통 요소 | 바꿔서 가져가기 |
|---|---|
| 산받이(재담 상대) | AI나 유저가 산받이 역할을 맡아 재담을 인터랙션으로 전환 |
| 풍자 대상(파계승, 탐관) | 유저 세계에서 생성된 위선과 권위로 교체, 덜미 양식으로 렌더링 |
| 육담과 욕설 | 해학과 말장난 수위로 순화 (교육과 체험 + 유저 생성 맥락) |
| 춤, 장단, 삽입가요 | 정적 매체에서는 삭제 대신 삽화 연출, 의성어, 리듬 있는 텍스트로 치환 |
| 라이브 즉흥성 | 실연자의 즉흥을 AI의 생성 가변성으로 이전 |

요약: 가져갈 것이 "덜미임"을 보장하고, 버릴 것이 결과물의 천편일률을 막으며, 바꿔 가져갈 것이 "재창조"를 완성함.

# 5. 디지털 휴먼 호스트 전환 (확정, 기획서 반영 예정)

박첨지 진행 호스트를 디지털 휴먼 아바타로 구현하기로 확정함(2026-07-06, L3 내부 결정). 지금 [[덜미 - 나만의 유람기 기획서]] 정본에는 넣지 않고, 스펙이 정리되면 반영함. 반영 시 기획서 §차 박첨지 진행 호스트를 페르소나 스펙에서 아바타 재생 시스템으로 바꾸고, Step 1 다음에 호스트 안내 단계를 신설함.

## 가. 확정 사항

- 박첨지 = 디지털 휴먼 아바타. 페르소나 스펙이 아니라 렌더링과 재생 시스템으로 승격
- Step 1 다음에 호스트가 안내하는 단계 신설 예정
- 적용 기술: TTS 음성 + 동작 애니메이션(입 모양 포함). 립싱크는 안 맞추고, 사전 생성한 입 움직임 애니메이션을 발화 중 재생하는 방식 검토

## 나. 확정 시 결정하거나 추가할 것

- **아바타 범위**: 안내 단계만인가, 전 세션 호스트(전 거리 질문을 아바타가 발화)인가. 규모를 가장 크게 가르는 결정
- **자산**: 아바타 리그, 동작 애니메이션 세트(대기, 인사, 말하기, 제스처), 입 모양 애니메이션(발화 중 루프). 픽처북 삽화 박첨지와 시각 정체성 일치(기획서 §카 콘텐츠 자산 인물 일관성 대상이 아바타까지 확장). 박첨지 TTS 보이스 확보(노인 재담꾼 톤, 한국어, 고정 보이스). 안내 대사 문안
- **사전 생성 이점**: 대사가 전부 사전에 알려지면(안내 문안 + 사전 고정형 거리 질문) TTS를 배치로 사전 생성해 런타임 지연이 없음. 대사별 영상 클립을 사전 렌더하면 실시간 렌더 엔진도 불필요. 단 유저 이름 호명 등 동적 요소가 있으면 그 부분만 런타임 합성이 필요하고, 이 여부가 사전 렌더와 실시간 렌더를 가름
- **재생 컨트롤러**: TTS 오디오 길이만큼 입 애니메이션을 루프하고 동작 애니메이션을 선택. 립싱크가 없어 음소 정렬은 불필요
- **흐름**: 신설 안내 단계가 재생 완료 시 자동 진행인지 유저 탭인지, 스킵 허용 여부, 타임아웃 처리. TTS 음성에 자막 병행(소음 환경과 접근성)
- **실패 강등**: 아바타 렌더나 TTS 재생 실패 시 정적 박첨지 삽화와 텍스트로 degrade. 기획서 §자 에러와 fallback에 경로 추가
