> 2026-07-14 자율 작업(기획서 5종 신양식 통일, UI 5종 재작성, 위키 정합성 검수)에서 나온 미결 항목의 처리 기록임. 사용자 피드백으로 결정된 항목은 본문에 반영하고 [[#2. 반영 완료 (2026-07-14 사용자 피드백)]]에 옮겼으며, 현재 남은 미결은 없음.

# 1. 남은 미결

현재 없음. 사용자 피드백으로 결정된 항목은 모두 본문에 반영했고, 남은 결정 대기 항목은 각 기획서 본문에 "확인 필요"로 표시함.

# 2. 반영 완료 (2026-07-14 사용자 피드백)

- 양반 놀리기의 별도 탈 디자인 단계는 두지 않기로 확정하고, 캐릭터 카드를 연령대 3개(아이/청소년/어른) × 성별 6종으로 통일함
- 공통 사양에서 Step 모델 절과 임베드 블록 ID를 제거하고, 결과물 전송 절을 병합 화면(결과물 감상과 받기) 기준으로 다시 씀. 에러 케이스와 처리 4갈래, 원인 3분류를 [[시범콘텐츠 공통 사양#4. 실패 처리와 에러 케이스]]로 승격함
- `_archive` 폐기 문서의 깨진 anchor를 사용자 예외 승인으로 정정함 (lint 0건)
- UI 문서 5종을 신양식 기준으로 재작성함: 결과물 미리보기와 QR 화면을 감상과 받기 한 화면으로 병합, 호스팅을 생성 파이프라인 끝으로 이동, 양반 Step 번호(7 → 6) 정정, 기획서 절 참조 갱신, 실패 안내를 확인 버튼 하나로, 기념 촬영 1컷, 유람기 결과 화면 타임아웃 300초
- UI 결과물 화면의 그만두기 버튼을 제거함 (기획서 진행 중 종료 미적용 화면이라 마침 하나로 끝냄)
- 공통 UI 컴포넌트에서 잔여 촬영 횟수 배지를 제거함 (촬영 1컷 확정)
- 채점 튜닝값(일치도 임계, 가중치, 게이지 달성, 난이도 곡선)을 정량 미정으로 되돌림. 재는 방식을 정하기 전에 수치를 박지 않음 (탈춤, 꼭두각시, 버나)
- "채점 구간"을 "채점 단위"로 바꾸고, 그 단위(장단 한 마디인지 동작 하나인지)는 채점 방식과 함께 개발 단계에서 정하기로 함
- 기념 촬영을 1컷으로 통일 (탈춤, 꼭두각시). 유효 촬영 복수 선택 문제가 사라짐
- 터치 미입력 타임아웃 60초로 통일, 다운로드 가능 기간 48시간으로 통일
- 양반 놀리기의 콘텐츠 입력 3종 보관 기간 30일(디버깅과 품질 분석용)
- 버나 센서 막대 주변기기를 항목별 선택지 비교표로 정리(센서 종류, 연결 방식, 폼팩터, 보정 방식)
- [[시범콘텐츠 공통 사양#5.6 실패 안내 (상황 안내 모달 팝업)]]를 기획서 기준으로 재작성. "처음으로" 버튼 폐지, 확인 버튼 하나
- [[시범콘텐츠 공통 사양#4. 실패 처리와 에러 케이스]] 위반 종료를 팝업 없이 종료로, [[시범콘텐츠 공통 사양#9. 운영 파라미터 (공통 기본값)]] 입력 위반 한도를 "3회째 위반에서 종료"로 정정
- 운영 알림 임계(연속 3회 실패, 5분 오류율 10%)를 5종에서 제거. 유람기 방식(원인이 외부 서비스나 시스템이면 알림)으로 통일
- 출력 가드레일 재생성 한도는 콘텐츠별로 다르게 유지하되 공통 사양에 근거 명시
- AI 호출 재시도 백오프와 TTS 호출 타임아웃을 5종에 반영
