> `01_Concepts` 폴더 11개 문서의 구조를 정리하는 작업의 진단과 실행안임. 사용자 지시는 [[남사당놀이]] 문서에 남사당놀이 자체와 공통 요소를 모으고, 종목 6개 문서에 개별 종목 내용을 남기며, [[컨소시엄 구성 개요]]가 개념 폴더에 맞는지 검토하라는 것이었음. 본문은 아직 손대지 않았음. 착수 전 결정 대기는 없음: 출처 보강을 이번 범위에 넣을지가 "구조 정리만"으로 결정됐음 ([[#3. 출처 근거 부재 (이번 범위 밖)]]).

# 1. 진단

폴더의 11개 문서를 읽고 `00_Index/MOC.md` 등록 상태, 인바운드 링크, 헤딩 구성을 대조해 결함 네 갈래를 찾았음. 파일 위치는 저장소 루트 기준으로 적음.

## 1.1 남사당놀이 문서가 허브 역할을 못 함

- [[남사당놀이#4. 공통 요소]](정리 전 명칭 「공통 특징」)가 두 줄뿐이었음. 정작 공통 요소는 종목 문서들에 흩어져 중복 서술됐음
- [[버나]], [[살판]], [[어름]] 세 문서가 각각 "재담과 장단과 묘기가 결합한 연희이고 나머지 둘과 유사 형식"이라고 서로를 가리키며 같은 말을 반복함 (`01_Concepts/살판.md:10,16,29,34`, `01_Concepts/어름.md:10,16,38`, `01_Concepts/버나.md:16`). 이 공통 형식은 상위 문서가 한 번만 소유해야 함
- 배역명(꼭두쇠, 잽이, [[매호씨]], 버나잡이, 살판쇠, 어름산이)이 상위에 모여 있지 않음. 남사당놀이 문서만 봐서는 연희를 누가 어떻게 꾸리는지 드러나지 않음

## 1.2 종목 6개 문서의 절 구성이 제각각임

같은 종류의 문서인데 절 골격이 문서마다 다름.

| 문서 | 첫 절 이름 | 구성 요소 절 | 시범콘텐츠 활용 절 | 관련 문서에 상위 링크 |
|---|---|---|---|---|
| [[풍물]] | 정의 | 없음 | 있음 | 있음 |
| [[버나]] | 정의 | 있음 (사용 도구) | 없음 | 없음 |
| [[살판]] | 정의 | 있음 (구성 요소) | 없음 | 없음 |
| [[어름]] | 정의 | 있음 (구성 요소) | 없음 | 있음 |
| [[덧뵈기]] | 정의 | 없음 | 있음 | 있음 |
| [[덜미]] | 개요 | 없음 | 없음 | 있음 |

## 1.3 MOC에서 종목 아닌 문서 3개가 종목과 나란히 나열됨

[[매호씨]](배역), [[덜미의 각본 재미 요소]](덜미 하위 분석), [[한국 전통 인형극]](덜미의 상위 계통)은 종목 6개와 성격이 다름. 그런데 [[MOC#1. 개념 (01_Concepts)]]에서 종목들과 한 줄씩 같은 층으로 나열돼, 색인만 봐서는 무엇이 종목이고 무엇이 아닌지 구별되지 않음.

## 1.4 컨소시엄 구성 개요는 개념 문서가 아님

- 내용이 참여 기관 5곳의 역할 분담, 선행 기술, 사업화 계획임. `sources`도 전부 연구개발계획서임
- `01_Concepts`는 개념 정리(정의, 원리, 이론)를 담는 폴더인데([[CONVENTIONS#2. 디렉토리 구조]]), 이 문서는 개념이 아니라 과제 수행 정보라 `04_Projects`가 맞음

# 2. 실행안

## 2.1 남사당놀이를 공통 요소의 단일 소유처로

- [[남사당놀이#4. 공통 요소]](옛 「공통 특징」)를 확장해 세 가지를 담음
	- 판의 구성: 연희가 벌어지는 놀이판을 누가 꾸리는지. 우두머리 꼭두쇠, 악사 잽이, 어릿광대 매호씨, 종목별 주역의 배역명
	- 공통 연희 형식: 묘기와 매호씨 재담과 잽이 장단이 결합하는 방식
	- 종목 간 관계: 풍물 장단이 여러 종목의 리듬 바탕이 됨
- 종목 문서에서는 이 중복 서술을 걷어내고 상위로 단방향 참조함. 단 TL;DR의 자족적 한 줄은 남김
- 양쪽 다 "상세는 저쪽"으로 미루면 순환 참조가 되므로([[반복 결함 카탈로그]] CONTENT-003), 공통 요소의 서술 본문은 남사당놀이가 소유하고 각 종목의 고유 정보(도구, 기술, 배역명)는 종목이 소유함

## 2.2 종목 6개를 공통 골격으로 병렬화

- 골격: 정의 → 구성 요소 → 종목 고유 항목 → 시범콘텐츠 활용 → 관련 문서 → 참고
- 덜미는 마당과 인물 표가 있어 고유 항목 절의 분량이 많은데, 이는 정보량 차이라 그대로 두고 절 이름과 순서만 맞춤
- 빠진 상위 링크(버나, 살판)와 빠진 시범콘텐츠 활용 절(버나, 살판, 어름, 덜미)을 채움. 종목별 콘셉트는 [[콘셉트 정리]]에 이미 있음

## 2.3 성격이 다른 3개는 위치 유지, MOC에서 층을 나눔

- 매호씨는 고유명사 배역이라 `entity` 페이지 유지가 규약에 맞음 ([[CONVENTIONS#1. 핵심 원칙]] 5). 8개 파일이 참조 중이라 링크 허브로도 작동함
- 한국 전통 인형극(인형극 계통 분류)과 덜미의 각본 재미 요소(각본 층위 분석)는 둘 다 정의와 분류를 다루는 서술이라 `concept` 문서로 적합함 ([[CONVENTIONS#3.2 프론트매터 (YAML)]] type 표). 옮기지 않음
- 대신 [[MOC#1. 개념 (01_Concepts)]]을 "남사당놀이와 종목 / 배역과 계통"으로 묶어 종목 6개와 구분되게 함

## 2.4 컨소시엄 구성 개요를 04_Projects로 이동

- wikilink는 파일명 기반이라 폴더를 옮겨도 참조 10곳이 깨지지 않음. MOC 등록만 [[MOC#1. 개념 (01_Concepts)]]에서 [[MOC#4. 프로젝트 (04_Projects)]]로 옮기면 됨
- 하위 폴더(데이터, 시범콘텐츠, 킥오프, 회의록) 중 어디에도 맞지 않고 과제 전반을 다루므로, `1차연도 셀빅 개발 준비자료.md`와 나란히 `04_Projects/` 최상위에 둠

# 3. 출처 근거 부재 (이번 범위 밖)

[[#1. 진단]]에서 함께 드러난 항목임. 버나, 살판, 매호씨 세 문서가 권위 출처 없이 서로에게 기대고 있음.

- 버나(`01_Concepts/버나.md:40`)와 살판(`01_Concepts/살판.md:39`)의 참고 절은 "사용자 제공 고증, 권위 출처 URL 보강 필요 (확인 필요)"임
- 매호씨(`01_Concepts/매호씨.md:20-21,32`)는 근거가 없는 그 버나와 살판을 다시 "위키 내부 고증"으로 근거 삼음
- 즉 셋 다 권위 출처(L1~L4, [[CONVENTIONS#3.7 외부 근거의 권위 계층]])가 없고, 매호씨는 근거 없는 문서를 근거로 씀
- **사용자 결정 (2026-07-14): 구조 정리만 진행함.** 출처 보강은 이번 범위에 넣지 않음. 세 문서의 "확인 필요" 표기는 그대로 두고, 구조를 옮기는 과정에서 근거 없는 서술을 권위 출처가 있는 것처럼 바꾸지 않음
- 남은 과제로 존치함: 권위 출처(한국민족문화대백과 등) 보강은 별도 작업으로 다룸
