- **플레이 화면**: 유저 카메라 뷰 + 우측에 내 아바타 인형의 내부 조작 구조 뷰. 유저 전신 움직임(포즈 추정)에 인형 내부 구조가 실시간 연동함

# 3. 결합안 검토: 인형극 난입 + 연동 시연 (2026-08-07, 검토 중)

유저가 "인형극이 자체 진행되고 유저가 난입하되 진행에는 영향을 못 미치는" 모델의 재미를 물었고, 논의 끝에 현행 연동 시연 단독 구성을 "1장 인형극 난입(관람과 추임새) → 2장 인형 연동 시연"의 2장 구성으로 발전시키는 검토에 착수함(사용자 결정 2026-08-07). 기획서 반영 전의 검토안임.

## 3.1 구성 원리

- **난입은 원전 산받이 구도의 정식화임**: 1965년 기록영상 분석([[덜미 영상 인형 동작 분석]]) 기준, 덜미는 극이 정해진 대본대로 흐르는 동안 산받이와 관객이 계속 끼어들되(문답, 추임새, 놀림) 진행은 바꾸지 못하는 구도임. "끼어들되 영향 없음"은 타협이 아니라 덜미 관람 문화의 원형이므로, 유저 난입은 관람 문화 자체를 체험시키는 장치가 됨
- **재미의 성립 조건: 영향 없음 + 표면 반응 있음**: 난입에 아무 반응이 없으면 유저가 입력의 무의미함을 간파하고 이탈함. 극 진행은 불변으로 두되 표면 반응(아래 1장 설계)을 촘촘히 둠. "무시당하는 관객"이 아니라 "인정받는 관객" 경험을 만드는 것이 핵심임

## 3.2 1장 인형극 난입 (신설 검토)

- **기술 제약: 극은 영상 파일 재생임 (2026-08-07 추가)**: 회사에 3D 모델링과 3D 애니메이션 인력이 없어(사용자 확인) 인형극을 실시간 렌더로 만들 수 없음. 1장의 극은 사전 제작 영상 파일 재생으로 함. 영상은 애초에 재생 중 바뀌지 않으므로 "진행에 영향 없음" 원칙과 원리상 완전히 맞음
- **대목**: 후보는 홍동지가 이시미를 잡는 대목(시각적으로 강렬, [[덜미 영상 인형 동작 분석]] 장면 지도 16:20~19:00). 각색 유의점(홍동지 알몸 표현)은 고증 자문과 함께 확정함. 영상 소스 후보는 [[#3.5 결합안 미결]] 참조
- **유저 입력**: 몸 움직임(뎁스 카메라)과 호응 음량(마이크). 1인 키오스크의 발화 부끄러움 장벽을 고려해 박수, 몸 흔들기 같은 저부담 입력을 우선하고 소리 추임새는 가산 요소로 둠
- **표면 반응 (진행 불변, 전부 영상 밖 레이어)**: 재생 영상 내부에는 개입할 수 없으므로 반응은 영상 밖 레이어에 둠
	- 산받이 호스트(상주 캐릭터)가 유저 호응을 받아 한마디 얹음 (사전 녹음 대꾸 풀에서 선택)
	- 유저 호응에 따라 잽이 장단 사운드 레이어와 신명 게이지가 달아오름 (연출 강화)
	- 화면 테두리와 바닥 프로젝션의 호응 연출 (조명, 꽃가루 등)
- **폐기와 격하**: 애초 검토한 "인형이 유저 쪽을 흘끗 보거나 멈칫하는" 반응은 영상 내 개입이라 기본 폐기함. 살리려면 대목을 세그먼트로 나눠 경계에 사전 제작 반응 컷을 끼우는 확장안이 있으나, 촬영과 편집 제작량이 늘어 별도 결정 사안임
- **유저 존재 표시**: 유저 실루엣이나 아바타를 영상 위 오버레이로 무대 가장자리에 "끼어든 관객"처럼 비추는 안을 검토함 (바닥 프로젝션 활용 여지 포함)

## 3.3 2장 인형 연동 시연 (현행 유지)

- 현행 설계([[#1. 확정된 결정 (사용자, 2026-08-05)]], [[#2. 확정된 결정 추가 (사용자, 2026-08-07)]])를 그대로 유지함
- 1장의 무대 맥락을 승계함: 1장에서 본 그 무대에 내 아바타 인형이 오르는 연결로, 연동 시연에 서사 배경이 생김
- **3D 인력 부재의 영향 판단 (사용자, 2026-08-07, L3)**: 통합 인형 모델은 몸통 뼈대 수준이라 복잡하지 않아 내부 제작이 가능할 것으로 봄. 2장 설계는 유지하되, 실제 제작 난도는 개발 착수 시 재확인함. 3D 아바타 생성은 기존대로 외부 API와 사전학습 모델 우선 검토([[덜미 - 나만의 꼭두각시 기획서]] Step 3 필요 리소스)

## 3.4 세션 배치

- **1장을 Step 3 아바타 생성 병행 대기 구간에 겹침**: 생성 대기 시간을 인형극 관람으로 채우므로 세션 총 길이 증가를 억제하고, 5 Step 골격을 유지한 채 Step 3의 대기 화면이 "진행 중인 인형극 + 난입"으로 바뀜
- 난입 구간 길이는 3~5분 검토: "영향 없음"이 간파되기 전에 2장으로 넘어가는 길이이며, 생성 대기 시간과의 정합은 개발 단계에서 확정함(확인 필요)

## 3.5 결합안 미결

- 대목 선정과 각색 범위 (고증 자문)
- **극 영상 소스**: ① 보유 중인 1965년 기록영상 클립([[남사당 기록영상 자료]]의 남사당 덜미 1965.mp4): 국립무형유산원 유튜브 공개본이나 콘텐츠 내 이용 조건과 저작권 확인 필요 ② 보존회 협력 신규 촬영(권리와 화질 유리, 비용 발생) ③ 2000년 기록화 사업 영상(무형유산지식새김): 열람과 이용 조건 확인 필요
- 산받이 대꾸 풀 제작량과 반응 트리거 기준
- 소리 추임새(음량 검출) 채택 여부 (덧뵈기 [[덧뵈기 가면극 재규정 검토]]와 공통 미결)
- 난입 구간 길이와 아바타 생성 대기 시간의 정합
- 게임 요소 3안과의 관계 정리: 해소됨(2026-08-07). 대잡이 도제 프레임이 3안과 결합안 1장을 함께 흡수함 ([[#4. 대잡이 도제 프레임 채택 (사용자 결정, 2026-08-07)]])

# 4. 대잡이 도제 프레임 채택 (사용자 결정, 2026-08-07)

탈춤 재설계의 수련 프레임("수련생을 진행 틀로, 배역을 목적지로", [[덧뵈기 가면극 재규정 검토]])을 덜미에 이식하기로 사용자가 결정함. 덜미에서 도제의 대상은 배역이 아니라 **대잡이(조종자)**임: 탈춤은 내 몸이 배역이 되는 기예, 덜미는 내 몸으로 인형을 놀리는 기예라 같은 수련 틀에 목적지가 다르고, 이 차이가 두 콘텐츠의 체감 중복을 막음. 조종법이 구전심수로만 전승되어 교본이 없다는 문제의식([[박첨지 장대 인형 조종법]])과 직결되어, 디지털 도제 명분이 탈춤보다도 직접적임.

## 4.1 새 체험 구조 (Step 3~4 내부)

- **견학**: 아바타 생성 대기 중의 인형극 난입 관람([[#3. 결합안 검토: 인형극 난입 + 연동 시연 (2026-08-07, 검토 중)]]의 1장을 재해석). 도제 서사에서 "스승 공연 견학"의 자리가 됨. 영상 재생과 표면 반응 설계는 3절 그대로 유지함
- **조종 수업 (1장)**: 전승 동작 10종([[박첨지 장대 인형 조종법]])에서 3~4개를 추려 낱개 학습. 구조 뷰가 교보재 역할("네 몸이 이렇게 기울면 장대가 이렇게 움직인다")
- **대목 실습 (2장)**: 원전의 산받이 큐-인형 응답 구조를 미션으로 삼음(전사본 근거: 구음에 맞춘 춤과 멈춤 236~238행, 벼락인사 512~518행, 춤 청하기 778행). NPC 박첨지 인형과의 문답
- **졸업 무대 (3장)**: 내 인형이 포장막 무대에 올라 박첨지와 한 거리를 놂. 최소안은 유람거리 춤 한 판(인형 1체로 성립), 확장안은 꼭두각시 거리 전반의 문답 상대역(2체). 이시미 잡기 같은 서사 대목은 유람기의 각본 재미를 잠식하므로 배제하고 기예 과시 대목으로 한정함
- **대잡이 인정 (결과)**: 점수 없는 인정 선언 + 수행 요약 + 게이지의 서사 번역. 탈춤의 "배역 인정"과 명칭을 갈라 차별화함(명칭은 미결)

## 4.2 기존 검토 항목의 흡수 정리

- **게임 요소 3안([[#2. 확정된 결정 추가 (사용자, 2026-08-07)]]) 흡수**: A 리듬 가산 → 졸업 무대의 게이지, B 산받이 대거리 미션 → 대목 실습, C 대목 수행 → 졸업 무대. 3안 택일 결정이 별도로 필요 없어짐
- **결합안 1장([[#3. 결합안 검토: 인형극 난입 + 연동 시연 (2026-08-07, 검토 중)]]) 흡수**: 견학 장으로 재해석하고 Step 3 대기 배치를 유지함
- **설계 원칙 이식**: "배운 것만 시키고 시킨 것만 판정"(탈춤 확정 원칙). 판정 강도는 채점 없는 수행 인정 수준으로 낮춰 2026-08-05 채점 없음 결정과 조화시킴

## 4.3 착수 조건 (기획서 반영 순서)

- **탈춤 3.0.0 확정 후 착수함 (사용자 결정, 2026-08-07)**: 탈춤 기획서 3.0.0(가면극 재설계, 커밋 3ffa152)의 외부 검토 2건이 2026-08-11(월) 회수와 G2 대기 중임([[덧뵈기 - 나만의 탈춤 작업노트#8. 기획서 3.0.0 가면극 재설계 후속 (2026-08-07)]]). 그 G2가 종결되어 탈춤이 확정된 뒤 덜미 기획서 반영을 시작함. 탈춤이 수련 프레임의 원본이라 확정 문안(Step 절 구성, 3장 헤딩 구조, 배역 인정 명세, 수행 인정의 판정 정의)이 덜미 번역의 템플릿이 됨

# 6. 설계 근거

- **디바이스 제약 해소**: 기존 최난도 근거였던 "핸드 트래킹이 손목까지라 핵심 조작이 센싱 한계에 걸림"([[1차연도 셀빅 개발 준비자료]])이 전신 포즈 추정 전환으로 해소됨. 탈춤의 "라이브 AR 제거 → 근거리/원거리 동시성 난제 해소"와 같은 구조임
- **가동 부위 고증**: 전사본 `03_References/converted/남사당놀이/남사당놀이 - 덜미.md` 기준, 일반 덜미 인형의 동작 부위는 양손과 상반신 흔들기뿐이고(207행), 상좌 2인만 포대 괴뢰라 목, 양손, 허리까지 움직임(209행). 유저 전신을 그대로 매핑하지 않고 이 가동 범위로 매핑하는 제약을 기획서에 명시함
- **조작 구조 어휘**: 애초 문헌 어휘가 "덜미 대"(대잡이가 잡는 대, 187행), "대잡이/대잡이 손"(171행)뿐이라 세부 부품 표현을 확인 필요(고증 자문)로 뒀으나, 2026-08-07 방성혁 논문([[박첨지 장대 인형 조종법]])으로 사각 장대, 어깨판, 입끈, 어깨끈, 하박 생략 목재 팔의 구조 어휘와 주손/보조손 조종법이 문헌 근거를 확보함. 통합 인형 모델 표현과 애니메이션 클립 목록(전승 동작 10종)이 이 논문을 정본 근거로 삼음. 고증 자문은 검증용으로 유지
- **플레이 화면 구성의 의도 명확화 (사용자, 2026-08-07)**: 사용자 의도는 처음부터 "플레이 화면에는 완성형 아바타 인형이 연기하고, 그 옆에 별도 내부 구조 뷰를 둬 작동 원리를 보여주는 것"임. 작성자가 제안했던 무대 단면(컷어웨이) 합침 안은 구조 뷰가 막 아래 막대 밑동만 남는 문제로 폐기함. 내부 구조 어휘는 논문([[박첨지 장대 인형 조종법]])이 근거를 줌. 같은 날 2뷰 구성으로 재결정됨([[#2. 확정된 결정 추가 (사용자, 2026-08-07)]] 플레이 화면 2뷰 확정): 구조 뷰는 사각 장대, 어깨판, 목재 팔까지만 표현하고 끈과 대잡이 양손은 제외함
- **가드레일 존치**: [[시범콘텐츠 공통 사양#8.2 가드레일 적용 3지점]]의 갈음 조건(런타임 AI 생성과 유저 자유 입력이 둘 다 없음)에 해당하지 않음. 얼굴 입력 검사(Step 2)와 3D 아바타 출력 검사(Step 3)가 남으므로 AI 가드레일 절은 존치하고 기념 사진 관련만 걷어냄
