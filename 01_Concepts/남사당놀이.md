> 유랑 예인 집단 남사당패가 펼친 여섯 종목의 떠돌이 연희. 풍물, 버나, 살판, 어름, 덧뵈기, 덜미로 구성됨. 이 위키 시범콘텐츠의 모태가 되는 상위 종목 묶음임.

# 1. 정의

- 남사당놀이는 유랑 예인 집단 남사당패가 마을을 돌며 펼친 종합 연희임
- 여섯 종목을 정해진 순서로 이어 펼침. 꼭두각시놀음(덜미, [[박첨지놀이]])이 여섯 종목 중 마지막 순서

# 2. 여섯 종목

각 종목은 별도 문서로 다룸. 시범콘텐츠 콘셉트는 [[콘셉트 정리]] 참조.

| 종목 | 내용 | 문서 |
|---|---|---|
| 풍물 | 풍물놀이(악기 연주와 상모놀이) | [[풍물]] |
| 버나 | 접시돌리기 묘기놀음 | [[버나]] |
| 살판 | 땅재주(곤두질) 묘기놀음 | [[살판]] |
| 어름 | 줄타기(외줄 곡예) | [[어름]] |
| 덧뵈기 | 탈놀음(탈춤) | [[덧뵈기]] |
| 덜미 | 꼭두각시놀음(막대 인형극) | [[박첨지놀이]] |

# 3. 공통 특징

- 묘기나 연희에 [[매호씨]](어릿광대)의 재담이 결합한 극성 있는 놀음임 (버나, 살판, 어름 등)
- 잽이(악사)의 풍물 장단이 여러 종목의 리듬을 받쳐줌

# 4. 관련 문서

- [[풍물]], [[버나]], [[살판]], [[어름]], [[덧뵈기]]: 남사당놀이 종목
- [[박첨지놀이]]: 덜미(꼭두각시놀음) 종목
- [[매호씨]]: 종목 공통 어릿광대 배역
- [[콘셉트 정리]]: 남사당놀이 6종목 시범콘텐츠 콘셉트
