핵심은 **복원이라기보다 ‘원본을 연출과 동작 자료로 사용하는 고화질 재제작’**입니다.

  가장 좋은 품질과 작업 효율을 기대할 수 있는 방식은 다음 3층 구조입니다.

  고정된 16:9 컬러 무대
          +
  AI로 생성한 인형 동작 전경
          +
  복원한 원본 음향과 시간축

  ## 권장 제작 방식

  ### 1. 원본은 확대하지 않고 분석 자료로 사용

  654×480 흑백 영상을 그대로 컬러화하고 업스케일하면 흐릿한 얼굴과 인형 디테일도 함께 확대됩니다. 따라서 원본에서는 다음
  만 추출합니다.

  - 대사와 전체 재생 시간
  - 인형의 등장과 퇴장 순서
  - 인형별 동작과 위치
  - 동작 속도와 대사 타이밍
  - 카메라 구도
  - 연희자가 나온 구간의 극 진행 내용

  기존 61개 구간표는 생성 클립 목록이 아니라 내용을 찾는 분석 마커로만 사용합니다.

  ### 2. 16:9 컬러 무대를 먼저 한 번 확정

  원본 4:3 화면의 좌우를 AI가 구간마다 제멋대로 확장하게 하면 무대 폭, 기둥, 조명, 배경색이 계속 달라집니다.

  따라서 먼저 다음을 만듭니다.

  - 1920×1080 고정 무대 배경
  - 원본 4:3의 핵심 공연 영역이 중앙에 들어가는 구도
  - 좌우는 원본 무대 구조를 바탕으로 자연스럽게 새로 설계
  - 조명 방향, 목재 색상, 천막과 무대 재질 고정
  - 카메라 위치와 렌즈 느낌 고정

  이 무대 이미지는 전편에서 계속 재사용하고, AI가 매 구간 다시 그리지 않게 합니다.

  ### 3. 인형별 고해상도 기준 자산 제작

  보유한 인형 사진을 이용해 배역마다 다음 기준 이미지를 만듭니다.

  - 정면
  - 좌우 3/4 방향
  - 측면
  - 대표 표정
  - 전신 크기 비율
  - 의상과 얼굴 색상표
  - 조종 막대, 팔과 손의 구조

  먼저 정지 이미지 단계에서 인형 외형을 승인한 뒤 영상 생성에 들어가야 합니다. 외형 승인을 건너뛰면 영상 생성 때마다 얼
  굴과 의상이 바뀝니다.

  ### 4. 무대와 인형을 분리해서 생성

  원본에서 인형극이 보이는 부분은 짧은 참조 영상으로 사용하여 인형의 동작만 재현합니다.

  - 고정 무대는 생성하지 않음
  - 인형과 필요한 소품만 생성
  - 가능하면 단색이나 정리된 배경으로 생성
  - 원본 클립은 모션 참조로 사용
  - 인형 사진은 캐릭터 참조로 사용
  - 생성 후 Resolve에서 배경을 제거해 고정 무대에 합성

  Seedance 2.5는 이미지, 영상과 오디오 참조, 모션 참조, 시간대별 지시와 그린스크린 방식의 편집 기능을 안내하고 있어 이런 제
  작 방식에 적합합니다. 다만 복잡한 동작과 여러 인물의 상호작용은 여전히 불안정할 수 있습니다. ByteDance 공식 소개

  ### 5. 연희자가 나온 부분은 새 인형 연기로 대체

  산받이 등 실사 인물이 보이는 구간은 사람을 인형으로 단순 변환하는 방식보다 다음처럼 처리하는 편이 자연스럽습니다.

  1. 해당 구간의 대사와 극적 기능을 확인
  2. 그 시간 동안 무대에서 수행할 인형 행동 설계
  3. 간단한 스토리보드나 애니매틱 작성
  4. 승인된 인형으로 새 동작 생성
  5. 원본 대사 타이밍에 맞춰 배치

  즉, 실사 인물을 지우는 작업이 아니라 그 구간에 있어야 할 인형극 장면을 새로 연출합니다.

  ## 생성 구간은 61개로 고정하지 않음

  61개 분석 마커마다 영상을 하나씩 만들 필요는 없습니다. 실제 생성 단위는 동작이 자연스럽게 이어지는 묶음으로 다시 잡습
  니다.

  처음에는 동일한 난도 높은 장면을 다음 길이로 시험합니다.

  - 8초
  - 15초
  - 20초
  - 30초

  각 길이를 같은 조건으로 2~3회 생성하여 다음을 비교합니다.

  - 인형 얼굴과 의상 유지
  - 팔다리와 조종 막대 구조
  - 무대 위 위치
  - 동작과 대사 타이밍
  - 깜박임과 형태 변형
  - 다음 클립과의 연결 가능성

  Seedance 2.5는 한 번에 최대 30초 생성을 지원하지만, 이는 안정성을 보장하는 길이가 아닙니다. ByteDance 모델 정보
  Higgsfield에서도 Seedance 2.5는 4~30초 범위를 지원합니다. Higgsfield 도움말

  시험 전 예상으로는 8~15초가 기본 생성 단위, 단순한 동작은 20~30초까지 확대하는 방식이 합리적입니다. 그러나 실제 결과를
  보고 확정해야 합니다.

  ## 원테이크처럼 연결하는 방법

  최종 영상의 원테이크는 “AI가 전편을 한 번에 생성했다”는 뜻이 아니라 시청자에게 컷이 보이지 않는 연속 영상으로 정의하는
  것이 현실적입니다.

  연결부마다:

  - 앞 클립 마지막 자세와 다음 클립 첫 자세를 일치
  - 이동 방향과 속도 유지
  - 0.5~1초 정도 중첩 구간 확보
  - 인형이 멈추거나 가려지는 순간에 연결
  - 고정 무대는 계속 유지
  - 필요한 경우 인형 전경에만 짧은 디졸브나 보간 적용

  배경이 완전히 고정되어 있으므로 전체 화면을 이어 붙이는 것보다 연결 흔적이 훨씬 적습니다.

  ### 중요한 원칙

  시작과 종료 이미지 62장을 먼저 모두 만들 필요는 없습니다. 필요한 것은:

  - 고정 무대 이미지 1장
  - 배역별 인형 기준 이미지 묶음
  - 각 생성 묶음의 시작 자세
  - 연결이 어려운 지점에서만 종료 자세나 브리지 프레임

  즉, 모든 구간에 기계적으로 시작, 중간과 종료 프레임을 만드는 방식은 피합니다.

  ## 음향 처리

  음향은 영상 생성과 분리해서 처리하는 것이 좋습니다.

  1. 원본 음향 추출
  2. 지속 잡음과 험 제거
  3. 클릭, 파열음과 과도한 바람 소리 보정
  4. 대사와 배경 소리 분리
  5. 대사 명료도 개선
  6. 손상된 구간만 수동 보정
  7. 전체 음량과 구간별 편차 정리
  8. 최종 영상 길이에 맞춰 동기화

  DaVinci Resolve Studio에는 시간과 공간 노이즈 감소, UltraNR, Magic Mask, Super Scale, Voice Isolation과 Dialogue
  Separator가 포함되어 있습니다. Blackmagic Design

  단, Voice Isolation을 과하게 적용하면 오래된 공연 음성이 금속성으로 변할 수 있으므로 원음과 처리음을 섞어 사용하는 편
  이 안전합니다.

  ## 가장 효율적인 전체 순서

  1. 원본 영상과 음향 분석
  2. 복원 음향을 기준 시간축으로 확정
  3. 16:9 컬러 무대 한 장 승인
  4. 배역별 인형 기준 이미지 승인
  5. 난도 높은 약 30초 구간으로 제작 방식 시험
  6. 전체 화면 생성과 인형 전경 분리 생성 비교
  7. 8초, 15초, 20초와 30초 길이별 안정성 비교
  8. 통과한 방식과 길이로 본편 생성
  9. Resolve에서 고정 무대와 인형 합성
  10. 연결부 보정, 색상 통일과 음향 동기화
  11. 1920×1080 최종 마스터 출력

  결론적으로 “고정된 16:9 무대 + AI 인형 동작 전경 + 복원 원음” 방식이 현재 가장 유력합니다. 전체 화면을 Seedance로 계속
  재생성하는 방식은 빠르게 시제품을 만들 수 있지만, 무대와 인형 외형이 흔들려 전편 수정 비용이 오히려 커질 가능성이 높습
  니다.
