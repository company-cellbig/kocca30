# 1. 검토자 역할과 금지 사항

당신은 이 변경의 외부 검토자임. 작성자의 의도나 중간 추론을 추정하지 말고, 지정한 커밋과 비교 파일을 직접 열어 완성된 결과만 검토함.

- 대상 파일, 로그와 Git을 수정하지 않음
- 새 보고서 파일을 만들지 않고 검토 결과를 채팅에만 반환함
- 커밋, 스테이징, 브랜치 전환과 승인 판정을 하지 않음
- 발견을 본문에 자동 반영하지 않음
- 접근 가능한 파일은 직접 열어 확인하고, 접근할 수 없는 근거만 `검증 불가`로 보고함
- 무발견을 결함 부재의 증명으로 표현하지 않고 수행 범위와 발견 건수만 보고함
- 각 발견은 위치, 문제, 근거, 영향과 제안을 포함함

# 8. 가독성/명료성 검토

처음 보는 개발자나 심사자의 시선으로 변경된 문장을 한 줄씩 읽고 다음을 적극적으로 찾음. `05_산출물/`은 명칭 치환이 직접 영향을 준 문장과 그 앞뒤 문맥으로 범위를 제한함.

**[가독성/명료성 (낯선 독자 시선)]**

- 정의되지 않은 용어나 막연한 지시어
- 구어체, 비표준어와 임의 조어
- 같은 뜻을 반복하는 군더더기

- 같은 수준 항목의 비병렬 구조

- `사기을`, `사기과`, `사기의 주장`과 같은 기계 치환 흔적이 남았는가
- `사기`, `사기 장면`, `부적을 이용한 사기`가 무엇을 가리키는지 문맥마다 분명한가
- `탈놀음 한바탕` 앞뒤에 조사가 빠져 낱말이 붙어 읽히는가

- 실제 화면 표시를 설명하는 곳에서 종목명까지 콘텐츠명에 포함한 것처럼 쓰지 않았는가

# 9. 전수 대조 방법

`git diff --find-renames 2fe3cbd..869d980`에 나타난 이름 관련 변경을 한 건도 생략하지 않고 표로 기록함. 정상 변경도 생략하지 않음. 변경되지 않은 파일과 파일명에 남은 옛 표현은 아래 저장소 전체 검색으로 별도 확인함.

```powershell
git grep -n -I -e "나만의 탈춤" -e "나만의탈춤" -e "덧뵈기-나만의탈춤-프로토타입.html" -e "거짓 영험" -e "05_덧뵈기 - 나만의 탈춤" -e "덧뵈기 나만의 탈춤 재설계 방향" 869d980 -- .
git grep -n -I -e "탈놀음 한바탕" -e "05_덧뵈기 - 탈놀음 한바탕" 869d980 -- .
git grep -n -I -e "사기을" -e "사기과" -e "사기의 주장" 869d980 -- .
git ls-tree -r --name-only 869d980 | Select-String -Pattern '나만의 탈춤|나만의탈춤|탈놀음 한바탕'
```

검색 결과는 다음 경계로 나눔.

- `10.1 명칭 전파 결과`: diff에 나타난 변경과, 이번 커밋에서 바뀌어야 했지만 빠진 활성 위치만 기록함
- `10.5 downstream과 의도적 제외`: 의도적으로 바꾸지 않은 비변경 downstream, 역사 기록과 현재도 유효한 기술 경로만 기록함
- 같은 위치를 두 표에 중복 기록하거나 중복 집계하지 않음

각 변경은 다음 넷 중 하나로 판정함.

- `적정`: 현재 문서와 경로의 역할에 맞게 새 이름으로 바뀜
- `부분 적정`: 이름은 바뀌었지만 주변 설명이나 참조 대상이 옛 방향에 남음
- `오변경`: 역사 기록, 일반 장르명이나 다른 대상을 콘텐츠명으로 잘못 바꿈
- `누락`: 바뀌어야 할 활성 표기나 경로가 옛 이름으로 남음

단순 문자열 검색만으로 판정하지 않음. 각 위치의 문맥을 읽고 다음을 구분함.

- 현재 콘텐츠명
- 덧뵈기나 탈놀이를 가리키는 일반 장르명
- 과거 시점의 콘텐츠명과 경로를 기록한 로그
- 아직 동기화하지 않은 downstream 원고, 화면과 도구 경로

## 9.1 downstream과 의도적 제외 검토

다음 파일을 `869d980` 시점으로 읽고 현재 명칭 및 방향과의 차이를 기록함.

- `prototype/덧뵈기-나만의탈춤-프로토타입.html`

이번 변경 범위 안에서 바꿨어야 하는 활성 위치가 빠졌다면 이 절에 넣지 않고 10.1에서 `누락`으로 기록함.
