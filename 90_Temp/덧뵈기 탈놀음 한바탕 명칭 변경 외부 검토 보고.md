# 1. 검토 범위와 방법

## 1.1 대상과 기준

- **지시서**: [[덧뵈기 탈놀음 한바탕 명칭 변경 외부 검수 패킷]]
- **기준 커밋**: `2fe3cbd7269e0529e696a469ecfde2a26652e12f`
- **검토 대상 커밋**: `869d980a1f171e9bbdbe67f74473827e40b48896`
- **스냅샷**: 워킹트리가 아니라 `869d980` 시점의 파일을 읽음. 운영 규칙도 같은 시점을 적용함
- **검토 종류**: 사실과 정합(P1, P5), 적대(P2, P3), 가독성(P4)

## 1.2 수행한 대조

- `git diff --find-renames`로 16개 파일의 변경을 한 건도 빼지 않고 표로 옮김
- `git grep`으로 옛 이름(`나만의 탈춤`, `나만의탈춤`, `거짓 영험`), 새 이름(`탈놀음 한바탕`), 축약명(`탈춤`), 기계 치환 흔적(`사기을`, `사기과`, `사기의 주장`)을 저장소 전체에서 훑음
- 검색으로 잡힌 위치는 문맥을 읽어 현재 콘텐츠명, 장르 일반명, 과거 기록, 미동기화 downstream으로 나눔
- `prototype/덧뵈기-프로토타입-검증.js`, `scripts/wiki_lint.mjs`, `scripts/wiki_number.mjs --check`, `scripts/quote_check.mjs`를 실행함. 저장소 파일은 수정하지 않음

## 1.3 표기 규약

- 저장소 파일의 위치는 파일 이름과 줄 번호로 적음. 전사본 인용은 이 검토에 없음
- 판정은 `적정`, `부분 적정`, `오변경`, `누락` 넷 중 하나임
- 무발견을 결함 부재의 증명으로 적지 않고 수행 범위와 건수만 적음
