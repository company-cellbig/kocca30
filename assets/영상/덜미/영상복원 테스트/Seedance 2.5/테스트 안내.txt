박첨지거리 Seedance 2.5 테스트

히그스필드의 Seedance 2.5에 현재 컬러복원 v2의 시작 이미지, 종료 이미지와 해당 원본 영상을 함께 입력해 만든 두 편임. 동작과 구도를 비교하기 위한 테스트이며 확정 복원본이 아님.
1번은 컬러 이미지 01→02와 원본 영상 1번, 2번은 컬러 이미지 02→03과 원본 영상 2번을 사용함. 이미지와 영상의 원래 파일을 그대로 업로드함.
2번에서는 기존 작업 노트의 손을 뺨 가까이에 둔다는 지시를 제외함. 손 형상을 수정한 03번을 종료 이미지로 사용하고 불분명한 흰 형상에 손바닥과 손가락을 추가하지 않도록 지시함.

박첨지거리_1_테스트.mp4와 박첨지거리_2_테스트.mp4는 1920×1080px, 16:9, 30fps임. 영상 트랙 길이는 각각 10초와 11초이며 원본 영상의 음향을 복사해 붙임. 음향 패킷 단위 때문에 컨테이너 재생 시간은 각각 약 10.005초와 11.008초임.
도구의 생성 원본은 같은 이름의 _생성원본.mp4로 별도 보관함. 생성 원본은 24fps, 1920×1080px이며 음향이 없음. 실제 길이는 약 10.042초와 11.042초임. 테스트 파일은 이를 30fps로 변환하고 지정한 10초와 11초로 맞춘 별도 사본임. 프레임 변환에 모션 보간을 사용하지 않음.
원본 이미지와 원본 영상은 수정하지 않음. 각 실행 프롬프트와 입력 경로, 해시, 업로드 ID, 생성 작업 ID 및 설정은 테스트 기록.json에 기록함. 생성 2회 예상 비용은 120크레딧과 132크레딧으로 합계 252크레딧임. 확인한 계정 잔액 변화도 252크레딧임.

원본 비교.html을 브라우저로 열면 원본과 테스트를 나란히 볼 수 있음. ‘함께 재생’을 누르면 테스트의 현재 시점에서 두 영상을 재생함. 왼쪽 원본은 음소거돼 있고 오른쪽 테스트에서 원본 음향을 들을 수 있음.
1번은 낮은 머리의 출몰과 후반 확대 흐름을 확인했으나 원본보다 지붕 상단과 주변이 더 보이며 천 주름, 글자와 머리 위치에 차이가 남음.
2번은 초반 확대, 직사각형 물체의 기울기와 후반 인형 등장 순서를 확인함. 마지막 프레임에서는 구체적인 손바닥과 손가락을 발견하지 못함. 물체와 얼굴 세부, 천과 건물 표현에는 편차가 남음.
원본과 테스트의 동일 시각 대표 프레임 23쌍 및 2번의 마지막 프레임과 수정된 03번을 대조한 관찰임. 전체 프레임의 동일성이나 종료 이미지와의 픽셀 일치를 확인한 결과가 아님. 색, 좌우 확장 영역과 고해상도 세부는 생성한 표현임.
