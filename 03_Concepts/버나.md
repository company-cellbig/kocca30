> [[남사당놀이]] 연희 종목의 하나. 쳇바퀴를 여러 겹 포개 만든 놀이도구(버나)나 접시, 대접, 놋대야 등을 막대로 균형 잡아 돌리는 묘기놀음. 접시돌리기라고도 함.

# 1. 정의

- 버나란 단순히 쳇바퀴나 대접을 돌리는 묘기로 끝나는 것이 아니라 직접 돌리는 사람인 버나잡이와 그의 대화자인 매호씨(어릿광대)와의 사이에 재담과 소리를 주고 받는 극성이 짙은 묘기놀이이다다
- 버나 = 여러 겹의 쳇바퀴를 포개어 천으로 고정하고, 가운데에 둥글게 오린 가죽을 붙여 만든 놀이도구를 일컫는 말
- 이 도구를 돌리는 연희 종목 자체도 버나라 부름. **접시돌리기**라고도 지칭
- 버나를 직접 돌리는 버나잡이가 [[남사당놀이#4.1 판의 구성 (배역)|매호씨]]와 재담과 소리를 주고받는 극성 짙은 묘기놀음임. 공통 연희 형식은 [[남사당놀이#4.2 공통 연희 형식]] 참조

# 2. 사용 도구

## 2.1 돌리는 대상

- 버나
	- 쳇바퀴를 두께 10cm 가량으로 자르고 그 양면에 헝겁을 몇겹 부하여 바르고, 원심에 직경 15cm 가량의 가죽을 둥글게 오려 붙였음
- 대야
	- 놋대야로써 밑바닥에 굽(둥근 받침테)이 있는 것
- 대접
	- 보통 자기 대접으로 직경 25cm 내외이다.

## 2.2 돌리는 연장

- 자새
	- 연을 띄울 때 쓰는 자새(얼레)를 그대로 사용함
- 긴 담뱃대
	- 길이 60cm 가량의 보통 담뱃대
- 짧은 담뱃대
	- 길이 40cm 가량의 보통 담뱃대
- 앵두나무 막대기
	- 길이 45cm 내외, 직경 6mm 가량의 앵두나무로 깎은 막대기
- 칼
	- 자루 길이 5cm 내외, 날 길이 15cm 가량의 창칼

# 4. 용어 주의: 쳇바퀴

- 여기서 **쳇바퀴**는 조리도구 **체(篩)의 테두리**를 말함. 그 테두리를 여러 겹 포개어 버나를 만듦
- 애완동물(다람쥐 등) 운동기구로서의 쳇바퀴가 **아님**: 혼동 주의
