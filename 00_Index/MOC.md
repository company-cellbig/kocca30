# 1. 개념 (03_Concepts)

## 1.1 남사당놀이와 종목

- [[남사당놀이]]: 여섯 종목(풍물/버나/살판/어름/덧뵈기/덜미)의 떠돌이 연희. 종목 허브이자 공통 요소(배역, 연희 형식, 종목 간 관계) 단일 소유처
- [[풍물]]: 남사당놀이 종목, 풍물놀이(악기 연주와 상모놀이). 여러 종목 장단의 바탕
- [[버나]]: 남사당놀이 종목, 접시돌리기. 쳇바퀴(체 테두리)로 만든 도구를 막대로 돌리는 묘기놀음
- [[살판]]: 남사당놀이 종목, 땅재주놀음. 살판쇠와 매호씨의 재담에 잽이 장단을 얹은 곤두질(땅재주)
- [[어름]]: 남사당놀이 종목, 줄타기. 어름산이가 외줄에서 사위(곡예)를 펼침
- [[덧뵈기]]: 남사당놀이 종목, 탈놀음(탈춤). 풍물 장단에 맞춘 춤사위와 양반 풍자
- [[덜미]]: 남사당놀이의 인형극 꼭두각시놀음, 2마당 7거리 구성

## 1.2 재미 분석
- [[덧뵈기의 재미 요소]]: 덧뵈기의 재미 분석 (과거 민중의 다섯 갈래 + 전사본 실증과 희극 이론 대응 + 현대 이식 가능성)

- [[컨소시엄 회의록 - 2026-06-22]]: 5개 기관 + 택견회 첫 대면 회의록 (성과지표, 성과물, 데이터와 LLM 역할, 모션 기술, 도제, 실증)
- [[1차연도 셀빅 개발 준비자료]]: 셀빅 2026 개발 계획. 콘텐츠 5종 + 공용/개별 시스템, AI 데이터셋, 디바이스, 개발 순서. 근거 4개(회의록 2, 콘셉트 정리, 디바이스 사양) 한정

- [[시범콘텐츠 공통 사양]]: 키오스크 콘텐츠 공통 프레임 정본 (세션/Step/공용기능/기술구성/개인정보/가드레일)
- [[플랫폼 사양]]: 1차연도 플랫폼 계층 정본 (런처, 서버, 결과물 호스팅, 사용자 모델). 연속성(이어하기, 학습 프로필)은 2차연도 확장 설계

- [[결과물 다운로드 페이지 사양]]: QR을 스캔한 유저가 결과물을 받는 웹페이지 정본 (화면 상태 4가지, 만료와 익명 접근, 콘텐츠별 결과물 구성. 유람기와 탈춤 작성, 양반 4컷과 버나는 자리만)
- [[덧뵈기 나만의 탈춤 재설계 방향]]: 재기획 방향 정본 (마당 범위/유저 배역/진행자 장쇠/채점 방침 확정. 마당별 진행 구조는 원전 비트 순서를 따름, 근거는 재미 요소와 전사본 순서 실증)

- [[마당 플롯 풀]]: 시드에서 사전 생성한 유형별 완결 플롯 80개 (거리별 박첨지 질문과 조연 인형 배역, 한 세션에 하나씩 배정해 씀)

- [[남사당놀이 데이터 보유 단체]]: 영상/문헌/사진/그림 보유 단체와 연락처 (1차 권리자 + 공공 아카이브 기관, 보존회 실무 창구와 협력 경위 포함)
- [[남사당놀이 아카이브 데이터셋 활용 검토]]: 정부 아카이브의 데이터셋 소스 활용성 평가 (무형유산지식새김 + 공공데이터포털 API, 공공누리 제4유형 제약)

# 5. 산출물층 (05_산출물)

사용자가 직접 쓰는 원고임. 외부로 나가는 문서라 위키 규칙을 적용하지 않음. 에이전트는 초안과 검수만 맡고 사용자 호출 없이 편집하지 않음 ([[AGENTS#2.9 산출물층 개입 절차 (05_산출물)]]).

## 5.1 콘텐츠 기획서

- [[덜미 - 나만의 유람기 기획서]]: 시범콘텐츠 개발 기획서, 박첨지 유람 합류 그림동화 전자책 생성 (골격, 작성 중)
- [[덧뵈기 - 나만의 탈춤 기획서]]: 시범콘텐츠 개발 기획서, 배역 동작 따라추기 체험 (포즈 채점과 점수 결과 안내)
- [[덜미 - 나만의 꼭두각시 기획서]]: 시범콘텐츠 개발 기획서, 얼굴 인형 아바타 연동 시연 체험 (몸 움직임으로 덜미 조작법 확인)
- [[덧뵈기 - 양반 놀리기 4컷 기획서]]: 시범콘텐츠 개발 기획서, 풍자 플롯 문답 4컷 만화 생성 (골격, 작성 중)

- [[살판 - 발장단 한 판 기획서]]: 시범콘텐츠 개발 기획서, 바닥 센서 발판 스텝 리듬 살판 체험 (미디어 케이브 체험형 추가 제안, 초안)
