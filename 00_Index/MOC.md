# 1. 개념 (01_Concepts)

- [[컨소시엄 구성 개요]]: 참여 기관 종합. 주관 큐랩 + 공동 셀빅/KETI/연세대/용인대 5개 기관 역할 분담
- [[남사당놀이]]: 여섯 종목(풍물/버나/살판/어름/덧뵈기/덜미)의 떠돌이 연희. 종목 허브
- [[박첨지놀이]] — 남사당놀이의 인형극 "덜미", 2마당 7거리 구성
- [[덜미의 각본 재미 요소]] — 덜미의 각본적 재미 4층위
- [[한국 전통 인형극]] — 인형극 계통 (꼭두각시놀음/만석중놀이/발탈)
- [[버나]] — 남사당놀이 종목, 접시돌리기. 쳇바퀴(체 테두리)로 만든 도구를 막대로 돌리는 묘기놀음
- [[살판]] — 남사당놀이 종목, 땅재주(곤두질). 살판쇠와 매호씨의 재담 + 잽이 장단에 맞춘 곤두질
- [[어름]]: 남사당놀이 종목, 줄타기. 어름산이가 외줄에서 사위(곡예)를 펼침
- [[덧뵈기]]: 남사당놀이 종목, 탈놀음(탈춤). 풍물 장단에 맞춘 춤사위와 양반 풍자
- [[풍물]]: 남사당놀이 종목, 풍물놀이(악기 연주와 상모놀이). 전 종목 장단의 바탕
- [[매호씨]]: 남사당놀이 공통 어릿광대 배역. 주역과 재담을 주고받음
