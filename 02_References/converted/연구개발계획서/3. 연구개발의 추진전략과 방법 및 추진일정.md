# 3-1. 연구개발 추진전략·방법

- 추진 전략
	- 다학제적 전문가 협업 체계(Expert-in-the-Loop) 기반 개발
		- 도메인 고증 및 기준점(Ground Truth) 설정: 무형유산 전문가(용인대, 남사당놀이보존회)의 철저한 고증을 통해 기술 개발의 과학적 기준점인 ‘Master 데이터’ 구축
		- 원천-상용화 기술의 유기적 결합: 원천기술(KETI, 연세대)과 상용화 기술(큐랩, 셀빅) 간의 기술 이행(Technology Transfer) 공백이 없는 ‘연구-개발-실증’ 통합 파이프라인 구축
	- 다학제적 요구사항 도출 및 융합 포럼 운영
		- 주요 주제 / 1차 포럼 (1차년도: 요구사항 도출): [방법론·데이터] 암묵지의 데이터화 방법론 및 무형유산 특화 AI 학습 데이터 규격 설정
		- 주요 주제 / 2차 포럼 (2차년도: 성과 공유 및 실증): [실증사례·글로벌] 4D 디지털 도제 시스템 실증 성과 분석 및 글로벌 확산 전략
		- 참여자 / 1차 포럼 (1차년도: 요구사항 도출): 무형유산 보유자(택견/남사당놀이), 데이터 아키텍트, AI 알고리즘 설계자, 수요처
		- 참여자 / 2차 포럼 (2차년도: 성과 공유 및 실증): 서비스 기획자(UX), 국내외 수요처(서울랜드/해외문화원), 에듀테크 전문가
		- 구분 / 1차 포럼 (1차년도: 요구사항 도출): 다학제 요구사항 정의서, 데이터 구축 가이드라인, 포럼 프로시딩(발표집)
		- 구분 / 2차 포럼 (2차년도: 성과 공유 및 실증): 피드백 리포트(보완사항), 성과 발표 영상, 기술/서비스 고도화 반영 결과표
	- 전주기 품질 보증을 위한 ‘무형유산 AI 검증위원회’ 구성 및 운영
		- 1. 방법론 / 자문 시기: 착수 후 2개월
		- 1. 방법론 / 검증 및 자문 내용: 암묵지(기세, 느낌)의 공학적 지표 변환 적정성 검토
		- 1. 방법론 / 의사결정 및 반영 절차: 자문 의견 수렴 → 연구계획 수정 → 위원회 승인
		- 2. 데이터 / 자문 시기: 데이터 수집시
		- 2. 데이터 / 검증 및 자문 내용: 멀티모달 데이터의 정밀도 및 온톨로지 정합성 검증
		- 2. 데이터 / 의사결정 및 반영 절차: 데이터 품질 검수 보고서 작성 → 미달 시 재수집
		- 3. 디지털재현 / 자문 시기: 알고리즘 개발시
		- 3. 디지털재현 / 검증 및 자문 내용: 4D 가우시안 스플래팅 및 AI 분석 엔진의 재현성 평가
		- 3. 디지털재현 / 의사결정 및 반영 절차: 명인-AI 동작 일치도 테스트 → 모델 최적화 반영
		- 4. 실증 / 자문 시기: 실증 테스트시
		- 4. 실증 / 검증 및 자문 내용: 사용자 경험(UX) 만족도 및 교육적 유효성 검증
		- 4. 실증 / 의사결정 및 반영 절차: 자문 반영 결과표(Action Plan) 작성 및 최종 보완
		- 위원회 구성: 총 5인 내외의 다학제 전문가 풀(Pool) 구성 (무형문화재 보유자, 보존회 전문가, 데이터 전문가, UX 디자인 전문가, 해외 사업화 컨설턴트)
		- 회의 주기: 반기 1회 정기회의 및 마일스톤 달성 시 수시 자문회의 개최
	- 암묵지의 형식지화를 위한 멀티모달 지식 융합 방법론 적용
		- [데이터 통합 학습] 영상(동작), 음성(구술), 문헌(역사) 데이터를 통합 학습하여 단순 외형 복원을 넘어선 동작의 '의도'와 '맥락'까지 재현하는 온톨로지 기반 생성 모델 구축
		- [공학적 해석] 무용 분석 이론(LMA)을 AI 동작 분석에 접목하여 스승의 '기세'와 '느낌'을 정량적 지표로 변환하는 창의적 방법론 채택
	- 애자일(Agile) 기반의 반복적 성능 검증 및 고도화
		- 현장 중심의 반복 개발: 개발 초기부터 국내외 수요처(서울랜드, 민속박물관, 해외 문화원 등)의 요구사항을 반영하고, 실제 체험자의 피드백을 실시간으로 수집하여 AI 코칭 엔진과 서비스 UI/UX를 지속적으로 개선
	- 글로벌 확산을 위한 초경량 AI 최적화 전략
		- [기기 독립적 환경] 고사양 서버에 의존하지 않고 전 세계 어디서나 웹/모바일을 통해 접속 가능하도록 모델 증류(Knowledge Distillation) 및 SLM(소형언어모델) 기술 집중 적용
		- [표준화 선점] 무형문화유산 동작 데이터 및 4D 에셋의 국제 표준 포맷을 제안하여 글로벌 시장 선점 및 기술적 진입장벽 구축
- 추진 방안
	- 데이터 수집 및 고품질 원천 데이터 확보
		- 명인·전승자가 직접 참여하는 고정밀 MoCap 데이터(FBX, BVH) 수집 및 멀티모달 DB 구축
		- 동작별 역사적 배경, 철학적 의미를 텍스트 및 음성 데이터로 변환하여 지식 그래프화
	- 핵심 엔진 개발 및 지능화
		- 4D 생성: 4D 가우시안 스플래팅(4DGS) 기술을 활용한 실시간(2K/30fps) 고실감 콘텐츠 생성 엔진 개발
		- AI 코칭: LMA 기반의 실시간 동작 분석 및 정밀 교정 피드백 생성 로직 구현
		- 대화형 에이전트: 문화특화 LLM을 연동하여 전승 지식 기반의 실시간 질의응답 서비스 구현
	- 시스템 최적화 및 경량화
		- AI 모델의 파라미터를 50% 이상 절감하는 경량화 알고리즘 적용 및 Latency 100ms 이하 달성
		- Web/Mobile/Kiosk 등 다양한 환경에 대응하는 크로스 플랫폼 최적화 기술 적용
	- 글로벌 실감형 서비스 플랫폼 통합
		- 고실감 4D 렌더링 엔진과 AI 분석 엔진이 결합된 통합 어플리케이션 서비스 패키징
		- SDK 및 API 형태의 모듈화를 통해 타 교육·전시 콘텐츠로의 확장성 확보
	- 국내외 실증 및 성과 확산
		- 국내: 서울랜드 내 고실감 인터랙티브 키오스크 설치 및 체험 데이터 분석
		- 국외: 주관기관 큐랩과 공동연구기관 셀빅의 글로벌 사업화 네트웍을 활용하여, 태국 초등학교, 필리핀 한국무화원등과 연계 실증 및 다국어 서비스 대응 역량 검증
		- 사업화: 실증 결과를 바탕으로 교육기관, 박물관, 테마파크 대상 B2B/B2G 시장 진입 전략 수립
- 연구개발 추진전략
	- 별도 센서 없이 카메라 영상만으로 사용자의 동작을 분석·교정할 수 있도록, “입력(영상) → 동작 인식 → 정확도 평가 → 교정 안내”의 한 흐름으로 구성
	- 개발 성과는 평균 fps, 관절 각도 오차, 말단 위치 오차의 3개 정량 지표로 관리
	- 속도 트랙(평균 fps), 각도 정확도 트랙(각도 오차), 말단 정확도 트랙(말단 오차)으로 구성하고, 개선 결과를 교정 안내 기능으로 연결
	- 교정 안내는 “오차 기반 교정”으로 정의하며, 실시간(즉시) 교정과 동작 완료 후 요약 교정의 2단 구조로 제공하여 실시간성과 의미 전달을 동시에 확보
- 연구개발 방법론(접근전략)
	- 카메라 영상 입력에서 사용자 자세/관절 정보를 추정하고, 기준 동작과의 차이를 관절 각도 오차와 말단 위치 오차로 계산
	- 동작 완료 후 요약 교정은 동작 전체 구간에서의 오차 변화(누적·최대·반복 패턴)를 요약하여 “의미 중심”의 개선점을 제공
	- 평균 fps는 동일 환경에서 반복 측정하여 관리하고, 각도/말단 오차는 기준 데이터 대비 평균 오차를 산출하여 관리
- 해결해야 할 기술적 난제 및 대응방안
	- 평균 fps가 목표에 미달하거나 처리 지연이 발생할 수 있으므로, 처리 단계를 단순화하고 연산량을 줄이는 방식으로 평균 fps를 확보하며, 동일 조건 반복 측정으로 개선 여부를 확인
	- 관절 각도 오차가 촬영 조건(거리/조명/각도) 변화로 증가할 수 있으므로, 촬영 조건 변화에 따른 흔들림을 완화하는 안정화 처리와 기준 동작 비교 방식의 정교화를 통해 평균 각도 오차를 감소
	- 말단 위치 오차가 가림·빠른 움직임·거리 변화에서 증가할 수 있으므로, 말단 추정이 불안정한 구간을 완화하는 보정/처리 전략을 적용하고, 평균 말단 오차를 목표 수준까지 감소
	- 교정 안내가 의미를 담으려면 동작 전체를 보고 판단해야 하는 경우가 있어 실시간 제공에 어려움이 생기므로, 실시간 교정은 계산이 가벼운 오차 기반 즉시 안내로 제한하고, 의미 기반 안내는 동작 완료 후 요약 교정으로 제공하여 계산 부담과 이해도를 동시에 만족
	- 무형문화유산 데이터 수집 / 추진 방안: 장애요소
	- 무형문화유산 데이터 수집 / (컬럼3): 무형문화유산 원천 데이터 확보 및 저작권 문제
	- 무형문화유산 데이터 수집 / 추진 방안: 연구개발 추진방법
	- 무형문화유산 데이터 수집 / (컬럼3): 용인대-전승협회 협력 체계 구축: 남사당놀이 보존협회와 참여 의사 확인서 확보
	- 무형문화유산 데이터 수집 / (컬럼3): 저작권 가이드라인 수립: 데이터 활용 범위를 명확히 규정하여 법적 분쟁 사전 차단
	- 동작 분석 및 교정 기술 / 추진 방안: 장애요소
	- 동작 분석 및 교정 기술 / (컬럼3): AI 모델의 높은 연산량으로 인한 실시간성 저하
	- 동작 분석 및 교정 기술 / 추진 방안: 연구개발 추진방법
	- 동작 분석 및 교정 기술 / (컬럼3): 연세대(참여3)의 경량화 기술 투입: 지식 증류 및 양자화 기술을 적용하여 모바일/웹 환경에서 Latency 100ms 이하 달성
	- 동작 분석 및 교정 기술 / (컬럼3): 엣지 컴퓨팅 기술 활용: 사용자 기기의 자원을 최적화하는 알고리즘 적용
	- 무형문화유산 고유 특징 추출 기술 / 추진 방안: 장애요소
	- 무형문화유산 고유 특징 추출 기술 / (컬럼3): 무형문화유산에 대한 멀티모달 학습데이터 구축의 어려움으로 인하여 무형문화 유산 고유특징을 추출하기 위한 파운데이터 모델 학습 및 추론 성능이 떨어짐.
	- 무형문화유산 고유 특징 추출 기술 / (컬럼3): 문화문화유산에 특징에 대한 정의와 추출된 특징에 대한 정확도 판단 기준 부재.
	- 무형문화유산 고유 특징 추출 기술 / 추진 방안: 연구개발 추진방법
	- 무형문화유산 고유 특징 추출 기술 / (컬럼3): 무형문화유산에 대한 동작 데이터의 경우 일부 학습 데이터를 기반으로 다양한 동작들을 만들어 낼 수 있는 시뮬레이터 개발 (자체보유 기술을 확장함)을 통하여 데이터를 확보하고 파운데이터션 모델을 학습하여 범용적으로 사용가능한 무형문화유산 특징 추출 인공지능 모델을 개발함.
