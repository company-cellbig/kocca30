> 분석용으로 로컬에 내려받은 남사당놀이 기록영상의 목록과 보관 규칙. 영상 파일 자체는 `assets/영상/`에 로컬 보관하고 git으로 추적하지 않으므로(대용량), 이 페이지가 출처와 파일 목록의 정본임. 전부 L4 외부 자료(공개 영상 다운로드본)임.

# 1. 보관 규칙

- **저장 경로**: `assets/영상/`. 파일명은 `남사당 {종목} {연도}.mp4` 꼴로 간결하게 붙임(내려받은 원제에서 이름을 바꿈). 출처 대조는 [[#2. 보유 영상 목록]] 표의 출처 URL로 함
- **git 미추적**: 영상 확장자(mp4, webm, mkv, avi, mov)는 `.gitignore`로 제외함. 근거는 GitHub 100MB 제한과 저장소 비대화 방지이며, 음성 녹취 원본(`assets/` 로컬 보관)과 같은 관례임
- **목록 관리**: 영상을 추가하거나 지울 때 본 페이지의 [[#2. 보유 영상 목록]] 표를 함께 갱신함. 파일은 로컬에만 있으므로 다른 작업 환경에서는 표의 출처 URL로 다시 내려받음
- **다시 내려받기**: 아래 명령으로 받되, `<파일명>`에 표의 파일명을 그대로 넣음 (yt-dlp, JS 챌린지 해결 스크립트 원격 허용)

```
python -m yt_dlp --js-runtimes node --remote-components ejs:github -f "bv*+ba/b" --merge-output-format mp4 -o "assets\영상\<파일명>.%(ext)s" "<영상 URL>"
```

- **분석 산출물 분리**: 영상에서 뽑은 프레임 캡처나 분석 노트는 영상 폴더에 두지 않음. 캡처 이미지는 `assets/` 하위 해당 콘텐츠 폴더에, 분석 문서는 `03_References/`나 `07_작업노트/`에 둠

# 3. 활용 관점

- 1965년 실연 기록이라 복원 전승 초기의 연행 모습을 담은 사료임. 시범콘텐츠의 동작, 인형 조작, 연행 구조 고증 분석의 소재로 씀
- 덜미 편은 꼭두각시 콘텐츠([[덜미 - 나만의 꼭두각시 기획서]])의 인형 조작 구조 참고 후보임. 인형 동작 분석은 [[덜미 영상 인형 동작 분석]]에 정리함(2026-08-07)
- 덧뵈기 편은 탈춤 콘텐츠([[덧뵈기 - 나만의 탈춤 기획서]])의 배역 동작과 장면 구성 고증 참고 후보임. 배역 동작 분석은 [[덧뵈기 영상 배역 동작 분석]]에 정리함(2026-08-07)
- 같은 채널에 나머지 종목([[살판]], [[어름]] 등) 기록영상이 있는지 추가 확인이 필요함(확인 필요). 2000년 기록화 사업 영상은 무형유산지식새김(iha.go.kr)이 별도 경로임 ([[남사당놀이 아카이브 데이터셋 활용 검토]] 참고)
