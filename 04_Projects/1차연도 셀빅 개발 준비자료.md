> 셀빅이 2026년에 개발할 남사당놀이 콘텐츠 5종을 정리하고, 그 개발에 필요한 사항(공용 시스템, 콘텐츠별 시스템과 데이터, 디바이스)을 모아 개발 계획을 세우는 자료. 근거는 6/22 두 회의([[컨소시엄 회의록 - 2026-06-22]], [[큐랩셀빅 사전회의 - 2026-06-22]])와 [[콘셉트 정리]], [[디바이스 사양]] 4개로 한정함. 미승인 문서(로드맵, 기획서 등)는 참조하지 않음.

# 1. 개요

셀빅이 2026년에 개발할 콘텐츠(남사당놀이 콘텐츠 5종)를 정리하고, 그 콘텐츠를 개발하는 데 필요한 사항을 모아 그것을 토대로 개발 계획을 세움.

# 2. 2026년 셀빅 개발 콘텐츠

남사당놀이 콘텐츠 5종을 개발함. 모두 키오스크용이며, 유형은 체험(실시간 동작과 조작이 핵심)과 생성(입력에서 결과물 산출이 핵심)으로 나뉨.

| 콘텐츠 | 종목 | 유형 | 한 줄 콘셉트 |
|---|---|---|---|
| 나만의 꼭두각시 | 덜미 | 체험 | 얼굴 촬영으로 목각 인형 3D 아바타를 만들어 산받이 재담에 맞춰 양손으로 조작 |
| 나만의 유람기 | 덜미 | 생성 | 플롯 문답을 AI 서사와 생성형 삽화로 엮어 그림동화 전자책 제작 |
| 버나잡이 한 판 | 버나 | 체험 | 센서 막대로 버나를 돌리는 물리 묘기와 매호씨 재담 대거리를 동시 수행 |
| 나만의 탈춤 | 덧뵈기 | 체험 | 배역 탈을 골라 코치 시연을 따라 춤사위를 추며 포즈 채점, 결과 화면에서 최종 점수 안내 |
| 양반 놀리기 4컷 | 덧뵈기 | 생성 | 풍자 플롯에 입력을 넣어 사용자 탈 캐릭터가 등장하는 4컷 만화 AI 생성 |

- **콘텐츠 통합**: 콘텐츠는 각자 독립 개발하고 런처로 메뉴만 통합함. 빌드 단계 통합은 안 함
- **도제 단계화**: 남사당은 표준 커리큘럼이 없어 난이도 수준으로만 구분함. 콘텐츠 설계 시 단계 난이도 반영 필요

# 3. 개발 계획

## 3.1 개발 단계

1. **디바이스 규격 (선행)**: 큐랩과 논의하여 확정 필요
2. **콘텐츠 개발 (나 순서대로)**: 첫 콘텐츠(유람기)가 공용 시스템(서버, 결과물 전송, AI 생성 연동, STT와 TTS, 디지털 휴먼)을 구체적 요구로 끌어내 만들고, 이후 콘텐츠가 재사용하며 확장함. 콘텐츠 요구가 정해지기 전 공용 시스템만 먼저 붙들면 앞 단계가 끝없이 늘어질 수 있어 피함
3. **런처 통합**: 콘텐츠 뒤. 콘텐츠가 나오는 대로 메뉴에 통합
4. **데이터 확보 (전 구간 병렬)**: 남사당보존회와 협의해 [[#5. 콘텐츠별 시스템과 데이터]] 원천 데이터(춤사위 모션, 탈과 인형 이미지, 재담, 장단 음원, 코칭용 정답 GT)를 확보. AI 학습용 대규모가 아니라 코칭용 정답 데이터 중심으로 소규모임. 폼과 형식, 취득 항목은 데이터 구축 전 실무 회의에서 정함.

## 3.2 콘텐츠 개발 순서

생성형이 체험형보다 쉬워 난이도 낮은 것부터 둠. 단 유람기와 거의 같은 양반 놀리기를 바로 잇지 않고, 체험형 첫 주자 탈춤을 2번으로 앞당겨 실시간 동작 인식과 채점 같은 체험형 기술을 일찍 세우고 그 경험을 나머지 체험형에 전파함.

| 순서 | 콘텐츠 | 유형 | 근거 |
|---|---|---|---|
| 1 | 나만의 유람기 | 생성 | 가장 쉬움. LLM과 이미지 생성이고 실시간 동작 없음 |
| 2 | 나만의 탈춤 | 체험 | 체험형 첫 주자. 실시간 동작 인식과 실시간 채점 등 체험형 기술 스택을 먼저 세워 그 경험을 나머지 체험형(버나잡이, 꼭두각시)에 전파 |
| 3 | 양반 놀리기 4컷 | 생성 | 유람기와 생성 골격이 거의 같아 재사용. 차이가 작아 뒤로 둠 |
| 4 | 버나잡이 한 판 | 체험 | 물리 시뮬레이션과 센서 막대 하드웨어 RnD |
| 5 | 나만의 꼭두각시 | 체험 | 3D 아바타와 양손 조작. 손 인식이 손목까지라 핵심 조작이 센싱 한계에 걸림. 최난도 |

# 4. 공용 시스템

5종이 함께 쓰는 시스템임. 콘텐츠와 따로 먼저 완성하지 않고, 첫 콘텐츠 개발이 구체적 요구로 끌어내 만든 뒤 이후 콘텐츠가 재사용하며 확장함. 런처는 콘텐츠 뒤에 조립함.

| 시스템 | 내용 |
|---|---|
| 런처 | 콘텐츠를 독립 개발한 뒤 메뉴만 통합하는 단일 진입 앱. 셸 조립은 콘텐츠가 나온 뒤 통합 단계에 함 |
| 서버 | 결과물 저장과 로그인 정도. 기기 간 동기화 없음 |
| 결과물 전송과 호스팅 | 결과물을 웹에 올려 다운로드로 제공. 포토는 인화 없이 QR 다운로드 |
| AI 생성 연동 | LLM과 이미지 생성을 콘텐츠가 공유. LLM은 상용이나 오픈소스로 자체 구축, 통합은 2차연도 |
| STT, TTS | 음성 입력과 음성 출력은 상용 API 유료 사용 |
| 디지털 휴먼(진행 호스트) | 산받이, 매호씨 등 진행 호스트. 셀빅 기존 자산을 포팅하고 음성은 STT, TTS 연동 |

- **서버의 1차연도 범위**: 1차연도는 결과물 저장과 익명 운영(결과물 다운로드)만 가동함. 디지털 도제 과제 달성을 위한 학습 정보 저장과 이어하기는 2차연도에 추가함. 회원 정보 관리 방식은 추후 결정 대상임

# 5. 콘텐츠별 시스템과 데이터

## 5.1 나만의 유람기 (덜미, 생성)

캐릭터 정보 입력(성별과 연령대 8개 조합) → AI 플롯 문답(유저 텍스트 입력, 키보드나 STT) → AI 서사와 생성형 삽화 생성 → 그림동화 전자책 → 전송

- **주요 시스템**
	- 플롯과 서사 생성 LLM
	- 삽화 이미지 생성
	- 전자책 조립
- **필요 데이터**
	- 덜미 재담과 플롯 텍스트 (LLM 서사 시드)
	- 인형과 삽화 양식 이미지 (이미지 생성 레퍼런스)

## 5.2 나만의 탈춤 (덧뵈기, 체험)

배역 선택 → 코치 시연 따라 춤사위 체험(풍물 장단에 맞춰 포즈 추정으로 자세와 타이밍 채점, 신명 게이지) → 결과 화면(최종 점수 안내)

- **주요 시스템**
	- 실시간 포즈 추정, 자세와 타이밍 채점
	- 동작 가이드 (코치 영상과 동작 안내 바)
- **필요 데이터**
	- 덧뵈기 춤사위 모션 (따라하기 동작과 채점 정답 GT)
	- 탈 이미지 (배역 선택 목록 표시)
	- 풍물 장단 음원 (장단 동기)

## 5.3 양반 놀리기 4컷 (덧뵈기, 생성)

캐릭터 정보 입력 → AI 풍자 플롯 문답(유저 텍스트 입력, 키보드나 STT) → 사용자 탈을 쓴 캐릭터가 등장하는 4컷 만화 AI 생성 → 전송

- **주요 시스템**
	- 풍자 플롯 생성 LLM
	- 4컷 만화 이미지 생성
	- 사용자 탈의 만화 캐릭터화
- **필요 데이터**
	- 덧뵈기 양반 풍자 텍스트 (풍자 플롯 시드)
	- 양반과 말뚝이 캐릭터 이미지 (만화 캐릭터 레퍼런스)

## 5.4 버나잡이 한 판 (버나, 체험)

센서 막대로 버나, 접시, 대접의 회전과 균형과 낙하를 물리 시뮬레이션 → 매호씨가 재담으로 도발하면 대거리 선택지로 응수(적절성 판정) → 적절성과 묘기 유지로 신명 게이지

- **주요 시스템**
	- 회전과 균형 물리 시뮬레이션
	- 센서 막대 입력 연동
	- 재담 대거리 적절성 판정
- **필요 데이터**
	- 버나 묘기 동작과 도구 형태 (물리 기준과 묘기 채점 정답 GT)
	- 매호씨 재담 (대거리 텍스트)
	- 풍물 장단 음원 (장단)

## 5.5 나만의 꼭두각시 (덜미, 체험)

얼굴 촬영 → 특징 추출로 목각 인형 3D 아바타 생성 → 산받이 미션과 재담에 맞춰 양손 조작과 장단 타이밍(산받이 추임새 채점) → 신명 게이지 → 기념 촬영

- **주요 시스템**
	- 얼굴 특징 추출
	- 3D 아바타 생성
	- 양손 조작 인식
	- 장단 타이밍과 산받이 추임새 채점
- **필요 데이터**
	- 목각 인형(박첨지, 홍동지) 이미지 (아바타 양식 레퍼런스)
	- 산받이 재담 (재담과 채점)
	- 장단 음원 (장단)
	- 정답 조작 동작 (행동 정확도 채점 GT)
- **제약**: 양손 조작은 뎁스 카메라 손 인식이 손목까지가 현실적이라 조작 설계가 이 한계를 넘지 않아야 함(디바이스 제약)

# 6. 디바이스

콘텐츠가 도는 물리 하드웨어임. 정본은 [[디바이스 사양]]이고, 본 절은 5종 개발에 필요한 항목만 추림. 5종은 모두 키오스크용이며 미디어 케이브는 1차연도 콘텐츠 대상이 아님.

## 6.1 키오스크 하드웨어

- **확정**: 가로형 키오스크, 모션 인식 뎁스 카메라, 바닥 프로젝션
- **검토 중**: 65인치, 뎁스 카메라 모델(키넥트나 오르벡), 라이다 채택. 바닥 프로젝션 투사 면적은 약 2m x 2m(셀빅 가정)
- **규격 주체**: 큐랩이 센서와 규격을 정하고 셀빅이 맞춤. 셀빅 포토부스(세로형)와 큐랩 케이팝(가로형) 자산을 단일 규격으로 통합
- **센싱 한계**: 전신 싱글 카메라는 손목까지가 현실적이고, 1인이 정확도와 속도에 유리하며, 청소년 이상 성인이 대상임

## 6.2 콘텐츠별 액세서리 (셀빅 RnD)

- **버나 센서 막대**: 버나잡이용 인식 도구. 분실과 관리, 충전 이슈로 시연용 한정 가능성. 도입 여부는 하드웨어 RnD 후 결정
- **카메라**: 꼭두각시(얼굴 촬영)와 탈춤(전신 포즈 채점)이 모션 인식 카메라를 사용. 하드웨어 영향은 적음
