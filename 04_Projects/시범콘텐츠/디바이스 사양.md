> 키오스크와 미디어 케이브 등 물리 하드웨어(디바이스) 정본. 두 회의록의 하드웨어 결정을 컴파일함. 소프트웨어 공통 계층은 [[플랫폼 사양]](1차연도 플랫폼 계층: 런처, 서버, 익명 사용자 모델)과 [[시범콘텐츠 공통 사양]](콘텐츠 공통)이 정본이고, 콘텐츠 고유 도구는 각 기획서가 소유함. 다수 항목이 검토 수준이며 최종 규격은 미결임.

# 1. 개요

- **담는 것**: 체험 전시의 물리 하드웨어(키오스크, 미디어 케이브, 카메라와 센서, 바닥 프로젝션)와 그 제약. 소프트웨어 계층은 제외함
- **디바이스 두 종류**: 키오스크(체험 중심), 미디어 케이브(관람 중심)
- **소유 경계**:
	- 디바이스(본 문서): 물리 하드웨어와 제약
	- 1차연도 플랫폼 계층 소프트웨어(런처, 서버, 결과물 호스팅, 사용자 모델): [[플랫폼 사양]]
	- 콘텐츠 공통 소프트웨어(세션, Step, 기능, 기술): [[시범콘텐츠 공통 사양]]
	- 콘텐츠 고유 입력 도구(버나 막대 등): 각 콘텐츠 기획서. 본 문서는 §5 콘텐츠별 하드웨어 쟁점에 색인만 둠
- **근거와 권위**: 본 문서는 회의록 두 개(L3, 음성 녹취 STT 기반 내부 정리)를 컴파일함. 컨소시엄 본회의 확정과 큐랩셀빅 사전회의 검토를 구분 표기함. 세부 규격과 수치는 원본 재확인이 필요함 ([[컨소시엄 회의록 - 2026-06-22]], [[큐랩셀빅 사전회의 - 2026-06-22]])

# 2. 키오스크

메인 디바이스. 택견과 남사당 모두 체험은 키오스크 중심으로 진행함.

## 가. 확정 (컨소시엄 본회의)

- 가로형 키오스크
- 모션 인식 카메라 탑재
- 바닥 프로젝션 동반
- 단일 키오스크에서 택견과 남사당을 선택 진입. 남사당도 체험형은 키오스크 중심 (출처: [[컨소시엄 회의록 - 2026-06-22#2. 핵심 합의]])

## 나. 구성안 (큐랩셀빅 사전회의, 검토)

세부 규격은 큐랩이 정하고 셀빅이 맞춤. 아직 검토 수준이라 확정이 아님.

- **모니터**: 65인치, 터치(UI 선택용). 가로형은 확정(§가 확정)이고, 65인치 등 세부 치수만 검토
- **카메라**: 뎁스 카메라(깊이 인식). 키넥트나 오르벡(Orbbec) 류 검토
- **바닥 프로젝션**: 프로젝터
- **라이다**: 저가형(RPLiDAR 등). 사람 위치 분할 보조용, 검토 중
- **규격화 기준**: 큐랩 케이팝 키오스크(65인치, 뎁스 카메라 장착 공간)와 셀빅 포토부스 키오스크(세로형) 자산을 단일 규격으로 통합 (출처: [[큐랩셀빅 사전회의 - 2026-06-22#가. 플랫폼과 하드웨어]])

## 다. 바닥 프로젝션 용도

- **출력 장치임**: 사용자 촬영용이 아니라 화면을 비추는 표시와 연출용임
- **용도**: 택견 스텝(품밟기) 위치 표시, 남사당 바닥 연출
- **상시 가동**: 프로젝터를 끌 수 없어 전 콘텐츠에 기본 배경이나 이펙트를 깖 (출처: [[큐랩셀빅 사전회의 - 2026-06-22#가. 플랫폼과 하드웨어]])
- **투사 면적**: 약 2m x 2m. 사람이 올라서서 발 위치 가이드를 밟는 영역. 셀빅 잠정 가정으로 회의 근거 없음(확인 필요)

## 라. 카메라 센싱 범위 (연세대)

- **입력**: 뎁스 카메라(RGBD, 색상과 깊이 영상)로 실시간 세그멘테이션(사람 영역 분리)
- **인원**: 알고리즘은 다인 기준이나 지표는 2~3인까지 맞춤. 1인이 정확도와 속도에 유리
- **연령**: 청소년 이상 성인 대상. 아동까지 넓히면 별도 모델 필요
- **손 동작 한계**: 전신 싱글 카메라로는 손목까지가 현실적임(SMPL 표준 인체 모델 기준). 손가락 추적은 장갑 센서나 구속 카메라가 필요해 별도 RnD로 둠 (출처: [[컨소시엄 회의록 - 2026-06-22#라. 모션 인식 기술 범위 (연세대)]])

## 마. 외형과 구성 (셀빅 자체 가정, 회의 근거 없음, 확인 필요)

회의록에 없는 셀빅 자체 가정임(확인 필요). 입출력과 외형은 [[콘셉트 정리]] §2 디바이스와 콘텐츠 배정에서 본 정본으로 이관했고(원본은 git 이력 보존), 거치와 본체는 외형 검토 과정에서 결정함(2026-06-25). 회의 결정이 아니므로 콘텐츠 재작성과 큐랩 규격 확정 시 갱신함.

- **입력**: 터치, 가상 키보드, 음성 텍스트 변환(STT), 카메라(얼굴과 포즈 인식), 마이크
- **출력**: 스피커, 디지털 전송(SMS, 이메일)
- **외형**: 현대적 미니멀, 화이트와 밝은 회색
- **화면 거치**: 수직 거치(틸트 없음). 2m 거리 시청과 키 편차에 대응
- **모션 카메라 조준**: 전방 약간 하향. 2m 거리의 전신 동작 포착
- **본체(하단 함체)**: 화면부는 얇아도 하단 캐비닛은 GPU 데스크탑 PC를 수용하는 깊은 함체임. 안정적 베이스로 바닥 활동 구역 전도 방지. 함체 깊이는 확정 PC 사양에 맞춤(확인 필요)
- **방열과 유지보수**: 흡기와 배기 환기구, 전시장 먼지 대응 필터, 점검과 교체용 도어를 둠
- **외부 액세서리**: 본체와 분리 배치. 콘텐츠별 도구는 §5 콘텐츠별 하드웨어 쟁점

## 바. 외형과 사용 예시 이미지 프롬프트 (ChatGPT)

키오스크 디바이스의 외형과 사용 모습을 ChatGPT 이미지 생성으로 뽑는 프롬프트임. 확정 사실(가로형, 모션 인식 카메라, 바닥 프로젝션, §가 확정)을 반영하되, 외형 스타일(현대적 미니멀, 화이트와 밝은 회색)과 65인치 등 세부 치수는 셀빅 가정이라 잠정임(확인 필요, §나 구성안, §마 외형과 구성). 규격 확정 시 프롬프트를 갱신함.

- **외형 예시(전면, 측면)**: "우리 키오스크가 이런 모습일 것이다"를 보여줌. 기기 단독, 순백색 배경, 바닥 투사 없음. 각 컷을 8:9로 뽑아 후편집으로 가로 16:9 한 장으로 합침. 측면은 1)에서 만든 전면 이미지를 첨부해 참조로 생성하므로 디자인이 일치함
- **사용 예시**: "이 키오스크를 이렇게 사용할 것이다"를 보여줌. 단일 장면 가로 16:9. 1)전면과 2)측면 이미지를 첨부 참조로 넣어 같은 기기로 생성함

# 3. 미디어 케이브 (CAVE)

관람 중심 디바이스. 셀빅 담당.

- **구성**: 3면과 바닥 스크린의 공간 몰입 전시 (확정, 컨소시엄 본회의)
- **용도**: 남사당 관람형(영상 재생) 위주. 택견은 미탑재
- **위치와 한계**: 서울랜드 시연의 전시 효과 확보용. 공수 대비 사업성이 낮아 관람형으로 최소화함. 해외 실증에는 못 가져감 (출처: [[컨소시엄 회의록 - 2026-06-22#2. 핵심 합의]], [[큐랩셀빅 사전회의 - 2026-06-22#가. 플랫폼과 하드웨어]])
- **잠정 구성안 (셀빅 자체 가정, 회의 근거 없음, 확인 필요)**: 회의는 구성과 담당만 정했고, 아래 치수와 장비 수량은 회의록에 없는 셀빅 자체 가정임(확인 필요). 원래 [[콘셉트 정리]] §2 디바이스와 콘텐츠 배정에 있던 값을 본 정본으로 이관함(원본은 git 이력 보존)
	- 공간: 큐브형, 약 W 4.8 x D 4.8 x H 2.7m(예상). 천장과 입구 면 제외, 다중 참여
	- 디스플레이: 4면 투사(3개 벽면과 바닥면). 빔 프로젝터 벽면 3대와 바닥 2대
	- 입력: 전면 카메라 1대, 레이저 센서(벽면 3대와 바닥 2대), 마이크(호응 감지)
	- 출력: 영상 투사, 스피커

# 4. 공통 결정과 제약

키오스크와 케이브를 가로지르는 하드웨어 관련 공통 결정임.

- **모바일 앱 없음**: 별도 앱을 만들지 않음. 결과물은 웹에 올려 다운로드로 제공(포토는 인화 없이 이미지로)
- **포토 촬영**: 미러리스 카메라 대신 모션 센싱 카메라 1대로 처리. 인화 없이 QR 다운로드
- **비주얼**: 3D 지양, 2D 영상과 AI 생성 위주
- **서버 연계**: 결과 저장과 로그인 정도만 필요함(동기화 없음). 소프트웨어 상세는 [[플랫폼 사양#3. 서버]] 소관 (출처: [[큐랩셀빅 사전회의 - 2026-06-22#2. 핵심 합의]], [[큐랩셀빅 사전회의 - 2026-06-22#바. 거버넌스와 1차연도 운영]])

# 5. 콘텐츠별 하드웨어 쟁점 (색인)

콘텐츠 고유 입력 도구는 각 기획서가 정본임. 본 표는 색인이며 상세는 각 기획서와 회의록을 참조함. 모두 검토 수준임.

| 콘텐츠 | 하드웨어 쟁점 | 상태 |
|---|---|---|
| 버나(접시돌리기) | 인식용 막대 도구 제작 | 검토 (분실과 관리, 충전 이슈로 시연용 한정 가능) |
| 어름(줄타기) | 밸런스 보드(롤러 보드) 또는 바닥 프로젝션 대체 | 검토 (실제 줄은 전용 공간 필요) |
| 덜미(꼭두각시) | 사진이나 AI로 캐릭터 생성 후 인형놀이와 포토 | 하드웨어 영향 적음 |
| 풍물(빛의 상모놀이, 케이브) | 무선 센서 모자(고개 회전 감지). 초기에 키넥트 뎁스 카메라 인식 안도 검토됨 | 검토 (미디어 케이브 콘텐츠) |

출처: [[큐랩셀빅 사전회의 - 2026-06-22#다. 콘텐츠별 하드웨어 쟁점 (남사당, 셀빅)]], [[콘셉트 정리]] §4 (빛의 상모놀이 무선 센서 모자)
