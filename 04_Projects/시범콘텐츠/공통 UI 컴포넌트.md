> 키오스크 시범콘텐츠 5종의 UI 개발 착수 전, 화면별로 흩어진 UI 요소를 위젯 단위 공통 컴포넌트로 모은 인벤토리. 화면 골격 정본은 [[시범콘텐츠 공통 사양#5. 공통 화면]], 화면별 배치는 각 UI 문서가 정본이고, 본 문서는 그 컴포넌트를 여러 콘텐츠에 걸쳐 한데 모아 목록으로 정리함. 재사용 범위(전체/생성형/체험형/일부)를 항목마다 표기해 공용 개발 우선순위를 드러냄.

# 1. 개요

## 가. 목적과 범위

- **목적**: UI 개발에 앞서 화면이 아니라 위젯(버튼, 라벨, 키보드 등) 단위로 공통 컴포넌트를 모아, 한 번 만들어 5종이 재사용할 기반을 정함
- **담는 것**: 2개 이상 화면이나 콘텐츠가 공유하는 재사용 컴포넌트. 각 컴포넌트의 역할과 구성, 재사용 범위, 정본 위치를 표로 정리함
- **담지 않는 것**: 화면 단위 흐름과 레이아웃(각 UI 문서 소관), 콘텐츠 고유 1회성 요소(각 UI 문서와 기획서 소관), 시각 스타일과 색상, 치수 같은 디자인 토큰(디자인 단계 확정, 확인 필요)
- **출처**: 5종 UI 문서와 [[시범콘텐츠 공통 사양#5. 공통 화면]], [[시범콘텐츠 공통 사양#13. 공용 화면 예시 이미지]]에서 반복 등장하는 요소를 추출함

## 나. 재사용 범위 표기

컴포넌트마다 어느 콘텐츠가 쓰는지를 아래 넷으로 표기함. 개발 우선순위 판단용임(§4 개발 착수 우선순위).

- **전체**: 5종 모두 공유
- **생성형**: [[덜미 - 나만의 유람기 UI|유람기]], [[덧뵈기 - 양반 놀리기 4컷 UI|양반 놀리기]] (텍스트 문답으로 결과물 생성)
- **체험형**: [[덜미 - 나만의 꼭두각시 UI|꼭두각시]], [[덧뵈기 - 나만의 탈춤 UI|탈춤]], [[버나 - 버나잡이 한 판 UI|버나]] (카메라나 센서 기반 체험)
- **일부**: 위 분류와 무관하게 특정 콘텐츠 한둘만 씀

## 다. 정본 경계

본 문서는 컴포넌트 색인이며, 각 컴포넌트의 동작 정본은 아래 문서가 소유함. 충돌 시 정본이 우선임.

- **화면 골격과 공용 동작**: [[시범콘텐츠 공통 사양#5. 공통 화면]] (16:9 3영역, 도달성, 각 공통 화면 흐름)
- **진행 호스트 계약**: [[시범콘텐츠 공통 사양#6. 진행 호스트]] (화면 상태 모델, 설정 스키마)
- **텍스트 입력과 음성**: [[시범콘텐츠 공통 사양#사. 텍스트 입력]]
- **화면별 배치와 변형**: 각 UI 문서(§5 관련 문서)
- **2차연도 이어하기(QR 스캔)**: [[플랫폼 사양#6. 2차연도 전방 설계 (디지털 도제 연속성, 현재 구현 밖)]] (1차연도 미구현)

모든 컴포넌트가 놓이는 공통 골격임. 개별 위젯에 앞서 이 프레임을 먼저 구현함.

|---|---|---|---|
| 16:9 3영역 프레임 | 화면 기본 골격. 헤더(상단, 표시 전용), 본문(중앙, 주기능 1개), 액션(본문 아래, 버튼)으로 나누고 호스트 슬롯을 얹음 | 전체 | [[시범콘텐츠 공통 사양#가. 공통 영역 골격 (16:9 가로)]] |

# 3. 컴포넌트 카탈로그

## 가. 버튼류

| 컴포넌트 | 역할과 구성 | 재사용 범위 | 정본 |
|---|---|---|---|
| 주 버튼 (primary) | 화면의 핵심 액션 1개. 큰 터치 타깃으로 액션 영역에 둠. 라벨 예: 시작하기, 다음, 동의하고 시작, 완료, 전송 | 전체 | [[시범콘텐츠 공통 사양#5. 공통 화면]] |
| 보조 버튼 (secondary) | 취소, 거부, 이탈용 작은 버튼. 라벨 예: 그만두기, 받지 않기, 처음으로 | 전체 | [[시범콘텐츠 공통 사양#5. 공통 화면]] |
| 음성 입력 버튼 | 마이크 버튼. 누르면 음성을 받아 텍스트로 변환(음성 텍스트 변환, STT)해 입력 필드에 채움(자동 제출 아님). 가상 키보드와 병행 | 생성형 | [[시범콘텐츠 공통 사양#사. 텍스트 입력]] |
| 선택 카드 + 하이라이트 | 후보 항목을 카드로 나열하고 1개 선택 시 하이라이트. 그리드(캐릭터 8종)나 병렬(유형 3~4종) 배치 | 생성형 | 각 UI 캐릭터/유형 선택 화면 |
| 제한시간 선택지 버튼 | 반응 윈도우가 열릴 때만 뜨는 대거리 선택지 2~3개. 남은 시간 표시 동반 | 버나 | [[버나 - 버나잡이 한 판 UI]] |
| 페이지/컷 넘김 컨트롤 | 결과물 뷰어의 좌우 넘김과 줌. 스와이프 병행 가능 | 생성형 | [[덜미 - 나만의 유람기 UI]], [[덧뵈기 - 양반 놀리기 4컷 UI]] |

음성 입력 버튼은 화면에 보이는 위젯 이름임. 음성 텍스트 변환(STT)은 버튼을 누른 뒤 일어나는 변환 동작이라, "STT 버튼"으로 부르면 위젯과 동작이 섞임. 위젯명을 우선함.

# 4. 개발 착수 우선순위

재사용 범위가 넓은 순으로 만들면 5종이 함께 이득을 봄. 아래 순서를 권함.

1. **전체 공유부터**: §2 레이아웃 기반(3영역 프레임과 중앙 도달 존), 주 버튼과 보조 버튼, 헤더 제목 라벨과 안내 문구, 숫자 키패드, 원 버튼 팝업(§3.마), 호스트 캐릭터 슬롯. 5종 모두 즉시 씀
2. **생성형 공유**: 텍스트 입력 필드, 가상 키보드, 음성 입력 버튼, 선택 카드, 단계 진행 인디케이터, 페이지형 뷰어. 유람기와 양반 놀리기가 공유
3. **체험형 공유**: 신명 게이지, 카메라 뷰, 합성 프레임, 모션 가이드, 결과물 카드. 꼭두각시, 탈춤, 버나가 공유
4. **콘텐츠 한둘 전용**: 타임드 선택지와 난이도 표시(버나), 얼굴 정렬 가이드(꼭두각시), 카운트다운과 잔여 촬영 배지(촬영 콘텐츠). 공용 우선순위에서 뒤로 둠

디자인 토큰(색상, 치수, 폰트 크기)과 상태 스타일은 본 문서 밖이며 디자인 단계에서 확정함(확인 필요).
