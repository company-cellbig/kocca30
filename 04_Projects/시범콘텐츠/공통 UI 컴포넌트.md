> 키오스크 시범콘텐츠 5종의 UI 개발 착수 전, 화면별로 흩어진 UI 요소를 위젯 단위 공통 컴포넌트로 모은 인벤토리. 각 컴포넌트를 구성 요소로 쪼개고 담당([아트]/[개발])을 표기해 아트 디자이너와 프로그래머가 무엇을 만들지 알게 함. 재사용 범위(전체/생성형/체험형/그 외)로 공용 개발 우선순위를 드러냄.

# 1. 개요

## 1.1 목적과 범위

- **목적**: UI 개발에 앞서 화면이 아니라 위젯(버튼, 라벨, 키보드 등) 단위로 공통 컴포넌트를 모아, 한 번 만들어 5종이 재사용할 기반을 정함
- **담는 것**: 2개 이상 화면이나 콘텐츠가 공유하는 재사용 컴포넌트. 각 컴포넌트를 역할, 구성 요소(만들 시각 자산과 동작), 재사용 범위로 정리함
- **담지 않는 것**: 화면 단위 흐름과 레이아웃(각 UI 문서 소관), 콘텐츠 고유 1회성 요소(각 UI 문서와 기획서 소관), 시각 스타일과 색상, 치수 같은 디자인 토큰(디자인 단계 확정, 확인 필요)

## 1.2 재사용 범위 표기

컴포넌트마다 어느 콘텐츠가 쓰는지를 표기함. 넓게 쓰이는 순으로 만들면 5종이 함께 이득을 보므로, 이 표기가 곧 개발 착수 순서임: 레이아웃 기반([[#2. 레이아웃 기반]])과 전체 표기를 먼저 만들고, 그다음 생성형이나 체험형(두세 콘텐츠 공유), 그 외(한둘 전용) 순으로 둠.

- **전체**: 5종 모두 공유
- **생성형**: [[덜미 - 나만의 유람기 UI|유람기]], [[덧뵈기 - 양반 놀리기 4컷 UI|양반 놀리기]] (텍스트 문답으로 결과물 생성)
- **체험형**: [[덜미 - 나만의 꼭두각시 UI|꼭두각시]], [[덧뵈기 - 나만의 탈춤 UI|탈춤]], [[버나 - 버나잡이 한 판 UI|버나]] (카메라나 센서 기반 체험)
- **그 외**: 위 세 묶음에 걸치지 않으면 쓰는 콘텐츠를 그대로 적음(예: 버나, 꼭두각시와 탈춤)

# 2. 레이아웃 기반

모든 컴포넌트가 놓이는 공통 골격임. 개별 위젯에 앞서 이 프레임을 먼저 구현함.

- **16:9 3영역 프레임**: 화면 기본 골격. 재사용 전체.
	- 헤더 영역: 상단, 제목이나 상태를 얹는 표시 전용 띠 [아트+개발]
	- 본문 영역: 중앙, 주기능 하나를 담는 최대 비중 영역 [아트+개발]
	- 액션 영역: 본문 아래, 버튼을 놓는 조작 띠 [아트+개발]
	- 호스트 슬롯: 위 영역들에 걸쳐 진행 호스트가 들어갈 자리 [아트+개발]
- **중앙 도달 존**: 만들 위젯이 아니라 위 프레임에 조작 요소를 놓는 배치 규칙임. 터치 조작 요소는 가운데 폭, 눈높이에서 허리 사이에 모으고 좌우 끝과 상하 가장자리에는 두지 않음. 구체 치수는 설계와 설치 단계에서 확정함(확인 필요).

# 3. 컴포넌트 카탈로그

각 컴포넌트를 역할 한 줄과 구성 요소로 나눔. 구성 요소마다 담당을 대괄호로 표기함: [아트]는 아트 디자이너가 만드는 시각 자산, [개발]은 프로그래머가 만드는 동작과 로직, [아트+개발]은 둘 다 필요함.

## 3.1 버튼류

- **버튼**: 터치 시 할당 기능을 실행하는 기본 버튼. 강조 정도와 라벨은 화면마다 각 UI 문서가 정함. 재사용 전체.
	- 기본 이미지: 평상시 버튼 모양 [아트]
	- 비활성 이미지: 터치 불가 상태 모양, 흐리게 처리 등 [아트]
	- 텍스트 영역: 라벨 문구를 얹는 자리, 문구는 후편집으로 넣음 [아트+개발]
	- 터치 피드백: 누르는 순간의 눌림 애니메이션이나 사운드 [아트+개발]
	- 터치 동작: 활성 상태일 때만 할당 기능 실행 [개발]
- **홈 버튼**: 상호작용 화면 상단에 상시 두는 원형 홈 버튼. 진행 중 종료 시스템의 유저 버튼으로, 터치 시 그만두기 확인 팝업을 띄워 종료를 확인받음. 현 단계에서는 이 형태로 확정함. 재사용 전체.
	- 기본 이미지: 원형 홈 아이콘 버튼, 주 버튼보다 약한 강조 [아트]
	- 눌림 이미지: 누르는 순간의 눌림 상태 [아트]
	- 터치 동작: 그만두기 확인 팝업 호출([[#3.5 팝업과 오버레이류]]의 그만두기 확인 팝업) [개발]
	- 배치: 헤더 좌상단 모서리에 원형 아이콘으로 상시 노출. 하단 액션 버튼 유무와 무관하게 같은 자리에 둠. 진행 중 종료를 적용하는 화면에 두고, 시작/대기/완주 마침 화면에는 두지 않음(동의 화면은 홈 버튼이 미동의 종료를 겸함) [개발]
- **언어 선택 요소**: 시작 화면에서 세션 언어를 고르는 요소. 고른 값이 세션 현재 언어가 되고 UI 카피와 AI 생성물이 그 언어를 따름(1차연도 한국어와 영어). 재사용 전체.
	- 선택 요소 이미지: 언어 토글이나 버튼 그래픽 [아트]
	- 선택 표시: 현재 언어 강조 [아트+개발]
	- 선택 동작: 고른 언어를 세션 현재 언어로 저장하고 화면 카피를 그 언어로 바꿈 [개발]
- **음성 입력 버튼**: 마이크 버튼. 음성을 받아 문자로 변환해 입력 필드에 채움(자동 제출 아님). 가상 키보드와 병행. 재사용 생성형.
	- 기본 이미지: 마이크 아이콘 버튼 [아트]
	- 녹음 중 이미지: 듣는 중 상태 표시, 색 변화나 파형 등 [아트]
	- 녹음 피드백: 말하는 동안의 반응 애니메이션이나 안내 [아트+개발]
	- 변환 동작: 마이크 입력을 음성 텍스트 변환(STT)해 입력 필드에 채움 [개발]
	- 실패 처리: 인식 실패나 무음 시 재시도 안내, 키보드로 전환 [개발]
- **선택 카드와 하이라이트**: 후보 항목을 카드로 나열하고 1개를 고름. 재사용 생성형.
	- 카드 이미지: 후보별 일러스트, 캐릭터나 마당/유형 [아트]
	- 선택 하이라이트: 고른 카드를 강조하는 테두리나 발광 [아트]
	- 카드 라벨: 카드 이름 자리 [아트+개발]
	- 선택 동작: 1개 선택 시 이전 선택 해제(단일 선택), 미선택이면 다음 비활성 [개발]
	- 배치: 그리드나 병렬. 후보 수는 화면이 정함 [개발]
- **제한 시간 선택지 버튼**: 반응 윈도우가 열릴 때만 뜨는 대거리 선택지 2~3개. 재사용 버나.
	- 선택지 버튼: 대거리 문구를 담은 버튼 여러 개 [아트+개발]
	- 남은 시간 표시: 반응 시간이 줄어드는 게이지나 숫자 [아트+개발]
	- 등장과 퇴장 연출: 윈도우 열림과 닫힘 애니메이션 [아트]
	- 선택 동작: 제한 시간 안에 1개 선택, 넘기면 무응답 판정 [개발]
- **페이지와 컷 넘김 컨트롤**: 결과물 뷰어의 좌우 넘김과 확대. 재사용 생성형.
	- 넘김 버튼 이미지: 좌우 화살표 [아트]
	- 확대 컨트롤: 줌 버튼이나 확대 제스처 [아트+개발]
	- 넘김 동작: 페이지나 컷 이동, 스와이프 병행 [개발]
	- 위치 감지: 현재 페이지와 마지막 페이지 판정 [개발]


## 3.2 텍스트와 라벨류

- **헤더 제목 라벨**: 화면 상단 제목이나 콘텐츠 타이틀. 표시 전용. 재사용 전체.
	- 텍스트 영역: 제목 문구를 얹는 자리, 문구는 후편집 [아트+개발]
	- 표시 스타일: 헤더 배경과 글자 위계, 표시 전용 비조작 [아트]
	- 내용 주입: 화면이 제목 문자열을 넣음 [개발]
- **안내 문구**: 본문 상단 한 줄 지시문. 재사용 전체(화면별 문구는 각 화면이 넣으며 UI 문서의 예시 문구는 표본임).
	- 텍스트 영역: 지시문 자리 [아트+개발]
	- 내용 주입: 화면별 안내 문구를 넣음, 예: 이름을 지어 주세요 [개발]
- **상태 문구**: 대기 화면의 진행 상태 텍스트. 재사용 대기 있는 콘텐츠.
	- 텍스트 영역: 상태 문구 자리 [아트+개발]
	- 내용 갱신: 백엔드 진행 상태(생성 중, 완료, 실패)에 따라 바꿈 [개발]
- **말풍선**: 호스트가 질문이나 재담을 던지는 대사 표시. 재사용 생성형과 버나.
	- 말풍선 이미지: 대사를 담는 풍선 그래픽 [아트]
	- 텍스트 영역: 질문이나 재담 문구 자리 [아트+개발]
	- 내용 주입: 사전 생성 고정 질문이나 재담을 넣음 [개발]
	- 등장 연출: 나타나는 애니메이션, 선택 [아트]
- **약관 텍스트 영역**: 동의 화면의 스크롤 가능한 약관 본문. 재사용 전체.
	- 스크롤 박스: 긴 약관을 담는 스크롤 영역 [아트+개발]
	- 텍스트 내용: 약관 본문, 규정 검토 확정 [개발]
	- 스크롤 동작: 터치로 위아래 스크롤 [개발]

## 3.3 입력류

- **텍스트 입력 필드**: 이름이나 서술형 응답을 담는 필드. 재사용 생성형.
	- 필드 이미지: 입력 박스 모양 [아트]
	- 입력 상태 표시: 커서와 입력 중 표시 [아트+개발]
	- 텍스트 표시: 입력된 글자 표시 [개발]
	- 입력 수집: 키보드와 음성 입력을 받아 필드에 채움 [개발]
	- 검증 상태: 빈 입력이면 다음 비활성, 한글 조합 중 제출 막음, 위반 시 안내 [개발]
- **이름 랜덤 입력 버튼**: 텍스트 입력 필드 옆 보조 입력 수단. 사전 검수한 이름 풀에서 하나를 랜덤으로 뽑아 필드를 채움([[덜미 - 나만의 유람기 UI|유람기]], [[덧뵈기 - 양반 놀리기 4컷 UI|양반 놀리기]]의 이름 입력). 재사용 생성형.
	- 기본 이미지: 랜덤 채움 버튼 모양 [아트]
	- 채움 동작: 사전 이름 풀에서 랜덤으로 하나를 골라 입력 필드에 채움. 직전 이름 중복 회피, 현재 언어(세션) 반영 [개발]
	- 재입력 연동: 채운 이름은 일반 입력과 동일하게 편집하거나 다시 눌러 바꿀 수 있고, 제출 시 유효성 검증을 그대로 받음 [개발]
- **가상 키보드 (한글)**: 화면 하단 밴드에 한정하는 한글 키보드. 재사용 생성형.
	- 키 이미지: 자모와 기능 키 그래픽 [아트]
	- 키 눌림 피드백: 눌린 키 표시나 소리 [아트+개발]
	- 자판 배열: 한글 자판, 하단 밴드에 한정해 질문과 필드를 가리지 않음 [아트+개발]
	- 입력 동작: 키 입력을 한글로 조합해 필드에 전달 [개발]

## 3.4 진행과 상태 표시류 (비조작)

터치를 받지 않는 표시 전용이라 터치 동작 구성 요소가 없음.

- **결과물 QR 코드**: 결과물 다운로드 주소를 인코딩해 표시하는 QR. 유저가 본인 휴대폰으로 스캔해 웹에서 결과물을 받음(결과물 다운로드용). 재사용 전체.
	- QR 이미지: 다운로드 URL을 인코딩한 QR 그래픽 [아트+개발]
	- 내용 주입: 백엔드가 발급한 만료형 다운로드 URL을 인코딩 [개발]
- **진행 인디케이터**: 생성이나 변환 대기 중 진행 표시. 재사용 대기 있는 콘텐츠.
	- 인디케이터 이미지: 원형이나 바 그래픽 [아트]
	- 진행 애니메이션: 회전이나 채워짐 [아트+개발]
	- 진행값 반영: 상태 조회로 받은 진행률 반영, 있으면 [개발]
- **단계 진행 인디케이터**: 다단계 반복의 현재 위치 표시. 재사용 생성형.
	- 단계 노드: 각 단계 아이콘, 도입/전개/절정/마무리나 기/승/전/결 등 [아트]
	- 현재 위치 강조: 진행 중 단계 하이라이트 [아트]
	- 상태 반영: 현재 단계로 갱신 [개발]
- **신명 게이지**: 채점이 쌓일수록 차오르는 상승형 보상 게이지. 재사용 체험형.
	- 게이지 이미지: 빈 상태와 찬 상태 그래픽 [아트]
	- 라벨: "신명" 표시 [아트+개발]
	- 상승 연출: 차오르는 애니메이션과 이펙트 [아트+개발]
	- 값 반영: 실시간 채점 결과로 수치 갱신 [개발]
- **난이도 단계 표시**: 재담 대결 난이도 단계 표시. 재사용 버나.
	- 단계 이미지: 난이도 표시 그래픽 [아트]
	- 값 반영: 현재 난이도로 갱신 [개발]
- **카운트다운 오버레이**: 자동 촬영까지 남은 시간을 큰 숫자로 표시. 1컷만 찍으므로 잔여 횟수 배지는 두지 않음. 재사용 꼭두각시와 탈춤.
	- 숫자 표시: 본문 위 큰 카운트 숫자 [아트]
	- 카운트 연출: 3에서 0까지 애니메이션과 찰칵 효과 [아트+개발]
	- 타이머 동작: 0이 되면 자동 촬영을 트리거 [개발]
- **등급 스탬프**: 결과물 위에 점수와 등급을 도장처럼 표기. 재사용 체험형.
	- 스탬프 이미지: 등급별 도장 그래픽 [아트]
	- 점수와 등급 텍스트: 표기 자리 [아트+개발]
	- 값 반영: 신명 게이지 결과로 등급 결정 [개발]

## 3.5 팝업과 오버레이류

세 팝업 모두 어둡게 깐 배경 위 중앙 카드를 공유함. 실패 안내와 위반 안내는 버튼 하나(원 버튼 팝업)이고, 그만두기 확인은 버튼 둘(계속하기와 그만두기)임. 하나의 모달 컴포넌트로 만들고 아이콘, 메시지, 버튼 수와 라벨을 파라미터로 두는 방식을 권함(설계 단계 확정, 확인 필요).

- **실패 안내 모달 팝업**: 실패 분기가 모이는 상황 안내 팝업. 재사용 전체.
	- 딤 배경: 직전 화면을 어둡게 까는 오버레이 [아트+개발]
	- 카드 이미지: 중앙 다이얼로그 카드 [아트]
	- 경고 아이콘: 카드 안 아이콘 [아트]
	- 메시지 영역: 상황 안내 메시지 자리, 오류 코드는 노출 안 함 [아트+개발]
	- 버튼: 확인 버튼 1개([[#3.1 버튼류]]의 버튼 재사용). "처음으로" 버튼은 두지 않음(모든 실패는 종료 Step으로만 빠져나감) [아트+개발]
	- 등장 연출: 카드가 뜨는 애니메이션 [아트]
	- 진행 동작: 확인을 누르면 즉시 종료 Step으로, 누르지 않아도 잠깐 뒤 자동 진행 [개발]
- **위반 안내 팝업**: 비속어나 가드레일 위반 시 재입력 안내 팝업. 재사용 생성형.
	- 딤 배경과 카드: 실패 안내 팝업과 공유 [아트]
	- 메시지 영역: 재입력 안내 문구 자리 [아트+개발]
	- 버튼: 확인 버튼 1개([[#3.1 버튼류]]의 버튼 재사용) [아트+개발]
	- 재입력 동작: 확인하면 같은 화면에서 재입력 [개발]
	- 남은 기회 표시: 메시지에 몇 번 더 걸리면 체험이 끝나는지 함께 보여줌. 한도에 닿으면 팝업 없이 종료 Step으로 보내므로 별도 위반 종료 팝업을 두지 않음 [개발]
- **그만두기 확인 팝업**: 홈 버튼 터치 시 세션 중도 종료를 확인받는 두 버튼 팝업. 재사용 전체.
	- 딤 배경과 카드: 실패 안내 팝업과 공유 [아트]
	- 메시지 영역: 그만두기 확인 문구 자리 [아트+개발]
	- 버튼: 계속하기(주, 원래 화면 복귀)와 그만두기(보조, 세션 종료) 두 버튼([[#3.1 버튼류]]의 버튼 재사용) [아트+개발]
	- 진행 동작: 계속하기 시 팝업을 닫고 복귀, 그만두기 시 종료 Step 직행 [개발]

## 3.6 진행 호스트

- **호스트 캐릭터 슬롯**: 콘텐츠별 인물(박첨지, 말뚝이, 산받이, 매호씨)을 담는 공통 슬롯. 재사용 전체.
	- 캐릭터 비주얼: 인물 스틸이나 애니메이션, 2D 플랫 [아트]
	- 표정 세트: 표정 슬롯별 이미지 [아트]
	- 위치 배치: 측면 안내(공통), 중앙 반응과 작별(결과와 종료 화면), 축소나 숨김(본문이 화면을 다 쓰는 창작, 카메라, 무대 화면). 전면 화자는 호스트가 질문을 던지는 문답 화면을 가진 콘텐츠만 씀 [아트+개발]
	- 음성: 대사와 추임새, 실시간 합성(TTS)이나 녹음 클립 [아트+개발]
	- 발화 연출: 말할 때 입 모양이나 모션, 선택 [아트]
	- 슬롯 제어: 사용 여부, 노출 상태, 위치와 표정과 발화 상태를 공통 엔진이 받아 렌더 [개발]

인물과 슬롯의 구체 값은 콘텐츠별로 각 UI 문서와 기획서가 채움.

## 3.7 카메라와 모션류

체험형 일부만 씀. 카메라 화면은 도달 존 예외라 터치 버튼을 두지 않는 경우가 많음([[시범콘텐츠 공통 사양#5.1 공통 영역 골격 (16:9 가로)]] 모션과 카메라 화면 예외).

- **카메라 뷰**: 사용자 정면이나 전신 실시간 영상. 재사용 꼭두각시와 탈춤.
	- 영상 표시 영역: 카메라 프레임을 비추는 뷰 [아트+개발]
	- 카메라 입력: 실시간 프레임 수신 [개발]
- **얼굴 정렬 가이드**: 얼굴을 프레임에 맞추게 하는 가이드. 재사용 꼭두각시.
	- 타원 프레임 이미지: 얼굴 맞출 프레임과 정렬 마크 [아트]
	- 검출 피드백: 얼굴 검출과 미검출 상태 표시 [아트+개발]
	- 정렬 판정: 얼굴 위치를 확인해 촬영 준비 판정 [개발]
- **합성 프레임**: 사용자 옆에 아바타나 탈 캐릭터를 합성한 한 장 구도. 재사용 꼭두각시와 탈춤.
	- 합성 구도: 사용자와 캐릭터를 한 장에 담는 프레임 [아트]
	- 캐릭터 오버레이: 옆에 얹는 아바타나 탈 캐릭터 [아트+개발]
	- 합성 동작: 카메라 뷰 위에 실시간 합성 [개발]
- **동작 시연 가이드**: 따라 할 동작을 보여주는 가이드. 두 콘텐츠가 공유하는 것은 시연 비주얼과 인식 처리뿐이고, 그 위에 얹는 힌트는 콘텐츠마다 다름. 재사용 꼭두각시와 탈춤.
	- 동작 가이드 비주얼: 시연 아바타나 실루엣 [아트]
	- 인식 처리: 포즈나 손 추적 입력 처리, 저신뢰 시 재시도 안내 [개발]
- **양손 조작 힌트와 리듬 인디케이터**: 인형 조작의 양손 힌트와 장단 타이밍 표시. 탈춤은 전신 춤사위라 쓰지 않음. 재사용 꼭두각시.
	- 손 실루엣 힌트: 양손 조작을 나타내는 실루엣 [아트]
	- 리듬 인디케이터: 장단 타이밍 표시 [아트+개발]

## 3.8 결과물 뷰어류

- **페이지형 뷰어**: 전자책이나 4컷 만화를 페이지나 컷으로 감상. 재사용 생성형.
	- 페이지 표시 영역: 전자책 페이지나 만화 컷을 크게 보여주는 영역 [아트+개발]
	- 넘김 컨트롤: 좌우 넘김과 확대([[#3.1 버튼류]]의 페이지와 컷 넘김 컨트롤 재사용) [아트+개발]
	- 넘김 연출: 페이지 넘기는 애니메이션 [아트]
	- 표시 동작: 페이지나 컷 로드와 이동. QR은 마지막 페이지 도달과 무관하게 화면 진입 시부터 함께 보임(감상과 받기가 한 화면) [개발]
- **결과물 카드**: 기념 사진이나 기록증을 결과물 감상과 받기 화면에 카드로 표시함. 재사용 체험형.
	- 카드 프레임 이미지: 결과물을 담는 카드나 템플릿 [아트]
	- 결과물 이미지: 꼭두각시와 탈춤은 AI 생성 파이프라인이 만든 기념 사진, 버나는 사전 제작 템플릿에 세션 수치를 얹은 기록증 [아트+개발]
	- 등급 스탬프: 점수와 등급 표기([[#3.4 진행과 상태 표시류 (비조작)]]의 등급 스탬프 재사용) [아트+개발]
	- 표시 동작: 완성된 결과물 로드와 표시 [개발]
