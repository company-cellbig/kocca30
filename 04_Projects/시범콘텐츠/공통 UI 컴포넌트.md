> 키오스크 시범콘텐츠 5종의 UI 개발 착수 전, 화면별로 흩어진 UI 요소를 위젯 단위 공통 컴포넌트로 모은 인벤토리. 화면 골격 정본은 [[시범콘텐츠 공통 사양#5. 공통 화면]], 화면별 배치는 각 UI 문서가 정본이고, 본 문서는 그 컴포넌트를 여러 콘텐츠에 걸쳐 한데 모음. 각 컴포넌트를 구성 요소로 쪼개고 담당([아트]/[개발])을 표기해 아트 디자이너와 프로그래머가 무엇을 만들지 알게 함. 재사용 범위(전체/생성형/체험형/일부)로 공용 개발 우선순위를 드러냄.

# 1. 개요

## 가. 목적과 범위

- **목적**: UI 개발에 앞서 화면이 아니라 위젯(버튼, 라벨, 키보드 등) 단위로 공통 컴포넌트를 모아, 한 번 만들어 5종이 재사용할 기반을 정함
- **담는 것**: 2개 이상 화면이나 콘텐츠가 공유하는 재사용 컴포넌트. 각 컴포넌트를 역할, 구성 요소(만들 시각 자산과 동작), 재사용 범위, 정본 위치로 정리함
- **담지 않는 것**: 화면 단위 흐름과 레이아웃(각 UI 문서 소관), 콘텐츠 고유 1회성 요소(각 UI 문서와 기획서 소관), 시각 스타일과 색상, 치수 같은 디자인 토큰(디자인 단계 확정, 확인 필요)
- **출처**: 5종 UI 문서와 [[시범콘텐츠 공통 사양#5. 공통 화면]], [[시범콘텐츠 공통 사양#13. 공용 화면 예시 이미지]]에서 반복 등장하는 요소를 추출함

## 나. 재사용 범위 표기

컴포넌트마다 어느 콘텐츠가 쓰는지를 아래 넷으로 표기함. 개발 우선순위 판단용임(§4 개발 착수 우선순위).

- **전체**: 5종 모두 공유
- **생성형**: [[덜미 - 나만의 유람기 UI|유람기]], [[덧뵈기 - 양반 놀리기 4컷 UI|양반 놀리기]] (텍스트 문답으로 결과물 생성)
- **체험형**: [[덜미 - 나만의 꼭두각시 UI|꼭두각시]], [[덧뵈기 - 나만의 탈춤 UI|탈춤]], [[버나 - 버나잡이 한 판 UI|버나]] (카메라나 센서 기반 체험)
- **일부**: 위 분류와 무관하게 특정 콘텐츠 한둘만 씀

## 다. 정본 경계

본 문서는 컴포넌트 색인이며, 각 컴포넌트의 동작 정본은 아래 문서가 소유함. 충돌 시 정본이 우선임.

- **화면 골격과 공용 동작**: [[시범콘텐츠 공통 사양#5. 공통 화면]] (16:9 3영역, 도달성, 각 공통 화면 흐름)
- **진행 호스트 계약**: [[시범콘텐츠 공통 사양#6. 진행 호스트]] (화면 상태 모델, 설정 스키마)
- **텍스트 입력과 음성**: [[시범콘텐츠 공통 사양#사. 텍스트 입력]]
- **화면별 배치와 변형**: 각 UI 문서(§5 관련 문서)
- **2차연도 이어하기(QR 스캔)**: [[플랫폼 사양#6. 2차연도 전방 설계 (디지털 도제 연속성, 현재 구현 밖)]] (1차연도 미구현)

# 2. 레이아웃 기반

모든 컴포넌트가 놓이는 공통 골격임. 개별 위젯에 앞서 이 프레임을 먼저 구현함.

- **16:9 3영역 프레임**: 화면 기본 골격. 재사용 전체, 정본 [[시범콘텐츠 공통 사양#가. 공통 영역 골격 (16:9 가로)]].
	- 헤더 영역: 상단, 제목이나 상태를 얹는 표시 전용 띠 [아트+개발]
	- 본문 영역: 중앙, 주기능 하나를 담는 최대 비중 영역 [아트+개발]
	- 액션 영역: 본문 아래, 버튼을 놓는 조작 띠 [아트+개발]
	- 호스트 슬롯: 위 영역들에 걸쳐 진행 호스트가 들어갈 자리 [아트+개발]
- **중앙 도달 존 컨테이너**: 터치 조작 요소를 손 닿는 범위에 모으는 배치 규칙. 재사용 전체, 정본 [[시범콘텐츠 공통 사양#가. 공통 영역 골격 (16:9 가로)]].
	- 도달 존 범위: 가운데 폭, 눈높이~허리. 조작 요소를 여기에 모음(구체 치수는 설계와 설치 단계 확정, 확인 필요) [개발]
	- 배제 영역: 좌우 끝과 상하 가장자리. 여백과 연출로 두고 조작 요소를 두지 않음 [개발]

# 3. 컴포넌트 카탈로그

각 컴포넌트를 역할 한 줄과 구성 요소로 나눔. 구성 요소마다 담당을 대괄호로 표기함: [아트]는 아트 디자이너가 만드는 시각 자산, [개발]은 프로그래머가 만드는 동작과 로직, [아트+개발]은 둘 다 필요함. 시각 스타일과 치수 같은 디자인 토큰은 본 문서 밖이며 디자인 단계에서 확정함(§4 끝, 확인 필요).

## 가. 버튼류

- **버튼**: 터치 시 할당 기능을 실행하는 기본 버튼. 강조 정도와 라벨은 화면마다 각 UI 문서가 정함. 재사용 전체, 정본 [[시범콘텐츠 공통 사양#5. 공통 화면]].
	- 기본 이미지: 평상시 버튼 모양 [아트]
	- 비활성 이미지: 터치 불가 상태 모양, 흐리게 처리 등 [아트]
	- 텍스트 영역: 라벨 문구를 얹는 자리, 문구는 후편집으로 넣음 [아트+개발]
	- 터치 피드백: 누르는 순간의 눌림 애니메이션이나 사운드 [아트+개발]
	- 터치 동작: 활성 상태일 때만 할당 기능 실행 [개발]
- **그만두기 버튼**: 상호작용 화면 액션 영역에 상시 두는 보조 버튼. 진행 중 종료 시스템의 유저 버튼으로, 터치 시 그만두기 확인 팝업을 띄워 종료를 확인받음(동의 화면의 미동의 그만두기도 이 버튼과 팝업을 공유). 재사용 전체, 정본 [[시범콘텐츠 공통 사양#아. 그만두기 확인 팝업]].
	- 기본 이미지: 보조 버튼 모양, 주 버튼보다 약한 강조 [아트]
	- 텍스트 영역: "그만두기" 라벨 자리 [아트+개발]
	- 터치 동작: 그만두기 확인 팝업 호출(§3.마 그만두기 확인 팝업) [개발]
	- 배치: 액션 영역 주 버튼 옆, 중앙 도달 존 [개발]
- **음성 입력 버튼**: 마이크 버튼. 음성을 받아 문자로 변환해 입력 필드에 채움(자동 제출 아님). 가상 키보드와 병행. 재사용 생성형, 정본 [[시범콘텐츠 공통 사양#사. 텍스트 입력]].
	- 기본 이미지: 마이크 아이콘 버튼 [아트]
	- 녹음 중 이미지: 듣는 중 상태 표시, 색 변화나 파형 등 [아트]
	- 녹음 피드백: 말하는 동안의 반응 애니메이션이나 안내 [아트+개발]
	- 변환 동작: 마이크 입력을 음성 텍스트 변환(STT)해 입력 필드에 채움 [개발]
	- 실패 처리: 인식 실패나 무음 시 재시도 안내, 키보드로 전환 [개발]
- **선택 카드와 하이라이트**: 후보 항목을 카드로 나열하고 1개를 고름. 재사용 생성형, 정본 각 UI 캐릭터/유형 선택 화면.
	- 카드 이미지: 후보별 일러스트, 캐릭터나 마당/유형 [아트]
	- 선택 하이라이트: 고른 카드를 강조하는 테두리나 발광 [아트]
	- 카드 라벨: 카드 이름 자리 [아트+개발]
	- 선택 동작: 1개 선택 시 이전 선택 해제(단일 선택), 미선택이면 다음 비활성 [개발]
	- 배치: 그리드나 병렬. 후보 수는 화면이 정함 [개발]
- **제한시간 선택지 버튼**: 반응 윈도우가 열릴 때만 뜨는 대거리 선택지 2~3개. 재사용 버나, 정본 [[버나 - 버나잡이 한 판 UI]].
	- 선택지 버튼: 대거리 문구를 담은 버튼 여러 개 [아트+개발]
	- 남은 시간 표시: 반응 시간이 줄어드는 게이지나 숫자 [아트+개발]
	- 등장과 퇴장 연출: 윈도우 열림과 닫힘 애니메이션 [아트]
	- 선택 동작: 제한 시간 안에 1개 선택, 넘기면 무응답 판정 [개발]
- **페이지와 컷 넘김 컨트롤**: 결과물 뷰어의 좌우 넘김과 확대. 재사용 생성형, 정본 [[덜미 - 나만의 유람기 UI]], [[덧뵈기 - 양반 놀리기 4컷 UI]].
	- 넘김 버튼 이미지: 좌우 화살표 [아트]
	- 확대 컨트롤: 줌 버튼이나 확대 제스처 [아트+개발]
	- 넘김 동작: 페이지나 컷 이동, 스와이프 병행 [개발]
	- 위치 감지: 현재 페이지와 마지막 페이지 판정 [개발]

음성 입력 버튼은 화면에 보이는 위젯 이름임. 음성 텍스트 변환(STT)은 버튼을 누른 뒤 일어나는 변환 동작이라, "STT 버튼"으로 부르면 위젯과 동작이 섞임. 위젯명을 우선함.

## 나. 텍스트와 라벨류

- **헤더 제목 라벨**: 화면 상단 제목이나 콘텐츠 타이틀. 표시 전용. 재사용 전체, 정본 [[시범콘텐츠 공통 사양#가. 공통 영역 골격 (16:9 가로)]].
	- 텍스트 영역: 제목 문구를 얹는 자리, 문구는 후편집 [아트+개발]
	- 표시 스타일: 헤더 배경과 글자 위계, 표시 전용 비조작 [아트]
	- 내용 주입: 화면이 제목 문자열을 넣음 [개발]
- **안내 문구**: 본문 상단 한 줄 지시문. 재사용 전체, 정본 각 UI 화면 내 텍스트.
	- 텍스트 영역: 지시문 자리 [아트+개발]
	- 내용 주입: 화면별 안내 문구를 넣음, 예: 이름을 지어 주세요 [개발]
- **상태 문구**: 대기 화면의 진행 상태 텍스트. 재사용 대기 있는 콘텐츠, 정본 [[시범콘텐츠 공통 사양#다. 생성과 변환 대기]].
	- 텍스트 영역: 상태 문구 자리 [아트+개발]
	- 내용 갱신: 백엔드 진행 상태(생성 중, 완료, 실패)에 따라 바꿈 [개발]
- **말풍선**: 호스트가 질문이나 재담을 던지는 대사 표시. 재사용 생성형과 버나, 정본 각 UI 문답/재담 화면.
	- 말풍선 이미지: 대사를 담는 풍선 그래픽 [아트]
	- 텍스트 영역: 질문이나 재담 문구 자리 [아트+개발]
	- 내용 주입: 사전 생성 고정 질문이나 재담을 넣음 [개발]
	- 등장 연출: 나타나는 애니메이션, 선택 [아트]
- **약관 텍스트 영역**: 동의 화면의 스크롤 가능한 약관 본문. 재사용 전체, 정본 [[시범콘텐츠 공통 사양#나. 인트로 (시작 + 동의)]].
	- 스크롤 박스: 긴 약관을 담는 스크롤 영역 [아트+개발]
	- 텍스트 내용: 약관 본문, 규정 검토 확정 [개발]
	- 스크롤 동작: 터치로 위아래 스크롤 [개발]

## 다. 입력류

- **텍스트 입력 필드**: 이름이나 서술형 응답을 담는 필드. 재사용 생성형, 정본 [[시범콘텐츠 공통 사양#사. 텍스트 입력]].
	- 필드 이미지: 입력 박스 모양 [아트]
	- 입력 상태 표시: 커서와 입력 중 표시 [아트+개발]
	- 텍스트 표시: 입력된 글자 표시 [개발]
	- 입력 수집: 키보드와 음성 입력을 받아 필드에 채움 [개발]
	- 검증 상태: 빈 입력이면 다음 비활성, 한글 조합 중 제출 막음, 위반 시 안내 [개발]
- **가상 키보드 (한글)**: 화면 하단 밴드에 한정하는 한글 키보드. 재사용 생성형, 정본 [[시범콘텐츠 공통 사양#사. 텍스트 입력]].
	- 키 이미지: 자모와 기능 키 그래픽 [아트]
	- 키 눌림 피드백: 눌린 키 표시나 소리 [아트+개발]
	- 자판 배열: 한글 자판, 하단 밴드에 한정해 질문과 필드를 가리지 않음 [아트+개발]

## 마. 팝업과 오버레이류

세 팝업 모두 어둡게 깐 배경 위 중앙 카드를 공유함. 실패 안내와 위반 안내는 버튼 하나(원 버튼 팝업)이고, 그만두기 확인은 버튼 둘(계속하기와 그만두기)임. 하나의 모달 컴포넌트로 만들고 아이콘, 메시지, 버튼 수와 라벨을 파라미터로 두는 방식을 권함(설계 단계 확정, 확인 필요).

- **실패 안내 모달 팝업**: 실패 분기가 모이는 상황 안내 팝업. 재사용 전체, 정본 [[시범콘텐츠 공통 사양#바. 실패 안내 (상황 안내 모달 팝업)]].
	- 딤 배경: 직전 화면을 어둡게 까는 오버레이 [아트+개발]
	- 카드 이미지: 중앙 다이얼로그 카드 [아트]
	- 경고 아이콘: 카드 안 아이콘 [아트]
	- 메시지 영역: 상황 안내 메시지 자리, 오류 코드는 노출 안 함 [아트+개발]
	- 버튼: 확인 버튼 1개(§3.가 버튼 재사용). "처음으로" 버튼은 두지 않음(모든 실패는 종료 Step으로만 빠져나감) [아트+개발]
	- 등장 연출: 카드가 뜨는 애니메이션 [아트]
	- 진행 동작: 확인을 누르면 즉시 종료 Step으로, 누르지 않아도 잠깐 뒤 자동 진행 [개발]
- **위반 안내 팝업**: 비속어나 가드레일 위반 시 재입력 안내 팝업. 재사용 입력 있는 콘텐츠, 정본 각 UI 상태별 안내.
	- 딤 배경과 카드: 실패 안내 팝업과 공유 [아트]
	- 메시지 영역: 재입력 안내 문구 자리 [아트+개발]
	- 버튼: 확인 버튼 1개(§3.가 버튼 재사용) [아트+개발]
	- 재입력 동작: 확인하면 같은 화면에서 재입력 [개발]
	- 남은 기회 표시: 메시지에 몇 번 더 걸리면 체험이 끝나는지 함께 보여줌. 한도에 닿으면 팝업 없이 종료 Step으로 보내므로 별도 위반 종료 팝업을 두지 않음 [개발]
- **그만두기 확인 팝업**: 그만두기 버튼 터치 시 세션 중도 종료를 확인받는 두 버튼 팝업. 재사용 전체, 정본 [[시범콘텐츠 공통 사양#아. 그만두기 확인 팝업]].
	- 딤 배경과 카드: 실패 안내 팝업과 공유 [아트]
	- 메시지 영역: 그만두기 확인 문구 자리 [아트+개발]
	- 버튼: 계속하기(주, 원래 화면 복귀)와 그만두기(보조, 세션 종료) 두 버튼(§3.가 버튼과 그만두기 버튼 재사용) [아트+개발]
	- 진행 동작: 계속하기 시 팝업을 닫고 복귀, 그만두기 시 종료 Step 직행 [개발]

# 4. 개발 착수 우선순위

재사용 범위가 넓은 순으로 만들면 5종이 함께 이득을 봄. 아래 순서를 권함.

1. **전체 공유부터**: §2 레이아웃 기반(3영역 프레임과 중앙 도달 존), 버튼, 그만두기 버튼, 헤더 제목 라벨과 안내 문구, 결과물 QR 코드, 원 버튼과 그만두기 확인 팝업(§3.마), 호스트 캐릭터 슬롯. 5종 모두 즉시 씀(그만두기 버튼과 확인 팝업은 동의 화면에서 5종 즉시 쓰고, 세션 중간 진행 중 종료 배치는 콘텐츠별 마이그레이션 후 연결함)
2. **생성형 공유**: 텍스트 입력 필드, 가상 키보드, 음성 입력 버튼, 선택 카드, 단계 진행 인디케이터, 페이지형 뷰어. 유람기와 양반 놀리기가 공유
3. **체험형 공유**: 신명 게이지, 카메라 뷰, 합성 프레임, 모션 가이드, 결과물 카드. 꼭두각시, 탈춤, 버나가 공유
4. **콘텐츠 한둘 전용**: 제한시간 선택지와 난이도 표시(버나), 얼굴 정렬 가이드(꼭두각시), 카운트다운과 잔여 촬영 배지(촬영 콘텐츠). 공용 우선순위에서 뒤로 둠

디자인 토큰(색상, 치수, 폰트 크기)과 상태 스타일은 본 문서 밖이며 디자인 단계에서 확정함(확인 필요).
