> [[남사당놀이]] 6종목의 시범콘텐츠 종목별 콘셉트 기획 초안. [[로드맵 1단계 1년차]] §8 시범서비스 시나리오 5종 선정의 입력 자료.

# 1. 개요

- 고증, 재미요소, 콘텐츠 볼륨의 3가지 요소를 지키며 종목별 콘셉트를 구성함
- 종목 — [[덜미]] / [[버나]] / [[덧뵈기]] / [[어름]] / [[살판]] / [[풍물]]

# 2. 전체 구조 정리

6종목 콘텐츠를 유형(체험/제작/관람)과 플랫폼(키오스크/미디어 케이브)으로 묶은 구조 개관. 종목별 상세는 §3. 표기는 「콘텐츠 (유형 / 플랫폼)」.

- 덜미
	- 나만의 꼭두각시 (체험 / 키오스크)
	- 나만의 유람기 (제작 / 키오스크)
- 버나
	- 버나잡이 한 판 (체험 / 키오스크)
- 덧뵈기
	- 나만의 탈춤 (체험 / 키오스크)
	- 양반 놀리기 4컷 (제작 / 키오스크)
	- 탈춤 군무 한마당 (관람 / 미디어 케이브)
- 어름
	- 어름산이 되기 (체험 / 키오스크)
	- 외줄 위의 어름산이 (관람 / 미디어 케이브)
- 살판
	- 곤두질 한 판 (관람 / 미디어 케이브)
- 풍물
	- 다 함께 풍물 한바탕 (체험 / 미디어 케이브)
	- 빛의 상모놀이 (체험 / 미디어 케이브)

# 3. 남사당놀이

## 가. 덜미

### 1) 나만의 꼭두각시

#### 가) 개요
- 사용자 얼굴 촬영 후 특징을 추출하여 전통 목각 인형 질감의 3D 아바타를 생성하고 그 아바타를 조작하는 콘텐츠
#### 나) 진행
1. 인트로
2. 사용자 얼굴 촬영
3. 아바타 생성(AI 이용)
4. 아바타 조작
	1. 산받이가 상황 + 미션 제시 (음성 재담): "어디서 온 누구인고? 유람가 한 자락 뽑아보게!"
	2. 사용자가 양손 조작 + 장단 타이밍으로 동작 수행 (리듬 게임 요소 결합)
	3. 산받이 실시간 추임새 채점 → 신명(興) 게이지 상승
	4. 골계적 반전 하이라이트 (홍동지 등장, 이시미 퇴치 등) = 결정적 Quick Time Event
5. 마무리 — 신명 게이지 달성 시 환호 사운드(군중 추임새/박수)로 거리 완성 / 미달 시 산받이가 적당히 눙치며 마무리(완만한 실패, 좌절 없음)

### 2) 나만의 유람기

#### 가) 개요
- 플롯별 유저 문답을 AI 스토리텔링과 생성형 삽화로 엮어 전자책으로 제작하는 콘텐츠
- 키보드 입력이 불편할 경우 STT도 병행 지원
#### 나) 진행
1. 인트로
2. 캐릭터 정보 입력
	1. 유저 정보가 아니며 스토리텔링에 영향을 줄 수 있는 요소로 남/녀, 유아/청소년/청년/장년의 8개 조합 제시
3. 플롯 문답
	1. AI가 뼈대(플롯) 단계별 질문 제시
	2. 사용자가 채움(텍스트 자유 입력)
4. 결과물 생성 + 대기 화면
5. 결과물 표시
6. 결과물 전송

## 나. 버나

### 1) 버나잡이 한 판

#### 가) 개요
- 버나잡이(사용자)가 [[버나]], 접시, 대접 등을 막대로 균형 잡아 돌리는 묘기와 대화자 [[매호씨]]와의 재담 대거리를 동시에 수행하는 키오스크 체험 콘텐츠
#### 나) 진행
1. 시작 — 키오스크 앞에서 버나잡이로 버나 잡기
2. 버나 돌리기 — 센서 막대(앵두나무막대기/곰방대 대응)로 버나, 접시, 대접 등의 회전, 균형, 낙하를 정밀 물리 시뮬레이션. 매호씨가 숙련도에 따라 실시간 추임새("얼씨구!", "밥 굶겠네") 제공
3. 매호씨 재담 대결 (돌리기와 동시 수행 = 극성)
	1. 매호씨가 안정 구간에 도발 재담과 소리로 끼어들어 집중 흔들기 ("그게 돌리는 거여?"), 반응 윈도우 열림
	2. 사용자가 돌리기를 유지하며 손 기반 대거리 선택지(2~3개) 중 택 (반응 윈도우 시간 제한)
	3. 적절성 판정
	4. 채점 = 대거리 적절성 × 묘기 유지 → 적절 시 매호씨 말문 막힘으로 신명(興) 게이지 상승 / 부적절이나 낙하 시 매호씨 승, 게이지 정체
	5. 난이도 상승 — 더 어려운 묘기(놋대야, 칼/바늘로 돌리기, 둘 동시)와 더 빠른 재담 공세 반복
4. 마무리 — 신명 게이지 달성 시 환호 사운드(군중 추임새/박수)로 버나 한 판 완성 / 미달 시 매호씨가 적당히 눙치며 마무리(완만한 실패)

## 다. 덧뵈기

### 1) 나만의 탈춤

#### 가) 개요
- 사용자가 디자인한 탈을 3D로 변환해 AR로 쓰고, 탈춤 춤사위를 따라 추며 탈 캐릭터와 기념 촬영하는 콘텐츠
#### 나) 진행
1. 탈 디자인 — 사용자가 탈을 직접 디자인
2. 3D 변환 — 디자인한 탈을 3D 모델로 변환
3. AR 착용 + 춤사위 따라하기
	1. 변환된 탈을 AR로 착용
	2. 화면이 제시하는 탈춤 춤사위를 풍물 장단에 맞춰 따라 추기
	3. 포즈 추정으로 자세 일치도 + 타이밍 채점 → 신명(興) 게이지 상승
	4. 게이지 달성 시 환호 사운드(군중 추임새/박수)로 보상
4. 기념 촬영 (포즈 챌린지) — 제한 시간 내 제시된 탈춤 정지 포즈를 정확히 취하면 베스트샷 캡처 + 점수/등급 스탬프가 찍힌 사진 제공

### 2) 양반 놀리기 4컷

#### 가) 개요
- '양반 놀리기' 등 풍자 템플릿에 키워드를 입력하면 사용자 탈을 쓴 캐릭터가 등장하는 4컷 만화를 AI가 생성하는 콘텐츠
- 키보드 입력이 불편할 경우 STT도 병행 지원
#### 나) 진행
1. 인트로
2. 캐릭터 정보 입력
	1. 유저 정보가 아니며 만화 각색에 영향을 줄 수 있는 요소로 남/녀, 유아/청소년/청년/장년의 8개 조합 제시
3. 풍자 템플릿 + 키워드 입력
	1. '양반 놀리기' 등 풍자 템플릿 제시
	2. 사용자가 키워드 입력(텍스트 자유 입력)
4. 결과물 생성 + 대기 화면
5. 결과물 표시 (4컷 만화)
6. 결과물 전송

### 3) 탈춤 군무 한마당

#### 가) 개요
- 관객이 디자인한 탈을 쓴 아바타가 미디어 케이브(벽면 투사로 공간감을 살리는 장치) 화면 속에서 함께 춤추는 모습을 관람하는 공연
#### 나) 진행
1. 아바타 합류 — 관객이 디자인한 탈 아바타가 미디어 케이브 무대에 등장
2. 군무 공연 — 벽면에 투사된 가상 무대에서 탈 아바타들이 함께 탈춤 군무를 펼침
3. 마무리 — 합동 군무 피날레로 공연 마무리

## 라. 어름

### 1) 어름산이 되기

#### 가) 개요
- 사용자가 [[어름산이]]가 되어 롤러 보드 위에서 균형을 잡으며, 줄 출렁임 효과와 [[매호씨]]의 실시간 자세 교정 코칭으로 줄타기를 체험하는 콘텐츠
#### 나) 진행
1. 롤러 보드 탑승 — 사용자가 어름산이가 되어 롤러 보드에 올라 줄타기 자세 준비
2. 줄타기 체험 (균형 + 자세 코칭)
	1. 롤러 보드 연동 줄 출렁임 속에서 균형을 유지하며 줄 위 전진 (이탈 시 신명 게이지 감소)
	2. 매호씨가 균형 흔들림을 실시간으로 짚어 자세 교정 코칭 ("팔 벌려 중심 잡게")
	3. 균형 안정도(흔들림이 적고 오래 버틸수록 높음) → 신명(興) 게이지 상승
	4. 곡예 미션 난이도 상승 (걷기 → 어려운 줄타기 재주)
3. 마무리 — 신명 게이지 달성 시 환호 사운드(군중 추임새/박수)로 줄타기 완수 / 미달 시 매호씨가 다독이며 마무리(완만한 실패)

### 2) 외줄 위의 어름산이

#### 가) 개요
- 미디어 케이브 정면에 줄과 [[어름산이]], 좌우에 풍물패와 [[매호씨]]가 펼쳐지고, 관객 호응도에 따라 어름산이의 곡예 난이도가 달라지는 인터랙티브 줄타기 관람 공연
#### 나) 진행
1. 무대 구성 — 미디어 케이브 정면에 줄과 어름산이, 좌우에 풍물패와 매호씨 배치
2. 인터랙티브 줄타기 공연
	1. 어름산이가 풍물 장단에 맞춰 줄 위에서 사위(곡예)를 시연
	2. 사위 중간중간 어름산이가 관객에게 질문을 던지고 매호씨가 재담으로 받음
	3. 관객 호응도(함성/박수)가 높을수록 다음 사위의 곡예 난이도 상승
3. 마무리 — 고난도 곡예 피날레로 공연 마무리

## 마. 살판

### 1) 곤두질 한 판

#### 가) 개요
- 미디어 케이브 4면에 [[살판쇠]]와 [[매호씨]]의 재담, 잽이의 장단에 맞춘 곤두질(땅재주)을 4DGS로 고실감 투사하는 관람 공연
#### 나) 진행
1. 공연 시작 — 미디어 케이브 4면에 살판 마당을 4DGS로 고실감 투사. 살판쇠, [[매호씨]], 잽이(악사) 등장
2. 살판 한 판
	1. 살판쇠와 매호씨가 재담을 주고받으며 판을 엶
	2. 잽이의 장단에 맞춰 살판쇠가 정해진 순서대로 곤두질(땅재주)을 펼침
	3. 곤두질 사이사이 매호씨와 재담이 이어짐
3. 마무리 — 고난도 곤두질 피날레로 공연 마무리

## 바. 풍물

### 1) 다 함께 풍물 한바탕

#### 가) 개요
- 미디어 케이브에서 여럿이 핸드 트래킹으로 가상 악기(꽹과리, 장구)를 함께 연주하며 소리와 반응을 공유하는 다중 참여 합주 체험
#### 나) 진행
1. 입장 — 미디어 케이브에 입장해 가상 악기(꽹과리, 장구 등) 선택
2. 합주 (리듬 + 앙상블 싱크)
	1. 풍물 장단 패턴에 맞춰 핸드 트래킹으로 악기를 타격, 타격 시점 타이밍 채점
	2. 참여자 간 타격 시점 일치도(앙상블 싱크)가 높을수록 집단 신명(興) 게이지 급상승
	3. 장단 난이도 상승 (느린 가락 → 자진모리 등 빠른 가락)
3. 마무리 — 신명 게이지 달성 시 환호 사운드(군중 추임새/박수)로 한바탕 합주 완성

### 2) 빛의 상모놀이

#### 가) 개요
- 무선 센서 모자를 쓰고 고개를 돌려 화면 속 거대 상모꾼 아바타의 화려한 빛의 궤적을 연동시키며 상모돌리기를 체험하는 콘텐츠
#### 나) 진행
1. 센서 모자 착용 — 무선 센서 모자를 쓰고 화면 속 상모꾼 아바타와 연결
2. 상모 돌리기 (게임)
	1. 고개 회전으로 상모꾼 아바타의 빛 궤적 생성
	2. 풍물 장단에 맞춰 제시된 궤적 패턴(원형, 8자 등)을 그리며 회전 정확도/지속 채점 → 신명(興) 게이지 상승
	3. 난이도 상승 (느린 회전 → 빠른 연속 회전)
3. 마무리 — 신명 게이지 달성 시 환호 사운드(군중 추임새/박수)로 상모놀이 완성
