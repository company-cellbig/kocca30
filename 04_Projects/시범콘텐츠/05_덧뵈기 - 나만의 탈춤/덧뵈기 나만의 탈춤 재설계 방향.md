> 장쇠가 세 마당의 진행을 맡고, 플레이어는 선택한 마당에 따라 꺽쇠, 말뚝이 또는 취발이가 됨. 옴탈잡이는 몸으로 피하고 몰아내며, 샌님잡이는 말의 허점을 집어내고, 먹중잡이는 취발이 등장 뒤 몸짓이 달라지는 순간을 지목함.

# 1. 재설계 목표

기존 덧뵈기의 세 마당을 하나의 판정 방식으로 묶지 않음. [[덧뵈기의 재미 요소]]가 구분한 희극 구조를 기준으로 마당마다 플레이어가 하는 일을 다르게 설계함.

| 마당 | 유저배역 | 상대배역 | 원형의 재미 | 유저배역이 하는 일 | 결과 |
|---|---|---|---|---|---|
| 옴탈잡이 | 꺽쇠 | 옴탈 | 기괴한 상대와 대치하고 몰아냄 | 피하고 밀어냄 | 옴탈이 과장되게 퇴장함 |
| 샌님잡이 | 말뚝이 | 샌님 | 높은 사람의 말을 이용해 권위를 무너뜨림 | 말의 허점을 집어내 재담으로 받아침 | 샌님의 체면이 깎임 |
| 먹중잡이 | 취발이 | 먹중 | 근엄한 인물의 욕망과 위선을 폭로함 | 수상한 몸짓이 나타난 순간을 지목함 | 지목 결과와 무관하게 먹중과 대결하고 퇴장으로 마당을 마침 |

세 마당을 관통하는 경험은 **겉으로 세운 질서가 플레이어의 개입으로 무너지는 과정**임. 조작을 통일하는 대신 관찰, 선택, 신체 반응이라는 참여 감각을 통일함.

## 1.1 문장 상태 판별 원칙

- **원형 근거**: `[원형 근거]`를 붙이고 출처 wikilink를 함께 적은 덧뵈기의 배역, 희극 구조와 표현 방식임
- **현재 설계안**: 별도 상태 표시가 없는 본문의 플레이 흐름, 입력, 판정과 연출임. 사용자 승인과 시험 전에는 확정 사양이 아님. `[사용자 확정]` 표시 항목은 제외함
- **확인 필요**: `[확인 필요]`를 붙이거나 [[#8. 제작 전에 확정할 항목]] 표에 넣은 원전 재대조, 사용자 결정, 기술 시험과 문화 자문 대상임

# 2. 설계 원칙

## 2.1 원형의 희극 구조를 먼저 보존함

- 캐릭터와 소재만 덧씌운 범용 미니게임을 만들지 않음. 각 마당의 조작은 해당 마당의 재담, 대치와 위선 폭로 구조에서 도출함.
- 각 마당의 도입에서 웃음이 성립하는 관계를 먼저 보여줌
- 성공 보상은 점수보다 상대 인물의 표정, 자세, 움직임이 무너지는 장면으로 줌
- 실패는 즉시 게임오버로 끊지 않고 새 재담이나 신체 코미디를 만드는 계기로 씀
- 원전의 배역, 원전에서의 마당 배열과 행위는 [[남사당놀이 - 덧뵈기]]와 다시 대조한 뒤 확정함

## 2.2 플레이어는 완성된 답을 고르지 않음

- 옴탈잡이에서는 접근 방향을 보고 몸으로 반응함
- 샌님잡이에서는 완성된 농담 대신 농담이 시작될 말의 허점을 찾음
- 먹중잡이에서는 결론을 맞히는 대신 취발이 등장 뒤 몸짓이 달라지는 시점을 판단함
- 선택지가 정답을 노출하지 않도록 화면 안내는 행동 직전의 최소 신호만 제공함

## 2.3 평상시 화면은 연희를 우선함

- 상시 점수판과 큰 버튼을 줄이고 배역과 플레이어 모습을 중심에 둠
- 입력이 성립한 순간에만 정지, 확대, 장단, 하이라이트를 강하게 사용함
- 재담 자막은 짧게 표시하고 플레이어의 몸과 배역을 가리지 않음
- 과장된 리액션은 정답 안내가 아니라 희극적 보상으로 사용함. 캐릭터 붕괴 연출의 참고 근거는 [[역전재판 캐릭터 연출 분석]]임

# 3. 전체 체험 흐름

**[사용자 확정]** 시작 화면에서 옴탈잡이, 샌님잡이, 먹중잡이 중 하나를 선택함. 선택과 동시에 유저배역을 고정 배정함. 옴탈잡이는 꺽쇠, 샌님잡이는 말뚝이, 먹중잡이는 취발이를 맡음. 한 번 선택하면 그 배역으로 해당 마당의 도입부터 결말까지 전체를 체험하며, 체험 도중 다른 마당이나 장을 다시 선택하지 않음. 아래 네 단계는 선택 화면의 하위 메뉴가 아니라 선택한 마당 전체 안에서 이어지는 진행 구조임.

1. **관계 제시**: 장쇠가 유저배역을 소개하고 상대배역의 상태와 갈등 관계를 짧게 보여줌
2. **규칙 학습**: 첫 행동은 방향과 성공 조건이 분명하게 보이게 함
3. **변주**: 속도, 표현의 강도, 선택 후보를 바꿔 같은 판단을 반복하게 함
4. **붕괴**: 입력 결과와 무관하게 각 마당의 원전 사건이 결말까지 이어지고, 성공은 상대 인물의 반응만 바꿈

세 마당 사이의 선후 순서는 없음. 플레이어는 원하는 마당 하나를 골라 해당 마당을 완주하고 체험을 마침.

# 4. 옴탈잡이: 피하고 쫓아내기

## 4.1 옴탈잡이 핵심 경험

플레이어에게 자꾸 접근하는 옴탈을 몸으로 피한 뒤 직접 몰아냄. 질병 자체를 조롱하는 체험으로 만들지 않고, 눈치 없이 거리를 좁히는 민폐 인물과의 신체적 대치로 현대화함.

**[원형 근거]** 재담, 대치, 몰아내기의 흐름을 보존해야 함 ([[덧뵈기의 재미 요소#3. 옴탈잡이]]).

## 4.3 원전 사건과 플레이 단계 대응

아래 표는 원자 사건을 현재 플레이 단계로 바꾸는 설계 선택을 드러냄. 원자 사건 수와 플레이 단계 수가 같다고 가정하지 않으며, 다른 묶음도 가능함.

| 현재 플레이 단계 | 원자 사건 | 변환 방식 | 설계 추가 또는 제외 |
|---|---|---|---|
| 회피 학습 | A1~A3 | 플레이어에게 꺽쇠를 배정하고, 몸 이동으로 꺽쇠 스프라이트를 움직여 옴탈을 피하게 함 | 유저 동작과 꺽쇠 스프라이트의 연동, 접근 방향을 알리는 춤과 재담, 충돌 영역, 성공과 실패 재담은 설계 추가임 |
| 연속 회피 | A2, A3 | `요리조리 쫓음`을 방향 변화가 있는 반복 회피로 바꿈 | 반복 횟수, 속도 변화, 가짜 방향 전환, 장쇠의 진행 안내와 재시도는 설계 추가임 |
| 퇴치 학습 | A4~A10 | 실랑이와 재담을 거쳐 옴탈이 대드는 흐름을 퇴치 입력의 전환 신호로 씀 | 팔로 미는 입력, 옴탈이 튕겨 나가거나 넘어지는 연출, 성공과 실패 재담, 재시도는 설계 추가임. 모자 잡기, 머리채 끌기와 얼굴 채검은 플레이어 행동에서 제외함. 원문 재담의 사용 범위는 문화 자문 뒤 정함 |
| 마무리 | A11~A13 | 꺽쇠가 춤으로 대들어 옴탈을 몰아내는 결말을 큰 몸동작 입력으로 바꿈 | 빠른 공방, 팔로 미는 판정 영역, 실패 뒤 추가 기회는 설계 추가임 |

## 4.4 옴탈잡이 기본 루프

1. 장쇠가 플레이어를 꺽쇠로 소개하고 회피 입력을 안내함
2. 옴탈이 짧은 재담과 우스꽝스러운 춤으로 접근 의도와 방향을 드러냄
3. 플레이어가 재담과 움직임을 함께 보고 반대쪽으로 몸을 옮기면 꺽쇠 스프라이트가 함께 피함
4. 성공과 실패에 따라 옴탈과 유저배역 꺽쇠가 다른 재담으로 반응함
5. 장쇠가 회피에서 퇴치로 행동이 바뀌는 시점을 안내함
6. 플레이어가 팔이나 몸을 크게 움직이면 꺽쇠가 옴탈을 밀어냄
7. 옴탈이 춤 동작으로 버티다가 튕겨 나가거나 넘어짐
8. 앞선 결과를 받아치는 새 재담 뒤 접근 방식과 춤을 바꿔 다음 시도를 시작함

## 4.5 단계와 판정

| 단계 | 재담과 춤의 신호 | 옴탈 행동 | 플레이어 입력 | 성공 판정 | 실패 연출 |
|---|---|---|---|---|---|
| 회피 학습 | 장쇠의 짧은 안내 뒤 옴탈이 다가가겠다고 너스레를 떨고 한쪽으로 몸을 기울임 | 한쪽에서 느리게 접근함 | 반대쪽으로 몸을 옮김 | 꺽쇠의 몸 중심이 충돌 영역을 벗어남 | 옴탈이 달라붙고 장쇠가 재시도를 안내함 |
| 연속 회피 | 앞선 실패나 성공을 받아치고 춤의 방향을 바꿈 | 방향과 속도를 바꿔 접근함 | 접근마다 방향을 바꿈 | 각 접근의 회피 성립 여부를 기록하고 준비된 새로운 접근을 모두 제시하면 단계를 끝냄. 성공과 실패 수는 종료 반응에만 사용함 | 옴탈이 좋아하며 새 재담으로 다시 접근함 |
| 퇴치 학습 | 장쇠가 몰아낼 때를 안내하고 옴탈이 버티는 춤을 춤 | 화면 가까이 머묾 | 팔로 밀어내는 동작을 함 | 유저배역 꺽쇠의 손이나 팔이 옴탈 판정 영역을 통과함 | 옴탈이 몸을 피하고 꺽쇠를 놀리며 다시 다가옴 |
| 마무리 | 옴탈과 꺽쇠의 공방이 빨라지고 장단이 고조됨 | 빠른 접근 중 가짜 방향 전환을 한 뒤 실제 접근 방향을 몸짓으로 드러냄 | 크게 밀어냄 | 마지막 퇴치 입력이 성립함 | 장쇠의 짧은 안내 뒤 판정 범위와 허용 시간을 완화해 한 번 더 기회를 줌. 다시 실패하면 실패 결말로 진행함 |

## 4.6 옴탈잡이 상세 진행

아래 진행 대사는 원전 인용이 아닌 **설계 대사 초안**임. 실제 재담은 원전 대목 선정과 문화 자문 뒤 확정함. 모든 대사는 말풍선 없이 화면 하단의 대사 표시 공간에 화자 이름과 함께 표시함. 행동 안내가 필요한 순간에는 같은 공간을 안내 문구로 바꾸며, 대사와 행동 안내를 동시에 겹쳐 표시하지 않음. 장쇠는 3번에서 안내를 마치고 뒤 레이어로 물러난 뒤, 대사나 시범이 있는 순서에서만 앞으로 나옴.

| 순서 | 화면 등장 인물 | 하단 진행 대사 또는 안내 | 화면 행동 | 플레이어 입력 | 성공 및 실패 시 진행 |
|---|---|---|---|---|---|
| 1. 마당 전경 | 장쇠, 꺽쇠 | `[장쇠] 여기는 옴탈잡이 마당이오. 오늘 자네는 꺽쇠요.` | 마당 전체를 보여준 뒤 장쇠와 꺽쇠를 차례로 크게 보여줌 | 없음 | 대사가 끝나면 2. 위치와 동작 인식 확인으로 진행함 |

## 4.7 연출 원칙

- 옴탈의 의상과 소품 실루엣을 과장하고, 엇박 걸음과 춤의 리듬, 거리 침범의 타이밍으로 기괴한 캐릭터 코미디가 성립하게 함. 질병 특징이나 환자의 신체를 본뜬 과장은 사용하지 않음
- 옴탈의 접근, 버티기와 퇴장을 춤으로 연결하고 실패와 퇴장을 크게 과장해 신체 코미디를 만듦
- 옴탈과 유저배역 꺽쇠의 재담은 장면 안의 대치와 반응으로 사용함. 장쇠는 배역 소개, 입력 안내와 시범, 장면 전환, 결과 선언과 마무리를 담당하되 플레이어 대신 행동하지 않음
- 옴탈의 외형과 행위를 설계할 때 질병의 증상이나 환자가 아니라 민폐 행동과 거리 침범이 웃음의 대상이 되게 함

# 5. 샌님잡이: 말의 허점 집어내기

## 5.1 샌님잡이 핵심 경험

샌님이 세운 권위를 먼저 충분히 보여준 뒤, 말뚝이 역의 플레이어가 샌님의 말에서 공격 지점을 찾고 재담으로 뒤집음. 완성된 반격 문장을 고르는 객관식 퀴즈가 아니라 **어디를 붙잡아야 웃음이 시작되는지 찾는 언어 관찰**이 핵심임 ([[덧뵈기의 재미 요소#4. 샌님잡이]]).

## 5.3 원전 사건 처리표

상세 순서를 나누기 전에 S1~S13을 모두 배치함. `사용`은 사건을 현재 흐름에 남긴다는 뜻이고, `각색`은 관계나 기능만 남긴다는 뜻이며, `제외`는 화면에서 쓰지 않는 대목과 사유를 밝힌 것임. 한 사건을 여러 화면 상태로 펼칠 수 있고 여러 사건을 한 상태에 함께 둘 수도 있음.

| 사건 ID | 처리 | 상세 진행에서 맡는 기능 | 각색 또는 제외 이유 |
|---|---|---|---|
| S1 | 각색 | 샌님과 노친네의 관계, 샌님이 체면을 앞세우는 성격을 도입에서 보여줌 | 배우자를 낮춰 부르는 원문 표현은 직접 재현하지 않고, 샌님이 동행을 숨기려다 노친네에게 제지당하는 몸짓으로 바꿈 |
| S2 | 사용 | 유람 허세와 원전 잽이의 지적을 통해 샌님의 자기모순을 보여줌 | 말뚝이 등장 전 사건이므로 플레이어 입력으로 만들지 않고, 원전 잽이의 재담은 장쇠가 맡음 |
| S3 | 사용 | 하인을 찾으면서 이름을 기억하지 못하는 허점과 원전 잽이의 지적을 보여줌 | 말뚝이 등장 전 사건이며 S4의 이름 말놀이로 바로 이어지므로 플레이어 입력으로 만들지 않음. 원전 잽이의 재담은 장쇠가 맡음 |
| S4 | 사용 | 막대기 이야기에서 말뚝이 이름을 떠올리는 말놀이를 이어감 | 말놀이의 핵심이 사라지지 않는 범위에서 대사를 줄임 |
| S5 | 사용 | 샌님의 긴 부름과 원전 잽이의 지적을 거쳐 말뚝이의 등장을 준비함 | 말뚝이 등장 전 사건이므로 플레이어 입력으로 만들지 않음. 긴 부름 전체를 복원하지 않고 원전 잽이 재담의 기능만 남겨 장쇠의 대사로 바꿈 |
| S6 | 사용 | 등장한 말뚝이가 절 요구를 다른 뜻으로 받을 표현을 플레이어가 찾게 함 | 이 사건부터 말뚝이가 전경에 등장하고 플레이어 선택이 말뚝이의 재담으로 직접 이어짐 |
| S7 | 사용 | 따라 하라는 지시에서 말뚝이가 행동으로 되받을 조건을 플레이어가 찾게 함 | 플레이어 선택이 S8의 말과 동작 모방으로 직접 이어짐 |
| S8 | 사용 | 말뚝이가 말과 동작을 그대로 따라 하며 위계를 뒤집는 결과 장면을 만듦 | 욕설은 직접 되풀이하지 않고 명령과 웃음을 따라 하는 몸짓으로 줄임 |
| S9 | 사용 | 씨름과 샌님의 패배로 말 그대로 따르기의 결과를 보여줌 | 씨름은 선택 입력이 아니라 두 배역의 자동 연출로 둠 |
| S10 | 사용 | 샌님이 조건을 고쳐 절 교육을 다시 시작하고 S11의 관계 역전을 준비함 | 수정 조건 자체에 말뚝이가 말이나 행동으로 직접 되받을 독립된 허점이 없어 플레이어 입력으로 만들지 않음 |
| S11 | 사용 | 샌님 내외가 말뚝이에게 절하게 되는 관계 역전을 절정으로 보여줌 | 조롱 대사는 문화 자문 전까지 설계 대사 초안으로만 둠 |
| S12 | 각색 | 세 인물의 춤으로 대결을 풀고 마당 결말을 시작함 | 대결 당사자의 상호 행동인 S9 씨름은 자동 연출로 남기되, 노친네를 희극의 대상으로 삼는 일방적 신체 접촉은 제외하고 세 인물이 각자 춤추다 퇴장하게 함 |
| S13 | 각색 | 피조리 등장, 샌님 퇴장과 피조리춤을 다음 연희가 이어지는 끝 장면으로 보존함 | 샌님이 피조리를 친족으로 부르는 대목은 제외함 |

선택 입력 후보는 사건 수를 정하지 않고 다음 조건으로 다시 추출함.

- 말뚝이가 원전에 등장한 뒤의 사건임
- 플레이어가 고른 표현을 말뚝이의 재담이나 행동으로 직접 되받을 수 있음
- 선택하지 않아도 원전 사건과 결말은 이어짐

이 조건을 충족한 사건은 S6의 절 요구와 S7의 따라 하기 조건임. S2, S3과 S5는 말의 허점이 있지만 말뚝이 등장 전 원전 잽이가 받아치는 사건이므로 관찰 장면으로 남김. S10은 말뚝이 등장 뒤 사건이지만 수정 조건에서 독립된 허점을 고르는 것과 관계 역전 사이에 직접 연결이 없어 관찰 장면으로 남김. 입력 후보 수는 미리 정한 값이 아니라 이 사건별 판정의 결과이며, 제작 시험에서 후보를 합치거나 뺄 때도 같은 조건과 사건별 사유를 먼저 기록함.

현재 설계 대사에서 실제 선택 영역을 다음과 같이 둠. 문구는 원문 인용이 아닌 **설계 대사 초안**이며 문화 자문 뒤 확정함.

| 사건 | 화면 설계 대사 | 강한 후보 | 약한 후보 | 비선택 영역 | 입력 뒤 차이 |
|---|---|---|---|---|---|
| S6 절 요구 | `나한테 절을 올려라.` | `절` | `나한테` | `올려라` | 강한 후보는 절을 다른 뜻으로 받는 재담, 약한 후보는 샌님만 높이려는 태도를 받아치는 재담을 더함 |
| S7 따라 하기 조건 | `내가 하는 건 한 가지도 빼놓지 말고 그대로 따라 해라.` | `한 가지도 빼놓지 말고` | `그대로` | `내가 하는 건` | 강한 후보는 빠짐없는 모방을 예고하는 재담, 약한 후보는 따라 하겠다는 짧은 응답을 더함 |

## 5.4 입력과 결과 규칙

- **입력**: 플레이어는 하단 대사 표시 공간에 나온 단어나 표현 영역에 손을 머물게 함
- **강한 선택**: 원전의 말꼬리, 중의성이나 자기모순을 직접 여는 표현임. 말뚝이의 큰 반격과 샌님의 큰 반응을 재생함
- **약한 선택**: 재담으로 연결은 되지만 핵심 허점은 아닌 표현임. 말뚝이의 짧은 받아치기와 샌님의 작은 반응을 재생함
- **무입력**: 선택 시간이 끝나면 영역을 한 번 크게 다시 보여줌. 두 번째에도 선택이 없으면 말뚝이의 추가 재담만 생략하고 해당 원전 사건의 행동과 다음 순서로 진행함
- **인식 실패**: 손이 잡히지 않으면 장쇠가 거리와 손 위치를 다시 안내함. 재확인에도 손이 잡히지 않으면 복구 화면으로 이동함. 복구 화면에서는 손 인식 확인을 다시 시작하거나 시작 화면으로 돌아갈 수 있으며, 아직 정하지 않은 터치 입력을 임의로 대신 쓰지 않음
- **내부 반응값**: 선택 결과에 맞는 샌님의 `기본`, `작은 흔들림`, `큰 흔들림` 상태에서 표정, 상체 자세와 옷매무새 자산을 고르는 데만 씀. 원전 사건의 진행 여부나 결말 도달 조건으로 쓰지 않음

## 5.5 샌님잡이 상세 진행

모든 대사와 안내는 말풍선 없이 화면 하단 전용 공간에 화자 이름과 함께 표시함. 아래 문구는 원문 인용이 아니라 화면 흐름을 확인하기 위한 **설계 대사 초안**임. 장쇠는 도입, 입력 안내, 장면 전환과 원전 잽이의 대사를 맡되 말뚝이의 재담은 대신하지 않음.

| 순서 | 근거 | 화면 등장 인물 | 하단 대사 또는 안내 | 화면 행동 | 플레이어 입력 | 성공, 실패와 다음 진행 |
|---|---|---|---|---|---|---|
| 마당 전경 | 설계 추가 | 장쇠, 샌님, 노친네. 말뚝이는 무대 밖 대기 위치에 작게 보임 | `[장쇠] 이번 마당에서는 말뚝이가 되어 샌님의 말에서 허점을 찾아냅니다.` | 전체 마당을 보여준 뒤 장쇠를 크게 보여줌 | 없음 | 장쇠 안내가 끝나면 손 인식 확인으로 진행함 |
| 손 인식 확인 | 설계 추가 | 장쇠, 말뚝이 대기 표시 | `[안내] 손을 표시된 영역에 잠시 머물러 보세요.` | 하단에 연습용 표현 영역을 하나 띄우고 손 위치에 따라 테두리가 반응함 | 손을 영역에 머물게 함 | 인식되면 관계 도입으로 진행함. 인식되지 않으면 [[#5.4 입력과 결과 규칙]]의 인식 실패 처리를 적용함 |
| 관계 도입 | S1 | 장쇠, 샌님, 노친네 | `[장쇠] 샌님은 함께 온 사람보다 자기 체면부터 챙기려 합니다.` | 샌님이 노친네와 거리를 두려 하고 노친네가 앞을 막아 세움. 장쇠는 뒤 레이어로 물러남 | 없음 | 두 인물의 관계가 보인 뒤 유람 허세로 진행함 |
| 유람 허세 | S2 | 장쇠, 샌님, 노친네 | `[장쇠] 어디를 다녀오셨습니까?` 뒤에 샌님의 허세와 장쇠의 지적을 차례로 표시함 | 샌님이 부채를 펴고 자신만만한 자세를 취했다가 장쇠의 지적에 잠시 멈칫함 | 없음 | 장쇠의 반응이 끝나면 하인 찾기로 진행함 |
| 하인 찾기 | S3 | 장쇠, 샌님, 노친네 | `[장쇠] 누구를 찾으십니까?` 뒤에 이름을 기억하지 못하는 샌님의 답을 표시함 | 샌님이 이름을 떠올리려다 말을 돌리고 장쇠가 재촉함 | 없음 | 이름 말놀이로 진행함 |
| 이름 말놀이 | S4 | 장쇠, 샌님 | 이름을 떠올리는 데 필요한 막대기 이야기를 짧게 표시함 | 샌님이 지팡이를 땅에 세우는 시늉을 하고 장쇠의 답을 듣고서 이름을 떠올림 | 없음 | 긴 부름으로 진행함 |
| 긴 부름 | S5 | 장쇠, 샌님, 말뚝이 대기 표시 | 샌님의 긴 부름과 이를 지적하는 장쇠의 재담을 차례로 표시함 | 샌님이 객석 쪽으로 크게 외치고 장쇠가 귀를 막은 뒤 말뚝이가 있는 무대 밖을 가리킴 | 없음 | 장쇠의 반응이 끝나면 말뚝이 등장으로 진행함 |
| 말뚝이 등장 | S5, S6 | 장쇠, 말뚝이, 샌님 | `[장쇠] 말뚝이가 불려 나왔습니다.` | 말뚝이가 무대 가운데로 들어오고 샌님과 마주 섬 | 없음 | 등장 동작이 끝나면 인사와 절 요구로 진행함 |
| 인사와 절 요구 | S6 | 말뚝이, 샌님 | 샌님이 인사를 받고 절하라고 요구하는 설계 대사를 표시함 | 말뚝이가 과장되게 인사하고 샌님이 절 동작을 지시함 | 없음 | 샌님의 발화가 끝나면 절 요구 허점 선택으로 진행함 |
| 절 요구 허점 선택 | S6 | 말뚝이, 샌님 | `[안내] 다른 뜻으로 바꿔 받을 수 있는 말을 찾으세요.` | 절 요구 문장을 표현 단위 영역으로 나눠 보여줌 | 표현 하나에 손을 머물게 함 | [[#5.4 입력과 결과 규칙]]에 따라 선택을 처리한 뒤 절 말놀이로 진행함 |
| 절 말놀이 | S6 | 말뚝이, 샌님 | 선택했으면 해당 표현에 연결된 추가 재담을 표시하고, 무입력이면 절을 다른 뜻으로 받는 기본 재담만 표시함 | 말뚝이는 엉뚱한 방향을 가리키고 샌님은 답답해하며 직접 가르치려 함 | 없음 | 반응이 끝나면 절 교육 조건으로 진행함 |
| 절 교육 조건 | S7 | 말뚝이, 샌님 | 샌님이 자기 행동을 빠짐없이 따라 하라고 지시하는 설계 대사를 표시함 | 샌님이 절 자세를 준비하고 말뚝이는 유심히 따라 볼 자세를 취함 | 없음 | 지시가 끝나면 따라 하기 조건 선택으로 진행함 |
| 따라 하기 조건 선택 | S7 | 말뚝이, 샌님 | `[안내] 말뚝이가 그대로 지키면 샌님이 곤란해질 표현을 찾으세요.` | 지시 문장을 표현 단위 영역으로 나눠 보여줌 | 표현 하나에 손을 머물게 함 | [[#5.4 입력과 결과 규칙]]에 따라 선택을 처리한 뒤 모방 연쇄로 진행함 |
| 모방 연쇄 | S8 | 말뚝이, 샌님, 노친네 | 선택했으면 해당 표현에 연결된 말뚝이의 설계 재담을 표시하고, 무입력이면 대사 없이 진행함 | 선택 결과와 관계없이 샌님의 절, 명령과 웃음을 말뚝이가 차례로 따라 함. 욕설은 재현하지 않음 | 없음 | 모방 연쇄 전체를 재생하고 선택 강도에 따라 앞뒤 연결 재담과 샌님의 반응 상태만 바꾼 뒤 씨름으로 진행함 |
| 씨름 | S9 | 말뚝이, 샌님 | `[샌님] 그것까지 따라 하라는 뜻은 아니었다.` | 두 인물이 중앙으로 이동해 씨름하고 샌님이 밀림. 말뚝이는 지시를 지켰다는 몸짓을 함 | 없음 | 씨름 연출이 끝나면 수정 조건 제시로 진행함 |
| 수정 조건 제시 | S10 | 말뚝이, 샌님, 노친네 | 샌님이 자기 잘못을 인정하고 말은 따라 하지 말고 몸만 굽히라는 조건을 덧붙임 | 샌님이 옷매무새를 고치고 노친네와 나란히 서서 절 교육을 다시 준비함 | 없음 | 수정 조건을 표시한 뒤 절의 관계 역전으로 진행함 |

상세 진행의 순서 수는 위 처리표를 화면 상태로 펼친 결과임. 제작 중 순서를 합치거나 나눌 때는 먼저 S1~S13의 대응과 제외 사유가 모두 남아 있는지 다시 확인하며, 목표 순서 수를 맞추기 위해 사건을 삭제하거나 설계 사건을 원전 사건처럼 쓰지 않음.

## 5.6 샌님의 반응 상태

반응 상태의 개수를 진행 단계와 맞추지 않음. 선택 결과로 고르는 반응과 원전 사건에 도달하면 재생하는 반응을 분리함.

**내부 반응값으로 고르는 상태**

- **기본**: 근엄한 자세와 안정된 말투를 유지함
- **작은 흔들림**: 약한 선택 뒤 표정이 굳거나 부채질이 빨라짐
- **큰 흔들림**: 강한 선택 뒤 자세와 옷매무새가 흐트러짐

**서사 도달로 재생하는 상태**

- **씨름 패배**: S9에서 말뚝이에게 밀린 뒤 자세와 옷매무새가 흐트러짐
- **관계 역전**: S11에서 말뚝이에게 절하는 모양이 되어 권위가 행동으로 뒤집힘
- **퇴장**: S13에서 피조리의 등장에 당황해 자리를 피함

내부 반응값은 첫 목록의 자산을 고르는 용도로만 사용함. 두 번째 목록은 값과 무관하게 해당 사건에 도달하면 재생함. 화면에 내부 반응값을 표시할지는 사용자 경험 검증 뒤 결정함.

# 6. 먹중잡이: 몸짓이 달라지는 순간 지목하기

지목 후보는 개수를 정하지 않고 다음 조건으로 추출함.

- 취발이 등장 뒤 먹중의 몸 상태가 원전 지문에서 실제로 바뀜
- 화면에서 먹중과 피조리를 함께 보아야 변화를 판단할 수 있음
- 몸짓 변화가 이어지는 원전 사건을 방해하지 않고 지목 가능한 시간으로 드러남

이 조건을 충족한 사건은 M2의 멈칫과 M3의 눈치 보기임. 다만 원전에서 두 사건은 먹중과 피조리의 집단 반응이므로, 먹중만 지목하게 만드는 차별 동작은 사용자 확정 입력을 구현하기 위한 설계 추가임. M1은 취발이 등장 전 상태라 첫 조건을 충족하지 않고, M4부터는 몸짓 변화의 순간이 아니라 정체 폭로와 대결이 진행되므로 후보에서 제외함. 지목 후보 수는 이 사건별 판정의 결과이며 원전에 없는 점진 단계를 추가하지 않음.

## 6.4 지목과 결과 규칙

- **입력**: 취발이 역의 플레이어가 행동 허용 시간에 화면 속 먹중을 손가락으로 가리킴
- **성공**: 손가락 방향이 먹중 영역 안에 들어오면 해당 순간을 잠깐 멈추고 확대하며 취발이의 짧은 반응을 재생함
- **이른 지목**: 행동 허용 시간 전에 먹중을 가리키면 확정하지 않고 연희를 계속함
- **늦은 지목과 무입력**: 행동 허용 시간이 끝나면 재시도하지 않고 다음 원전 사건으로 진행함. 포착 재담만 생략함
- **연습 인식 실패**: 지목 인식 확인에서 손가락 방향이 잡히지 않으면 장쇠가 손 위치를 다시 안내함. 재확인에도 잡히지 않으면 복구 화면으로 이동함
- **판정창 중 인식 끊김 또는 모호 입력**: 해당 포착을 생략하고 원전 사건을 계속 재생함. 같은 사건을 반복하지 않으며 다음 지목 후보나 정체 확인으로 진행함
- **진행값**: 성공 횟수는 마무리 화면의 취발이 반응을 고르는 데만 사용함. 원전 사건의 진행, 춤 대결의 승패와 결말 도달 조건으로 사용하지 않음

상세 진행의 순서 수는 M1~M11과 두 지목 후보를 화면 상태로 펼친 결과임. 제작 중 순서를 합치거나 나눌 때는 먼저 모든 사건의 대응과 제외 사유가 남아 있는지 확인하며, 목표 순서 수나 난도 단계를 맞추기 위해 원전에 없는 사건을 추가하지 않음.

## 6.6 마무리 반응

- **두 순간 모두 포착**: 취발이가 먹중의 멈칫과 눈치 보기를 차례로 짚었다는 짧은 반응을 마무리 화면에 표시함
- **한 순간 포착**: 포착한 행동 하나만 되짚고 나머지를 실패로 강조하지 않음
- **무포착**: 추가 포착 재담 없이 원전의 춤 대결과 전체 춤을 완주했음을 표시함

포착 수는 마무리 반응을 고르는 내부 값이며 먹중의 퇴장, 피조리와의 춤이나 전체 출연진의 춤을 바꾸지 않음.

# 7. 공통 입력과 화면

세 마당은 같은 웹캠 몸 인식을 사용하지만 같은 조작을 되풀이하지 않음. 입력은 각 마당에서 플레이어가 해야 하는 판단에 맞춰 분리함.

## 7.1 공통 배역 구조

장쇠는 세 마당에 항상 등장해 시작, 입력 안내, 재시도, 장면 전환과 원전 잽이의 대사를 맡음. 플레이어의 재담이나 대결은 대신 수행하지 않음. 마당 선택과 동시에 배정된 유저배역 스프라이트가 플레이어의 입력과 결과를 표현함.

| 마당 | 진행자 | 유저배역 | 상대배역 | 보조배역 |
|---|---|---|---|---|
| 옴탈잡이 | 장쇠 | 꺽쇠 | 옴탈 | 없음 |
| 샌님잡이 | 장쇠 | 말뚝이 | 샌님 | 노친네, 피조리 둘 |
| 먹중잡이 | 장쇠 | 취발이 | 먹중 | 피조리 둘, 마무리의 전체 출연진 |

## 7.2 마당별 입력 계약

| 마당 | 플레이어가 판단하는 것 | 입력 | 판정에 필요한 값 | 입력 뒤 반응 |
|---|---|---|---|---|
| 옴탈잡이 | 어느 방향으로 피하고 언제 밀어낼지 | 꺽쇠 역으로 몸 중심을 좌우로 옮기고, 손이나 팔을 크게 뻗음 | 유저 동작과 꺽쇠 스프라이트의 연동, 꺽쇠와 옴탈 충돌 영역의 분리, 손이나 팔의 판정 영역 통과 | 꺽쇠가 피하고 맞서며 옴탈은 접근 실패, 버티기, 튕김이나 퇴장으로 반응함 |
| 샌님잡이 | 대사에서 어느 표현이 재담의 공격 지점인지 | 말뚝이 역으로 손을 단어나 표현 영역에 일정 시간 머물게 함 | 손 위치, 선택 영역과 머무른 시간 | 선택 영역을 확정하고 유저배역 말뚝이의 재담과 샌님의 내부 반응값에 맞는 자산을 재생함 |
| 먹중잡이 | 취발이 등장 뒤 먹중의 몸 상태가 바뀐 순간이 언제인지 | 취발이 역으로 M2의 멈칫과 M3의 눈치 보기에서 화면 속 먹중을 손가락으로 지목함 | 손가락 방향, 먹중 영역과 두 행동의 허용 시간 | 성공한 순간만 잠깐 멈춰 확대하고 취발이의 반응을 재생함. 지목 결과와 무관하게 정체 확인과 춤 대결로 진행함 |

**[사용자 확정]** 샌님잡이의 영역 머무름과 먹중잡이의 손가락 지목은 입력 방식 자체를 바꾸지 않음. 시험에서는 영역 크기, 머무름 시간, 지목 허용 범위와 판정 시간만 조정함.

## 7.3 화면 정보 원칙

- **공통**: 현재 해야 할 행동 하나만 전면에 보여주고, 다음 행동의 정답을 미리 노출하지 않음
- **옴탈잡이**: 플레이어의 실루엣과 옴탈의 거리 관계를 보여주되 안전 방향을 화살표로 직접 알려주지 않음. 옴탈의 재담, 몸 기울기와 춤이 접근 방향의 신호가 됨
- **샌님잡이**: 샌님의 대사를 읽을 수 있는 크기로 띄우고 선택 가능한 표현 영역을 서로 겹치지 않게 둠. 선택이 확정되기 전에는 어느 표현이 강한 공격 지점인지 표시하지 않음
- **먹중잡이**: 먹중과 함께 움직이는 인물들이 보여도 지목 대상인 먹중을 잃지 않게 배치함. 성공 뒤에만 포착 순간을 확대해 지목 후보가 된 몸짓을 보여줌
- **결과 표현**: 점수판보다 옴탈의 거리와 퇴장, 샌님의 표정과 자세, 먹중과 취발이의 대결처럼 배역 상태의 변화로 진행을 보여줌

## 7.4 체험 화면의 흐름

1. 시작 화면에서 세 마당의 핵심 행동을 서로 다른 짧은 설명으로 보여줌
2. 마당을 선택하면 장쇠가 유저배역을 소개하고 카메라 인식 범위와 그 마당의 입력을 안내함
3. 한 차례 연습 입력으로 몸이나 손이 정상 인식되는지 확인함. 유저배역이 아직 원전 등장 시점에 이르지 않은 마당은 스프라이트 대신 입력 표식과 방향선으로 반응을 보여줌
4. 선택한 마당의 도입부터 결말까지 진행함
5. 결말과 선택으로 달라진 배역 반응을 보여주고 체험을 끝냄. 샌님잡이에서 선택이 한 번도 없었으면 추가 재담 없이 원전 사건을 완주했음을 보여줌

정상 완주 뒤에는 결과와 종료 안내를 보여주는 `마무리 화면`으로 이동한 다음 시작 화면으로 돌아감. 센서 인식 실패로 진행할 수 없을 때는 `복구 화면`으로 이동해 인식 확인을 다시 시작하거나 시작 화면으로 돌아가게 함. 두 화면을 같은 종료 상태로 합치지 않음.

체험 중에는 마당 선택 화면으로 돌아가는 분기를 두지 않음. 인식 실패로 계속할 수 없을 때는 처음부터 다시 시작하거나 종료하는 복구 화면으로 보냄.

## 7.5 인식 실패와 재시도

- 연습 입력에서 몸이나 손을 찾지 못하면 장면을 멈추고 인식 범위로 돌아오도록 실루엣 안내를 한 차례 보여줌. 다시 찾지 못하면 복구 화면으로 이동함. 먹중잡이 판정창 중 인식 끊김은 [[#6.4 지목과 결과 규칙]]에 따라 포착만 생략함
- 두 후보가 동시에 선택되거나 지목 방향이 모호하면 실패로 연출하지 않고 입력을 확정하지 않음
- 같은 입력을 반복해서 놓치면 입력별 허용 범위를 완화함. 옴탈잡이는 충돌 영역을 줄이거나 회피 여유를 늘림. 먹중잡이의 M2와 M3은 같은 사건을 반복하거나 다음 후보의 판정 범위를 바꾸지 않음. 마당의 입력 종류는 다른 조작으로 바꾸지 않음
- 샌님잡이에서 손은 정상 인식됐지만 선택하지 않으면 선택 영역을 한 번 크게 표시하고 허용 시간을 늘려 다시 제시함. 두 번째에도 선택하지 않으면 [[#5.4 입력과 결과 규칙]]에 따라 추가 재담을 생략하고 다음 원전 사건으로 진행함
- 먹중잡이에서 손가락은 정상 인식됐지만 행동 구간에 지목하지 않으면 다음 지목 후보나 먹중의 정체 확인으로 진행함

## 7.6 65인치 가로형 화면 구성 초안

**[초안 전제]** 16:9 화면을 1920×1080 논리 좌표로 설계함. 등장인물은 2D 이미지와 스프라이트 애니메이션으로 표시함. 카메라 영상 원본이나 별도 플레이어 캐릭터를 두지 않고, 인식한 동작을 유저배역 스프라이트와 손 위치 표식에 연결함. 실제 출력 해상도가 달라도 아래 비율을 유지함.

### 7.6.1 공통 화면 골격

| 영역 | 기준 범위 | 용도 |
|---|---:|---|
| 안전 여백 | 화면 네 변에서 4% 안쪽 | 글자와 선택 영역이 화면 끝에 붙지 않고, 인물의 중요한 표정이 장식 프레임에 가리지 않게 함 |
| 상단 상태 영역 | 화면 높이의 10% | 선택한 마당 이름과 그만두기 버튼만 둠 |
| 중앙 무대 | 화면 높이의 72% | 배경, 장쇠, 유저배역과 상대배역 스프라이트를 배치함. 마당별 상호작용은 이 영역에서 일어남 |
| 하단 재담 영역 | 화면 높이의 18% | 재담 자막과 짧은 입력 안내를 둠. 샌님잡이에서는 선택할 대사 영역으로 확장함 |

- **정보 우선순위**: 인물 행동, 하단의 대사 또는 행동 안내, 화자 이름, 진행 상태 순으로 읽히게 함
- **고정 UI 최소화**: 마당 이름과 그만두기 외에는 필요한 순간에만 나타나게 해 2D 무대를 가리지 않음
- **하단 대사와 안내 공간**: 모든 대사에 화자 이름을 붙여 하단 고정 영역에 표시함. 행동 안내도 같은 영역을 사용하되 대사와 교대로 표시함. 말풍선은 사용하지 않음
- **플레이어 표시**: 별도 실루엣을 인물처럼 세우지 않음. 유저배역 스프라이트가 플레이어의 움직임과 선택 결과를 나타내고, 손 위치 표식은 선택이나 지목이 필요할 때만 겹쳐 표시함
- **장쇠 고정 위치**: 화면 한쪽 뒤 레이어에 작은 전신 스프라이트로 배치하고 안내와 장면 전환 때만 앞으로 나오게 함
- **인식 상태**: 정상 인식은 실루엣이나 손 커서를 그대로 표시하고, 인식 끊김은 점선과 안내 문구, 모호한 입력은 확정되지 않은 윤곽으로 세 마당에 동일하게 표시함
- **글자와 선택 영역 초안**: 1920×1080에서 하단 행동 안내 52px 이상, 하단 대사 40px 이상, 선택판 제목 44px 이상으로 시작함. 손으로 고르는 영역은 180×120px 이상을 첫 시험값으로 둠
- **공통 장면 문법**: 마당이 시작되면 먼저 마당 전체를 보여 인물 관계와 공간을 설정함. 이후 장쇠가 마당을 열고 주요 인물을 소개함. 상호작용 중에는 마당별 행동 화면과 성공 또는 실패 반응 화면을 오가며, 결말에서는 다시 전체 마당을 보여줌
- **인물별 화면의 범위**: 재담, 입력 안내와 표정 반응은 필요한 인물을 크게 보여줌. 인물 사이의 거리, 접근 방향이나 행동 관계가 판정에 필요한 동안에는 관련 인물을 같은 화면에 두며, 인물별 화면을 계속 유지하지 않음
- **장쇠의 전환**: 전체 마당과 도입 화면에서는 장쇠를 분명히 보여줌. 상호작용이 시작되면 장쇠는 뒤 레이어의 고정 위치로 물러나 주요 인물의 이동 공간을 침범하지 않음

### 7.6.2 시작 화면

- 화면 가운데에 옴탈잡이, 샌님잡이와 먹중잡이 선택판을 가로로 나란히 둠
- 각 선택판은 유저배역인 꺽쇠, 말뚝이와 취발이의 대기 스프라이트, 마당 이름과 핵심 행동 한 줄만 보여줌
  - 옴탈잡이: `피하고 밀어내기`
  - 샌님잡이: `말의 허점 짚기`
  - 먹중잡이: `수상한 순간 지목하기`
- 선택판에 짧은 대기 애니메이션을 재생하되 동시에 큰 동작을 하지 않게 해 시선 경쟁을 줄임
- 선택판 전체를 하나의 선택 영역으로 씀. 선택 뒤에는 선택한 마당의 전체 전경과 배역 소개를 먼저 보여주고, 그다음 위치와 동작 인식 확인과 입력 연습으로 이어감

### 7.6.3 옴탈잡이 화면

- **도입 화면**: 마당 전체에 장쇠, 꺽쇠와 옴탈을 함께 보여준 뒤 장쇠의 안내와 두 배역의 소개 화면으로 전환함
- **중앙 36%**: 유저배역 꺽쇠와 이동 가능 영역을 둠. 플레이어가 움직이면 꺽쇠 스프라이트가 같은 방향으로 피함
- **좌우 각 25%**: 옴탈이 접근하고 물러나는 공간으로 사용함. 접근 방향에 따라 옴탈 스프라이트를 좌우 반전하거나 방향별 자산으로 교체함
- **장쇠 영역 14%**: 무대 한쪽 뒤에 작은 전신 스프라이트로 두고, 시작 안내와 행동 전환 때만 앞으로 움직임. 장쇠의 대사와 안내는 하단 전용 공간에 표시함
- **행동 화면**: 회피와 밀어내기 중에는 꺽쇠와 옴탈을 같은 화면에 두어 접근 방향, 두 인물의 거리와 밀어내는 관계가 보이게 함. 옴탈이 재담할 때는 옴탈을 크게 보여주고, 성공 또는 실패 뒤에는 반응하는 인물을 크게 보여줌
- **판정 표현**: 회피 성공은 옴탈이 플레이어 옆을 지나치는 동작으로, 밀어내기 성공은 옴탈의 버티기 뒤 튕김과 퇴장으로 보여줌
- **화면 상태**: 회피 준비와 결과, 밀어내기 준비와 결과를 구분함. 밀어내기 준비에서는 플레이어 손 위치와 옴탈의 몸 영역을 보여주되 성공 전에는 충돌 효과를 재생하지 않음
- **금지**: 안전 방향 화살표, 큰 충돌 박스와 점수 숫자로 정답을 직접 노출하지 않음

### 7.6.4 샌님잡이 화면

- **도입 화면**: 마당 전체에 장쇠, 샌님과 노친네를 함께 보여줌. 말뚝이는 플레이어 배역임을 알 수 있는 무대 밖 대기 표시로 먼저 보여주고, 원전의 부름이 끝난 뒤 무대에 등장함
- **말뚝이 대기 표시**: 말뚝이의 작은 전신 스프라이트를 화면 오른쪽 가장자리의 무대 밖 영역에 둠. 플레이어 배역 표식일 뿐 S6의 등장 전에는 말하거나 무대 안으로 움직이지 않음
- **말뚝이 등장 전 배치**: 샌님과 노친네를 무대 중앙에 두고 장쇠는 질문하거나 받아칠 때 앞 레이어로 나옴. 그 밖에는 뒤쪽 고정 영역에서 입력과 장면 전환을 안내함
- **말뚝이 등장 뒤 배치**: 상대배역 샌님과 유저배역 말뚝이를 무대 좌우에 서로 마주 보는 전신 또는 허벅지 위 크기의 스프라이트로 배치함. 노친네는 사건에 필요할 때 샌님 뒤에 두고 장쇠는 뒤 레이어로 물러남
- **중앙 여백**: 인물의 몸짓과 관계가 겹치지 않게 비우고, 씨름이나 절 장면에서만 관련 스프라이트가 중앙으로 이동함
- **마지막 배치**: 말뚝이와 노친네가 퇴장하면 샌님을 중앙에 남기고 피조리 둘을 양옆에서 등장시킴. 샌님 퇴장 뒤에는 피조리 둘을 중앙에 나란히 둠
- **재담 화면**: 샌님의 발화, 플레이어의 허점 선택, 말뚝이의 반격과 샌님의 반응 순서로 인물별 화면을 전환함. 노친네나 장쇠가 사건의 주체인 동안에는 해당 인물을 함께 보여주며, 씨름과 절처럼 관계가 행동으로 드러나는 장면은 관련 인물을 같은 화면에 둠
- **하단 대사판**: 한 번에 제시하는 샌님의 대사는 최대 2줄로 보여주고, 선택 가능한 단어나 표현을 큰 영역으로 나눔. 입력 안내와 대사판은 동시에 표시하지 않고 교대로 보여줌
- **선택 상태**: 손이 영역에 들어오면 테두리만 반응하고, 머무름 시간이 채워졌을 때 확정 효과와 말뚝이 재담을 재생함. 강한 공격 지점인지는 확정 전 표시하지 않음
- **결과 상태**: [[#5.6 샌님의 반응 상태]]의 내부 반응값에 맞춰 샌님의 `기본`, `작은 흔들림`, `큰 흔들림` 자산을 고름. 선택 결과와 무관하게 원전 사건은 이어지며, 씨름 패배, 관계 역전과 퇴장은 정해진 서사 순서에 도달하면 재생함
- **진행 표시**: 내부 반응값은 반응 자산 선택에만 쓰고 별도 점수판은 두지 않는 안을 기본으로 시험함

### 7.6.5 먹중잡이 화면

- **도입 화면**: 마당 전체에 장쇠, 먹중과 두 피조리를 함께 보여주고 취발이는 플레이어 배역임을 알 수 있는 무대 밖 대기 표시로 둠. 원전의 등장 시점인 M2에서 취발이를 전경에 배치함
- **중앙 34%**: 지목 대상인 먹중을 전신으로 배치하고 다른 인물보다 앞 레이어에 둠
- **중앙 양옆 각 23%**: 두 피조리를 배치해 먹중의 시선과 이동 방향이 읽히게 함
- **유저배역 취발이**: M1에서는 무대 밖 대기 표시로 두고 M2에서 전경으로 뛰어나오게 함. 지목 성공마다 반응하고 M4부터 먹중과 대결함
- **장쇠**: 취발이와 반대쪽 뒤 레이어에 둠. 입력 안내, 장면 전환과 M4의 정체 설명을 맡고, M7의 장단 요청과 M8~M10의 재담에 반응함
- **관찰 화면**: M2의 멈칫과 M3의 눈치 보기 동안 먹중과 피조리 둘을 반드시 같은 화면에 둠. M2에서는 먹중이 부채로 얼굴을 다시 가리고 피조리는 제자리에서 굳으며, M3에서는 먹중이 취발이와 피조리 사이로 고개를 거듭 돌리고 피조리는 취발이를 한 차례 바라봄. 먹중만 따로 보여주는 동안에는 플레이어의 지목을 판정하지 않음
- **반응 화면**: 지목이 성립하면 해당 순간을 잠깐 멈춰 먹중의 몸짓을 크게 보여주고, 이어서 취발이의 반응을 보여준 뒤 전체 화면으로 돌아감
- **지목 상태**: 손가락이 가리키는 지점이 먹중 영역 안에 있고 M2 또는 M3의 허용 시간 안이면 지목을 확정함. 허용 시간 전에는 동작을 계속하고, 허용 시간이 지난 지목, 무입력, 모호 입력과 인식 끊김은 포착을 생략함. 같은 사건은 반복하지 않음
- **대결 화면**: M4의 정체 확인부터 취발이와 먹중을 중앙에 마주 세움. M7과 M8의 춤 대결에서는 두 인물을 같은 화면에 두고 피조리 둘은 뒤 레이어로 물러나게 함
- **결말 화면**: 먹중이 퇴장하면 장쇠, 취발이와 피조리 둘을 같은 화면에 두고, 마지막 전체 춤에서는 모든 출연진이 들어올 공간을 확보함

### 7.6.6 스프라이트 레이어와 상태

화면 뒤에서 앞으로 다음 순서로 합성함.

1. **배경**: 마당 공간과 장단에 반응하는 최소 환경 효과
2. **진행자와 뒤 인물**: 장쇠, 현재 상호작용의 대상이 아닌 배역과 대기 동작
3. **주 인물**: 유저배역과 상대배역의 전신 스프라이트
4. **입력 표식**: 손, 손가락 위치와 유저배역의 인식 상태
5. **반응 효과**: 충돌, 지목 확정, 웃음과 장단 강조 효과
6. **UI**: 상태, 재담 자막, 입력 안내와 종료 조작

각 주요 인물은 `대기`, `말하기`, `이동 또는 춤`, `성공 반응`, `실패 반응`, `장면 전환` 상태를 기본 슬롯으로 가짐. 스프라이트 재생이 끝나는 시점과 판정 가능 시간 구간을 분리해, 긴 애니메이션 도중 입력을 놓치거나 다음 장면이 먼저 시작되지 않게 함. 인물별로 실제 필요한 슬롯과 재생 규칙은 8절의 제작 명세에서 확정함.

# 8. 제작 전에 확정할 항목

마당 선택 구조와 샌님잡이의 영역 머무름, 먹중잡이의 손가락 지목은 확정됐으므로 다시 미결로 올리지 않음. 아래에는 현재 설계를 실제 화면과 판정으로 만들기 위해 정해야 하는 값, 자산과 세부 설계 결정을 둠.

| 미결 항목 | 이미 정해진 경계 | 확정 방법 |
|---|---|---|
| 시작 화면의 마당 선택 조작 | 세 마당 중 하나만 선택함 | 터치와 몸짓 중 무인 키오스크에서 오선택이 적은 방식을 시험함 |
| 마당별 목표 체험 시간 | 선택한 마당의 도입부터 결말까지 전체를 진행함 | 각 마당 완주 시간과 전시장 대기 시간을 실측해 장면 수와 반복 횟수를 조정함 |
| 옴탈잡이 판정값 | 몸 이동으로 피하고 큰 팔 동작으로 밀어냄 | 충돌 영역, 이동 거리, 준비된 새 접근 횟수, 밀어내기 범위와 허용 시간을 체형별로 시험함. 실패 재시도와 완화 시도는 새 접근 횟수에서 제외함 |
| 샌님잡이 대사와 선택 영역 | S6과 S7을 입력 후보로 삼고, 무입력이어도 원전 사건은 이어짐 | 두 후보의 설계 대사, 강한 선택과 약한 선택의 연결 재담을 검수해 유지, 통합 또는 제외를 정함. 영역 크기와 머무름 시간도 함께 시험함 |
| 샌님잡이 진행 표시 | 내부 반응값과 [[#5.6 샌님의 반응 상태]]를 사용함 | 수치 비표시안과 최소 진행 표시안을 비교해 수치 표시 여부와 표정, 상체 자세, 옷매무새 자산을 정함 |
| 먹중잡이 지목 장면 | M2와 M3의 원전 집단 반응에서 먹중만 지목하게 하는 몸짓은 설계 추가이며, 무입력이어도 원전 사건은 이어짐 | 먹중과 피조리의 차별 동작을 문화 자문하고, 두 행동의 시작과 끝, 지목 허용 시간, 먹중 영역과 오지목률을 영상 시제품으로 시험해 후보의 유지, 통합 또는 제외를 정함 |
| 카메라 인식 범위와 접근성 | 세 마당 모두 플레이어의 몸이나 손을 인식함 | 서기와 앉기, 신장, 휠체어 사용과 동작 범위를 포함해 거리, 높이와 대체 안내를 시험함 |
| 65인치 화면 실측 배치 | 16:9, 1920×1080 논리 좌표와 비율 기반 영역을 사용함 | 실제 설치 거리에서 하단 행동 안내 52px, 하단 대사 40px, 선택판 제목 44px와 180×120px 손 선택 영역을 시작값으로 시험하고 안전 여백을 확정함 |
| 스프라이트 제작 명세 | 2D 인물에 상태별 스프라이트 애니메이션을 적용함 | 인물별 상태, 기준 크기, 발 기준점, 좌우 반전, 반복 또는 1회 재생, 초당 프레임과 길이, 중단 우선순위, 판정창 시작과 끝, 완료 이벤트, 다음 상태와 장면별 앞뒤 순서를 확정함 |
| 재담과 음향 자산 | 원전의 관계와 희극 구조를 유지하고 선택 결과에 즉시 반응함 | 사용할 원전 대목, 새로 쓸 연결 재담, 장단과 웃음의 재생 조건을 문화 자문과 연출 검수로 확정함 |
| 민감 표현의 현대화 | 질병 자체를 조롱하지 않음. 대결 당사자가 서로 겨루는 자동 연출은 별도로 검수하고, 배우자나 피조리를 희극의 대상으로 삼는 일방적 신체 접촉과 폭력은 제외함 | 옴탈 외형과 세 마당의 대사, 씨름을 포함한 대결 동작을 문화 자문과 관객 수용성 시험으로 검수함 |
