> 장쇠가 세 마당의 진행을 맡고, 플레이어는 선택한 마당에 따라 꺽쇠, 말뚝이 또는 취발이가 됨. 옴탈잡이는 옴탈의 공격을 몸으로 피하고 옴을 없애 옴탈을 몰아내며, 샌님잡이는 샌님의 대사를 바탕으로 소재 키워드와 방식 키워드를 차례로 골라 말뚝이의 재담을 만듦. 먹중잡이는 연희에서 얻은 증거 두 개를 조합해 향락, 여색, 폭력, 거짓 영험의 네 가지 비행을 폭로하고 먹중의 위선이 무너지는 과정을 지켜봄.

# 1. 재설계 목표

기존 덧뵈기의 세 마당을 하나의 판정 방식으로 묶지 않음. [[덧뵈기의 재미 요소]]가 구분한 희극 구조를 기준으로 마당마다 플레이어가 하는 일을 다르게 설계함.

| 마당 | 유저배역 | 상대배역 | 원형의 재미 | 유저배역이 하는 일 | 결과 |
|---|---|---|---|---|---|
| 옴탈잡이 | 꺽쇠 | 옴탈 | 기괴한 상대와 대치하고 몰아냄 | 옴탈의 공격을 피하고 옴을 없앰 | 성공하면 옴탈이 퇴장하고, 패배하면 옴탈이 남아 꺽쇠를 도발함 |
| 샌님잡이 | 말뚝이 | 샌님 | 높은 사람의 말을 이용해 권위를 무너뜨림 | 샌님의 대사를 바탕으로 소재 키워드와 방식 키워드를 차례로 골라 말뚝이의 재담을 만듦 | 샌님의 화를 돋우고 누적 점수로 승패를 가름함 |
| 먹중잡이 | 취발이 | 먹중 | 근엄한 인물의 욕망과 위선을 폭로함 | 연희에서 얻은 증거 두 개를 조합해 향락, 여색, 폭력, 거짓 영험의 네 가지 비행을 폭로함 | 네 폭로에 따라 먹중의 자세가 무너지고 끝내 퇴장함 |

세 마당을 관통하는 경험은 **겉보기의 질서가 플레이어의 개입으로 무너지는 과정**임. 조작 방식은 다르지만 선택과 신체 반응을 통해 직접 개입하는 참여 구조를 공유함.

## 1.1 문장 상태 판별 원칙

- **원형 근거**: `[원형 근거]`를 붙이고 출처 wikilink를 함께 적은 덧뵈기의 배역, 희극 구조와 표현 방식임
- **현재 설계안**: 별도 상태 표시가 없는 본문의 플레이 흐름, 입력, 판정과 연출임. 사용자 승인과 시험 전에는 확정 사양이 아님. `[사용자 확정]` 표시 항목은 제외함
- **확인 필요**: `[확인 필요]`를 붙인 원전 재대조, 사용자 결정, 기술 시험과 문화 자문 대상임

# 2. 설계 원칙

## 2.1 원형의 희극 구조를 먼저 보존함

- 캐릭터와 소재만 덧씌운 범용 미니게임을 만들지 않음. 각 마당의 조작은 해당 마당의 재담, 대치와 위선 폭로 구조에서 도출함.
- 각 마당의 도입에서 웃음이 성립하는 관계를 먼저 보여줌
- 성공 보상은 점수보다 상대 인물의 표정, 자세, 움직임이 무너지는 장면으로 줌
- 실패는 즉시 게임오버로 끊지 않고 새 재담이나 신체 코미디를 만드는 계기로 씀
- 원전의 배역, 원전에서의 마당 배열과 행위는 [[남사당놀이 - 덧뵈기]]와 다시 대조한 뒤 확정함

## 2.2 플레이어가 직접 판단하고 반응함

- 옴탈잡이에서는 접근 방향을 보고 몸으로 반응함
- 샌님잡이에서는 완성된 농담을 고르는 대신 샌님의 대사에서 소재 키워드를 고른 뒤 그 소재에 맞는 방식 키워드를 골라 말뚝이의 재담을 만듦
- 먹중잡이에서는 완성된 폭로를 고르는 대신 연희에서 드러난 증거 두 개를 조합해 먹중의 비행을 판단함
- 선택지가 정답을 노출하지 않도록 화면 안내는 행동 직전의 최소 신호만 제공함

## 2.3 평상시 화면은 연희를 우선함

- 상시 점수판과 큰 버튼을 줄이고 배역과 플레이어 모습을 중심에 둠
- 입력이 성립한 순간에만 정지, 확대, 장단, 하이라이트를 강하게 사용함
- 재담 자막은 짧게 표시하고 플레이어의 몸과 배역을 가리지 않음
- 과장된 리액션은 정답 안내가 아니라 희극적 보상으로 사용함. 캐릭터 붕괴 연출의 참고 근거는 [[역전재판 캐릭터 연출 분석]]임

# 3. 전체 체험 흐름

**[사용자 확정]** 시작 화면에서 옴탈잡이, 샌님잡이, 먹중잡이 중 하나를 선택함. 선택과 동시에 유저배역을 고정 배정함. 옴탈잡이는 꺽쇠, 샌님잡이는 말뚝이, 먹중잡이는 취발이를 맡음. 한 번 선택하면 그 배역으로 해당 마당의 도입부터 결말까지 전체를 체험하며, 체험 도중 다른 마당이나 장을 다시 선택하지 않음. 아래 네 국면은 선택 화면의 하위 메뉴가 아니라 선택한 마당 전체 안에서 이어지는 진행 구조임.

1. **관계 제시**: 장쇠가 유저배역을 소개하고 상대배역의 상태와 갈등 관계를 짧게 보여줌
2. **첫 대결**: 유저배역과 상대배역이 처음 맞서는 사건을 진행함
3. **변주**: 각 마당의 갈등을 되풀이하며 상대와의 관계 변화를 선명하게 함
4. **결말**: 각 마당의 원전 사건을 마무리까지 이어가고 체험을 끝냄

샌님잡이의 여섯 단계는 관계 제시의 `시작`, 첫 대결의 `인사`와 `절 배우기`, 변주의 `따라 하기`와 `절 받기`, 결말의 `마무리`에 대응함.

세 마당 사이의 선후 순서는 없음. 플레이어는 원하는 마당 하나를 골라 해당 마당을 완주하고 체험을 마침.

## 3.1 공통 종료와 입력 복구

- **공통 콘텐츠 마무리 화면**: 마당을 정상 완주하면 장쇠가 결과를 짧게 말함. 결과 표시 시간이 끝나면 시작 화면으로 자동 복귀하며, 표시 시간은 `[확인 필요]`로 두고 프로토타입에서 정함. 마당 안의 결말 연출과 이 화면을 같은 상태로 합치지 않음
- **복구 화면**
	- 진입: 입력 구간에서 센서 인식이 끊긴 시간이 기준값을 넘고 재안내 뒤에도 정해진 횟수만큼 인식되지 않으면 이동함. 인식 중단 시간과 재안내 횟수는 `[확인 필요]`임
	- 입력 다시 확인: 현재 마당의 진행값, 완료한 폭로와 `증거 완료 표시`를 보존함. 판정 전에 고른 관찰 증거와 보강 증거는 해제하고 인식이 끊긴 입력 단계부터 다시 시작함
	- 처음으로: 현재 마당의 진행값을 지우고 시작 화면으로 돌아감
	- 판정: 복구 화면 이동은 게임 안의 패배로 세지 않음
- **접근성 원칙**: 몸이나 손을 인식하는 입력은 서거나 앉은 자세, 다양한 신장, 휠체어 사용과 다양한 동작 범위에서 시험함. 인식 거리와 높이, 대체 입력 제공 여부, 대체 시각 및 음성 안내 방식은 `[확인 필요]`로 두고 프로토타입에서 정함

# 4. 옴탈잡이: 피하고 쫓아내기

## 4.1 옴탈잡이 핵심 경험

플레이어에게 자꾸 접근하는 옴탈을 몸으로 피한 뒤 직접 몰아냄. 질병 자체를 조롱하는 체험으로 만들지 않고, 눈치 없이 거리를 좁히는 민폐 인물과의 신체적 대치로 현대화함.

**[원형 근거]** 재담, 대치, 몰아내기의 흐름을 보존해야 함 ([[덧뵈기의 재미 요소#3. 옴탈잡이]]).

## 4.3 원전 사건 처리표

[[#4.2 원전 원자 사건 추출]]의 B1~B30을 현재 흐름에 빠짐없이 대응함. `사용`은 사건을 현재 흐름에 남긴다는 뜻이고, `각색`은 관계나 기능을 남기되 카메라 시점, 동작 또는 재생 시점을 바꾼다는 뜻이며, `제외`는 화면에서 쓰지 않는 사건과 사유를 밝힌 것임. `플레이 단계`는 각 사건이 [[#4.4 옴탈잡이 기본 루프]]의 어느 단계에 쓰이는지 나타냄.

|---|---|---|---|---|
| B1 | 사용 | 시작 | 꺽쇠의 재등장으로 마당을 엶 | 장쇠의 진행과 센서 확인은 별도 설계 추가로 분리함 |
| B2 | 사용 | 시작 | 꺽쇠의 등장 기세를 발화로 보여줌 | 원전 순서를 유지함 |

## 4.4 옴탈잡이 기본 루프

**[초안]** [[#4.3 원전 사건 처리표]]의 사건을 여섯 단계로 연결하고 단계마다 화면과 시점이 어떻게 바뀌는지 정함. 입력과 전이는 [[#4.5 단계와 판정]]이 소유함.

`시작 → 조우 → 반격 → 채검 → 몰아내기 → 마무리`

| 단계   | 화면과 시점                                                                       | 단계 역할                                    |
| ---- | ---------------------------------------------------------------------------- | ---------------------------------------- |
| 시작   | 장쇠와 꺽쇠를 함께 보여주는 마당 전경                                                        | 플레이어 역할을 소개하고 위치와 손 인식 안내를 준비함           |
| 조우   | 꺽쇠와 옴탈의 거리 관계가 보이는 3인칭 화면                                                    | 옴탈의 임의 방향 접근과 거리 상태 갱신을 반복함              |
| 반격   | 꺽쇠를 숨기고 옴탈의 머리를 가까이 보여주는 1인칭 화면. 하단 대사창을 함께 표시함                              | 플레이어가 꺽쇠로 행동하는 시점으로 바꾸고 외모와 옴 내력 재담을 시작함 |
| 채검   | 옴탈의 얼굴과 하단 대사창을 계속 보여주는 1인칭 화면                                               | 얼굴 채검과 재담으로 몰아내기의 근거를 드러내고 옴탈의 반발로 마무리함  |
| 몰아내기 | B26에서 3인칭으로 전환해 옴탈 본체를 숨기고 화면 중앙의 꺽쇠 주위에 옴 표적을 배치함. 옴 표적은 꺽쇠와 하단 대사창을 가리지 않음 | 원전의 춤 대치를 옴 표적 상태가 바뀌는 반복으로 각색함          |
| 마무리  | 옴 표적을 모두 숨기고 꺽쇠와 옴탈 본체를 다시 보여주는 결과 화면                                        | 성공이면 옴탈의 퇴장을, 패배이면 옴탈의 춤과 도발을 보여줌        |

- **반복 구간**
	- 조우: `옴탈 접근 → 거리 상태 갱신 → 접근 위치 재설정`을 조우 구간이 끝날 때까지 반복함
	- 몰아내기: `옴 표적 표시 → 표적 상태 갱신 → 남은 표적 확인`을 성공 또는 패배가 정해질 때까지 반복함

## 4.5 단계와 판정

**[초안]** 각 단계에서 무엇을 입력으로 받고 언제 다음 단계로 넘어가는지 정함. 출처 없이 수치를 만들지 않고, 프로토타입 시험으로 정할 값은 `확인 필요`로 남김.

- **판정 원칙**
	- 최종 분기: 성공과 패배는 몰아내기에서 옴 표적을 모두 없앴는지로만 가름함
	- 앞 단계 결과: 조우의 접촉은 즉시 반응만 일으키며 반격, 채검, 몰아내기 진입을 막지 않음
	- 인식 실패: 플레이어 입력이 실제로 열린 구간에서만 센서 인식 실패 처리를 적용함. B20 발화 이전을 포함한 자동 연출 구간에는 적용하지 않음. 입력 구간에서 센서가 플레이어를 찾지 못해도 게임 안의 실패로 세지 않으며, 진행과 제한 시간을 멈추고 다시 안내함. 거듭 인식되지 않으면 복구 화면으로 이동함

| 단계 | 플레이어 입력 | 판정 조건과 결과 | 판정 미성립 처리 | 다음 진행 |
|---|---|---|---|---|
| 시작 | 위치 안내 영역 안에 서서 손을 화면에 보이게 함 | 몸의 중심과 손이 안내 영역에서 설정된 확인 시간 동안 함께 인식됨 | 몸의 중심이나 손이 안내 영역을 벗어나면 확인 진행을 초기화하고 다시 안내함 | 인식이 성립하면 조우로 진행함 |
| 조우 | 플레이어가 몸을 옮겨 옴탈과 거리를 유지함 | 꺽쇠와 옴탈의 충돌 영역이 겹치지 않으면 회피, 겹치면 접촉으로 판정함 | 접촉 반응을 보여준 뒤 두 인물을 접촉 전 위치로 되돌리고 조우를 계속함 | 설정된 조우 시간이 끝나면 접촉 결과와 관계없이 반격으로 진행함 |
| 반격 | 옴탈 머리의 행동 아이콘 위에 손을 유지함 | 손과 아이콘 영역이 설정된 유지 시간 동안 계속 겹치면 머리 잡기가 성립함 | 손이 영역을 벗어나면 유지 진행을 초기화하고 아이콘을 계속 보여줌 | 머리 잡기 뒤 반응과 B15~B16 재담이 끝나면 채검으로 진행함 |
| 채검 | B20 발화가 끝난 뒤 옴탈 얼굴의 행동 아이콘 위에 손을 유지함 | 손과 아이콘 영역이 설정된 유지 시간 동안 계속 겹치면 채검이 성립함 | 손이 영역을 벗어나면 유지 진행을 초기화하고 아이콘을 계속 보여줌 | 채검, 재담과 옴탈의 반발이 끝나면 B26 화면 전환으로 몰아내기를 시작함 |
| 몰아내기 | 꺽쇠 주위에 나타난 옴 표적을 손으로 침 | 손이 옴 표적 영역을 통과하면 해당 표적을 없앰. 제한 시간 안에 모든 표적을 없애면 성공함 | 손이 옴 표적 영역을 통과하지 않으면 표적을 그대로 둠. 제한 시간이 끝났을 때 표적이 남아 있으면 패배함 | 성공 또는 패배가 정해지면 남은 옴 표적을 모두 숨기고 옴탈 본체를 다시 표시한 뒤 마무리로 진행함 |
| 마무리 | 없음 | 몰아내기의 성공 또는 패배 판정을 그대로 사용함 | 해당 없음 | 결과 연출이 끝나면 공통 콘텐츠 마무리 화면으로 이동함. 이 화면에서 장쇠가 결과를 말함 |

- **프로토타입 확인 항목**
	- 조우: 옴탈 이동 범위와 속도, 방향 전환 간격, 충돌 영역, 조우 시간을 프로토타입에서 정함
	- 반격과 채검: 행동 아이콘의 크기와 위치, 손 인식 유지 시간, 유지 진행 표시 방식을 프로토타입에서 정함
	- 몰아내기: 옴 표적의 수와 크기, 출현 영역과 배치 방식, 제한 시간을 프로토타입에서 정함
	- 인식 복구: 센서 인식이 끊겼다고 보는 시간과 복구 화면으로 넘기는 재안내 횟수를 프로토타입에서 정함

## 4.6 연출 원칙

- 옴탈의 의상과 소품 실루엣을 과장하고, 엇박 걸음과 춤의 리듬, 거리 침범의 타이밍으로 기괴한 캐릭터 코미디가 성립하게 함. 질병 특징이나 환자의 신체를 본뜬 과장은 사용하지 않음
- 옴탈의 접근과 버티기를 춤으로 연결하고, 패배 때의 도발과 성공 때의 퇴장을 크게 과장해 신체 코미디를 만듦
- 옴탈과 유저배역 꺽쇠의 재담은 장면 안의 대치와 반응으로 사용함. 장쇠는 배역 소개, 입력 안내와 시범, 장면 전환을 담당하되 플레이어 대신 행동하지 않음. 성공 또는 패배 결과는 마당 연출이 끝난 뒤 공통 콘텐츠 마무리 화면에서 장쇠가 말함
- 옴탈의 외형과 행위를 설계할 때 질병의 증상이나 환자가 아니라 민폐 행동과 거리 침범이 웃음의 대상이 되게 함

샌님이 세운 권위를 먼저 충분히 보여준 뒤, 말뚝이 역의 플레이어가 샌님의 말을 바탕으로 소재 키워드와 방식 키워드를 차례로 골라 재담을 만들고 샌님의 권위를 뒤집음. 높은 사람의 말을 이용해 권위를 무너뜨리는 원형의 재미를 보존하면서, 샌님을 거듭 골탕먹여 화를 돋우는 것이 플레이 목표임 ([[덧뵈기의 재미 요소#4. 샌님잡이]]).

| S6    | 528~530행 | 말뚝이가 등장해 과장된 인사를 함                                      |
| S7    | 532~542행 | 샌님이 절을 요구하자 말뚝이가 사찰 이름으로 비틀어 받음                         |
| S8    | 544~558행 | 샌님이 절을 가르치려 하고 말뚝이는 샌님의 행동과 말을 하나도 빼지 않고 따라 하겠다고 함     |

## 5.3 원전 사건 처리표

[[#5.2 원전 원자 사건 추출]]의 S1~S14 각각을 `사용`, `각색`, `제외` 중 하나로 분류함. `사용`은 원전 사건의 관계와 순서를 유지하는 처리이고, `각색`은 사건의 기능을 남기되 화자나 행동, 대사를 현재 체험에 맞게 바꾸는 처리이며, `제외`는 사용하지 않는 사건과 사유를 밝힌 것임. 이 절에서는 사건의 처리와 플레이 단계, 승패 결과에 따른 마무리 분기만 다룸. 재담 입력 방식과 승패 판정 기준은 다루지 않음.

**단계 순서**: 시작 → 인사 → 절 배우기 → 따라 하기 → 절 받기 → 마무리

| 사건 ID | 처리  | 플레이 단계    | 맡는 기능                                                             | 적용 방식 또는 사유                                                                          |
| ----- | --- | --------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| S1    | 제외  | 해당 없음     | 해당 없음                                                             | 노친네를 등장 인물에서 빼고 샌님과 노친네의 관계 도입도 제외함                                                  |
| S2    | 제외  | 해당 없음     | 해당 없음                                                             | 유람 허세 대목을 빼고 샌님이 말뚝이를 찾는 사건부터 시작함                                                    |
| S3    | 각색  | 시작        | 장쇠가 샌님에게 찾는 사람을 물어 하인의 이름을 기억하지 못하는 허점을 드러냄                       | 원전 잽이의 질문과 지적은 진행자 장쇠가 맡음                                                            |
| S4    | 각색  | 시작        | 장쇠와 샌님의 막대기 말놀이 끝에 장쇠가 말뚝이라는 이름을 말하자 샌님이 하인의 이름임을 알아챔             | 원전 잽이의 대사는 장쇠가 맡고 원문 대사 중 필요한 부분을 골라 씀                                               |
| S5    | 각색  | 인사        | 샌님의 긴 부름을 장쇠가 받아 말뚝이의 인사 분기를 엶                                    | 원전 잽이의 지적은 장쇠가 맡고 원문 대사 중 필요한 부분을 골라 씀                                               |
| S6    | 각색  | 인사        | 말뚝이가 등장한 뒤 과장된 인사로 첫 재담 갈래를 만듦                                    | 528행의 등장은 공통부로 사용하고 530행의 인사부터 선택 조합에 따른 갈래로 나눔. 갈래 안에서 말뚝이의 인사와 샌님의 반응을 다르게 작성함          |
| S7    | 각색  | 절 배우기     | 샌님의 절 요구를 말뚝이가 다른 뜻으로 받아치며 절 말놀이 대결을 이어감                          | 532행의 샌님 대사를 공통부로 삼고, 그 뒤 재담을 선택 조합에 따른 갈래로 나눔                                        |
| S8    | 사용  | 절 배우기     | 하나도 빼놓지 말고 따라 하라는 명령이 이후 모방의 조건이 되게 함                             | 샌님의 말이 빠짐없는 모방을 허용하는 조건이 되는 원전 흐름을 유지함                                               |
| S9    | 각색  | 따라 하기     | 말뚝이가 샌님의 말을 그대로 되받으며 위계를 흔듦                                       | 대사를 되받는 반복은 남기되 욕설을 직접 되풀이하지 않음                                                       |
| S10   | 각색  | 따라 하기     | 샌님과 말뚝이의 말싸움이 격해지고 말뚝이가 명령을 따랐다고 항변하게 함                           | 씨름은 제외하고, 샌님의 말과 행동을 되받은 말뚝이가 빠짐없이 따르라는 명령을 근거로 항변하는 재담만 남김                          |
| S11   | 사용  | 절 받기      | 샌님이 자기 잘못을 인정하고 말은 따라 하지 말라는 조건을 붙여 절하는 법을 다시 가르침                 | 샌님이 새 조건을 붙이고 절 교육을 다시 시작하는 원전 순서를 유지함                                               |
| S12   | 각색  | 절 받기      | 샌님이 말뚝이에게 절하는 모양이 되어 권위가 뒤집히고, 말뚝이가 자신은 양반 노릇을 그만두겠다며 샌님의 권위를 조롱함 | 노친네를 제외하고 샌님과 말뚝이의 관계 변화와 말뚝이의 조롱을 남김                                                |
| S13   | 제외  | 해당 없음     | 해당 없음                                                             | 노친네를 제외하고 승패에 따라 갈리는 새 마무리를 사용하므로 세 인물이 함께 추는 춤, 말뚝이와 노친네의 퇴장을 제외함                   |
| S14   | 제외  | 해당 없음     | 해당 없음                                                             | 먹중잡이로 바로 연결하지 않으므로 피조리 등장, 원전에서의 샌님 퇴장과 피조리춤을 제외함                                    |

여섯 단계, 네 주요 분기와 분기 뒤 합류 구조는 사용자 확정 진행임. 두 마무리 분기의 연출은 현재 초안임.

## 5.4 샌님잡이 진행 초안

**[사용자 확정]** 이 절은 샌님잡이 진행 규칙의 정본임. 키워드 조합은 샌님의 모든 대사에서 실행하지 않고 `인사`, `절 배우기`, `따라 하기`, `절 받기`의 네 주요 분기에서만 한 번씩 실행함. 여섯 단계 가운데 이 네 단계가 각각 같은 이름의 주요 분기를 품으며, `시작`과 `마무리`에는 주요 분기를 두지 않음. 선택한 조합은 분기 안에서 진행할 재담 갈래를 정하고, 갈래가 끝나면 다음 주요 분기 또는 마무리 판정으로 이어지는 공통 사건에 합류함. 분기 사이의 원전 사건은 키워드 입력 없이 단선으로 진행함.

전체 진행은 다음 흐름을 따름.

`시작(S3~S4) → 인사(S5와 S6 528행 공통부 → S6 530행 재담 갈래 → S7 532행 합류부) → 절 배우기(S7 532행 공통부 뒤 재담 갈래 → S8 합류부) → 따라 하기(S9 공통부 → 재담 갈래 → S10 합류부) → 절 받기(S11 공통부 → 재담 갈래 → S12 합류부) → 마무리`

앞 분기의 합류부와 다음 분기의 공통부가 같은 원전 사건이면 그 사건을 한 번만 재생하고, 앞 분기의 종료와 다음 분기의 시작을 잇는 전환 사건으로 함께 사용함. 따라서 S7의 532행은 인사 분기의 합류부이자 절 배우기 분기의 공통부지만 한 번만 재생함.

네 주요 분기의 역할과 합류 지점은 다음과 같음.

| 주요 분기 | 원전 사건   | 분기 전 공통부                               | 키워드 조합 뒤 재담 갈래                                   | 합류 공통부                                                |
| ----- | ------- | -------------------------------------- | ------------------------------------------------ | ----------------------------------------------------- |
| 인사    | S5~S6   | 샌님이 말뚝이를 길게 부르고 말뚝이가 등장함                  | 선택 조합에 따라 말뚝이가 샌님의 부름을 이용해 인사를 다르게 비틀고 샌님이 서로 다른 강도로 반응함 | 샌님이 인사 대신 절을 요구하는 S7에 합류한 뒤 절 배우기로 진행함                 |
| 절 배우기 | S7~S8   | 샌님이 말뚝이에게 인사 대신 절을 요구함                  | 선택 조합에 따라 말뚝이가 절 요구를 다르게 비틀고 샌님이 서로 다른 강도로 반응함   | 샌님이 말뚝이에게 자신의 말과 행동을 빠짐없이 따라 하라고 조건을 제시한 뒤 따라 하기로 진행함 |
| 따라 하기 | S9~S10  | 샌님이 절하는 법을 보여주고 말뚝이가 샌님의 말을 되받기 시작함    | 선택 조합에 따라 되받는 말과 샌님의 반응이 달라지며, 원전의 따라 하기 관계는 유지함 | 말뚝이가 샌님의 지시를 따랐다고 항변한 뒤 절 받기로 진행함                     |
| 절 받기  | S11~S12 | 샌님이 자기 잘못을 인정하고 새 조건을 붙여 절하는 법을 다시 가르침 | 선택 조합에 따라 말뚝이의 재담, 샌님이 말뚝이에게 절하게 되는 과정과 반응이 달라짐  | 샌님의 권위가 뒤집힌 공통 사건으로 합류한 뒤 마무리 판정으로 진행함                |

`재담 갈래`는 소재 키워드와 방식 키워드의 조합에 대응하도록 미리 작성한 진행임. 각 갈래에는 말뚝이의 대사, 샌님의 맞대응과 반응, 분노 점수를 함께 정함.

각 주요 분기는 다음 순서로 처리함.

1. **공통 사건 제시**: 현재 주요 분기를 여는 공통 대사와 행동을 키워드 입력 없이 진행함
2. **소재 키워드 제시**: 현재 샌님의 대사를 바탕으로 미리 정한 소재 키워드를 화면 중앙의 선택 영역에 표시함
3. **소재 선택**: 플레이어가 소재 키워드 하나를 고름
4. **방식 키워드 제시**: 소재 키워드 목록을 그대로 둔 채 선택한 소재에 대응하는 방식 키워드만 표시함. 플레이어가 다른 소재를 고르면 방식 키워드 목록을 새 소재에 맞게 바꿈
5. **조합 확정**: 플레이어가 방식 키워드 하나를 고르는 즉시 소재 키워드와 방식 키워드의 조합을 확정하고 선택 영역을 닫음
6. **갈래 진행**: 현재 주요 분기와 선택 조합에 대응하는 사전 작성 갈래를 재생함
7. **점수 획득**: 갈래가 샌님의 권위를 얼마나 직접 흔드는지에 따라 해당 조합의 분노 점수를 한 번 부여함
8. **공통 사건 합류**: 갈래를 끝내고 다음 주요 분기 또는 마무리 판정으로 이어지는 공통 사건에 합류함. 현재 갈래까지 얻은 분노 점수의 누적 합계는 유지하지만 이후 공통 사건은 바꾸지 않음

키워드 선택과 재담 갈래에는 다음 원칙을 적용함.

- **키워드 유형**
	- 소재 키워드와 방식 키워드는 모두 플레이어가 고르는 키워드이며, 재담에서 맡는 역할로 유형을 구분함
	- **소재 키워드**: 현재 샌님의 대사에서 공격에 사용할 단어나 표현을 나타내며, 주요 분기별로 선택 가능한 목록을 미리 정함
	- **방식 키워드**: 선택한 소재를 어떤 방법으로 비틀지 나타내며, 소재 키워드별로 선택 가능한 목록을 미리 정함
- **선택 순서**
	- **소재 우선**: 화면 중앙에 소재 키워드를 먼저 표시하고 플레이어가 하나를 고르게 함
	- **방식 후속**: 선택한 소재와 조합할 수 있는 방식 키워드만 이어서 표시함
	- **소재 재선택**: 방식 키워드를 고르기 전까지 다른 소재 키워드를 고를 수 있음. 다른 소재를 고르면 방식 키워드 목록을 새 소재에 맞게 바꿈
- **갈래 결과**
	- **갈래 사전 작성**: 각 소재 키워드와 그 소재에 연결된 방식 키워드의 모든 조합에 말뚝이의 대사, 샌님의 맞대응과 반응, 분노 점수를 미리 대응함
	- **분기 내 차이**: 모든 갈래에 분노 점수와 샌님의 반응을 부여함. 실패 갈래는 두지 않고 샌님의 권위가 흔들리는 정도만 다르게 함
	- **분기 밖 합류**: 키워드 조합은 현재 주요 분기의 재담 갈래에만 영향을 줌. 모든 갈래의 후속 원전 사건과 판정 절차는 같고, 현재 갈래까지 얻은 분노 점수의 누적 합계만 유지함
- **데이터 관리**
	- 화면에 제시할 키워드 목록, 소재 키워드에 연결할 방식 키워드의 조합, 각 조합에 대응하는 사전 작성 갈래와 분노 점수를 진행 코드와 분리된 데이터 테이블에서 관리함
	- 키워드와 조합, 각 조합에 대응하는 갈래와 분노 점수를 바꿀 때 진행 코드를 함께 고치지 않게 함

- **마무리**
	- 절 받기 분기까지 끝나면 네 주요 분기에서 얻은 분노 점수를 합산하고, 아직 확정하지 않은 승패 기준에 따라 말뚝이 승리 또는 패배로 나눔
	- 판정 뒤에는 [[#5.3 원전 사건 처리표]]의 마무리 연출을 재생함. 두 마무리 분기는 관계가 한 방향으로 역전되는 원전 결말과 구분되는 설계 추가임
- **미결값**: 분기별 소재 키워드 수, 소재별 방식 키워드 수, 사전 작성 갈래, 분노 점수와 승패 기준은 `[확인 필요]`임

# 6. 먹중잡이: 연희에서 증거를 모아 폭로하기

## 6.1 먹중잡이 핵심 경험

취발이 역의 플레이어가 먹중의 근엄한 첫인상과 욕망이 드러나는 연희를 지켜본 뒤, 그 장면에서 얻은 증거를 두 개씩 조합해 네 가지 비행을 폭로함. 폭로가 쌓일수록 먹중의 자세와 움직임이 무너지고 네 폭로를 마치면 먹중이 스스로 물러남.

- **용어**
	- 피조리: 이 마당에서 먹중과 함께 춤추는 두 인물임
	- 송낙: 원전에서 먹중이 머리에 쓰는 소품임
	- 농탕: 이 문서에서는 먹중이 두 피조리를 데리고 노는 관계를 가리킴
	- 여색: 먹중이 피조리에게 드러내는 욕망과 관계를 가리키는 폭로 이름임
- **원형 근거**: 원전은 먹중이 두 피조리와 농탕치는 모습을 승려의 본분과 대비하고, 취발이와 맞춤을 춘 먹중이 취발이의 코를 때린 뒤 퇴장하는 사건을 담음([[남사당놀이 - 덧뵈기#넷째 마당, 먹중잡이]] 630, 644, 654, 666, 668, 672행)
- **설계 추가**
	- 입력: 연희에서 얻은 증거 두 개를 조합해 비행을 판단함
	- 원형 계승: 먹중과 두 피조리의 관계, 먹중의 무언 행동과 M8의 폭력성을 사용함
	- 새 폭로: 향락과 거짓 영험을 추가하고, 폭력은 술상을 뒤엎는 사건과 말뚝이의 목격으로 각색함
	- 진행: 각 장면을 본 뒤 증거를 내부 수집 목록에 기록함. 모든 장면과 증언이 끝나면 증거판을 한 번 열어 네 폭로를 순서와 관계없이 찾음
- **연출 원칙**: `근엄함 → 작은 이상 행동 → 욕망 노출 → 폭로 누적 → 자세 붕괴 → 퇴장`의 순서를 지킴. 증거판을 열기 전에 먹중의 무언 행동과 주변 인물의 반응을 먼저 보여주고, 유효 조합 뒤에는 설명문보다 먹중의 반응을 앞세움([[덧뵈기의 재미 요소#5. 먹중잡이]])
- **문화 검수**: 피조리가 아니라 먹중의 위선이 웃음의 대상이 되게 함. 거짓 영험과 부적은 불교 문화 일반이 아니라 이 설계에서 추가한 먹중의 속임수로 한정하며, 표현과 동작은 `[확인 필요]` 문화 자문 대상으로 둠

## 6.3 원전 사건 처리표

각 원전 단위를 새 구조에 대응함. 한 단위를 두 곳에 사용할 때는 기능을 나눈 이유를 적용 방식에 적고, 원전에 없는 사건은 아래 설계 추가 표로 분리함.

| 사건 ID | 처리 | 적용 구간 | 맡는 기능 | 적용 방식 또는 사유 |
|---|---|---|---|---|
| M1 | 각색 | 근엄한 등장, 욕망 노출 연희 | 먹중과 피조리의 첫 관계를 보여줌 | 먹중의 근엄한 첫인상을 먼저 세우기 위해 먹중 단독 등장 뒤 피조리가 나타나게 순서를 나눔 |
| M2 | 각색 | 욕망 노출 연희 | 먹중과 두 피조리의 춤과 멈칫을 보여줌 | 취발이는 화면 가장자리에서 이 장면을 지켜본 뒤 증거판에서 관계를 폭로함 |
| M3 | 사용 | 욕망 노출 연희 | 취발이가 나타난 뒤 먹중과 피조리의 눈치 보는 반응을 보여줌 | 원전의 관계 변화를 증거를 얻는 연희 장면으로 사용함 |
| M4 | 각색 | 승려 신분 확인, 여색 폭로 | 먹중의 정체와 두 피조리를 데리고 논다는 정보를 나눠 씀 | M4의 대사는 먹중의 승려 정체와 여색 관계를 전달함. E1과 E2의 시각 단서는 M4가 아니라 원전 복식 설명 127행에서 가져옴 |
| M5 | 각색 | 여색 폭로, 폭로 반응 | 취발이의 꾸짖음과 먹중의 공격적 반응을 보여줌 | 여색 폭로 대사와 폭로가 쌓일수록 거칠어지는 먹중의 무언 반응으로 나눠 사용함 |
| M6 | 각색 | 여색 폭로, 마지막 대치 | 취발이의 여색 지적과 먹중을 꺾겠다는 대치를 이어감 | 여색 폭로의 근거를 보강하고 네 폭로 뒤 취발이가 먹중을 물러나게 하는 대치로 바꿈 |
| M7 | 제외 | 해당 없음 | 춤 대결을 사용하지 않음 | 증거 조합을 먹중잡이의 중심 입력으로 삼아 별도 춤 판정을 두지 않음 |

| M11 | 제외 | 해당 없음 | 사용하지 않음 | 선택한 마당의 독립 체험을 먹중 퇴장과 공통 콘텐츠 마무리 화면에서 끝냄 |

## 6.4 전체 상태 흐름

`취발이 소개 → 먹중의 근엄한 등장 → 승려 신분 확인 안내 → 욕망 노출 연희 → 향락과 폭력 장면 → 거짓 영험 장면 → 말뚝이와 꺽쇠의 증언 → 증거판 열기 → 증거 두 개 선택 → 유효 또는 무효 조합 판정 → 남은 폭로가 있으면 증거 선택으로 복귀 → 네 폭로 완료 → 먹중의 자세 붕괴와 퇴장 → 공통 콘텐츠 마무리 화면`

- **진행 순서**
	1. 장쇠가 플레이어를 취발이로 소개함. 화면 속 취발이는 가장자리에서 먹중을 지켜봄. 플레이어는 다음 승려 신분 확인에서만 안내 입력을 하고, 이후 연희 관찰 구간에는 입력하지 않음
	2. 먹중이 홀로 등장해 근엄한 첫인상을 보임. 송낙과 염주가 차례로 강조되면 플레이어가 두 항목을 고르는 안내용 조합으로 승려 신분을 확인함
	3. 두 피조리가 등장하면 먹중이 시선과 몸을 기울이고 함께 춤춤. 화면 가장자리의 취발이가 판 안으로 들어와 춤추면 먹중과 피조리가 멈칫하고 취발이의 눈치를 봄. 이어 먹중이 술잔을 거듭 비우고, 화가 나 술상을 뒤엎어 부숨
	4. 먹중은 같은 모양의 부적 묶음과 효험을 장담하는 문구를 내보임. 말뚝이는 술상 사건을 증언하고, 꺽쇠는 먹중에게 받은 같은 부적을 돌려주며 장담한 효험이 나타나지 않았다고 증언함. 증언은 증거판이 열리기 전에 모두 들려줌
	5. 각 장면에서 E3~E10을 내부 수집 목록에 기록하고, 모든 장면과 증언이 끝나면 증거판에 한꺼번에 표시함. 플레이어는 관찰 증거와 보강 증거를 하나씩 골라 네 유효 조합을 순서와 관계없이 찾음
	6. 유효 조합이면 앞서 본 장면이나 증언을 짧게 다시 보여주고 취발이가 비행을 폭로함. 먹중의 무언 반응은 폭로가 쌓일수록 커짐
	7. 네 폭로를 모두 마치면 추가 입력 없이 먹중이 균형을 잃고 물러나다가 퇴장함. 마당 연출이 끝나면 공통 콘텐츠 마무리 화면으로 이동함
- **배역 역할**
	- **취발이**: 플레이어 배역으로서 연희를 지켜보고 증거를 선택하며 유효 조합에 대응하는 폭로를 함
	- **장쇠**: 플레이어 역할과 승려 신분 확인을 안내하고, 폭로 근거와 마당 결과를 정리함
	- **먹중**: 대사 없이 몸짓으로 욕망을 드러내고 폭로가 쌓일수록 자세와 움직임이 무너짐
	- **피조리**: 두 사람이 한 증거 단위로 나타나 먹중의 시선과 행동이 달라지는 관계를 보여줌
	- **말뚝이**: 술상 사건을 연희 안에서 목격하고 증거판이 열리기 전에 증언함
	- **꺽쇠**: 먹중이 효험을 장담하며 건넨 부적을 돌려주고 증거판이 열리기 전에 결과를 증언함

## 6.5 승려 신분 확인과 폭로 증거

승려 신분 확인은 증거 조합의 조작을 익히는 안내 단계임. E1과 E2만 제시하고 오답을 고르는 판단 과제로 다루지 않음.

| 증거 ID | 화면에 제시할 항목 | 근거 층 | 원전 위치 |
|---|---|---|---|
| E1 | 먹중이 머리에 쓴 송낙 | 원형 근거 | [[남사당놀이 - 덧뵈기]] 127행 |
| E2 | 먹중이 목과 손에 건 염주 | 원형 근거 | [[남사당놀이 - 덧뵈기]] 127행 |

폭로 증거는 해당 행동, 소품 또는 증언을 확인할 때 내부 수집 목록에 기록함. 모든 장면과 증언이 끝난 뒤 증거판을 한 번 열어 수집한 증거를 공개함. 증거판은 `관찰 증거`와 그 뜻을 보태는 `보강 증거`로 나누며, 피조리 둘은 한 증거 단위로 취급함.

| 증거 ID | 선택 칸 | 화면에 제시할 증거와 관찰 사실 | 근거 층 | 원전 위치 또는 설계 근거 | 수집 장면 |
|---|---|---|---|---|---|
| E3 | 관찰 증거 | 먹중이 술잔을 거듭 비우는 행동 | 설계 추가 | MG-C | 향락 장면 |
| E4 | 보강 증거 | 먹중 자리에 남은 빈 술병과 술잔 | 설계 추가 | MG-C | 향락 장면 |
| E5 | 관찰 증거 | 먹중과 함께 춤추며 농탕친 피조리 둘 | 원형 각색 | [[남사당놀이 - 덧뵈기]] 630, 644, 654행 | 욕망 노출 연희 |
| E6 | 보강 증거 | 피조리 쪽으로 시선과 몸을 기울이는 먹중의 무언 행동 | 설계 추가 | [[덧뵈기의 재미 요소#5.2 먹중의 무언 자체가 재미 요소]]에서 착안한 MG-B | 욕망 노출 연희 |
| E7 | 관찰 증거 | 먹중이 뒤엎어 부서진 술상 | 원형에서 착안한 설계 추가 | M8, MG-D | 폭력 장면 |
| E8 | 보강 증거 | 먹중이 화를 내며 술상을 뒤엎었다는 말뚝이의 목격 증언 | 설계 추가 | MG-D | 말뚝이 증언 |
| E9 | 관찰 증거 | 먹중 곁의 같은 모양 부적 묶음과 특정 효험을 장담하는 문구 | 설계 추가 | MG-E, `[확인 필요]` 문화 자문 | 거짓 영험 장면 |
| E10 | 보강 증거 | 꺽쇠가 돌려준 같은 부적과 장담한 효험이 나타나지 않았다는 증언 | 설계 추가 | MG-E, `[확인 필요]` 문화 자문 | 꺽쇠 증언 |

## 6.6 네 폭로 조합

각 조합은 서로 다른 증거 두 개가 같은 비행의 행동과 관계를 함께 가리키게 함. 증언은 조합 뒤 처음 나오는 근거가 아니라 이미 확보한 근거를 다시 보여주는 연출임.

| 폭로 | 증거 조합 | 두 증거가 입증하는 관계 | 유효 조합 뒤 진행 |
|---|---|---|---|
| 향락 | E3 술을 마시는 행동 + E4 빈 술병과 술잔 | 먹중이 술을 거듭 마신 행동과 남은 결과가 연결됨 | 취발이가 향락을 폭로함 |
| 여색 | E5 피조리 둘 + E6 먹중의 무언 행동 | 원전의 농탕 관계와 피조리 쪽으로 기우는 행동이 연결됨 | 취발이가 여색을 폭로함 |
| 폭력 | E7 뒤엎어 부서진 술상 + E8 말뚝이의 목격 증언 | 파손 결과와 먹중이 술상을 뒤엎은 행동 주체가 연결됨 | 목격 장면을 짧게 다시 보여준 뒤 취발이가 폭력을 폭로함 |
| 거짓 영험 | E9 효험 장담 문구가 붙은 부적 묶음 + E10 꺽쇠가 돌려준 부적과 증언 | 먹중의 효험 장담과 같은 부적에서 확인된 결과가 어긋남 | 꺽쇠의 증언을 짧게 다시 들려준 뒤 취발이가 거짓 영험을 폭로함 |

## 6.7 조합 판정과 완료 조건

- **선택**
	- 플레이어가 관찰 증거에서 하나, 보강 증거에서 하나를 고르면 조합을 판정함
	- 각 칸에서 선택한 증거를 다시 고르면 해당 칸의 선택을 해제함. 같은 칸의 다른 증거를 고르면 기존 선택을 새 선택으로 바꿈
	- 유효 조합에 사용한 두 증거에는 `증거 완료 표시`를 붙이고 선택 대상에서 제외함. 해당 비행에는 별도의 `폭로 완료 표시` 한 개를 붙임
- **유효 조합**
	- 취발이가 조합에서 읽어낸 비행을 폭로하고 장쇠가 근거를 확인함
	- 앞서 본 장면이나 증언을 짧게 다시 보여준 뒤 해당 폭로를 완료 상태로 기록함
	- 먹중은 말하지 않고 몸을 움츠리거나 시선을 피함. 폭로가 쌓일수록 반응 동작의 폭을 키움
- **무효 조합**
	- 장쇠가 두 증거의 관계가 성립하지 않는 이유를 짧게 말함
	- 두 선택을 해제하고 증거판을 유지함. 실패 횟수를 기록하거나 마당 진행을 막지 않음
	- 무효로 판정한 두 증거의 ID를 이력에 남김. 같은 두 증거를 다시 고르면 개별 증거 카드를 흐리지 않고 증거판 위에 `이미 성립하지 않은 조합`이라고 표시함
- **완료 조건**
	- 승려 신분 확인은 네 폭로에 포함하지 않음
	- 향락, 여색, 폭력과 거짓 영험을 각각 한 번씩 완료하면 증거판을 닫고 먹중 퇴장 연출로 진행함
- **인식 실패**
	- 증거를 고르는 동안 센서가 플레이어를 찾지 못하면 진행을 멈추고 손 위치를 다시 안내함
	- 거듭 인식되지 않으면 [[#3.1 공통 종료와 입력 복구]]의 복구 화면으로 이동함
- **확인 필요**
	- 카드를 고르는 물리 조작, 한 화면에 보이는 증거 수와 배치, 무효 조합 표시 시간은 프로토타입에서 정함
	- 거짓 영험 장면에서 먹중이 장담하는 구체적 효험, 기대 결과와 실제 결과, E9와 E10이 같은 부적임을 보여주는 시각 특징은 문화 자문 뒤 정함

## 6.8 진행 데이터 관리

- 증거 설명, 수집 장면, 유효 조합, 무효 조합 안내, 폭로 대사, 장쇠의 확인 대사와 먹중의 반응 동작을 진행 코드와 분리된 데이터 테이블에서 관리함
- 증거 내용이나 조합을 바꿀 때 상태 전이 코드를 수정할 필요가 없도록 함

## 6.9 먹중 퇴장과 마무리

- **전환**: 네 폭로를 모두 마치면 증거판을 닫고 폭로별로 하나씩 기록한 네 `폭로 완료 표시`를 먹중 주위에 차례로 다시 보여줌
- **입력**: 추가 입력을 받지 않음. 네 폭로에서 누적된 먹중의 반응을 결말 연출로 이어감
- **완료**: 먹중이 네 `폭로 완료 표시`를 차례로 피하다가 자세와 균형을 잃고 화면 밖으로 물러남. 장쇠가 결과를 짧게 정리한 뒤 [[#3.1 공통 종료와 입력 복구]]의 공통 콘텐츠 마무리 화면으로 이동함
- **접근성 확인**: 증거 선택의 손 인식 범위, 대체 입력 제공 여부, 대체 시각 및 음성 안내 방식은 [[#3.1 공통 종료와 입력 복구]]의 접근성 원칙에 따라 시험함
- **문화 검수**: 여색, 폭력과 부적 표현이 피조리, 폭력 피해자나 종교 문화를 조롱하지 않고 먹중의 위선과 속임수만 겨냥하는지 문화 자문으로 확인함
- **확인 필요**: 폭로별 먹중 반응, `증거 완료 표시`와 `폭로 완료 표시`의 화면 표현, 퇴장 동작과 장쇠의 마무리 대사는 프로토타입 시험과 문화 자문으로 정함
