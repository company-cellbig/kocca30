> 장쇠가 세 마당의 진행을 맡고, 플레이어는 선택한 마당에 따라 꺽쇠, 말뚝이 또는 취발이가 됨. 옴탈잡이는 옴탈의 공격을 몸으로 피하고 옴을 없애 옴탈을 몰아내며, 샌님잡이는 말의 허점을 집어내고, 먹중잡이는 취발이가 등장한 뒤 몸짓이 달라지는 순간을 지목함.

# 1. 재설계 목표

기존 덧뵈기의 세 마당을 하나의 판정 방식으로 묶지 않음. [[덧뵈기의 재미 요소]]가 구분한 희극 구조를 기준으로 마당마다 플레이어가 하는 일을 다르게 설계함.

| 마당 | 유저배역 | 상대배역 | 원형의 재미 | 유저배역이 하는 일 | 결과 |
|---|---|---|---|---|---|
| 옴탈잡이 | 꺽쇠 | 옴탈 | 기괴한 상대와 대치하고 몰아냄 | 옴탈의 공격을 피하고 옴을 없앰 | 성공하면 옴탈이 퇴장하고, 패배하면 옴탈이 남아 꺽쇠를 도발함 |
| 샌님잡이 | 말뚝이 | 샌님 | 높은 사람의 말을 이용해 권위를 무너뜨림 | 말의 허점을 집어내 재담으로 받아침 | 샌님의 체면이 깎임 |
| 먹중잡이 | 취발이 | 먹중 | 근엄한 인물의 욕망과 위선을 폭로함 | 수상한 몸짓이 나타난 순간을 지목함 | 지목 결과와 무관하게 먹중과 대결하고 퇴장으로 마당을 마침 |

세 마당을 관통하는 경험은 **겉으로 세운 질서가 플레이어의 개입으로 무너지는 과정**임. 조작을 통일하는 대신 관찰, 선택, 신체 반응이라는 참여 감각을 통일함.

## 1.1 문장 상태 판별 원칙

- **원형 근거**: `[원형 근거]`를 붙이고 출처 wikilink를 함께 적은 덧뵈기의 배역, 희극 구조와 표현 방식임
- **현재 설계안**: 별도 상태 표시가 없는 본문의 플레이 흐름, 입력, 판정과 연출임. 사용자 승인과 시험 전에는 확정 사양이 아님. `[사용자 확정]` 표시 항목은 제외함
- **확인 필요**: `[확인 필요]`를 붙이거나 [[#8. 제작 전에 확정할 항목]] 표에 넣은 원전 재대조, 사용자 결정, 기술 시험과 문화 자문 대상임

# 2. 설계 원칙

## 2.1 원형의 희극 구조를 먼저 보존함

- 캐릭터와 소재만 덧씌운 범용 미니게임을 만들지 않음. 각 마당의 조작은 해당 마당의 재담, 대치와 위선 폭로 구조에서 도출함.
- 각 마당의 도입에서 웃음이 성립하는 관계를 먼저 보여줌
- 성공 보상은 점수보다 상대 인물의 표정, 자세, 움직임이 무너지는 장면으로 줌
- 실패는 즉시 게임오버로 끊지 않고 새 재담이나 신체 코미디를 만드는 계기로 씀
- 원전의 배역, 원전에서의 마당 배열과 행위는 [[남사당놀이 - 덧뵈기]]와 다시 대조한 뒤 확정함

## 2.2 플레이어는 완성된 답을 고르지 않음

- 옴탈잡이에서는 접근 방향을 보고 몸으로 반응함
- 샌님잡이에서는 완성된 농담 대신 농담이 시작될 말의 허점을 찾음
- 먹중잡이에서는 결론을 맞히는 대신 취발이 등장 뒤 몸짓이 달라지는 시점을 판단함
- 선택지가 정답을 노출하지 않도록 화면 안내는 행동 직전의 최소 신호만 제공함

## 2.3 평상시 화면은 연희를 우선함

- 상시 점수판과 큰 버튼을 줄이고 배역과 플레이어 모습을 중심에 둠
- 입력이 성립한 순간에만 정지, 확대, 장단, 하이라이트를 강하게 사용함
- 재담 자막은 짧게 표시하고 플레이어의 몸과 배역을 가리지 않음
- 과장된 리액션은 정답 안내가 아니라 희극적 보상으로 사용함. 캐릭터 붕괴 연출의 참고 근거는 [[역전재판 캐릭터 연출 분석]]임

# 3. 전체 체험 흐름

**[사용자 확정]** 시작 화면에서 옴탈잡이, 샌님잡이, 먹중잡이 중 하나를 선택함. 선택과 동시에 유저배역을 고정 배정함. 옴탈잡이는 꺽쇠, 샌님잡이는 말뚝이, 먹중잡이는 취발이를 맡음. 한 번 선택하면 그 배역으로 해당 마당의 도입부터 결말까지 전체를 체험하며, 체험 도중 다른 마당이나 장을 다시 선택하지 않음. 아래 네 단계는 선택 화면의 하위 메뉴가 아니라 선택한 마당 전체 안에서 이어지는 진행 구조임.

1. **관계 제시**: 장쇠가 유저배역을 소개하고 상대배역의 상태와 갈등 관계를 짧게 보여줌
2. **규칙 학습**: 첫 행동은 방향과 성공 조건이 분명하게 보이게 함
3. **변주**: 속도, 표현의 강도, 선택 후보를 바꿔 같은 판단을 반복하게 함
4. **붕괴**: 입력 결과와 무관하게 각 마당의 원전 사건이 결말까지 이어지고, 성공은 상대 인물의 반응만 바꿈

세 마당 사이의 선후 순서는 없음. 플레이어는 원하는 마당 하나를 골라 해당 마당을 완주하고 체험을 마침.

# 4. 옴탈잡이: 피하고 쫓아내기

## 4.1 옴탈잡이 핵심 경험

플레이어에게 자꾸 접근하는 옴탈을 몸으로 피한 뒤 직접 몰아냄. 질병 자체를 조롱하는 체험으로 만들지 않고, 눈치 없이 거리를 좁히는 민폐 인물과의 신체적 대치로 현대화함.

**[원형 근거]** 재담, 대치, 몰아내기의 흐름을 보존해야 함 ([[덧뵈기의 재미 요소#3. 옴탈잡이]]).

| B27 | 각색 | 몰아내기 | 장단을 청하는 발화로 절정의 리듬을 높임 | 발화 순서는 유지하되 옴 표적 제거 반복과 함께 재생함 |

## 4.4 옴탈잡이 기본 루프

**[초안]** [[#4.3 원전 사건 처리표]]의 사건을 여섯 단계로 연결하고 단계마다 화면과 시점이 어떻게 바뀌는지 정함. 입력과 전이는 [[#4.5 단계와 판정]]이 소유함.

`시작 → 조우 → 반격 → 채검 → 몰아내기 → 마무리`

| 단계 | 화면과 시점 | 단계 역할 |
|---|---|---|
| 시작 | 장쇠와 꺽쇠를 함께 보여주는 마당 전경 | 플레이어 역할을 소개하고 위치와 손 인식 안내를 준비함 |
| 조우 | 꺽쇠와 옴탈의 거리 관계가 보이는 3인칭 화면 | 옴탈의 임의 방향 접근과 거리 상태 갱신을 반복함 |
| 반격 | 꺽쇠를 숨기고 옴탈의 머리를 가까이 보여주는 1인칭 화면. 하단 대사창을 함께 표시함 | 플레이어가 꺽쇠로 행동하는 시점으로 바꾸고 외모와 옴 내력 재담을 시작함 |
| 채검 | 옴탈의 얼굴과 하단 대사창을 계속 보여주는 1인칭 화면 | 얼굴 채검과 재담으로 몰아내기의 근거를 드러내고 옴탈의 반발로 마무리함 |
| 몰아내기 | B26에서 3인칭으로 전환해 옴탈 본체를 숨기고 화면 중앙의 꺽쇠 주위에 옴 표적을 배치함. 옴 표적은 꺽쇠와 하단 대사창을 가리지 않음 | 원전의 춤 대치를 옴 표적 상태가 바뀌는 반복으로 각색함 |
| 마무리 | 옴 표적을 모두 숨기고 꺽쇠와 옴탈 본체를 다시 보여주는 결과 화면 | 성공이면 옴탈의 퇴장을, 패배이면 옴탈의 춤과 도발을 보여줌 |

- **반복 구간**
	- 조우: `옴탈 접근 → 거리 상태 갱신 → 접근 위치 재설정`을 조우 구간이 끝날 때까지 반복함
	- 몰아내기: `옴 표적 표시 → 표적 상태 갱신 → 남은 표적 확인`을 성공 또는 패배가 정해질 때까지 반복함

## 4.5 단계와 판정

**[초안]** 각 단계에서 무엇을 입력으로 받고 언제 다음 단계로 넘어가는지 정함. 출처 없이 수치를 만들지 않고, 프로토타입 시험으로 정할 값은 `확인 필요`로 남김.

- **판정 원칙**
	- 최종 분기: 성공과 패배는 몰아내기에서 옴 표적을 모두 없앴는지로만 가름함
	- 앞 단계 결과: 조우의 접촉은 즉시 반응만 일으키며 반격, 채검, 몰아내기 진입을 막지 않음
	- 인식 실패: 플레이어 입력이 실제로 열린 구간에서만 센서 인식 실패 처리를 적용함. B20 발화 이전을 포함한 자동 연출 구간에는 적용하지 않음. 입력 구간에서 센서가 플레이어를 찾지 못해도 게임 안의 실패로 세지 않으며, 진행과 제한 시간을 멈추고 다시 안내함. 거듭 인식되지 않으면 복구 화면으로 이동함

| 단계 | 플레이어 입력 | 판정 조건과 결과 | 판정 미성립 처리 | 다음 진행 |
|---|---|---|---|---|
| 시작 | 위치 안내 영역 안에 서서 손을 화면에 보이게 함 | 몸의 중심과 손이 안내 영역에서 설정된 확인 시간 동안 함께 인식됨 | 몸의 중심이나 손이 안내 영역을 벗어나면 확인 진행을 초기화하고 다시 안내함 | 인식이 성립하면 조우로 진행함 |
| 조우 | 플레이어가 몸을 옮겨 옴탈과 거리를 유지함 | 꺽쇠와 옴탈의 충돌 영역이 겹치지 않으면 회피, 겹치면 접촉으로 판정함 | 접촉 반응을 보여준 뒤 두 인물을 접촉 전 위치로 되돌리고 조우를 계속함 | 설정된 조우 시간이 끝나면 접촉 결과와 관계없이 반격으로 진행함 |
| 반격 | 옴탈 머리의 행동 아이콘 위에 손을 유지함 | 손과 아이콘 영역이 설정된 유지 시간 동안 계속 겹치면 머리 잡기가 성립함 | 손이 영역을 벗어나면 유지 진행을 초기화하고 아이콘을 계속 보여줌 | 머리 잡기 뒤 반응과 B15~B16 재담이 끝나면 채검으로 진행함 |
| 채검 | B20 발화가 끝난 뒤 옴탈 얼굴의 행동 아이콘 위에 손을 유지함 | 손과 아이콘 영역이 설정된 유지 시간 동안 계속 겹치면 채검이 성립함 | 손이 영역을 벗어나면 유지 진행을 초기화하고 아이콘을 계속 보여줌 | 채검, 재담과 옴탈의 반발이 끝나면 B26 화면 전환으로 몰아내기를 시작함 |
| 몰아내기 | 꺽쇠 주위에 나타난 옴 표적을 손으로 침 | 손이 옴 표적 영역을 통과하면 해당 표적을 없앰. 제한 시간 안에 모든 표적을 없애면 성공함 | 손이 옴 표적 영역을 통과하지 않으면 표적을 그대로 둠. 제한 시간이 끝났을 때 표적이 남아 있으면 패배함 | 성공 또는 패배가 정해지면 남은 옴 표적을 모두 숨기고 옴탈 본체를 다시 표시한 뒤 마무리로 진행함 |
| 마무리 | 없음 | 몰아내기의 성공 또는 패배 판정을 그대로 사용함 | 해당 없음 | 결과 연출이 끝나면 공통 콘텐츠 마무리 화면으로 이동함. 이 화면에서 장쇠가 결과를 말함 |

- **프로토타입 확인 항목**
	- 조우: 옴탈 이동 범위와 속도, 방향 전환 간격, 충돌 영역, 조우 시간을 프로토타입에서 정함
	- 반격과 채검: 행동 아이콘의 크기와 위치, 손 인식 유지 시간, 유지 진행 표시 방식을 프로토타입에서 정함
	- 몰아내기: 옴 표적의 수와 크기, 출현 영역과 배치 방식, 제한 시간을 프로토타입에서 정함
	- 인식 복구: 센서 인식이 끊겼다고 보는 시간과 복구 화면으로 넘기는 재안내 횟수를 프로토타입에서 정함

## 4.6 연출 원칙

- 옴탈의 의상과 소품 실루엣을 과장하고, 엇박 걸음과 춤의 리듬, 거리 침범의 타이밍으로 기괴한 캐릭터 코미디가 성립하게 함. 질병 특징이나 환자의 신체를 본뜬 과장은 사용하지 않음
- 옴탈의 접근과 버티기를 춤으로 연결하고, 패배 때의 도발과 성공 때의 퇴장을 크게 과장해 신체 코미디를 만듦
- 옴탈과 유저배역 꺽쇠의 재담은 장면 안의 대치와 반응으로 사용함. 장쇠는 배역 소개, 입력 안내와 시범, 장면 전환을 담당하되 플레이어 대신 행동하지 않음. 성공 또는 패배 결과는 마당 연출이 끝난 뒤 공통 콘텐츠 마무리 화면에서 장쇠가 말함
- 옴탈의 외형과 행위를 설계할 때 질병의 증상이나 환자가 아니라 민폐 행동과 거리 침범이 웃음의 대상이 되게 함

# 5. 샌님잡이: 말의 허점 집어내기

## 5.1 샌님잡이 핵심 경험

샌님이 세운 권위를 먼저 충분히 보여준 뒤, 말뚝이 역의 플레이어가 샌님의 말에서 공격 지점을 찾고 재담으로 뒤집음. 완성된 반격 문장을 고르는 객관식 퀴즈가 아니라 **어디를 붙잡아야 웃음이 시작되는지 찾는 언어 관찰**이 핵심임 ([[덧뵈기의 재미 요소#4. 샌님잡이]]).

## 5.3 원전 사건 처리표

[[#5.2 원전 원자 사건 추출]]의 S1~S13 각각을 `사용`, `각색`, `제외` 중 하나로 분류함. `사용`은 원전 사건의 관계와 순서를 유지하는 처리이고, `각색`은 사건의 기능을 남기되 화자나 행동, 대사를 현재 체험에 맞게 바꾸는 처리이며, `제외`는 사용하지 않는 사건과 사유를 밝힌 것임. 이 절에서는 사건의 처리와 플레이 단계를 정하고 승패 판정 결과에 따른 마무리 분기만 둠. 재담 입력 방식과 승패 판정 기준은 다루지 않음.

**단계 순서**: 시작 → 절 말놀이 → 따라 하기 → 관계 역전 시도 → 마무리

| 사건 ID | 처리 | 플레이 단계 | 맡는 기능 | 적용 방식 또는 사유 |
|---|---|---|---|---|
| S1 | 제외 | 해당 없음 | 해당 없음 | 노친네를 등장 인물에서 빼고 샌님과 노친네의 관계 도입도 제외함 |
| S2 | 제외 | 해당 없음 | 해당 없음 | 유람 허세 대목을 빼고 샌님이 말뚝이를 찾는 사건부터 시작함 |
| S3 | 각색 | 시작 | 장쇠가 샌님에게 찾는 사람을 물어 하인의 이름을 기억하지 못하는 허점을 드러냄 | 원전 잽이의 질문과 지적은 진행자 장쇠가 맡음 |
| S4 | 각색 | 시작 | 장쇠와 샌님의 막대기 말놀이에서 샌님이 말뚝이의 이름을 떠올림 | 원전 잽이의 대사는 장쇠가 맡고 원문 대사 중 필요한 부분을 골라 씀 |
| S5 | 각색 | 시작 | 샌님의 긴 부름을 장쇠가 받아 말뚝이의 등장을 준비함 | 원전 잽이의 지적은 장쇠가 맡고 원문 대사 중 필요한 부분을 골라 씀 |
| S6 | 각색 | 절 말놀이 | 말뚝이가 등장해 샌님의 절 요구를 다른 뜻으로 받아치며 첫 대결을 만듦 | `절하라`의 `절`을 사찰이라는 뜻으로 바꾸어 받아 말놀이로 이어지는 사건으로 만듦 |
| S7 | 각색 | 따라 하기 | 하나도 빼놓지 말고 따라 하라는 명령이 이후 모방의 조건이 되게 함 | 샌님의 말에서 빠짐없는 모방을 허용하는 표현을 플레이어가 찾는 사건으로 바꿈 |
| S8 | 각색 | 따라 하기 | 말뚝이가 샌님의 말과 동작을 그대로 따라 하며 위계를 흔듦 | 모방의 반복은 남기되 욕설을 직접 되풀이하지 않음 |
| S9 | 각색 | 따라 하기 | 샌님과 말뚝이의 말싸움이 격해지고 말뚝이가 명령을 따랐다고 항변하게 함 | 씨름은 제외하고, 샌님의 말과 행동을 되받은 말뚝이가 빠짐없이 따르라는 명령을 근거로 항변하는 재담만 남김 |
| S10 | 사용 | 관계 역전 시도 | 샌님이 자기 잘못을 인정하고 말은 따라 하지 말라는 조건을 붙여 절하는 법을 다시 가르침 | 입력 슬롯 4에서 관계 역전을 시도할 조건을 만드는 원전 순서를 유지함 |
| S11 | 각색 | 관계 역전 시도 | 입력 슬롯 4의 결과가 `REVERSAL`이면 샌님이 말뚝이에게 절하는 상황이 되어 권위가 뒤집히게 함 | `REVERSAL`이 아니면 관계 역전 연출을 재생하지 않고 해당 반응 유형의 공용 반응만 재생함. 사용할 대사는 원문에서 고름 |
| S12 | 제외 | 해당 없음 | 해당 없음 | 노친네를 제외하고 승패에 따라 갈리는 새 마무리를 사용하므로 세 인물이 함께 추는 춤, 말뚝이와 노친네의 퇴장을 제외함 |
| S13 | 제외 | 해당 없음 | 해당 없음 | 먹중잡이로 바로 연결하지 않으므로 피조리 등장, 원전에서의 샌님 퇴장과 피조리춤을 제외함 |

**설계 추가 마무리**

| 결과 | 조건 | 마무리 연출 |
|---|---|---|
| 말뚝이 승리 | 재담 결과가 말뚝이 승리로 판정됨 | 샌님이 뒷목을 잡고 쓰러진 뒤 화면 밖으로 실려 나감. 운반 주체는 후속 화면 흐름에서 정함 |
| 말뚝이 패배 | 재담 결과가 말뚝이 패배로 판정됨 | 샌님이 말뚝이의 머리채를 잡고 함께 퇴장함 |

다섯 단계와 두 마무리 분기는 현재 진행 초안임. 재담 시스템은 절 말놀이부터 관계 역전 시도까지의 입력과 판정만 맡으며, 장쇠와 샌님의 시작 재담, 마무리 연출과 공통 콘텐츠 마무리 화면은 전체 진행이 맡음.

## 5.4 입력과 결과 규칙

재담 입력은 원전 사건에 대응하는 네 개의 입력 슬롯에서 진행함. 각 슬롯에는 원전의 샌님 대사에서 고른 소재와 비틀기 방식을 결합함. 조합마다 공용 반응을 고르는 `반응 유형 ID`와 샌님을 화나게 한 정도를 나타내는 `분노 효과값`을 함께 기록함.

**입력 구간과 극적 흐름**

| 입력 슬롯 | 대응 사건 | 재담 기능 | 원전 사건의 대표 반응 유형 | 다음 진행 |
|---:|---|---|---|---|
| 1 | S6 | 절의 뜻을 바꾸어 첫 말놀이를 만듦 | `WORDPLAY` 말꼬리 잡기 | 반응 재생 뒤 S7로 진행함 |
| 2 | S7 | 따라 하라는 명령에서 이후 말싸움의 조건을 찾음 | `PROVOKE` 발끈시키기 | 반응 재생 뒤 S8로 진행함 |
| 3 | S8~S9 | 샌님의 말과 행동을 되받고 그 명령을 근거로 항변함 | `SELF_TRAP` 자승자박 | 반응 재생 뒤 S10으로 진행함 |
| 4 | S10 + 조건부 S11 | 새로 붙인 조건을 이용해 관계 뒤집기를 시도하고, `REVERSAL`이면 실제로 뒤집음 | `REVERSAL` 주객전도 | 반응 재생 뒤 분노 효과값을 모아 최종 승패를 계산함 |

- **극적 흐름**: 네 입력 슬롯이 대표하는 극적 기능은 `WORDPLAY → PROVOKE → SELF_TRAP → REVERSAL` 순서로 전개됨. 이는 원전 해석을 통해 잡은 설계 순서이며 실제 반응 유형은 플레이어가 고른 조합에 따라 달라짐. 반응 유형의 점수 서열을 뜻하지 않음
- **사건 전이**: `MISS` 또는 미입력일 때만 같은 슬롯의 입력을 한 번 다시 제시함. 그 밖의 반응 유형은 다음 입력 슬롯으로 진행하고, 입력 슬롯 4가 끝나면 최종 승패 계산과 마무리로 진행함
- **관계 역전 결과**: 입력 슬롯 4에서 `REVERSAL`이 성립할 때만 S11의 관계 역전 연출을 재생함. 다른 반응 유형이면 관계 역전 없이 해당 공용 반응을 재생한 뒤 마무리로 진행함
- **최종 승패**: S11의 관계 역전 성립 여부를 필수 조건으로 쓰지 않음. 네 슬롯의 누적 분노 효과값만으로 말뚝이 승리와 패배를 판정함
- **전체 진행과의 경계**: 재담 시스템은 S6~S11의 네 입력 구간만 맡음. S3~S5의 시작 재담과 승패별 퇴장, 공통 콘텐츠 마무리 화면은 재담 시스템 밖에서 진행함

**한 차례의 입력과 판정**

1. 샌님의 원문 대사를 보여주고 공격 소재로 쓸 단어나 표현을 선택 영역으로 제시함
2. 플레이어가 손을 소재 영역에 머물게 해 하나를 고름
3. `딴뜻`, `그대로`, `뒤집기` 중 한 방식의 영역에 손을 머물게 해 고름
4. 현재 사건 ID, 선택한 소재와 비틀기 방식에 일치하는 조합 레코드에서 반응 유형 ID, 분노 효과값과 재생할 원전 대사를 찾음
5. 원전 대사와 말뚝이의 행동을 재생한 뒤 [[#5.6 샌님의 반응 상태]]에서 반응 유형 ID에 대응하는 공용 반응을 재생함
6. 네 번째 입력 슬롯까지 끝나면 네 슬롯의 분노 효과값을 합산해 최종 승패 기준과 대조함

**반응 유형**

| 반응 유형 ID | 이름 | 판정 기준 |
|---|---|---|
| `MISS` | 헛발질 | 선택한 소재와 방식이 재담으로 이어지지 않아 샌님에게 영향을 주지 못함. 분노 효과값은 항상 분노 효과가 없는 최솟값으로 둠 |
| `COMPLY` | 순응 | 재담은 성립하지만 샌님의 말과 권위를 그대로 받아들임 |
| `WORDPLAY` | 말꼬리 잡기 | 샌님의 표현을 비틀어 한 차례 당황하게 함 |
| `PROVOKE` | 발끈시키기 | 샌님이 말뚝이의 말에 말려들어 평정을 잃고 화를 냄 |
| `SELF_TRAP` | 자승자박 | 샌님이 자신이 만든 말이나 규칙 때문에 반박하기 어려워짐 |
| `REVERSAL` | 주객전도 | 샌님과 말뚝이의 관계가 뒤집혀 샌님의 권위가 무너짐 |

반응 유형 ID는 결과의 종류를 구별하고 공용 반응 자산을 찾는 키임. 유형 사이에는 점수 서열이 없음.

**승패 산정**

- **승리 목표**: 말뚝이의 재담으로 샌님을 화나게 하는 것임
- **판정값**: 각 슬롯에서 최종 확정한 조합의 분노 효과값만 승패 계산에 사용함. 웃음, 권위 손상과 극 진행 상태는 승패 점수에 합산하지 않음
- **판정 방식**: 네 슬롯의 분노 효과값 합계가 승리 기준 이상이면 말뚝이 승리, 미만이면 말뚝이 패배로 판정함
- **미정값**: 분노 효과값의 범위와 승리 기준은 조합표 작성 뒤 QA에서 정함
- **화면 표시**: 분노 효과값은 내부 판정에만 사용하고 화면에 점수로 표시하지 않음

**원문 대사 사용 규칙**

- 샌님과 말뚝이의 대사는 [[남사당놀이 - 덧뵈기#셋째 마당, 샌님잡이]]의 원문에서 고름. 요약하거나 새로 쓴 예시 대사를 결과 대사로 사용하지 않음
- 조합표에는 사용할 원문 행과 대사 식별자를 함께 기록함. 대응하는 원문 대사가 없는 조합은 새 대사를 만들어 채우지 않고 선택 후보에서 제외함
- 첫 선택에는 조합표에 유효한 비틀기 방식이 하나 이상 있는 소재만 보여줌. 소재를 고른 뒤에는 해당 소재와 조합 레코드가 있는 비틀기 방식만 보여줌
- `MISS`는 조합표에 등록된 유효한 조합이지만 샌님을 화나게 하지 못한 결과임. 조합표에 없는 입력과 구분함
- 여러 조합이 같은 원문 대사와 행동으로 자연스럽게 이어지면 해당 자산을 함께 사용함

**판정 미성립과 다음 상태**

- 손 인식이 끊기면 결과를 기록하지 않고 진행을 멈춘 뒤 인식 안내를 다시 보여줌
- 정해진 시간 안에 선택하지 않은 미입력은 입력 안내를 다시 보여주고 같은 슬롯의 입력을 한 번 다시 제시함. 공용 반응은 재생하지 않음
- 첫 결과가 `MISS`이면 `MISS` 공용 반응을 재생한 뒤 같은 슬롯의 입력을 한 번 다시 제시함
- 재입력에서는 처음의 미입력 또는 `MISS`를 폐기하고 두 번째 결과만 해당 슬롯의 최종 결과로 기록함. 두 결과의 분노 효과값을 합산하지 않음
- 재입력에서도 선택하지 않으면 반응 유형 없이 분노 효과가 없는 결과로 확정하고 공용 반응을 재생하지 않은 채 다음 원전 사건으로 진행함
- 재입력에서 다시 `MISS`가 나오면 `MISS`와 분노 효과가 없는 최솟값을 기록하고 `MISS` 공용 반응을 재생한 뒤 다음 원전 사건으로 진행함
- `COMPLY`, `WORDPLAY`, `PROVOKE`, `SELF_TRAP`, `REVERSAL`이 나오면 재입력하지 않고 다음 원전 사건으로 진행함
- 조합이 확정되면 해당 슬롯의 반응 유형 ID와 분노 효과값을 한 번만 기록함. 반응 재생 중에는 다음 입력을 받지 않음
- 말뚝이 승리 또는 패배 마무리가 끝나면 세 마당이 함께 쓰는 공통 콘텐츠 마무리 화면으로 이동하고 장쇠가 결과를 말함

## 5.5 조합별 효과표 초안

반응 유형 ID와 분노 효과값은 같은 조합 레코드에 함께 두되 하나의 값으로 합치지 않음. 반응 유형 ID는 공용 연출을 고르고, 분노 효과값은 최종 승패를 계산함. 같은 반응 유형 안에서도 조합별 원전 반응에 따라 샌님을 화나게 한 정도가 다를 수 있음.

분노 효과값은 조합별 원전 재담 뒤에 이어지는 샌님의 반응 가운데 가장 강한 반응을 기준으로 먼저 배정한 설계 초안임. `사용` 조합 가운데 후속 원전 반응이 없는 설계 분기는 분노 효과가 없는 값으로 둠. `MISS` 설계 분기는 원전에서 이어지는 후속 반응을 분리해 재생하지 않으므로 예외적으로 분노 효과가 없는 값을 사용함. 이 값은 반응 유형의 서열을 뜻하지 않으며 승리 기준은 QA 뒤에 정함.

- **분노 효과값 초안 기준**
	- `0`: 원전 재생 구간에서 샌님이 직접 화내는 반응이 없음
	- `1`: 샌님이 놀라거나 불편해하지만 직접 꾸짖지 않음
	- `2`: 샌님이 말뚝이를 한 차례 직접 꾸짖거나 항의함
	- `3`: 샌님이 꾸짖음이나 항의를 거듭함
	- `4`: 샌님이 말뚝이를 위협하거나 물리적으로 공격함

| 조합 ID | 처리 | 입력 슬롯 | 대응 사건 | 소재 | 비틀기 방식 | 반응 유형 ID | 분노 효과값 초안 | 원문 행 | 대사 식별자 | 말뚝이 행동 또는 제외 사유 | 샌님 후속 반응과 값 근거 |
|---|---|---:|---|---|---|---|---:|---:|---|---|---|
| C1-01 | 사용 | 1 | S6 | 절 | 딴뜻 | `WORDPLAY` | 2 | 534~536행 | `S6-L534-536` | 절을 사찰로 받아 여러 절 이름을 늘어놓음 | 다른 절이 아니라고 직접 꾸짖음 |

**QA 확인 항목**

- **조합 완전성**
	- 화면에서 실제로 선택 가능한 모든 소재와 비틀기 방식의 쌍이 표에 있는지 확인함
	- 각 조합의 원문 행, 대사 식별자와 말뚝이 행동이 실제 원문 사건에 대응하는지 확인함
	- 조합 ID가 중복되지 않고 모든 `사용` 행에 반응 유형 ID와 분노 효과값이 있는지 확인함
	- 모든 `제외` 행의 반응 유형 ID와 분노 효과값이 `해당 없음`으로 표시되어 있고 제외 사유가 있는지 확인함
	- 네 입력 슬롯마다 유효한 조합이 하나 이상 있는지 확인함
- **분노 효과값 분포**
	- 특정 소재나 비틀기 방식에만 0보다 큰 값이 몰리지 않는지 확인함
	- 각 값이 표에 기록한 샌님의 후속 원전 반응과 일치하는지 확인함
	- 승리 기준을 정한 뒤 네 슬롯에서 조합을 하나씩 고른 선택열을 한 경로로 보고, 서로 다른 경로로 승리 기준에 도달할 수 있는지 확인함
- **승패 기준**
	- QA를 시작하기 전에 분노 효과값 범위, 승리 기준, 필요한 승리 경로 수, 시험할 조합 집합과 목표 승패 비율을 기준표에 기록함
	- 분노 효과값 범위와 승리 기준을 바꾸며 예상 승리와 패배 비율을 비교함
	- 웃음, 권위 손상이나 극 진행 상태가 승패 계산에 섞이지 않는지 확인함
	- 입력 슬롯 4에서 `REVERSAL`이 성립하지 않아도 누적 분노 효과값만으로 최종 승패가 정해지는지 확인함
- **관계 역전 연출**
	- 입력 슬롯 4에서 `REVERSAL`이 성립할 때만 S11의 관계 역전 연출이 재생되는지 확인함
	- 다른 반응 유형이면 S11을 재생하지 않고 해당 공용 반응 뒤 마무리로 진행하는지 확인함
- **재입력 기록**
	- 미입력 또는 `MISS` 뒤 한 번만 재입력이 열리는지 확인함
	- 같은 슬롯에서 두 결과가 중복 합산되지 않고 최종 결과 하나만 기록되는지 확인함
- **공용 반응 재사용**
	- 같은 반응 유형 ID가 항상 같은 공용 반응 자산을 가리키는지 확인함
	- 분노 효과값 차이가 공용 반응의 강도나 자산 선택을 바꾸지 않는지 확인함

## 5.6 샌님의 반응 상태

조합표는 원전 사건을 진행하는 대사, 그 대사에 필요한 말뚝이 행동, 반응 유형 ID와 분노 효과값을 소유함. 아래 표는 반응 유형 ID에 대응하는 샌님, 말뚝이와 관객의 짧은 공용 반응 및 음향 효과를 소유함. 마무리 연출은 승패가 정해진 뒤 [[#5.3 원전 사건 처리표]]에서 한 번만 재생함.

|---|---|---|---|---|---|

| `WORDPLAY` | `REACTION_WORDPLAY` | 능청스럽게 받아넘김 | 잠깐 당황함 | 짧은 웃음을 사용함 | 샌님의 평정이 조금 흔들림 |
| `PROVOKE` | `REACTION_PROVOKE` | 기세가 오름 | 표정이 굳고 화를 냄 | 큰 웃음을 사용함 | 샌님의 분노가 드러남 |
| `SELF_TRAP` | `REACTION_SELF_TRAP` | 우세한 태도를 보임 | 반박하지 못하고 곤란한 표정으로 자기 말을 되짚음 | 큰 웃음과 장단 강조를 사용함 | 샌님이 자기 말에 갇힘 |
| `REVERSAL` | `REACTION_REVERSAL` | 샌님보다 앞으로 나서며 우쭐한 태도를 보임 | 한 발 물러서며 분한 표정을 보임 | 관계 역전을 강조하는 웃음과 장단을 사용함 | 관계 역전이 드러남 |

같은 반응 유형 ID를 받은 조합은 분노 효과값과 관계없이 위 표의 공용 반응 묶음 ID가 가리키는 자산을 그대로 재사용함. 분노 효과값은 조합별 원전 재생 구간에 포함된 샌님의 후속 반응을 근거로 내부 승패 판정에만 사용하며, 공용 반응의 강도나 자산 선택을 바꾸지 않음.

# 6. 먹중잡이: 몸짓이 달라지는 순간 지목하기

## 6.1 먹중잡이 핵심 경험

취발이 역의 플레이어가 취발이 등장 전 먹중과 피조리의 춤 상태를 먼저 관찰한 뒤, 취발이의 등장에 무리의 몸짓이 달라지는 순간 화면 속 먹중을 지목함. 원전에서는 먹중과 피조리 모두 반응하므로, 먹중을 단독 지목 대상으로 구별하는 몸짓은 설계 추가로 다룸 ([[덧뵈기의 재미 요소#5. 먹중잡이]]).

상세 순서를 나누기 전에 M1~M11을 모두 배치함. 원전에 없는 정상 수행 장면이나 단서 개수를 먼저 만들지 않고, 각 사건을 현재 체험에서 어떻게 처리하는지 밝힘.

| 사건 ID | 처리 | 상세 진행에서 맡는 기능 | 설계 추가 또는 제외 |
|---|---|---|---|
| M1 | 사용 | 먹중이 얼굴을 가리고 나와 두 피조리와 춤추는 상태를 도입에서 그대로 보여줌 | 원전에 없는 피조리 등장 전 정상 수행 장면은 추가하지 않음 |
| M2 | 사용 | 취발이가 등장하자 먹중과 피조리가 함께 멈칫하는 순간을 지목 후보로 씀 | 원전의 집단 반응 중 먹중을 단독 대상으로 고르게 하기 위해 먹중은 부채로 얼굴을 다시 가리고 피조리는 제자리에서 굳는 차이를 추가함. 지목 허용 시간과 포착 확대도 설계 추가임 |
| M3 | 사용 | 취발이가 춤추는 동안 먹중과 피조리가 모두 눈치를 보는 순간을 지목 후보로 씀 | 먹중은 취발이와 피조리 사이로 고개를 거듭 돌리고 피조리는 취발이를 한 차례 바라보게 해 먹중을 구별하는 동작은 설계 추가임 |
| M4 | 사용 | 원전 잽이가 먹중의 정체를 알리고 취발이가 자신을 소개하는 대결의 말머리로 씀 | 원전 잽이의 대사는 장쇠가 맡고, 긴 자기소개는 화면용 설계 대사로 줄임 |

| M7 | 사용 | 맞춤과 취발이의 인정 뒤 장단이 빨라지는 대결 상승을 보존함 | 플레이어 점수로 승패를 바꾸지 않음 |

| M9 | 사용 | 취발이가 먹중의 퇴장을 자기 승리로 말하고 피조리를 찾는 연결 장면으로 씀 | 원전 잽이의 방향 안내는 장쇠가 맡고 피조리의 갈라지는 동작을 보존함 |

| M11 | 각색 | 취발이와 피조리의 춤, 퇴장과 전체 출연진의 춤을 마당 마무리로 씀 | 피조리를 감싸 안는 신체 접촉은 제외하고 세 인물이 나란히 춤추며 퇴장함 |

지목 후보는 개수를 정하지 않고 다음 조건으로 추출함.

- 취발이 등장 뒤 먹중의 몸 상태가 원전 지문에서 실제로 바뀜
- 화면에서 먹중과 피조리를 함께 보아야 변화를 판단할 수 있음
- 몸짓 변화가 이어지는 원전 사건을 방해하지 않고 지목 가능한 시간으로 드러남

이 조건을 충족한 사건은 M2의 멈칫과 M3의 눈치 보기임. 다만 원전에서 두 사건은 먹중과 피조리의 집단 반응이므로, 먹중만 지목하게 만드는 차별 동작은 사용자 확정 입력을 구현하기 위한 설계 추가임. M1은 취발이 등장 전 상태라 첫 조건을 충족하지 않고, M4부터는 몸짓 변화의 순간이 아니라 정체 폭로와 대결이 진행되므로 후보에서 제외함. 지목 후보 수는 이 사건별 판정의 결과이며 원전에 없는 점진 단계를 추가하지 않음.

## 6.4 지목과 결과 규칙

- **입력**: 취발이 역의 플레이어가 행동 허용 시간에 화면 속 먹중을 손가락으로 가리킴
- **성공**: 손가락 방향이 먹중 영역 안에 들어오면 해당 순간을 잠깐 멈추고 확대하며 취발이의 짧은 반응을 재생함
- **이른 지목**: 행동 허용 시간 전에 먹중을 가리키면 확정하지 않고 연희를 계속함
- **늦은 지목과 무입력**: 행동 허용 시간이 끝나면 재시도하지 않고 다음 원전 사건으로 진행함. 포착 재담만 생략함
- **연습 인식 실패**: 지목 인식 확인에서 손가락 방향이 잡히지 않으면 장쇠가 손 위치를 다시 안내함. 재확인에도 잡히지 않으면 복구 화면으로 이동함
- **판정창 중 인식 끊김 또는 모호 입력**: 해당 포착을 생략하고 원전 사건을 계속 재생함. 같은 사건을 반복하지 않으며 다음 지목 후보나 정체 확인으로 진행함
- **진행값**: 성공 횟수는 마무리 화면의 취발이 반응을 고르는 데만 사용함. 원전 사건의 진행, 춤 대결의 승패와 결말 도달 조건으로 사용하지 않음

상세 진행의 순서 수는 M1~M11과 두 지목 후보를 화면 상태로 펼친 결과임. 제작 중 순서를 합치거나 나눌 때는 먼저 모든 사건의 대응과 제외 사유가 남아 있는지 확인하며, 목표 순서 수나 난도 단계를 맞추기 위해 원전에 없는 사건을 추가하지 않음.

## 6.6 마무리 반응

- **두 순간 모두 포착**: 취발이가 먹중의 멈칫과 눈치 보기를 차례로 짚었다는 짧은 반응을 마무리 화면에 표시함
- **한 순간 포착**: 포착한 행동 하나만 되짚고 나머지를 실패로 강조하지 않음
- **무포착**: 추가 포착 재담 없이 원전의 춤 대결과 전체 춤을 완주했음을 표시함

포착 수는 마무리 반응을 고르는 내부 값이며 먹중의 퇴장, 피조리와의 춤이나 전체 출연진의 춤을 바꾸지 않음.

# 7. 공통 입력과 화면

세 마당은 같은 웹캠 몸 인식을 사용하지만 같은 조작을 되풀이하지 않음. 입력은 각 마당에서 플레이어가 해야 하는 판단에 맞춰 분리함.

## 7.1 공통 배역 구조

장쇠는 세 마당에 항상 등장해 시작, 입력 안내, 재시도, 장면 전환과 원전 잽이의 대사를 맡음. 플레이어의 재담이나 대결은 대신 수행하지 않음. 마당 선택과 동시에 배정된 유저배역 스프라이트가 플레이어의 입력과 결과를 표현함.

| 마당 | 진행자 | 유저배역 | 상대배역 | 보조배역 |
|---|---|---|---|---|
| 옴탈잡이 | 장쇠 | 꺽쇠 | 옴탈 | 없음 |
| 샌님잡이 | 장쇠 | 말뚝이 | 샌님 | 노친네, 피조리 둘 |
| 먹중잡이 | 장쇠 | 취발이 | 먹중 | 피조리 둘, 마무리의 전체 출연진 |

## 7.2 마당별 입력 계약

| 마당 | 플레이어가 판단하는 것 | 입력 | 판정에 필요한 값 | 입력 뒤 반응 |
|---|---|---|---|---|
| 옴탈잡이 | 어느 방향으로 피하고 언제 밀어낼지 | 꺽쇠 역으로 몸 중심을 좌우로 옮기고, 손이나 팔을 크게 뻗음 | 유저 동작과 꺽쇠 스프라이트의 연동, 꺽쇠와 옴탈 충돌 영역의 분리, 손이나 팔의 판정 영역 통과 | 꺽쇠가 피하고 맞서며 옴탈은 접근 실패, 버티기, 튕김이나 퇴장으로 반응함 |
| 샌님잡이 | 대사에서 어느 표현이 재담의 공격 지점인지 | 말뚝이 역으로 손을 단어나 표현 영역에 일정 시간 머물게 함 | 손 위치, 선택 영역과 머무른 시간 | 선택 영역을 확정하고 유저배역 말뚝이의 재담과 반응 유형 ID에 맞는 공용 반응 자산을 재생함 |
| 먹중잡이 | 취발이 등장 뒤 먹중의 몸 상태가 바뀐 순간이 언제인지 | 취발이 역으로 M2의 멈칫과 M3의 눈치 보기에서 화면 속 먹중을 손가락으로 지목함 | 손가락 방향, 먹중 영역과 두 행동의 허용 시간 | 성공한 순간만 잠깐 멈춰 확대하고 취발이의 반응을 재생함. 지목 결과와 무관하게 정체 확인과 춤 대결로 진행함 |

**[사용자 확정]** 샌님잡이의 영역 머무름과 먹중잡이의 손가락 지목은 입력 방식 자체를 바꾸지 않음. 시험에서는 영역 크기, 머무름 시간, 지목 허용 범위와 판정 시간만 조정함.

## 7.3 화면 정보 원칙

- **공통**: 현재 해야 할 행동 하나만 전면에 보여주고, 다음 행동의 정답을 미리 노출하지 않음
- **옴탈잡이**: 플레이어의 실루엣과 옴탈의 거리 관계를 보여주되 안전 방향을 화살표로 직접 알려주지 않음. 옴탈의 재담, 몸 기울기와 춤이 접근 방향의 신호가 됨
- **샌님잡이**: 샌님의 대사를 읽을 수 있는 크기로 띄우고 선택 가능한 표현 영역을 서로 겹치지 않게 둠. 선택이 확정되기 전에는 어느 표현이 강한 공격 지점인지 표시하지 않음
- **먹중잡이**: 먹중과 함께 움직이는 인물들이 보여도 지목 대상인 먹중을 잃지 않게 배치함. 성공 뒤에만 포착 순간을 확대해 지목 후보가 된 몸짓을 보여줌
- **결과 표현**: 점수판보다 옴탈의 거리와 퇴장, 샌님의 표정과 자세, 먹중과 취발이의 대결처럼 배역 상태의 변화로 진행을 보여줌

## 7.4 체험 화면의 흐름

1. 시작 화면에서 세 마당의 핵심 행동을 서로 다른 짧은 설명으로 보여줌
2. 마당을 선택하면 장쇠가 유저배역을 소개하고 카메라 인식 범위와 그 마당의 입력을 안내함
3. 한 차례 연습 입력으로 몸이나 손이 정상 인식되는지 확인함. 유저배역이 아직 원전 등장 시점에 이르지 않은 마당은 스프라이트 대신 입력 표식과 방향선으로 반응을 보여줌
4. 선택한 마당의 도입부터 결말까지 진행함
5. 결말과 선택으로 달라진 배역 반응을 보여주고 체험을 끝냄. 샌님잡이에서 선택이 한 번도 없었으면 추가 재담 없이 원전 사건을 완주했음을 보여줌

정상 완주 뒤에는 결과와 종료 안내를 보여주는 `마무리 화면`으로 이동한 다음 시작 화면으로 돌아감. 센서 인식 실패로 진행할 수 없을 때는 `복구 화면`으로 이동해 인식 확인을 다시 시작하거나 시작 화면으로 돌아가게 함. 두 화면을 같은 종료 상태로 합치지 않음.

체험 중에는 마당 선택 화면으로 돌아가는 분기를 두지 않음. 인식 실패로 계속할 수 없을 때는 처음부터 다시 시작하거나 종료하는 복구 화면으로 보냄.

## 7.5 인식 실패와 재시도

- 연습 입력에서 몸이나 손을 찾지 못하면 장면을 멈추고 인식 범위로 돌아오도록 실루엣 안내를 한 차례 보여줌. 다시 찾지 못하면 복구 화면으로 이동함. 먹중잡이 판정창 중 인식 끊김은 [[#6.4 지목과 결과 규칙]]에 따라 포착만 생략함
- 두 후보가 동시에 선택되거나 지목 방향이 모호하면 실패로 연출하지 않고 입력을 확정하지 않음
- 같은 입력을 반복해서 놓치면 입력별 허용 범위를 완화함. 옴탈잡이는 충돌 영역을 줄이거나 회피 여유를 늘림. 먹중잡이의 M2와 M3은 같은 사건을 반복하거나 다음 후보의 판정 범위를 바꾸지 않음. 마당의 입력 종류는 다른 조작으로 바꾸지 않음
- 샌님잡이에서 손은 정상 인식됐지만 선택하지 않으면 선택 영역을 한 번 크게 표시하고 허용 시간을 늘려 다시 제시함. 두 번째에도 선택하지 않으면 [[#5.4 입력과 결과 규칙]]에 따라 추가 재담을 생략하고 다음 원전 사건으로 진행함
- 먹중잡이에서 손가락은 정상 인식됐지만 행동 구간에 지목하지 않으면 다음 지목 후보나 먹중의 정체 확인으로 진행함

## 7.6 65인치 가로형 화면 구성 초안

**[초안 전제]** 16:9 화면을 1920×1080 논리 좌표로 설계함. 등장인물은 2D 이미지와 스프라이트 애니메이션으로 표시함. 카메라 영상 원본이나 별도 플레이어 캐릭터를 두지 않고, 인식한 동작을 유저배역 스프라이트와 손 위치 표식에 연결함. 실제 출력 해상도가 달라도 아래 비율을 유지함.

### 7.6.1 공통 화면 골격

| 영역 | 기준 범위 | 용도 |
|---|---:|---|
| 안전 여백 | 화면 네 변에서 4% 안쪽 | 글자와 선택 영역이 화면 끝에 붙지 않고, 인물의 중요한 표정이 장식 프레임에 가리지 않게 함 |
| 상단 상태 영역 | 화면 높이의 10% | 선택한 마당 이름과 그만두기 버튼만 둠 |
| 중앙 무대 | 화면 높이의 72% | 배경, 장쇠, 유저배역과 상대배역 스프라이트를 배치함. 마당별 상호작용은 이 영역에서 일어남 |
| 하단 재담 영역 | 화면 높이의 18% | 재담 자막과 짧은 입력 안내를 둠. 샌님잡이에서는 선택할 대사 영역으로 확장함 |

- **정보 우선순위**: 인물 행동, 하단의 대사 또는 행동 안내, 화자 이름, 진행 상태 순으로 읽히게 함
- **고정 UI 최소화**: 마당 이름과 그만두기 외에는 필요한 순간에만 나타나게 해 2D 무대를 가리지 않음
- **하단 대사와 안내 공간**: 모든 대사에 화자 이름을 붙여 하단 고정 영역에 표시함. 행동 안내도 같은 영역을 사용하되 대사와 교대로 표시함. 말풍선은 사용하지 않음
- **플레이어 표시**: 별도 실루엣을 인물처럼 세우지 않음. 유저배역 스프라이트가 플레이어의 움직임과 선택 결과를 나타내고, 손 위치 표식은 선택이나 지목이 필요할 때만 겹쳐 표시함
- **장쇠 고정 위치**: 화면 한쪽 뒤 레이어에 작은 전신 스프라이트로 배치하고 안내와 장면 전환 때만 앞으로 나오게 함
- **인식 상태**: 정상 인식은 실루엣이나 손 커서를 그대로 표시하고, 인식 끊김은 점선과 안내 문구, 모호한 입력은 확정되지 않은 윤곽으로 세 마당에 동일하게 표시함
- **글자와 선택 영역 초안**: 1920×1080에서 하단 행동 안내 52px 이상, 하단 대사 40px 이상, 선택판 제목 44px 이상으로 시작함. 손으로 고르는 영역은 180×120px 이상을 첫 시험값으로 둠
- **공통 장면 문법**: 마당이 시작되면 먼저 마당 전체를 보여 인물 관계와 공간을 설정함. 이후 장쇠가 마당을 열고 주요 인물을 소개함. 상호작용 중에는 마당별 행동 화면과 성공 또는 실패 반응 화면을 오가며, 결말에서는 다시 전체 마당을 보여줌
- **인물별 화면의 범위**: 재담, 입력 안내와 표정 반응은 필요한 인물을 크게 보여줌. 인물 사이의 거리, 접근 방향이나 행동 관계가 판정에 필요한 동안에는 관련 인물을 같은 화면에 두며, 인물별 화면을 계속 유지하지 않음
- **장쇠의 전환**: 전체 마당과 도입 화면에서는 장쇠를 분명히 보여줌. 상호작용이 시작되면 장쇠는 뒤 레이어의 고정 위치로 물러나 주요 인물의 이동 공간을 침범하지 않음

### 7.6.2 시작 화면

- 화면 가운데에 옴탈잡이, 샌님잡이와 먹중잡이 선택판을 가로로 나란히 둠
- 각 선택판은 유저배역인 꺽쇠, 말뚝이와 취발이의 대기 스프라이트, 마당 이름과 핵심 행동 한 줄만 보여줌
  - 옴탈잡이: `피하고 밀어내기`
  - 샌님잡이: `말의 허점 짚기`
  - 먹중잡이: `수상한 순간 지목하기`
- 선택판에 짧은 대기 애니메이션을 재생하되 동시에 큰 동작을 하지 않게 해 시선 경쟁을 줄임
- 선택판 전체를 하나의 선택 영역으로 씀. 선택 뒤에는 선택한 마당의 전체 전경과 배역 소개를 먼저 보여주고, 그다음 위치와 동작 인식 확인과 입력 연습으로 이어감

### 7.6.3 옴탈잡이 화면

- **도입 화면**: 마당 전체에 장쇠, 꺽쇠와 옴탈을 함께 보여준 뒤 장쇠의 안내와 두 배역의 소개 화면으로 전환함
- **중앙 36%**: 유저배역 꺽쇠와 이동 가능 영역을 둠. 플레이어가 움직이면 꺽쇠 스프라이트가 같은 방향으로 피함
- **좌우 각 25%**: 옴탈이 접근하고 물러나는 공간으로 사용함. 접근 방향에 따라 옴탈 스프라이트를 좌우 반전하거나 방향별 자산으로 교체함
- **장쇠 영역 14%**: 무대 한쪽 뒤에 작은 전신 스프라이트로 두고, 시작 안내와 행동 전환 때만 앞으로 움직임. 장쇠의 대사와 안내는 하단 전용 공간에 표시함
- **행동 화면**: 회피와 밀어내기 중에는 꺽쇠와 옴탈을 같은 화면에 두어 접근 방향, 두 인물의 거리와 밀어내는 관계가 보이게 함. 옴탈이 재담할 때는 옴탈을 크게 보여주고, 성공 또는 실패 뒤에는 반응하는 인물을 크게 보여줌
- **판정 표현**: 회피 성공은 옴탈이 플레이어 옆을 지나치는 동작으로, 밀어내기 성공은 옴탈의 버티기 뒤 튕김과 퇴장으로 보여줌
- **화면 상태**: 회피 준비와 결과, 밀어내기 준비와 결과를 구분함. 밀어내기 준비에서는 플레이어 손 위치와 옴탈의 몸 영역을 보여주되 성공 전에는 충돌 효과를 재생하지 않음
- **금지**: 안전 방향 화살표, 큰 충돌 박스와 점수 숫자로 정답을 직접 노출하지 않음

### 7.6.4 샌님잡이 화면

- **도입 화면**: 마당 전체에 장쇠, 샌님과 노친네를 함께 보여줌. 말뚝이는 플레이어 배역임을 알 수 있는 무대 밖 대기 표시로 먼저 보여주고, 원전의 부름이 끝난 뒤 무대에 등장함
- **말뚝이 대기 표시**: 말뚝이의 작은 전신 스프라이트를 화면 오른쪽 가장자리의 무대 밖 영역에 둠. 플레이어 배역 표식일 뿐 S6의 등장 전에는 말하거나 무대 안으로 움직이지 않음
- **말뚝이 등장 전 배치**: 샌님과 노친네를 무대 중앙에 두고 장쇠는 질문하거나 받아칠 때 앞 레이어로 나옴. 그 밖에는 뒤쪽 고정 영역에서 입력과 장면 전환을 안내함
- **말뚝이 등장 뒤 배치**: 상대배역 샌님과 유저배역 말뚝이를 무대 좌우에 서로 마주 보는 전신 또는 허벅지 위 크기의 스프라이트로 배치함. 노친네는 사건에 필요할 때 샌님 뒤에 두고 장쇠는 뒤 레이어로 물러남
- **중앙 여백**: 인물의 몸짓과 관계가 겹치지 않게 비우고, 씨름이나 절 장면에서만 관련 스프라이트가 중앙으로 이동함
- **마지막 배치**: 말뚝이와 노친네가 퇴장하면 샌님을 중앙에 남기고 피조리 둘을 양옆에서 등장시킴. 샌님 퇴장 뒤에는 피조리 둘을 중앙에 나란히 둠
- **재담 화면**: 샌님의 발화, 플레이어의 허점 선택, 말뚝이의 반격과 샌님의 반응 순서로 인물별 화면을 전환함. 노친네나 장쇠가 사건의 주체인 동안에는 해당 인물을 함께 보여주며, 씨름과 절처럼 관계가 행동으로 드러나는 장면은 관련 인물을 같은 화면에 둠
- **하단 대사판**: 한 번에 제시하는 샌님의 대사는 최대 2줄로 보여주고, 선택 가능한 단어나 표현을 큰 영역으로 나눔. 입력 안내와 대사판은 동시에 표시하지 않고 교대로 보여줌
- **선택 상태**: 손이 영역에 들어오면 테두리만 반응하고, 머무름 시간이 채워졌을 때 확정 효과와 말뚝이 재담을 재생함. 강한 공격 지점인지는 확정 전 표시하지 않음
- **결과 상태**: [[#5.6 샌님의 반응 상태]]의 반응 유형 ID에 맞는 공용 반응 자산을 재생함. 분노 효과값은 자산 선택에 쓰지 않음
- **진행 표시**: 분노 효과값은 내부 승패 판정에만 쓰고 별도 점수판에는 표시하지 않음

### 7.6.5 먹중잡이 화면

- **도입 화면**: 마당 전체에 장쇠, 먹중과 두 피조리를 함께 보여주고 취발이는 플레이어 배역임을 알 수 있는 무대 밖 대기 표시로 둠. 원전의 등장 시점인 M2에서 취발이를 전경에 배치함
- **중앙 34%**: 지목 대상인 먹중을 전신으로 배치하고 다른 인물보다 앞 레이어에 둠
- **중앙 양옆 각 23%**: 두 피조리를 배치해 먹중의 시선과 이동 방향이 읽히게 함
- **유저배역 취발이**: M1에서는 무대 밖 대기 표시로 두고 M2에서 전경으로 뛰어나오게 함. 지목 성공마다 반응하고 M4부터 먹중과 대결함
- **장쇠**: 취발이와 반대쪽 뒤 레이어에 둠. 입력 안내, 장면 전환과 M4의 정체 설명을 맡고, M7의 장단 요청과 M8~M10의 재담에 반응함
- **관찰 화면**: M2의 멈칫과 M3의 눈치 보기 동안 먹중과 피조리 둘을 반드시 같은 화면에 둠. M2에서는 먹중이 부채로 얼굴을 다시 가리고 피조리는 제자리에서 굳으며, M3에서는 먹중이 취발이와 피조리 사이로 고개를 거듭 돌리고 피조리는 취발이를 한 차례 바라봄. 먹중만 따로 보여주는 동안에는 플레이어의 지목을 판정하지 않음
- **반응 화면**: 지목이 성립하면 해당 순간을 잠깐 멈춰 먹중의 몸짓을 크게 보여주고, 이어서 취발이의 반응을 보여준 뒤 전체 화면으로 돌아감
- **지목 상태**: 손가락이 가리키는 지점이 먹중 영역 안에 있고 M2 또는 M3의 허용 시간 안이면 지목을 확정함. 허용 시간 전에는 동작을 계속하고, 허용 시간이 지난 지목, 무입력, 모호 입력과 인식 끊김은 포착을 생략함. 같은 사건은 반복하지 않음
- **대결 화면**: M4의 정체 확인부터 취발이와 먹중을 중앙에 마주 세움. M7과 M8의 춤 대결에서는 두 인물을 같은 화면에 두고 피조리 둘은 뒤 레이어로 물러나게 함
- **결말 화면**: 먹중이 퇴장하면 장쇠, 취발이와 피조리 둘을 같은 화면에 두고, 마지막 전체 춤에서는 모든 출연진이 들어올 공간을 확보함

### 7.6.6 스프라이트 레이어와 상태

화면 뒤에서 앞으로 다음 순서로 합성함.

1. **배경**: 마당 공간과 장단에 반응하는 최소 환경 효과
2. **진행자와 뒤 인물**: 장쇠, 현재 상호작용의 대상이 아닌 배역과 대기 동작
3. **주 인물**: 유저배역과 상대배역의 전신 스프라이트
4. **입력 표식**: 손, 손가락 위치와 유저배역의 인식 상태
5. **반응 효과**: 충돌, 지목 확정, 웃음과 장단 강조 효과
6. **UI**: 상태, 재담 자막, 입력 안내와 종료 조작

각 주요 인물은 `대기`, `말하기`, `이동 또는 춤`, `성공 반응`, `실패 반응`, `장면 전환` 상태를 기본 슬롯으로 가짐. 스프라이트 재생이 끝나는 시점과 판정 가능 시간 구간을 분리해, 긴 애니메이션 도중 입력을 놓치거나 다음 장면이 먼저 시작되지 않게 함. 인물별로 실제 필요한 슬롯과 재생 규칙은 8절의 제작 명세에서 확정함.

# 8. 제작 전에 확정할 항목

마당 선택 구조와 샌님잡이의 영역 머무름, 먹중잡이의 손가락 지목은 확정됐으므로 다시 미결로 올리지 않음. 아래에는 현재 설계를 실제 화면과 판정으로 만들기 위해 정해야 하는 값, 자산과 세부 설계 결정을 둠.

| 미결 항목 | 이미 정해진 경계 | 확정 방법 |
|---|---|---|
| 시작 화면의 마당 선택 조작 | 세 마당 중 하나만 선택함 | 터치와 몸짓 중 무인 키오스크에서 오선택이 적은 방식을 시험함 |
| 마당별 목표 체험 시간 | 선택한 마당의 도입부터 결말까지 전체를 진행함 | 각 마당 완주 시간과 전시장 대기 시간을 실측해 장면 수와 반복 횟수를 조정함 |
| 옴탈잡이 판정값 | 몸 이동으로 피하고 큰 팔 동작으로 밀어냄 | 충돌 영역, 이동 거리, 준비된 새 접근 횟수, 밀어내기 범위와 허용 시간을 체형별로 시험함. 실패 재시도와 완화 시도는 새 접근 횟수에서 제외함 |
| 샌님잡이 대사와 선택 영역 | S6과 S7을 입력 후보로 삼고, 무입력이어도 원전 사건은 이어짐 | 두 후보의 설계 대사, 강한 선택과 약한 선택의 연결 재담을 검수해 유지, 통합 또는 제외를 정함. 영역 크기와 머무름 시간도 함께 시험함 |
| 샌님잡이 진행 표시 | 반응 유형 ID와 [[#5.6 샌님의 반응 상태]]를 사용하고 분노 효과값은 화면에 표시하지 않음 | 공용 반응 자산이 반응 유형 ID에 맞게 재생되고 분노 효과값 차이에 따라 바뀌지 않는지 확인함 |
| 먹중잡이 지목 장면 | M2와 M3의 원전 집단 반응에서 먹중만 지목하게 하는 몸짓은 설계 추가이며, 무입력이어도 원전 사건은 이어짐 | 먹중과 피조리의 차별 동작을 문화 자문하고, 두 행동의 시작과 끝, 지목 허용 시간, 먹중 영역과 오지목률을 영상 시제품으로 시험해 후보의 유지, 통합 또는 제외를 정함 |
| 카메라 인식 범위와 접근성 | 세 마당 모두 플레이어의 몸이나 손을 인식함 | 서기와 앉기, 신장, 휠체어 사용과 동작 범위를 포함해 거리, 높이와 대체 안내를 시험함 |
| 65인치 화면 실측 배치 | 16:9, 1920×1080 논리 좌표와 비율 기반 영역을 사용함 | 실제 설치 거리에서 하단 행동 안내 52px, 하단 대사 40px, 선택판 제목 44px와 180×120px 손 선택 영역을 시작값으로 시험하고 안전 여백을 확정함 |
| 스프라이트 제작 명세 | 2D 인물에 상태별 스프라이트 애니메이션을 적용함 | 인물별 상태, 기준 크기, 발 기준점, 좌우 반전, 반복 또는 1회 재생, 초당 프레임과 길이, 중단 우선순위, 판정창 시작과 끝, 완료 이벤트, 다음 상태와 장면별 앞뒤 순서를 확정함 |
| 재담과 음향 자산 | 원전의 관계와 희극 구조를 유지하고 선택 결과에 즉시 반응함 | 사용할 원전 대목, 새로 쓸 연결 재담, 장단과 웃음의 재생 조건을 문화 자문과 연출 검수로 확정함 |
