> 덧뵈기 기획서에 적용했으나 [[덜미 - 전자책 변환 기획서]]에 아직 적용 안 한 공통 사양 표준 항목 목록. 나중에 한 번에 마이그할 작업 백로그. 정합 대상 정본은 [[시범콘텐츠 공통 사양]], 적용 예시는 [[덧뵈기 - 나만의 탈춤 기획서]]. (2026-06-08 기준)

# 1. 배경

2026-06-08 작업에서 덧뵈기 기획서에 공통 사양 표준 여러 개를 적용함. 덜미는 일부만 따라가, 미적용 항목을 모아 나중에 일괄 정리하려고 둠. 이미 정합된 항목(프로세스 순차 sub-step 번호 형식, 행위자 표준, 분기/실패 sub-step 하위)은 제외하고, 남은 것만 적음.

# 2. 미적용 항목

## 가. 화면 필드 (Step별 스크린 목록 + 전환)

- 내용: 각 Step에 `화면` 필드로 풀스크린 목록 + 전환 트리거 기재
- 상태: 덧뵈기 적용, 덜미 미적용 (덜미 Step에 화면 필드 없음)
- 정본: [[시범콘텐츠 공통 사양#나. Step 명세 항목]] 화면 필드

## 나. UI 화면 태그 (프로세스)

- 내용: 프로세스 UI sub-step을 `UI(화면명): 동작`으로 표기해 동작이 어느 화면 건지 연결
- 상태: 덧뵈기 적용, 덜미 미적용 (덜미는 `UI: 동작`)
- 정본: [[시범콘텐츠 공통 사양#3. Step 모델]] 프로세스 정의

## 다. AI 모듈 명세 템플릿

- 내용: AI 모듈을 역할/입출력/모델 확보/판정/성능/적용/데이터/평가 항목으로 명세 (한 줄 라벨 금지)
- 상태: 부분 적용(2026-06-26 재확인). 덧뵈기 5장 가. AI 시스템 적용. 덜미 §4.가 4개 모듈(마당 플롯 LLM, 유저 입력 가공 LLM, 이미지 생성, AI 가드레일)은 역할/입력/출력(+마당 플롯 LLM은 생성 절차)까지 갖췄으나, 템플릿의 모델 확보/판정/성능/적용/데이터/평가 항목은 미반영. (백로그 최초 기록의 "한 줄 라벨 미적용"은 06-19~22 덜미 손질로 해소된 stale 진술이라 갱신)
- 정본: [[시범콘텐츠 공통 사양#가. AI 시스템]] AI 모듈 명세 항목

## 라. 세션 데이터 표 형식 (확인 필요)

- 내용: 세션 데이터를 분류/값/처리 보관/파기 단일 표로 정리
- 상태: 덜미는 별도 구조(세션 안 저장 데이터)라 형식 정합 여부 점검 필요
- 정본: [[시범콘텐츠 공통 사양#2. 세션]]

## 마. 절참조 기호 정리 (워드 이관 시)

- 내용: 자기 문서 절참조 기호(예: 4장 마절을 가리키는 § 표기)를 사람용 표현(N장 X. 제목)으로 전환
- 상태: 덧뵈기는 워드 이관 대비로 전환 완료, 덜미는 기호 유지
- 조건: 덜미를 워드로 옮길 계획이면 동일 정리 필요. 위키 내 열람만이면 보류 가능

## 바. 가독성 표준 (슬래시 절제, 두괄식 라벨, 쉬운 말)

- 내용: 덧뵈기에 적용한 가독성 정비. (1) 슬래시 절제: 3항목 이상 `A/B/C`는 쉼표로, 2항목은 진짜 대안만 유지 (2) 모든 불릿에 두괄식 볼드 라벨, 다항목은 sub-bullet 분리 (3) 표 셀 경량화, 반복 조건은 표 아래 불릿으로 (4) 전문용어 이중부정 금지, 쉬운 말(외래어 한글화 포함, 덧뵈기 예: 폴링→상태 조회, 횡단→공통, 스택→구현 기술)
- 상태: 덜미 미적용. 부분 점검(2026-06-09)에서 3항목 슬래시 다수 확인 (예: `시작/진행/마무리`, `아이/청소년/청년/장년`, `위협/권력/위선/욕심`, `도입/전개/절정/마무리`, `PDF/EPUB/이미지 묶음`, `실사/애니/AI`). 가운뎃점, em-dash는 없음. 두괄식 라벨, 표 셀, 쉬운 말 항목은 전체 점검 미완
- 외래어 잔존(2026-06-26 확인, 덧뵈기는 전역 한글화 완료): `폴링` 8곳(§2.나 S4, §2.다 운영 파라미터), `횡단` 2곳(§4.가.4 "AI 가드레일 (횡단)"은 덧뵈기와 같은 "여러 영역에 걸치는" 뜻이라 "공통"류로 교체, §1.가 "콘텐츠 횡단 누적"은 플랫폼 사양 용어라 교체 전 점검 필요). 마이그 시 이 목록을 체크리스트로 사용
- 정본: [[CONVENTIONS#4) 읽기 쉬운 개조식]], [[CONVENTIONS#2) 쉽게 쓰기]]. 적용 예시 [[덧뵈기 - 나만의 탈춤 기획서]]
