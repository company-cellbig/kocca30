> AI가 덜미 인형극 플롯을 제시하고, 사용자가 거리별 텍스트를 입력하면 AI가 덜미 그림동화로 완성하는 창작 콘텐츠. 기획서 작성 전 콘셉트, 제약, 설계 원칙, 확정 결정을 정리함. [[로드맵 1단계 1년차]] §8 시범서비스 시나리오 5종 중 하나임.

# 1. 콘셉트

- **창작 플로우**: AI가 뼈대(플롯) 제시 → 사용자가 채움(거리별 텍스트) → AI가 완성(그림동화 생성)
  1. 정리된 덜미 문법(마당과 그 구성 거리를 분석해 추출한 설계 자산)을 토대로 AI가 다수의 마당 플롯을 생성해 유저에게 제시
  2. 유저는 주어진 마당의 거리 단위별로 답(대사/전개 텍스트, 이름, 상황별 행동)을 입력
  3. AI가 입력을 토대로 일러스트와 서사를 묶어 덜미 그림동화(전자책)로 생성
- **강점**: 덜미의 문법은 고정하고 그 안에서 사용자가 창작 → 전승과 참여가 동시에 성립함
- **활용 기술**: 생성형 전통 서사 AI ([[로드맵 1단계 1년차]] 3.4), 이미지 생성
- **성격 주의**: 2D 일러스트와 서사 중심 산출물임. 4D 연계는 하지 않기로 결정 (§5 개발 전 결정사항 4) — 프로젝트 4D 코어와 분리된 산출물임

# 2. 제약

- **플레이타임 5분**
- **비고정 출력** — AI 변환 콘텐츠이므로 고정된 이야기가 나오면 안 됨. 유저 입력(이름, 상황별 행동)에 따라 결과물이 실질적으로 달라져야 함
- **매체 환경** — 9:16 세로형 화면 키오스크, 터치 인터페이스

# 3. 전통의 재창조 — 취사 기준

유저 입력으로 극을 구성할 때 무엇을 가져가고 버릴지의 잣대는 "덜미를 덜미이게 하는 문법(정체성)인가, 아니면 특정 대본/시대/연행 매체에 묶인 우연한 살인가"임. 문법은 가져가고, 우연한 살은 버리고, 매체에 묶인 것은 바꿔서 가져감. 그 "바꿔 가져가기"가 곧 재창조임.

## 가. 가져갈 것 — 덜미의 정체성 (문법)

- 박첨지 = 떠돌이 노인 해설자 겸 주역. 거리를 잇는 목소리. 유저는 그 곁에 편입되는 조연
- 재담과 메타연극성 — 인형이 무대 밖(산받이/관객)에 말을 거는 구조. 인터랙티브 콘텐츠와 맞물려 유저가 곧 재담 상대가 됨
- 풍자 정신 — 권위, 위선, 허세를 비트는 태도. 특정 대상이 아니라 태도 자체를 가져감
- 홍동지식 응징의 카타르시스 — 민중의 힘이 위협과 위선을 처치하는 통쾌함
- 에피소드(거리)식 구성 — 느슨하고 빠르고 모듈적. 유저 입력으로 재조합이 가능한 이유가 이 구조
- 골계적 반전 — 권위의 갑작스럽고 허망한 추락
- 인형극 시각 양식 — 나무 인형, 포장, 과장된 형상. 무엇을 그리든 이 양식으로 렌더링

## 나. 버릴 것 — 재창조를 막거나 매체/시대에 묶인 것

- 고정된 특정 줄거리 — 박첨지의 첩, 평안감사 사건 등 특정 사건. 채록본마다 달라 정전도 아니며, 고정하면 결과물이 대동소이해짐
- 시대적으로 낡은 내용 — 처첩 삼각관계를 갈등의 기본값으로 쓰는 것, 여성 인물의 도구적/비하적 취급
- 연행 규모 — 2시간 7거리. 5분 플레이타임 제약과 맞지 않음
- 현장 즉흥성의 라이브 의존 — 실연자가 실제 관객을 읽으며 치는 애드립. AI 콘텐츠에는 라이브 연행자가 없음

## 다. 바꿔서 가져갈 것 — 재창조의 핵심

| 전통 요소 | 바꿔서 가져가기 |
|---|---|
| 산받이(재담 상대) | AI 또는 유저 자신이 산받이 역할 — 재담을 인터랙션으로 |
| 풍자 대상(파계승/탐관) | 유저 세계에서 생성된 위선/권위로 교체, 덜미 양식으로 렌더링 |
| 육담과 욕설 | 해학과 말장난 수위로 순화 (교육/체험 + 유저 생성 맥락) |
| 춤, 장단, 삽입가요 | 정적 매체에서는 삭제 대신 삽화 연출, 의성어, 리듬 있는 텍스트로 치환 |
| 라이브 즉흥성 | 실연자의 즉흥 → AI의 생성 가변성으로 이전 |

요약: 가져갈 것이 "덜미임"을 보장하고, 버릴 것이 "대동소이"를 풀며, 바꿔 가져갈 것이 "재창조"를 완성함.

# 4. 그림동화 적용

- 거리는 "고정 줄거리"가 아니라 "거리 문법"으로 활용 — 거리의 구조와 풍자 초점을 골격으로 삼되 사건 내용은 유저 입력으로 생성
- 박첨지, 홍동지 등 핵심 인물과 그 역할은 고정, 사건과 대사는 유저가 창작
- 거리별 "초점"(풍자 대상)을 가드레일 힌트로 활용
- 구체적 취사 기준은 §3 전통의 재창조 참조

# 5. 개발 전 결정사항

> 아래 항목은 2026-05-15 결정 완료.

1. **그림 스타일** — 인형의 시각 정체성을 일러스트에 유지. 덜미는 나무 인형극이므로 인형의 도구/의상 고유특징을 살리고 일반 동화풍은 배제함
2. **고유특징 가드레일 + 이용 동의** — AI 가드레일을 구축함. 인트로에서 동의 약관으로 주의사항을 안내하고 사용자 동의를 받는 절차를 둠. RFP §2 나의 검증위원회 자문은 별도 병행 ([[ref_제안요청서]] §2 나)
3. **저작권** — 사용자가 저작권 확인을 진행(예정). 박첨지놀이 자체는 공유 자산이나 특정 보존회 대본/연출 차용 시 권리 확인 필요
4. **4D 연계 여부** — 미연계로 결정. 본 콘텐츠는 2D 일러스트와 서사 산출물로 한정함
