> [[덜미 - 전자책 변환 기획서]] §3.가.2 마당 유형(4종) + §3.가.3 공통 골격의 거리별 사건 컨텍스트 풀. 박첨지 페르소나 LLM이 변주 시 선택하는 사전 검수된 후보. §3.나 AI 질문 변주 정책 + §4.가 박첨지 LLM 구현 단계에서 활용. **시드 버전 — 운영 중 추가/제거**.

# 1. 풀 운영 정책

- **시드 분량**: 각 거리/유형 5~10개. 본 문서는 전개 시드 ~7개씩 + 절정 시드 ~4개씩
- **추상화 원칙**: 특정 인물/사건이 아닌 **유형** 정의. 실명/단체/특정 시대 사건 금지 ([[덜미 - 전자책 변환 기획서]] §3.다 가드레일 정책 정합)
- **사전 가드레일 검수**: 풀 항목 추가 시 §3.다 가드레일 정책 통과 확인 (실명/단체/정치인/시대 부적합 차단)
- **골격 문법 보존**: 각 항목은 §3.가.2 해당 유형(전개/절정) 또는 §3.가.3 공통 골격(도입/마무리)의 고정 문법을 유지한 범위 안에서 변주
- **유저 입력 적합성**: 항목은 박첨지 페르소나 LLM이 유저 직전 응답과 어울리는 컨텍스트를 선택할 수 있는 형태로 정의

# 2. 공통 도입 사건 풀

> 고정 문법: 박첨지 떠돌이 노인 등장 + 유저(조연) 일행 합류 + 첫 재담. 모든 유형 공유

- 길에서 우연 마주침
- 잔치/마을 행사에서 합류
- 시장/장터에서 호객 또는 거래 중 합석
- 주막에서 합석
- 산길/들길에서 도움 청함
- 강 건너편에서 부름
- 떠돌이 동행 권유

# 3. 공통 마무리 사건 풀

> 고정 문법: 무언가 지어졌다 곧 허물어짐, 박첨지의 닫는 해설, 무상함. 모든 유형 공유

- 큰 잔치 끝나고 일행이 흩어짐
- 지은 집/물건/공물이 곧 무너짐
- 풍성한 한 해 끝의 정적
- 모인 인연 흩어지는 작별
- 노력의 결과가 짧은 시간에 사라짐
- 마을 떠나는 박첨지 작별 인사
- 무대 정리하고 다음 마을로 향함

# 4. 유형별 전개/절정 사건 풀

각 유형은 전개(갈등)와 절정(해소)이 인과로 직결됨. 절정 사건은 그 전개 대상의 해소로 생성.

## 가. 위협-구원형

> 전개: 외부 위협 고조 / 절정: 홍동지가 힘으로 처치 (응징 카타르시스)

**전개 사건**

- 외부 침입자(괴물/짐승) 마을 위협
- 흉년/재난 위협
- 부랑자 떼 시장 위협
- 도적 떼 행인 위협
- 미지의 그림자 마을 출몰
- 늙은 토호/유지 약자 약탈
- 부당한 요구 압박하는 자

**절정 사건** (홍동지가 전개의 위협을 처치)

- 맨몸으로 때려잡음
- 꾀로 함정에 빠뜨림
- 힘으로 쫓아냄
- 위협의 허점을 폭로해 무력화

## 나. 권력 풍자형

> 전개: 권력자 허세 / 절정: 골계적 추락 (홍동지 조롱 가능). **실제 정치인/공공인물 차단**

**전개 사건**

- 허세 부리는 새 부임 관리
- 권위 자처하는 작은 자
- 시찰 나와 격식만 차리는 자
- 거들먹거리며 잔치 주관
- 신통력/예언 자랑
- 큰 행사 주관
- 가짜 권위/직함으로 위세 부리는 자

**절정 사건** (허세가 우스꽝스럽게 추락)

- 허세가 들통나 망신
- 자기 꾀에 자기가 넘어짐
- 홍동지의 조롱에 체면 무너짐
- 우스꽝스러운 실수로 추락

## 다. 위선 폭로형

> 전개: 위선 행각 / 절정: 폭로/망신 (홍동지 축출 가능). 특정 실명/단체 차단

**전개 사건**

- 겉으로 도덕적 말하던 자가 자기 이익 챙김
- 약자 돕는 척하다 결정적 순간 외면
- 신실함 자처하다 작은 유혹에 무너짐
- 남을 비난하다 자기가 같은 행동
- 친한 척하다 뒤에서 험담
- 청렴 자처하다 작은 뇌물에 손이 가는 모습
- 검소함 가장하다 사치

**절정 사건** (위선이 드러나 망신)

- 겉과 속이 한 자리에서 드러남
- 홍동지가 들춰내 쫓아냄
- 위선의 결과가 자기에게 돌아옴
- 박첨지 재담에 정체 탄로

## 라. 욕심/다툼형

> 전개: 욕심 다툼 / 절정: 파국/손해, 떠남. **처첩 삼각관계 default 금지**, 재산/명예/기회 등으로 추상화. **홍동지 카타르시스가 약한 유형** — 절정 홍동지 변주는 추후 확장 (기획서 §3.가.2, 현 단계 미구체화)

**전개 사건**

- 재산/유산 분배 다툼
- 명예/지위/순위 경쟁
- 공동 작업 결과물 독차지
- 작은 기회에 형제/이웃과 충돌
- 약속된 분배 어김
- 노동 결과 가로채기
- 빌린 것 안 돌려주기

**절정 사건** (욕심이 파국으로)

- 욕심부리다 다 잃음
- 다투다 둘 다 손해
- 갈등 끝에 누군가 떠남
- 나눴어야 할 것을 독차지하려다 파국

# 5. 풀 갱신 절차

- **추가**: 신규 사건 컨텍스트 제안 → §3.다 가드레일 정책 검수 → 본 문서 해당 거리/유형 절에 추가 → log update
- **제거**: 운영 데이터(사용 빈도/유저 반응) 검토 → 제거 결정 → 본 문서에서 삭제 → log update
- **수정**: 사건 컨텍스트 표현 정제 시 의미 보존 확인 → 본 문서 해당 항목 갱신
- **골격/유형 추가/제거 금지**: 마당 공통 골격(도입/전개/절정/마무리)과 4종 유형(위협-구원/권력/위선/욕심) 자체 변경은 §3.가 마당 유형 절의 안건. 본 문서 범위 밖
