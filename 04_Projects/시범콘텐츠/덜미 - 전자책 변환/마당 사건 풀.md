> [[덜미 - 전자책 변환 기획서]] §3.가.2 마당 골격(도입/전개/응징/마무리)의 거리별 사건 컨텍스트 풀. 박첨지 페르소나 LLM이 변주 시 선택하는 사전 검수된 후보. §3.나 AI 질문 변주 정책 + §4.가 박첨지 LLM 구현 단계에서 활용. **시드 버전 — 운영 중 추가/제거**.

# 1. 풀 운영 정책

- **시드 분량**: 각 거리/풍자 유형 5~10개. 본 문서는 시드 ~7개씩 (도입 7 + 전개 21(위선/욕심/권력 각 7) + 응징 7 + 마무리 7 = 총 ~42개)
- **추상화 원칙**: 특정 인물/사건이 아닌 **유형** 정의. 실명/단체/특정 시대 사건 금지 ([[덜미 - 전자책 변환 기획서]] §3.다 가드레일 정책 정합)
- **사전 가드레일 검수**: 풀 항목 추가 시 §3.다 가드레일 정책 통과 확인 (실명/단체/정치인/시대 부적합 차단)
- **골격 문법 보존**: 각 항목은 §3.가.2 해당 거리(전개는 풍자 유형)의 고정 문법을 유지한 범위 안에서 변주
- **유저 입력 적합성**: 항목은 박첨지 페르소나 LLM이 유저 직전 응답과 어울리는 컨텍스트를 선택할 수 있는 형태로 정의

# 2. 도입 거리 사건 풀

> 고정 문법: 박첨지 떠돌이 노인 등장 + 새 인물(유저) 일행에 들임 + 첫 재담

- 길에서 우연 마주침
- 잔치/마을 행사에서 합류
- 시장/장터에서 호객 또는 거래 중 합석
- 주막에서 합석
- 산길/들길에서 도움 청함
- 강 건너편에서 부름
- 떠돌이 동행 권유

# 3. 전개 거리 사건 풀 (풍자 유형 3종)

> 고정 문법: 유저 세계 기반 풍자 갈등 1건 등장. 전개 거리는 아래 풍자 유형 중 1택 (§3.가.3 변주)

## 가. 위선

> 겉/속 다른 자가 망신/응징당함. 위선(가족/이웃 수준) 풍자

- 겉으로 도덕적 말하던 자가 자기 이익 챙기다 들킴
- 약자 돕는 척하다 결정적 순간 외면
- 신실함 자처하다 작은 유혹에 무너짐
- 남을 비난하다 자기가 같은 행동 들킴
- 친한 척하다 뒤에서 험담
- 청렴 자처하다 작은 뇌물에 손이 가는 모습
- 검소함 가장하다 사치 들킴

## 나. 욕심/다툼

> 욕심으로 다툼이 일어나 누군가 떠나거나 손해. 욕심(내부 갈등) 풍자. **처첩 삼각관계 default 금지**

- 재산/유산 분배 다툼
- 명예/지위/순위 경쟁
- 공동 작업 결과물 독차지
- 작은 기회에 형제/이웃과 충돌
- 약속된 분배 어김
- 노동 결과 가로채기
- 빌린 것 안 돌려주기

## 다. 권력

> 권력자 허세 부리다 우스꽝스럽게 추락 (골계적 반전). 권력/허세(위계 수준) 풍자. **실제 정치인/공공인물 차단**

- 허세 부리는 새 부임 관리
- 권위 자처하는 작은 자
- 시찰 나와 격식만 차리는 자
- 거들먹거리며 잔치 주관하다 망신
- 신통력/예언 자랑하다 들킴
- 큰 행사 주관하다 실수
- 가짜 권위/직함으로 위세 부리는 자

# 4. 응징 거리 사건 풀

> 고정 문법: 전개 갈등이 위협으로 고조 + 홍동지 처치 (응징 카타르시스). 모든 마당의 고정 절정. 위협 정체 풍자

- 외부 침입자(괴물/짐승) 마을 위협
- 흉년/재난 위협
- 부랑자 떼 시장 위협
- 도적 떼 행인 위협
- 미지의 그림자 마을 출몰
- 늙은 토호/유지 약자 약탈
- 부당한 요구 압박하는 권력자

# 5. 마무리 거리 사건 풀

> 고정 문법: 무언가 지어졌다 곧 허물어짐. 박첨지의 닫는 해설. 무상함 풍자

- 큰 잔치 끝나고 일행이 흩어짐
- 지은 집/물건/공물이 곧 무너짐
- 풍성한 한 해 끝의 정적
- 모인 인연 흩어지는 작별
- 노력의 결과가 짧은 시간에 사라짐
- 마을 떠나는 박첨지 작별 인사
- 무대 정리하고 다음 마을로 향함

# 6. 풀 갱신 절차

- **추가**: 신규 사건 컨텍스트 제안 → §3.다 가드레일 정책 검수 → 본 문서 해당 거리/풍자 유형 절에 추가 → log update
- **제거**: 운영 데이터(사용 빈도/유저 반응) 검토 → 제거 결정 → 본 문서에서 삭제 → log update
- **수정**: 사건 컨텍스트 표현 정제 시 의미 보존 확인 → 본 문서 해당 항목 갱신
- **골격/풍자 유형 추가/제거 금지**: 마당 골격(도입/전개/응징/마무리)과 전개 풍자 유형(위선/욕심/권력) 자체 변경은 §3.가 마당 골격 절의 안건. 본 문서 범위 밖
