> 장쇠가 공통 체험 준비와 세 마당의 도입을 안내하고, 플레이어는 선택한 마당에 따라 꺽쇠, 말뚝이 또는 취발이의 행동에 개입함. 옴탈잡이는 옴탈을 공격하고 잡아채기와 채검을 거쳐 날아오는 탈을 쳐서 몰아냄. 샌님잡이는 소재 키워드와 방식 키워드를 세 차례 조합해 재담을 만든 뒤 날아오는 샌님의 탈을 쳐서 몰아냄. 먹중잡이는 신분을 확인하고 네 증거 조합으로 향락, 여색, 폭력과 사기를 폭로한 뒤 날아오는 먹중의 탈을 쳐서 몰아냄. 선택한 마당이 끝나면 수행 기록을 결과 화면에 표시하고 체험을 종료함.

# 1. 재설계 목표

각 마당의 핵심 상호작용은 서로 다르게 구성하되, 마당 말미에는 날아오는 상대의 탈을 쳐서 몰아내는 공통 모션 체험을 둠. 옴탈잡이는 신체 대치, 샌님잡이는 키워드 조합, 먹중잡이는 증거 조합을 중심 경험으로 유지함.

| 마당 | 유저배역 | 상대배역 | 원형의 재미 | 유저배역이 하는 일 | 결과 |
|---|---|---|---|---|---|
| 옴탈잡이 | 꺽쇠 | 옴탈 | 기괴한 상대와 대치하고 몰아냄 | 옴탈 공격, 잡아채기와 채검을 진행한 뒤 날아오는 옴탈의 탈을 쳐서 몰아냄 | 지정된 진행 횟수를 채우면 옴탈이 우스꽝스럽게 퇴장함 |
| 샌님잡이 | 말뚝이 | 샌님 | 높은 사람의 말을 이용해 권위를 무너뜨림 | 소재 키워드와 방식 키워드를 세 차례 조합하고 날아오는 샌님의 탈을 쳐서 몰아냄 | 샌님이 말뚝이에게 절한 뒤 화를 내며 마당을 마침 |
| 먹중잡이 | 취발이 | 먹중 | 근엄한 인물의 욕망과 위선을 폭로함 | 신분을 확인하고 향락, 여색, 폭력과 사기의 네 증거 조합을 찾은 뒤 날아오는 먹중의 탈을 쳐서 몰아냄 | 먹중이 다시 등장해 취발이의 마무리 대사를 듣고 우스꽝스럽게 퇴장함 |

세 마당을 관통하는 경험은 **겉보기의 질서가 플레이어의 개입으로 무너지는 과정**임. 조작 방식은 다르지만 선택과 신체 반응을 통해 직접 개입하는 참여 구조를 공유함.

## 1.1 문장 상태 판별 원칙

- **원형 근거**: `[원형 근거]`를 붙이고 출처 wikilink를 함께 적은 덧뵈기의 배역, 희극 구조와 표현 방식임
- **현재 설계안**: 별도 상태 표시가 없는 본문의 플레이 흐름, 입력, 판정과 연출임. 사용자 승인과 시험 전에는 확정 사양이 아님. `[사용자 확정]` 표시 항목은 제외함
- **확인 필요**: `[확인 필요]`를 붙인 원전 재대조, 사용자 결정, 기술 시험과 문화 자문 대상임

# 2. 설계 원칙

## 2.1 원형의 희극 구조를 먼저 보존함

- 캐릭터와 소재만 덧씌운 범용 미니게임을 만들지 않음. 각 마당의 조작은 해당 마당의 재담, 대치와 위선 폭로 구조에서 도출함.
- 각 마당의 도입에서 웃음이 성립하는 관계를 먼저 보여줌
- 성공 피드백은 수행 기록에만 맡기지 않고 진행 표시의 변화와 상대 인물의 반응 동작으로 함께 보여줌
- 실패는 즉시 게임오버로 끊지 않고 새 재담이나 신체 코미디를 만드는 계기로 씀
- 원전의 배역, 원전에서의 마당 배열과 행위는 [[남사당놀이 - 덧뵈기]]와 다시 대조한 뒤 확정함

## 2.2 플레이어가 직접 판단하고 반응함

- 옴탈잡이에서는 화면에 나타난 옴탈을 공격하고 옴탈의 머리와 얼굴에 표시된 행동 아이콘을 모션 입력으로 선택함
- 샌님잡이에서는 완성된 농담을 고르는 대신 샌님의 대사에서 소재 키워드를 고른 뒤 그 소재에 맞는 방식 키워드를 골라 말뚝이의 재담을 만듦
- 먹중잡이에서는 화면에 표시된 소품과 인물 가운데 증거 두 개를 골라 먹중의 비행을 판단함
- 선택지가 정답을 노출하지 않도록 화면 안내는 행동 직전의 최소 신호만 제공함

## 2.3 평상시 화면은 연희를 우선함

- 상시 점수판과 큰 버튼을 줄이고 배역과 플레이어 모습을 중심에 둠
- 입력이 성립한 순간에만 정지, 확대, 장단, 하이라이트를 강하게 사용함
- 재담 자막은 짧게 표시하고 플레이어의 몸과 배역을 가리지 않음
- 과장된 리액션은 정답 안내가 아니라 희극적 보상으로 사용함. 반응 연출의 참고 근거는 [[역전재판 캐릭터 연출 분석]]임

# 3. 전체 체험 흐름

**[사용자 확정]** 인트로 이후 마당 선택 화면에서 옴탈잡이, 샌님잡이, 먹중잡이 중 하나를 선택함. 선택과 동시에 유저배역을 고정 배정함. 옴탈잡이는 꺽쇠, 샌님잡이는 말뚝이, 먹중잡이는 취발이를 맡음. 한 번 선택하면 그 배역으로 해당 마당의 도입부터 결말까지 전체를 체험하며, 체험 도중 다른 마당이나 장을 다시 선택하지 않음. 아래 네 국면은 선택 화면의 하위 메뉴가 아니라 선택한 마당 전체 안에서 이어지는 진행 구조임.

1. **센서 확인**: 화면에 가이드라인을 표시하고 유저가 적절한 위치에 서도록 장쇠가 안내함
2. **관계 제시**: 장쇠가 유저배역을 소개하고 상대배역의 상태와 갈등 관계를 짧게 보여줌
3. **첫 대결**: 유저배역과 상대배역이 처음 맞서는 사건을 진행함
4. **변주**: 각 마당의 갈등을 되풀이하며 상대와의 관계 변화를 선명하게 함
5. **결말**: 각 마당의 원전 사건을 마무리까지 이어가고 체험을 끝냄

샌님잡이의 여섯 단계는 관계 제시의 `시작`, 첫 대결의 `인사하기`와 `절 배우기`, 변주의 `따라 하기`와 `몰아내기`, 결말의 `마무리`에 대응함.

세 마당 사이의 선후 순서는 없음. 플레이어는 원하는 마당 하나를 골라 해당 마당을 완주하고 체험을 마침.

## 3.1 공통 종료

- **결과 데이터 집계**: 현재 언어, 선택 마당과 수행 기록을 불러와 모션 체험의 성공 횟수, 키워드 조합의 획득 점수 또는 증거 조합의 성공 개수로 정리함. 기록이 없는 항목은 미수행 상태로 처리함
- **결과 화면 표시**: 선택한 마당의 명칭과 최종 결과 요약을 현재 언어로 표시함
- **체험 종료**: 유저가 `처음으로` 버튼을 터치하거나 화면 타임아웃 또는 미입력 타임아웃이 실행되면 추가 입력을 차단하고 타이머와 대사 출력을 종료함. 서버에 해당 세션의 체험 종료 상태를 기록하는 기능은 2차년도 개발 사양으로 처리함
- **초기화와 복귀**: 임시 세션 데이터, 선택값, 진행 표시와 타이머를 초기화한 뒤 시작 화면으로 이동함

# 4. 옴탈잡이: 맞서고 쫓아내기

## 4.1 옴탈잡이 핵심 경험

플레이어가 꺽쇠의 행동에 개입해 화면에 나타나는 옴탈을 공격하고, 옴탈을 잡아채고 채검한 뒤 날아오는 탈을 쳐서 몰아냄. 질병 자체를 조롱하는 체험으로 만들지 않고 옴탈과 꺽쇠의 재담과 신체적 대치를 중심에 둠.

**[원형 근거]** 재담, 대치, 몰아내기의 흐름을 보존해야 함 ([[덧뵈기의 재미 요소#3. 옴탈잡이]]).

## 4.3 원전 사건 처리표

[[#4.2 원전 원자 사건 추출]]의 B1~B30을 현재 흐름에 빠짐없이 대응함. `사용`은 사건을 현재 흐름에 남긴다는 뜻이고, `각색`은 관계나 기능을 남기되 카메라 시점, 동작 또는 재생 시점을 바꾼다는 뜻이며, `제외`는 화면에서 쓰지 않는 사건과 사유를 밝힌 것임. `플레이 단계`는 각 사건이 [[#4.4 옴탈잡이 기본 루프]]의 어느 단계에 쓰이는지 나타냄.

| 사건 ID | 처리 | 플레이 단계 | 맡는 기능 | 적용 방식 또는 사유 |
|---|---|---|---|---|
| B1~B3 | 각색 | 시작 | 꺽쇠의 등장과 마당 도입을 보여줌 | 장쇠와 꺽쇠의 재담으로 시작함 |
| B4~B9 | 각색 | 옴탈 조우 | 옴탈 등장과 두 인물의 첫 대치를 보여줌 | 옴탈을 화면 좌우에 반복 배치하고 플레이어의 팔 휘두르기를 꺽쇠의 공격으로 변환함 |
| B10~B16 | 각색 | 옴탈 잡아채기 | 꺽쇠가 옴탈의 머리를 잡으며 주도권을 얻음 | 옴탈 머리 영역에 행동 아이콘을 표시하고 모션 입력 유지로 잡아채기를 판정함 |
| B17~B25 | 각색 | 옴탈 채검하기 | 얼굴 내력 재담과 채검 행동을 이어감 | 옴탈 얼굴 영역에 긁기 아이콘을 표시하고 모션 입력 유지로 채검을 판정함 |
| B26~B28 | 각색 | 옴탈 몰아내기 | 꺽쇠가 옴탈에게 맞서 마당의 절정을 만듦 | 옴탈 본체를 숨기고 여섯 방향에서 날아오는 옴탈의 탈을 팔 휘두르기로 공격함 |

| B30 | 제외 | 해당 없음 | 사용하지 않음 | 꺽쇠가 옴탈을 뒤따라 퇴장하지 않고 마당의 결과 연출에 남음 |

## 4.4 옴탈잡이 기본 루프

[[#4.3 원전 사건 처리표]]의 사건을 여섯 단계로 연결함. 입력과 전이는 [[#4.5 단계와 판정]]이 소유함.

`시작 → 옴탈 조우 → 옴탈 잡아채기 → 옴탈 채검하기 → 옴탈 몰아내기 → 마무리`

| 단계 | 화면과 시점 | 단계 역할 |
|---|---|---|
| 시작 | 장쇠와 꺽쇠를 함께 보여주는 마당 전경 | 두 인물의 재담으로 마당을 시작함 |
| 옴탈 조우 | 화면 중앙의 꺽쇠와 좌우에 나타나는 옴탈을 함께 보여줌 | 옴탈을 팔 휘두르기로 공격하고 진행값을 누적함 |
| 옴탈 잡아채기 | 꺽쇠를 숨기고 옴탈과 머리 영역의 행동 아이콘을 보여줌 | 모션 입력 유지로 옴탈 잡아채기를 반복함 |
| 옴탈 채검하기 | 옴탈과 얼굴 영역의 긁기 아이콘을 보여줌 | 모션 입력 유지로 옴탈 채검을 반복함 |
| 옴탈 몰아내기 | 옴탈을 숨기고 화면 중앙의 꺽쇠 주위로 날아오는 옴탈의 탈을 보여줌 | 팔 휘두르기로 탈을 공격하고 진행값을 누적함 |
| 마무리 | 꺽쇠와 옴탈을 다시 보여줌 | 꺽쇠의 대사 뒤 옴탈이 우스꽝스럽게 퇴장함 |

- **반복 구간**
	- 옴탈 조우: `옴탈 배치 → 팔 휘두르기 판정 → 진행값 반영`을 지정 횟수까지 반복함
	- 잡아채기와 채검하기: `아이콘 표시 → 모션 입력 유지 → 쿨다운 → 진행값 반영`을 지정 횟수까지 반복함
	- 몰아내기: `옴탈의 탈 이동 → 팔 휘두르기 판정 → 진행값 반영`을 지정 횟수까지 반복함

## 4.5 단계와 판정

각 단계에서 무엇을 입력으로 받고 언제 다음 단계로 넘어가는지 정함. 횟수와 쿨다운은 데이터 테이블로 관리함.

| 단계 | 플레이어 입력 | 판정 조건과 결과 | 다음 진행 |
|---|---|---|---|
| 시작 | 없음 | 장쇠와 꺽쇠의 재담을 자동 진행함 | 재담이 끝나면 옴탈 조우로 진행함 |
| 옴탈 조우 | 팔을 휘두름 | 활성 ROI에서 유효한 움직임이 감지되면 공격 성공으로 처리하고 수행 기록과 진행 표시를 갱신함 | 지정 횟수에 도달하면 옴탈 잡아채기로 진행함 |
| 옴탈 잡아채기 | 머리 영역의 행동 아이콘에 손을 유지함 | ROI 유효 판정이 쿨다운 동안 유지되면 잡아채기 성공으로 처리하고 수행 기록과 진행 표시를 갱신함 | 지정 횟수에 도달하면 옴탈 채검하기로 진행함 |
| 옴탈 채검하기 | 얼굴 영역의 긁기 아이콘에 손을 유지함 | ROI 유효 판정이 쿨다운 동안 유지되면 채검 성공으로 처리하고 수행 기록과 진행 표시를 갱신함 | 지정 횟수에 도달하면 옴탈 몰아내기로 진행함 |
| 옴탈 몰아내기 | 날아오는 옴탈의 탈을 향해 팔을 휘두름 | 활성 ROI에서 유효한 움직임이 감지되면 공격 성공으로 처리하고 수행 기록과 진행 표시를 갱신함 | 지정 횟수에 도달하면 마무리로 진행함 |
| 마무리 | 없음 | 꺽쇠의 대사와 옴탈 퇴장 연출을 자동 진행함 | 연출이 끝나면 공통 결과 화면으로 이동함 |

- **프로토타입 확인 항목**
	- 옴탈 조우: 옴탈 배치 횟수와 위치, 공격 ROI와 입력 임계값을 시험함
	- 잡아채기와 채검하기: 행동 아이콘의 크기와 위치, 입력 유지 시간과 쿨다운을 시험함
	- 몰아내기: 탈의 수와 크기, 여섯 출현 지점, 이동 속도와 공격 ROI를 시험함

## 4.6 연출 원칙

- 옴탈의 의상과 소품이 만드는 실루엣, 엇박 걸음과 춤의 리듬을 과장해 기괴한 캐릭터 코미디가 성립하게 함. 질병 특징이나 환자의 신체를 본뜬 과장은 사용하지 않음
- 장쇠는 도입 재담을 맡고, 꺽쇠와 옴탈의 대치가 시작된 뒤에는 플레이어의 입력과 두 인물의 반응을 중심에 둠
- 마당 안의 마무리 연출이 끝나면 수행 기록을 공통 결과 화면에 표시함

| S-B | 몰아내기 | 여섯 방향에서 날아오는 샌님의 탈을 팔 휘두르기로 공격함 | 세 마당 공통의 몰아내기 모션 체험을 적용함 |
| S-C | 마무리 | 샌님이 말뚝이에게 절하고 화내는 동작을 실행함 | 원전의 권위 역전 결과를 단일 마무리로 보여줌 |

여섯 단계 가운데 세 단계에서 키워드 조합을 진행하고, 몰아내기와 마무리는 모든 조합 결과가 합류하는 단일 흐름으로 진행함.

## 5.4 샌님잡이 진행

키워드 조합은 `인사하기`, `절 배우기`, `따라 하기`에서 한 번씩 실행함. 선택한 조합은 해당 단계의 말뚝이 대사, 샌님의 반응과 점수를 정하고, 재담이 끝나면 다음 단계의 공통 흐름으로 합류함.

`시작 → 인사하기 → 절 배우기 → 따라 하기 → 몰아내기 → 마무리`

| 단계 | 주요 진행 | 입력과 결과 |
|---|---|---|
| 시작 | 장쇠와 샌님이 등장해 재담함 | 입력 없이 자동 진행함 |
| 인사하기 | 샌님이 말뚝이를 부른 뒤 조합 이벤트를 엶 | 소재와 방식 키워드를 조합하고 결과 대사와 점수를 수행 기록에 반영함 |
| 절 배우기 | 샌님이 말뚝이에게 절을 시킨 뒤 조합 이벤트를 엶 | 소재와 방식 키워드를 조합하고 결과 대사와 점수를 수행 기록에 반영함 |
| 따라 하기 | 샌님이 말뚝이에게 절을 가르친 뒤 조합 이벤트를 엶 | 소재와 방식 키워드를 조합하고 결과 대사와 점수를 수행 기록에 반영함 |
| 몰아내기 | 말뚝이 주위로 날아오는 샌님의 탈을 표시함 | 팔 휘두르기 입력이 활성 ROI에서 유효하면 공격 성공으로 처리함 |
| 마무리 | 말뚝이와 샌님이 다시 등장해 재담함 | 샌님이 말뚝이에게 절하고 화내는 동작을 실행한 뒤 공통 결과 화면으로 진행함 |

각 키워드 조합은 다음 순서로 처리함.

1. 현재 단계의 샌님 대사를 진행함
2. 선택 가능한 소재 키워드를 표시함
3. 플레이어가 소재 키워드 하나를 선택함
4. 선택한 소재와 조합할 수 있는 방식 키워드를 표시함
5. 플레이어가 방식 키워드 하나를 선택하면 바로 조합을 판정함
6. 조합에 연결된 말뚝이 대사와 샌님의 반응 동작을 진행함
7. 조합별 점수를 수행 기록에 반영함
8. 현재 단계의 조합을 종료하고 다음 단계로 진행함

- **키워드 유형**
	- 소재 키워드는 현재 샌님의 대사에서 재담에 사용할 단어나 표현을 나타냄
	- 방식 키워드는 선택한 소재를 어떤 방법으로 비틀지 나타냄
- **선택 변경**
	- 방식 키워드를 선택하기 전까지 다른 소재 키워드로 바꿀 수 있음
	- 소재 키워드를 바꾸면 방식 키워드 목록을 새 소재에 맞게 갱신함
- **데이터 관리**
	- 단계별 소재와 방식 키워드, 조합 결과 대사, 반응 동작과 점수를 데이터 테이블에서 관리함
	- 키워드 조합 결과는 재담과 수행 기록에만 반영하고 이후 단계의 진행 순서는 바꾸지 않음
- **몰아내기**
	- 화면 우상단의 키워드 조합 진행 표시를 숨기고 몰아내기 진행 표시를 보여줌
	- 화면 좌우의 상, 중, 하 여섯 지점에서 샌님의 탈을 말뚝이에게 이동시킴
	- 공격 성공 횟수를 수행 기록과 몰아내기 진행 표시에 반영함
	- 지정된 공격 성공 횟수에 도달하면 마무리로 진행함

# 6. 먹중잡이: 증거를 조합해 위선 폭로하기

## 6.1 먹중잡이 핵심 경험

취발이 역의 플레이어가 먹중의 모자와 의상을 골라 신분을 확인한 뒤, 화면에 놓인 소품과 인물을 두 개씩 조합해 향락, 여색, 폭력과 사기를 폭로함. 네 위선 폭로를 마치면 날아오는 먹중 탈을 팔 휘두르기로 쳐내고 고정 마무리 연출로 넘어감.

- **용어**
	- 피조리: 이 마당에서 먹중과 함께 춤추는 두 인물임
	- 농탕: 이 문서에서는 먹중이 두 피조리를 데리고 노는 관계를 가리킴
	- 여색: 먹중이 피조리에게 드러내는 욕망과 관계를 가리키는 폭로 이름임
- **원형 근거**: 원전은 먹중이 두 피조리와 농탕치는 모습을 승려의 본분과 대비하고, 취발이와 맞춤을 춘 먹중이 취발이의 코를 때린 뒤 퇴장하는 사건을 담음([[남사당놀이 - 덧뵈기#넷째 마당, 먹중잡이]] 630, 644, 654, 666, 668, 672행)
- **설계 추가**
	- 입력: 화면에 보이는 소품과 인물 가운데 두 개를 골라 위선을 판단함
	- 원형 계승: 먹중과 두 피조리의 관계, M8의 폭력성과 퇴장을 각색 근거로 사용함
	- 새 폭로: 향락과 사기를 추가하고, 폭력은 부서진 술상과 말뚝이의 조합으로 나타냄
	- 진행: 승려 신분을 먼저 확인한 뒤 네 위선을 순서와 관계없이 폭로하고, 날아오는 먹중 탈을 팔 휘두르기로 쳐냄
- **연출 원칙**: `시작 재담 → 승려 신분 확인 → 네 위선 폭로 → 먹중 탈 몰아내기 → 고정 마무리` 순서를 지킴. 완료한 신분과 위선은 화면 상단 아이콘의 색으로 구별함
- **문화 검수**: 피조리가 아니라 먹중의 위선이 웃음의 대상이 되게 함. 부적을 이용한 사기를 불교 문화 일반의 속성으로 제시하지 않고, 이 설계에서 추가한 먹중의 속임수로 한정함. 표현과 동작은 `[확인 필요]` 문화 자문 대상으로 둠

## 6.4 전체 상태 흐름

`장쇠와 취발이의 시작 재담 → 먹중 신분 확인 → 소품과 인물 표시 → 증거 두 개 선택 → 유효 또는 무효 조합 판정 → 남은 폭로가 있으면 증거 선택으로 복귀 → 네 위선 폭로 완료 → 먹중 탈 몰아내기 → 취발이와 먹중의 고정 마무리 → 공통 마무리 화면`

- **진행 순서**
	1. 장쇠를 화면 왼쪽, 취발이를 화면 오른쪽에 놓고 시작 재담을 진행함
	2. 두 인물이 퇴장하면 먹중을 화면 중앙에 놓고 화면 상단에 무채색 신분 아이콘을 표시함. 모자와 의상을 선택하면 신분 조합을 완료하고 아이콘을 유채색으로 바꿈
	3. 소품과 인물을 표시하고 화면 상단에 향락, 여색, 폭력과 사기 아이콘을 무채색으로 추가함. 피조리 갑과 을을 먼저 보이며, 인물 교체 버튼으로 꺽쇠와 말뚝이 조를 바꿔 볼 수 있게 함
	4. 플레이어는 다음 네 증거 조합을 순서와 관계없이 완료함
		- 향락: 부서진 술상 + 염주
		- 여색: 피조리 갑과 을 + 먹중
		- 폭력: 부서진 술상 + 말뚝이
		- 사기: 꺽쇠 + 먹중 허리춤의 부적
	5. 유효 조합을 찾으면 해당 위선 아이콘을 유채색으로 바꿈. 네 위선을 모두 폭로하면 위선 진행 표시를 숨기고 몰아내기 단계로 넘어감
	6. 먹중과 증거 인물이 퇴장하고 취발이를 화면 중앙에 놓음. 화면 여섯 지점에서 포물선으로 날아오는 먹중 탈을 팔 휘두르기로 지정 횟수만큼 쳐냄
	7. 취발이를 화면 오른쪽, 먹중을 화면 왼쪽에 놓고 취발이의 마무리 대사 뒤 먹중의 익살스러운 퇴장을 보여줌. 이후 공통 마무리 화면으로 이동함
- **배역 역할**
	- **취발이**: 플레이어 배역으로서 증거를 선택하고 먹중 탈을 쳐내며 마무리 대사를 함
	- **장쇠**: 시작 재담에 참여함
	- **먹중**: 신분 확인의 대상 인물이며, 여색 조합의 선택 대상이자 몰아내기 대상임
	- **피조리 갑과 을**: 둘이 한 선택 단위로 나타나 여색 조합을 구성함
	- **말뚝이**: 부서진 술상과 함께 폭력 조합을 구성함
	- **꺽쇠**: 먹중 허리춤의 부적과 함께 사기 조합을 구성함

## 6.5 승려 신분 확인과 폭로 증거

승려 신분 확인은 증거 조합의 조작을 익히는 안내 단계임. 모자와 의상만 활성화하고 오답을 고르는 판단 과제로 다루지 않음.

| 증거 ID | 화면에 제시할 항목 | 선택 결과 |
|---|---|---|
| I1 | 먹중의 모자 | I2와 함께 선택하면 신분 조합을 완료함 |
| I2 | 먹중의 의상 | I1과 함께 선택하면 신분 조합을 완료함 |

신분 조합이 끝나면 폭로에 사용할 소품과 인물을 한 화면에 제시함. 피조리 갑과 을은 한 선택 단위로 취급하고, 인물 교체 버튼으로 피조리 갑과 을로 이룬 조와 꺽쇠와 말뚝이로 이룬 조를 교체해 표시함.

| 증거 ID | 화면에 제시할 항목 | 구성 조합 |
|---|---|---|
| E1 | 부서진 술상 | 향락, 폭력 |
| E2 | 염주 | 향락 |
| E3 | 피조리 갑과 을 | 여색 |
| E4 | 먹중 | 여색 |
| E5 | 말뚝이 | 폭력 |
| E6 | 꺽쇠 | 사기 |
| E7 | 먹중 허리춤의 부적 | 사기 |

## 6.6 네 폭로 조합

각 조합은 화면에 보이는 소품과 인물 가운데 증거 두 항목으로 하나의 위선을 가리킴. 네 조합은 순서와 관계없이 완료할 수 있음.

| 폭로 | 증거 조합 | 유효 조합 뒤 진행 |
|---|---|---|
| 향락 | E1 부서진 술상 + E2 염주 | 화면 상단의 향락 아이콘을 유채색으로 바꿈 |
| 여색 | E3 피조리 갑과 을 + E4 먹중 | 화면 상단의 여색 아이콘을 유채색으로 바꿈 |
| 폭력 | E1 부서진 술상 + E5 말뚝이 | 화면 상단의 폭력 아이콘을 유채색으로 바꿈 |
| 사기 | E6 꺽쇠 + E7 먹중 허리춤의 부적 | 화면 상단의 사기 아이콘을 유채색으로 바꿈 |

## 6.7 조합 판정과 완료 조건

- **선택**
	- 플레이어가 화면에 보이는 소품과 인물 가운데 첫 번째 증거와 두 번째 증거를 차례로 고르면 바로 조합을 판정함
	- 이미 선택한 증거를 다시 고르면 해당 선택을 해제함. 선택 순서가 달라도 같은 조합으로 처리함
	- 인물 교체 버튼으로 피조리 갑과 을로 이룬 조와 꺽쇠와 말뚝이로 이룬 조를 바꿔 볼 수 있게 함
- **유효 조합**
	- 해당 위선을 완료 상태로 기록하고 화면 상단 아이콘을 무채색에서 유채색으로 바꿈
	- 성공한 위선의 증거 오브젝트를 숨김
	- 조합 성공에 해당하는 재담과 먹중의 반응 동작을 진행함
	- 미완료 위선이 남아 있으면 선택값을 초기화하고 남은 조합을 계속 찾게 함
- **무효 조합**
	- 실패에 해당하는 재담을 진행함
	- 선택값을 초기화하고 플레이어가 증거 두 개를 다시 선택하게 함
- **완료 조건**
	- 승려 신분 확인은 네 폭로에 포함하지 않음
	- 향락, 여색, 폭력과 사기를 각각 한 번씩 완료하면 위선 진행 표시를 숨기고 먹중 몰아내기로 진행함
- **확인 필요**
	- 항목을 고르는 물리 조작, 한 화면에 보이는 소품과 인물의 배치, 무효 조합 표시 시간은 프로토타입에서 정함
	- 부서진 술상은 향락과 폭력 조합에 함께 쓰이므로, 한 조합을 완료했을 때 해당 오브젝트를 숨기는 정본 공통 규칙과 충돌함. 두 조합을 모두 완료하기 전까지 유지할지 정해야 함
	- 부적의 시각 표현은 문화 자문 뒤 정함

## 6.8 진행 데이터 관리

- 신분과 위선 조합, 성공과 실패 재담, 먹중의 반응 동작, 아이콘 상태, 몰아내기 목표 횟수, 취발이의 대사와 먹중의 퇴장 동작을 진행 코드와 분리된 데이터 테이블에서 관리함
- 증거 내용이나 조합을 바꿀 때 상태 전이 코드를 수정할 필요가 없도록 함

## 6.9 먹중 몰아내기와 마무리

- **전환**: 네 위선을 모두 폭로하면 화면 상단의 위선 진행 표시를 숨기고 몰아내기 진행 표시를 나타냄. 먹중과 증거 인물을 퇴장시키고 취발이를 화면 중앙에 놓음
- **입력**
	- 화면 왼쪽과 오른쪽의 위, 가운데, 아래 여섯 지점에서 먹중 탈이 무작위로 나타나 취발이에게 포물선으로 이동함
	- 플레이어가 팔을 휘두르면 취발이의 팔 휘두르기 동작을 실행함. 모션 인식값이 기준 이상이고 관심 영역 판정이 유효할 때 공격 성공으로 처리함
	- 공격 성공 횟수를 수행 기록과 진행 표시에 반영하고, 데이터 테이블에 정한 횟수에 도달하면 마무리로 넘어감
- **마무리**: 취발이를 화면 오른쪽, 먹중을 화면 왼쪽에 놓음. 취발이의 마무리 대사 뒤 먹중이 익살스럽게 화면 밖으로 퇴장하면 공통 마무리 화면으로 이동함
- **문화 검수**: 여색, 폭력과 부적 표현이 피조리, 폭력 피해자나 종교 문화를 조롱하지 않고 먹중의 위선과 속임수만 겨냥하는지 문화 자문으로 확인함
- **확인 필요**: 먹중 탈의 이동 속도, 팔 휘두르기 인식 기준, 목표 횟수, 취발이의 마무리 대사와 먹중의 퇴장 동작은 프로토타입 시험과 문화 자문으로 정함
