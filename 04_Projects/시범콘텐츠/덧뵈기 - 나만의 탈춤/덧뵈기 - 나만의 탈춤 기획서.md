> 덧뵈기(탈춤)를 소재로 한 AR 탈춤 체험 시범콘텐츠의 개발 기획서. [[콘셉트 정리#1) 나만의 탈춤]]을 입력으로 작성함. 골격 단계로, 점차 채워나감.

# 1. 개요

사용자가 직접 디자인한 탈을 3D로 변환해 AR로 쓰고, 풍물 장단에 맞춰 탈춤 춤사위를 따라 추며, 탈 캐릭터와 기념 촬영하는 체험 콘텐츠.

- **소재**: 남사당놀이 탈놀음 덧뵈기 ([[덧뵈기]])
- **유형**: 체험 (실시간 동작 놀이가 핵심, 탈 만들기는 도입 단계. [[콘셉트 정리#3. 전체 구조 정리]] 유형 정의)
- **플랫폼**: 키오스크 (세로형 터치 + 카메라/마이크. [[콘셉트 정리#가. 키오스크]])
- **플로우**: 탈 디자인 → AI 3D 변환 → AR 착용 + 춤사위 따라하기(포즈 채점) → 기념 촬영 → 사진 전송 ([[콘셉트 정리#1) 나만의 탈춤]]). 여기에 숏폼 리플레이 영상 제공을 더함
- **핵심 특성**: 사용자가 만든 탈을 쓰고 직접 몸으로 춤을 따라 추는 능동 체험. 자세 일치도/타이밍을 실시간 채점해 신명(興) 게이지로 보상
- **진행 호스트**: 말뚝이. 탈춤 풍자의 화자가 전 Step 진행을 안내하고 추임새로 호응 (페르소나는 3장 가. 진행 호스트 참조)
- **산출물**: 기념 사진(베스트샷 + 점수/등급 스탬프) + 숏폼 리플레이 영상(AR 탈 착용 춤사위, 음원 포함). 상세는 4장 산출물 참조

목표, 범위 등 나머지 개요 항목은 작성 예정.

# 2. 시스템 플로우

- 매체: 9:16 세로형 키오스크 터치 + 카메라(포즈/얼굴 인식) + 마이크. 1인 사용
- 큰 흐름(스케치): 인트로(동의 약관) → 탈 디자인 → 3D 변환 → AR 춤사위 체험 → 기념 촬영 → 결과물 전송 → 종료
- 목표 플레이타임: **확인 필요** (콘셉트/로드맵 원문 미명시. 임의 추정 금지)

**개요**: Step 1 인트로 → Step 2 탈 디자인 → Step 3 3D 변환 + 대기 화면 → Step 4 AR 착용 + 춤사위 따라하기 → Step 5 기념 촬영 → Step 6 결과물 전송 → Step 7 종료/리셋

## 가. 세션

한 유저의 키오스크 사용 전체(Step 1 시작 → Step 7 종료)를 감싸는 상위 컨테이너. 하위 Step들이 세션 안에서 순차 실행됨. 라이프사이클/저장 데이터 모델은 [[시범콘텐츠 공통 사양#2. 세션]] 구조를 준용하되, 본 콘텐츠 고유 데이터(탈 디자인, 3D 모델, 동작 채점, 기념 사진, 리플레이 영상)로 재정의함.

### 1) 세션 라이프사이클

[[시범콘텐츠 공통 사양#다. Step별 세션 동작]] 준용.

- 생성: Step 1 시작 시 신규 세션 생성 + 동의 기록 저장. 미동의 또는 타임아웃 시 세션 즉시 파기(동의 기록 미생성)
- 갱신: Step 2~6 진행 중 각 산출물을 세션에 저장/갱신 (탈 디자인 → 3D 탈 모델 → 동작 채점 기록 → 기념 사진/리플레이 영상 → 연락처)
- 종료: Step 7에서 세션 종료 + 임시 데이터 파기 + 시작 화면 리셋(다음 유저 대기)

### 2) 세션 데이터

데이터별 분류, 값, 보관/파기. 개인정보 민감 데이터(영상/사진/연락처)는 최소 보관 원칙. 보관 기간 잠정값은 법무 검토 후 확정함 (임의 추정 금지, [[CONVENTIONS#바. 수치/목표 인용 원칙 (엄격)]]).

| 데이터 | 분류 | 값 / 구성 | 보관 / 파기 |
|---|---|---|---|
| 세션 ID | 시스템 | 세션 고유 식별자 | 세션 종료 시 파기 |
| 동의 기록 | 시스템 | 약관 버전 + 동의 시각 (카메라 필수 + 영상 선택) | 보관 |
| 탈 디자인(2D) | 콘텐츠 | 사용자가 디자인한 2D 탈 도안 | 별도 저장소 보관 (재방문/재사용/품질 분석) |
| 3D 탈 모델 | 콘텐츠 | 디자인에서 변환된 3D 자산 | 별도 저장소 보관 |
| 동작 채점 기록 | 콘텐츠 | 자세 일치도/타이밍 점수, 신명 게이지 | 익명 통계만 보관, 식별 원본은 세션 종료 시 파기 |
| 기념 사진 | 콘텐츠 | 베스트샷 + 점수/등급 스탬프 | 메모리 임시 (서버 디스크 비보관), 전송 최종 결과 후 파기 |
| 리플레이 영상 | 콘텐츠 | AR 탈 춤사위 하이라이트 + 기념 포즈 숏폼 (MP4) | 다운로드용 임시 보관, 다운로드 또는 만료 시 파기 (미다운로드 시 세션 종료 시) |
| 영상 피드 | 개인정보 | 카메라 원본 스트림 (포즈 추정/녹화 입력) | 메모리 임시 (비저장), 세션 종료 시 파기 |
| 연락처 | 개인정보 | 유저 연락처 (SMS/이메일) | 메모리 임시, 전송 최종 결과 후 즉시 파기 |

- 메모리 임시 보관 데이터(영상 피드, 연락처)는 디스크 영속화/로그 기록 금지, 파기 시 메모리 명시적 덮어쓰기 ([[시범콘텐츠 공통 사양#가. 개인정보 처리 정책 (공통 원칙)]] 준용)
- 익명 채점 통계는 개인 식별 정보(얼굴/영상/연락처)와 결합 불가하도록 비연결 설계
- 보관 대상 데이터의 보관 기간/저장소 정책은 5장 사. 개인정보 처리 정책에서 정의

### 3) 영상 처리 주의

본 콘텐츠는 카메라로 얼굴/신체를 촬영(포즈 추정 + 기념 사진 + 리플레이 영상)하므로 덜미보다 개인정보 민감도가 높음. 데이터별 보관/파기는 위 세션 데이터 표를 따르며, 세부 처리 정책과 법무 검토 사항은 5장 사. 개인정보 처리 정책에서 정의.

## 다. Step별 명세

본 콘텐츠 Step별 골격 명세 (상세 작성 예정). 각 Step 화면 수는 기획 잠정값(UI 설계 단계 확정), RFP 정량 요건 아님.

### 1) Step 1. 인트로 (시작 + 동의)

- **트리거**: 유저가 시작 버튼 터치
- **시스템**: 클라이언트 UI, 백엔드 (상세는 5장 기술 구성)
- **화면**: 시작 → 가이드 → 동의 약관 (3개). 전환: 시작 화면 터치(대기 상태) → 다음 → 동의/거부 입력. 시작 화면은 Step 7 복귀 대상과 동일
- **프로세스 (골격)**:
	1. 백엔드: 신규 세션 생성
	2. UI(가이드): 인사말/가이드 표시
	3. UI(동의 약관): 고객 동의 약관 표시 (**카메라 촬영 동의 필수 + AR 합성 영상 녹화/리플레이 영상 생성/제공 동의**)
	4. UI(동의 약관): 동의 입력 감지
		- 분기: 필수 동의(카메라 촬영) 미동의 또는 무응답 타임아웃 시 Step 7 직행. 영상 산출물 동의(선택)만 거부 시 Step 4 녹화/Step 5 영상 생성 생략(사진만 진행)
	5. 백엔드: 동의 기록 저장
- **다음**: Step 2

### 2) Step 2. 탈 디자인

- **트리거**: Step 1 동의 완료
- **시스템**: 클라이언트 UI, 백엔드 (상세는 5장 기술 구성)
- **화면**: 탈 디자인 도구 (1개). 전환: 도안 확정 → Step 3 (도구 내부 영역 분할은 UI 설계 단계)
- **프로세스 (골격)**:
	1. UI(탈 디자인 도구): 탈 디자인 도구 제공, 사용자 도안 입력 수집 (디자인 방식 템플릿/조합/드로잉은 **확인 필요**, 콘셉트 미상세)
	2. 백엔드: 입력 유효성 검증
	3. AI: 가드레일 검사 (부적절 도안 차단, 상세 3장 마. 가드레일)
	4. 백엔드: 세션 저장
- **입력**: 사용자 탈 디자인 입력
- **출력**: 2D 탈 도안
- **다음**: Step 3

### 3) Step 3. 3D 변환 + 대기 화면

- **트리거**: 탈 디자인 완료
- **시스템**: AI 시스템, 클라이언트 UI, 백엔드 (상세는 5장 기술 구성)
- **화면**: 변환 대기 (1개, 폴링 진행 표시). 전환: 변환 완료 → Step 4
- **프로세스 (골격)**:
	1. 백엔드: 3D 변환 작업 큐 등록/시작
	2. AI: 2D 도안을 3D 탈 모델로 변환
		- 실패: 변환 실패 시 fallback (에러/fallback 공용 기능)
	3. AI: 생성물 가드레일 검사
		- 실패: 가드레일 한도 초과 시 fallback (에러/fallback 공용 기능)
	4. 백엔드: 3D 탈 모델 저장
	- (병행) UI(변환 대기): 변환 진행 표시, 백엔드 job 상태 폴링
- **입력**: 2D 탈 도안
- **출력**: 3D 탈 모델
- **다음**: 변환 완료 시 Step 4

### 4) Step 4. AR 착용 + 춤사위 따라하기 (핵심 체험)

- **트리거**: 3D 변환 완료
- **시스템**: AI 시스템(포즈 추정), 클라이언트 UI, 백엔드 (상세는 5장 기술 구성)
- **화면**: AR 춤사위 체험 (1개, 동적: AR 카메라 뷰 + 춤사위 가이드 + 신명 게이지 + 말뚝이). 전환: 춤사위 종료 → Step 5
- **프로세스 (골격)**:
	1. UI(AR 춤사위 체험): 변환된 3D 탈을 AR로 착용 (카메라 얼굴 추적 → 탈 오버레이)
	2. UI(AR 춤사위 체험): 탈춤 춤사위 가이드 제시, 사용자 동작 캡처
		- 분기: 무응답 타임아웃 → Step 7
	3. AI: 포즈 추정으로 자세 일치도 + 타이밍 채점 → 신명(興) 게이지 상승 (상세는 3장 라. 채점 체계 참조)
	4. UI(AR 춤사위 체험): 말뚝이가 채점에 따라 실시간 추임새 피드백 (3장 가. 진행 호스트)
	5. UI(AR 춤사위 체험): 게이지 달성 시 환호 사운드(군중 추임새/박수)로 보상, 미달 시 말뚝이가 눙치며 마무리 (상세 작성 예정)
	- (병행) 백엔드: (영상 동의 시) 춤사위 진행 중 AR 합성 화면을 리플레이 소재로 임시 녹화 (Step 5 영상 편집 입력). 영상 미동의 시 생략
- **입력**: 카메라 동작 영상, 풍물 장단 타이밍
- **출력**: 동작 채점 기록, 신명 게이지 결과, 리플레이용 임시 녹화 영상
- **다음**: Step 5

### 5) Step 5. 기념 촬영 (포즈 챌린지)

- **트리거**: 춤사위 체험 완료
- **시스템**: AI 시스템(포즈 추정), 클라이언트 UI, 백엔드 (상세는 5장 기술 구성)
- **화면**: 포즈 챌린지 촬영 → 생성 대기 (2개, 영상 인코딩 동안 대기). 전환: 촬영 완료 → 생성 대기 → 통과 산출물 확정 시 Step 6. 실패/fallback(사진만 또는 에러 안내)은 sub-step 5 실패 참조
- **프로세스 (골격)**:
	1. UI(포즈 챌린지 촬영): 탈춤 정지 포즈 제시 + 제한 시간, 사용자 포즈 캡처
	2. AI: 포즈 일치 판정 → 베스트샷 캡처
	3. 백엔드: 점수/등급 스탬프 합성한 기념 사진 생성 (탈 쓴 캐릭터 + 사용자)
	4. 백엔드: (영상 동의 시) 춤사위 따라하기(Step 4) 하이라이트 + 기념 포즈를 AR 탈 합성 숏폼 영상으로 편집/인코딩 (풍물 장단 음원 포함). 영상 미동의 시 생략
	5. AI: 생성물(사진/영상) 가드레일 검사 (3장 마. 가드레일), 통과물만 출력으로 확정
		- 실패: 가드레일 실패/한도 초과 시 위험 생성물 파기 후 사진만 제공, 전부 실패 시 에러 안내 (에러/fallback 공용 기능). Step 6은 통과 산출물이 있을 때만 진행
	- (병행) UI(생성 대기): 사진/영상 생성/인코딩 동안 대기 표시
- **입력**: 카메라 영상, 포즈 판정, Step 4 임시 녹화 영상
- **출력**: 기념 사진 (베스트샷 + 스탬프), 리플레이 영상 (숏폼 MP4, 영상 동의 시)
- **다음**: Step 6

### 6) Step 6. 결과물 전송

- **트리거**: 기념 사진 생성 완료 (리플레이 영상은 영상 동의 시)
- **시스템**: 클라이언트 UI, 백엔드, 외부 서비스 (상세는 5장 기술 구성)
- **화면**: 결과물 미리보기(사진/영상) → 연락처 입력/전송 (영상 동의 시 전송 후 다운로드 QR 표시) (2개). 전환: 전송 또는 거부 → Step 7
- **프로세스 (골격)**:
	1. UI(결과물 미리보기): 기념 사진/리플레이 영상 미리보기 (다운로드 수단 노출 전)
	2. UI(연락처 입력/전송): 연락처 입력 + 전송 동의 입력 수집
		- 분기: 전송 거부/무응답 시 연락처 즉시 파기, 전송/다운로드 생략하고 Step 7로
	3. 백엔드: 전송 동의 시 연락처 임시 저장
	4. 외부 서비스: 사진 전송 (SMS 링크 또는 이메일, 채널 **확인 필요** [[콘셉트 정리#가. 키오스크]], 5장 라. 외부 서비스 연동)
		- 실패: 전송 실패는 에러/fallback 공용 기능 ([[시범콘텐츠 공통 사양#나. 결과물 전송]] 준용)
	5. 외부 서비스: (영상 동의 시) 리플레이 영상 다운로드 URL 생성 (signed one-time URL)
	6. UI(연락처 입력/전송): (영상 동의 시) 다운로드 QR 표시
	7. 백엔드: 사진/연락처는 전송 최종 결과 후, 영상은 다운로드 성공 또는 유효기간 만료 후 파기
- **입력**: 연락처, 전송 동의
- **출력**: 전송/다운로드 결과
- **다음**: Step 7

### 7) Step 7. 종료 / 리셋

- **트리거**: 결과물 전송 완료 또는 미동의 또는 타임아웃 또는 유저 이탈
- **시스템**: 클라이언트 UI, 백엔드 (상세는 5장 기술 구성)
- **화면**: 마무리 인사 (1개) → 시작 화면 복귀. 시작 화면은 Step 1 진입 화면과 동일(신규 아님)
- **프로세스 (골격)**:
	1. UI(마무리 인사): 마무리 인사 표시
	2. 백엔드: 세션 종료 + 임시 데이터 파기 (연락처/영상 피드/미다운로드 리플레이 영상)
	3. UI(시작): 시작 화면 복귀 (다음 유저 대기)
- **다음**: 다음 유저용 Step 1 대기

## 라. 운영 파라미터

무응답 타임아웃, 채점 임계, AI 변환 재시도/폴링 주기 등 운영 파라미터는 구현/운영 단계에서 확정 (작성 예정). 잠정값은 임의 추정 금지, 근거 확보 후 기재 ([[CONVENTIONS#바. 수치/목표 인용 원칙 (엄격)]]).

# 3. 콘텐츠 설계

본 콘텐츠의 설계 요소(진행 호스트, 탈/춤사위 고증, 탈 디자인, 채점 체계, 가드레일)와 제작 자산을 정의. 5장 기술 구성은 본 장에서 정의된 것의 구현/배치를 다룸.

## 가. 진행 호스트 (말뚝이)

본 콘텐츠의 진행 안내자. 탈춤 풍자의 화자 말뚝이가 전 Step을 잇는 목소리로 등장, 탈 디자인부터 춤사위 따라하기, 기념 촬영까지 안내하고 추임새로 호응함.

- **역할**: 양반을 놀리는 탈춤 풍자의 화자. 관객과 대거리하는 전통 기능을 진행 안내/추임새로 계승 (덜미 박첨지의 해설자/길잡이에 대응, [[덜미 - 전자책 변환 기획서#가. 박첨지 페르소나]])
- **화법**: 재담과 추임새. 춤사위 채점 피드백을 추임새로 전달 (3장 라. 채점 체계와 연동)
- **시각 정체성**: 말뚝이 탈/의상 고유 양식 유지 (고증은 3장 나. 탈/춤사위 고증 참조)
- **고증 주의**: 말뚝이 배역 해석은 일반 탈춤 문헌 수준(L5 추론, [[CONVENTIONS#사. 외부 근거의 권위 계층]]). [[덧뵈기]] 문서 작성 후 검증 (확인 필요)
- 세부 페르소나(말투, 어휘, 반응 패턴 등) 작성 예정

## 나. 탈/춤사위 고증

- **탈**: 덧뵈기 탈놀음의 배역 탈(말뚝이/양반/먹중/샌님 등) 양식을 디자인 레퍼런스로 활용 (목록/종수 **확인 필요**, [[덧뵈기]] 문서 작성 후 보강)
- **춤사위**: 따라 추기 대상 춤사위 동작과 풍물 장단의 고증 매핑 (작성 예정, 고증 자문 연계)
- **시각 정체성**: 탈 양식/질감의 전통 정합성 유지 방향 (작성 예정)

## 다. 탈 디자인

- 사용자가 탈을 직접 디자인하는 도구의 입력 방식과 제약 (템플릿/조합/드로잉 중 택, **확인 필요**)
- 디자인 결과가 3D 변환(5장 가. AI 시스템) 입력으로 연결되는 형식 규격 (작성 예정)

## 라. 채점 체계 (신명 게이지)

본 콘텐츠 핵심 루프. 실시간 동작을 채점해 신명(興) 게이지로 시각화하고 달성 시 보상.

- **채점 입력**: 포즈 추정 기반 자세 일치도 + 풍물 장단 대비 타이밍 (Step 4), 정지 포즈 일치도 (Step 5)
- **게이지/보상**: 채점 누적 → 신명 게이지 상승, 달성 시 환호 사운드(군중 추임새/박수) 보상, 미달 시 마무리 처리
- **세부 설계 (작성 예정)**: 채점 가중치, 게이지 임계, 난이도 곡선, 미달 시 처리 정책

## 마. 가드레일

콘텐츠 안전 정책. 구현은 5장 가. AI 시스템의 AI 가드레일 모듈에서. [[시범콘텐츠 공통 사양#나. 가드레일 적용 3지점]]을 준용하되 본 콘텐츠 입출력에 맞춰 재정의.

- **적용 지점 (골격)**:
	- 입력: 탈 디자인 도안 검사 (Step 2), 부적절 이미지 차단
	- 출력: 3D 변환물(Step 3) / 기념 사진, 리플레이 영상(Step 5) 검사, 부적절 생성물 + 전통 정체성 왜곡 차단
- **세부 정책 (작성 예정)**: 부적절 도안 분류, 전통 왜곡 판정, 동의 약관(카메라 촬영 + 영상 산출물 생성/제공) 항목 구체화

## 바. 콘텐츠 자산

> 본 콘텐츠 제작에 필요한 자산 목록(발주/견적 입력). 산출 방식은 5장 기술 구성에서. (골격, 작성 예정)

| 자산 | 분류 | 비고 |
|---|---|---|
| 탈 디자인 템플릿/프리셋 | 디자인 입력 자산 | 배역 탈 양식 기반, 종수 확인 필요 |
| 춤사위 레퍼런스 (모션) | 채점 기준 데이터 | 따라하기 대상 동작 + 채점 기준 |
| 풍물 장단 음원 | 음향 자산 | 춤사위 타이밍 기준. 무저작권/자체 제작/AI 생성 음원 사용 (리플레이 SNS 공유 대비) |

# 4. 산출물

- 기념 사진 (베스트샷 + 점수/등급 스탬프, 탈 쓴 캐릭터 + 사용자)
- 숏폼 리플레이 영상 (AR 탈 착용 춤사위 하이라이트 + 기념 포즈 합본, 세로형 MP4, 무저작권/자체 제작/AI 생성 음원 포함)
- 전송/제공/파기 정책은 2장 가. 세션의 세션 데이터 표, 영상 합성/제공 상세는 5장 아. 리플레이 영상 파이프라인 참조
- 형식/규격(해상도, 길이, 코덱 등)은 구현 단계 확정

# 5. 기술 구성

본 콘텐츠 구현 시스템을 6개 영역(가~바)으로 정리하고, 영역을 가로지르는 횡단 항목(사. 개인정보 처리 정책, 아. 리플레이 영상 파이프라인)을 따로 둠. 6영역 구조는 [[시범콘텐츠 공통 사양#4. 기술 구성 (6영역 템플릿)]]을 준용하되 본 콘텐츠 고유 모듈(3D 변환, 포즈 추정 채점)로 재구성. (골격, 작성 예정)

## 가. AI 시스템

- **탈 3D 변환 모델**: 2D 탈 도안 → 3D 탈 모델 변환 (Step 3)
- **포즈 추정/채점**: 카메라 영상에서 자세 추정, 자세 일치도/타이밍 채점 (Step 4/Step 5)
- **AI 가드레일 (횡단)**: 탈 디자인 입력 + 3D 변환물 + 기념 사진/리플레이 영상 출력 검사 (3장 마. 가드레일)

## 나. 하드웨어 (키오스크)

- 9:16 세로형 디스플레이 (터치 인식)
- 카메라 (얼굴 추적 AR + 포즈 추정용)
- 음향 출력 (풍물 장단, 환호 사운드)
- 마이크 (필요 시)
- 네트워크 연결 (AI 서버 통신, 사진/영상 전송)

## 다. 백엔드

- 키오스크 ↔ AI 서버 API
- 세션 관리 (세션별 진행 상태, 2장 가. 세션)
- 체험 진행 제어 (탈 디자인 → 3D 변환 → 춤사위 채점 → 기념 촬영 → 결과물 전송)
- 결과물 저장소 (3D 모델, 기념 사진, 리플레이 영상)
- 리플레이 영상 합성/편집/인코딩 (AR 탈 합성 + 하이라이트 + 음원, 상세는 5장 아. 리플레이 영상 파이프라인)
- 개인정보 처리: 연락처 + 영상/사진/리플레이 영상, 상세 정책은 5장 사. 개인정보 처리 정책

## 라. 외부 서비스 연동

- 사진 전송 서비스 (SMS 또는 이메일, 채널 확인 필요)
- 리플레이 영상 다운로드 호스팅 (현장 QR/링크, 다운로드 후 즉시 파기)
- AI API (3D 변환, 포즈 추정 등 외부 모델 사용 시)

## 마. 클라이언트 UI (키오스크 앱)

- 페이지 전환 / 터치 인터랙션 프레임워크
- 화면 흐름: 2장 시스템 플로우의 Step 1~Step 7 화면 순서 구현
- 말뚝이 진행 호스트 렌더링 (전 Step 진행 안내/추임새, 3장 가. 진행 호스트)
- 탈 디자인 도구 UI (3장 다. 탈 디자인)
- AR 렌더링 (3D 탈 오버레이) + 춤사위 가이드/게이지 표시
- 카메라 프리뷰 + 기념 촬영 UI
- 결과물 화면: 기념 사진/리플레이 영상 미리보기 + 다운로드 QR
- 자동 타임아웃, 다음 유저용 리셋

## 바. 운영/모니터링

- 키오스크 가동 상태 모니터링
- 사용 로그 (유저 수, 완주율, 오류율)
- 에러 fallback (AI 호출/외부 서비스 실패): [[시범콘텐츠 공통 사양#바. 운영/모니터링]] 처리 규칙 준용

## 사. 개인정보 처리 정책

영역을 가로지르는 횡단 정책. 데이터별 보관/파기 시점은 2장 가. 세션의 세션 데이터 표가 정본이며, 본 절은 범위/동의/설계 원칙을 정의함.

- **개인정보 범위**: 연락처(전송용) + **얼굴/신체 영상 및 기념 사진/리플레이 영상** (덜미와 달리 영상 처리 포함, 민감도 높음)
- **동의 범위**: 카메라 촬영(포즈 추정)은 필수 동의, AR 합성 영상 녹화/리플레이 영상 생성/제공은 별도 선택 동의. 영상 동의 미보유 시 녹화/영상 생성 미수행(사진만 제공)
- **데이터별 처리/파기**: 2장 가. 세션의 세션 데이터 표 참조 (영상 피드/사진/리플레이 영상/연락처 보관, 파기 일원화)
- **비연결 설계**: 익명 채점 통계는 개인 식별 정보(얼굴/영상/연락처)와 결합 불가
- **리플레이 영상 파기 트리거**: 아. 리플레이 영상 파이프라인에서 정의
- **세부 정책 (작성 예정)**: 보관 데이터의 보관 기간 잠정값은 법무 검토 후 확정, 임의 추정 금지

## 아. 리플레이 영상 파이프라인 (구현 요건)

숏폼 리플레이 영상의 소재 확보부터 제공/파기까지 구현 요건. 클라이언트(녹화/QR), 백엔드(합성/인코딩), 외부 서비스(다운로드 호스팅)에 걸침. 정량값(해상도/길이/코덱/유효기간)은 구현 단계 확정, 임의 추정 금지.

1. **소재 녹화 (Step 4)**: AR 탈 합성 화면(탈 오버레이된 카메라 화면)을 클라이언트에서 프레임 캡처해 임시 녹화. 사후 재합성 부담을 피하려 렌더된 화면을 그대로 확보. 메모리/임시 버퍼 보관 (디스크 영속화 금지)
2. **하이라이트 선별**: 동작 채점 기록(자세 점수/신명 게이지)으로 고득점 구간 자동 선별. 선별 기준/구간 길이는 운영 파라미터
3. **합성/편집 (Step 5)**: 선별 하이라이트 + 기념 포즈를 이어 붙이고, 세로형(9:16) 프레임/워터마크/스탬프 오버레이, 무저작권/자체 제작/AI 생성 음원 믹싱
4. **인코딩**: 세로형 MP4로 인코딩, SNS 업로드 호환 우선. 해상도/비트레이트/코덱/길이는 구현 단계 확정. 키오스크 부하를 고려해 서버 측 인코딩 권장
5. **제공/다운로드**: 인코딩 완료물을 서버 임시 저장소에 단일 다운로드용으로 보관 → signed one-time URL(QR/단축 링크) 생성 → 사용자 다운로드. 파기는 단일 권위 트리거로 일원화 = 다운로드 성공 또는 유효기간 만료 중 먼저 오는 시점(미다운로드 시 세션 종료 시 파기). 중복 요청은 만료 전까지 같은 URL 재사용, 파기 실패 시 운영 알림
6. **가드레일**: 최종 영상에 출력 가드레일 검사 (부적절/전통 왜곡, 3장 마. 가드레일)
7. **대기/실패 처리**: 인코딩 동안 대기 화면(폴링 동기화). 실패 시 fallback으로 영상 생략하고 사진만 제공 (에러/fallback 공용 기능)
8. **음원**: 무저작권/자체 제작/AI 생성 풍물 장단 음원만 사용 (SNS 공개 공유 전제, 라이선스 리스크 제거). 외부 라이선스 음원 확보가 어려우면 AI 생성 음원을 최종 안전장치로 사용
