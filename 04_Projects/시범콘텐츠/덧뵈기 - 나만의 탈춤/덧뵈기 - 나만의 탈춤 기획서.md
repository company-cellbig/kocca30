> 덧뵈기(탈춤)를 소재로 한 AR 탈춤 체험 시범콘텐츠의 개발 기획서. [[콘셉트 정리#1) 나만의 탈춤]]을 입력으로 작성함. 골격 단계로, 점차 채워나감.

# 1. 개요

## 가. 콘텐츠 정의

사용자가 직접 디자인한 탈을 3D로 변환해 AR로 쓰고, 풍물 장단에 맞춰 탈춤 춤사위를 따라 추며, 탈 캐릭터와 기념 촬영하는 체험 콘텐츠.

- **소재**: 남사당놀이 탈놀음 덧뵈기 ([[덧뵈기]])
- **유형**: 체험 (실시간 동작 놀이가 핵심, 탈 만들기는 도입 단계. [[콘셉트 정리#3. 전체 구조 정리]] 유형 정의)
- **플랫폼**: 키오스크 (세로형 터치 + 카메라/마이크. [[콘셉트 정리#가. 키오스크]])
- **플로우**: 탈 디자인 → AI 3D 변환 → AR 착용 + 춤사위 따라하기(포즈 채점) → 기념 촬영 → 사진 전송 ([[콘셉트 정리#1) 나만의 탈춤]])
- **핵심 특성**: 사용자가 만든 탈을 쓰고 직접 몸으로 춤을 따라 추는 능동 체험. 자세 일치도/타이밍을 실시간 채점해 신명(興) 게이지로 보상
- **진행 호스트**: 말뚝이. 탈춤 풍자의 화자가 전 Step 진행을 안내하고 추임새로 호응 (페르소나 §3.가)
- **산출물**: 기념 사진 (베스트샷 + 점수/등급 스탬프). 상세 §5

목표, 범위 등 나머지 개요 항목은 작성 예정.

# 2. 시스템 플로우

- 매체: 9:16 세로형 키오스크 터치 + 카메라(포즈/얼굴 인식) + 마이크. 1인 사용
- 큰 흐름(스케치): 인트로(동의 약관) → 탈 디자인 → 3D 변환 → AR 춤사위 체험 → 기념 촬영 → 사진 전송 → 종료
- 목표 플레이타임: **확인 필요** (콘셉트/로드맵 원문 미명시. 임의 추정 금지)

**표기**: `S` = Step(순차 단계). S1~S7은 진행 순서대로의 단계 ID

**개요**: S1 인트로 → S2 탈 디자인 → S3 3D 변환 + 대기 화면 → S4 AR 착용 + 춤사위 따라하기 → S5 기념 촬영 → S6 사진 전송 → S7 종료/리셋

## 가. 세션

한 유저의 키오스크 사용 전체(S1 시작 → S7 종료)를 감싸는 상위 컨테이너. 하위 Step들이 세션 안에서 순차 실행됨. 라이프사이클/저장 데이터 모델은 [[덜미 - 전자책 변환 기획서#가. 세션]] 구조를 준용하되, 본 콘텐츠 고유 데이터(탈 디자인, 3D 모델, 동작 채점, 기념 사진)로 재정의 (상세 작성 예정).

**세션 저장 데이터 (골격)**

| 데이터 | 분류 | 들어가는 값 / 구성 | 비고 |
|---|---|---|---|
| 세션 ID | 시스템 | 세션마다 부여되는 고유 식별자 | S1에서 생성 |
| 동의 기록 | 시스템 | 약관 버전 + 동의 시각 | 카메라 촬영 동의 포함 (§4.다.1) |
| 탈 디자인 | 콘텐츠 입력 | 사용자가 디자인한 2D 탈 도안 | S2 산출 |
| 3D 탈 모델 | 콘텐츠 데이터 | 디자인에서 변환된 3D 자산 | S3 산출 (AI 변환) |
| 동작 채점 기록 | 콘텐츠 데이터 | 춤사위별 자세 일치도/타이밍 점수, 신명 게이지 | S4 산출, 디버깅/품질 분석용 |
| 기념 사진 | 콘텐츠 데이터 | 베스트샷 + 점수/등급 스탬프 | S5 산출(생성 결과), 전송 대상. 얼굴 포함 영상 기반이라 개인정보 민감 |
| 연락처 | 개인정보 | 유저 연락처 (사진 전송용, SMS 또는 이메일) | S6 전송 동의 시 임시 저장 → 발송 후 즉시 파기 |

**얼굴/신체 영상 처리 주의**: 본 콘텐츠는 카메라로 얼굴/신체를 촬영(포즈 추정 + 기념 사진)하므로 덜미보다 개인정보 민감도가 높음. 영상 피드 처리/보관 정책은 §4.다.1 및 법무 검토 (상세 작성 예정).

## 나. Step

Step 정의, 명세 항목, 공용 기능 체계는 [[덜미 - 전자책 변환 기획서#나. Step]]을 준용함. 공용 기능(입력 유효성 검증, AI 가드레일, 개인정보 처리/파기, 외부 서비스 호출 래퍼, 에러/fallback, 무응답 타임아웃, 사용 로그/모니터링)은 본 콘텐츠에도 동일 적용. 아래는 Step별 골격 명세 (상세 작성 예정).

### 1) S1. 인트로 (시작 + 동의)

- **트리거**: 유저가 시작 버튼 터치
- **시스템**: 클라이언트 UI (§4.마), 백엔드 (§4.다)
- **프로세스 (골격)**: 신규 세션 생성 → 인사말/가이드 화면 → 고객 동의 약관(**카메라 촬영 동의 포함**) → 동의 감지 → 동의 기록 저장
- **분기**: 무응답 타임아웃에 의한 미동의 시 S7 직행
- **다음**: S2

### 2) S2. 탈 디자인

- **트리거**: S1 동의 완료
- **시스템**: 클라이언트 UI (§4.마), 백엔드 (§4.다)
- **프로세스 (골격)**: 탈 디자인 도구 제공 → 사용자가 탈 도안 작성 → 디자인 유효성/가드레일 검사 → 세션 저장
	- 디자인 방식(템플릿 채색 / 부분 조합 / 자유 드로잉 등) **확인 필요** (콘셉트 미상세)
	- 가드레일: 부적절 도안 차단 (§3.마)
- **입력**: 사용자 탈 디자인 입력
- **출력**: 2D 탈 도안
- **다음**: S3

### 3) S3. 3D 변환 + 대기 화면

- **트리거**: 탈 디자인 완료
- **시스템**: AI 시스템 (§4.가), 클라이언트 UI (§4.마), 백엔드 (§4.다)
- **프로세스 (골격, 백그라운드 생성 + 포그라운드 대기 병행)**: 2D 도안을 AI로 3D 탈 모델 변환 → 생성물 가드레일 검사 → 저장. 대기 화면은 폴링으로 동기화
	- 생성 실패/가드레일 한도 초과 시 fallback (에러/fallback 공용 기능)
- **입력**: 2D 탈 도안
- **출력**: 3D 탈 모델
- **다음**: 변환 완료 시 S4

### 4) S4. AR 착용 + 춤사위 따라하기 (핵심 체험)

- **트리거**: 3D 변환 완료
- **시스템**: AI 시스템 (§4.가 포즈 추정), 클라이언트 UI (§4.마), 백엔드 (§4.다)
- **프로세스 (골격)**:
	1. UI: 변환된 3D 탈을 AR로 착용 (카메라 얼굴 추적 → 탈 오버레이)
	2. UI: 화면이 제시하는 탈춤 춤사위를 풍물 장단에 맞춰 따라 추기
	3. AI: 포즈 추정으로 자세 일치도 + 타이밍 채점 → 신명(興) 게이지 상승 (채점 체계 §3.라)
	4. 말뚝이(§3.가): 채점에 따라 실시간 추임새 피드백
	5. UI: 게이지 달성 시 환호 사운드(군중 추임새/박수)로 보상, 미달 시 말뚝이가 눙치며 마무리 (상세 작성 예정)
	- 분기: 무응답 타임아웃 → S7
- **입력**: 카메라 동작 영상, 풍물 장단 타이밍
- **출력**: 동작 채점 기록, 신명 게이지 결과
- **다음**: S5

### 5) S5. 기념 촬영 (포즈 챌린지)

- **트리거**: 춤사위 체험 완료
- **시스템**: AI 시스템 (§4.가 포즈 추정), 클라이언트 UI (§4.마), 백엔드 (§4.다)
- **프로세스 (골격)**:
	1. UI: 제한 시간 내 제시된 탈춤 정지 포즈를 정확히 취하기
	2. AI: 포즈 일치 판정 → 베스트샷 캡처
	3. UI: 점수/등급 스탬프가 찍힌 기념 사진 생성 (탈 쓴 캐릭터 + 사용자)
	- 사진 생성물 가드레일 검사 (§3.마)
- **입력**: 카메라 영상, 포즈 판정
- **출력**: 기념 사진 (베스트샷 + 스탬프)
- **다음**: S6

### 6) S6. 사진 전송

- **트리거**: 기념 사진 생성 완료
- **시스템**: 클라이언트 UI (§4.마), 백엔드 (§4.다), 외부 서비스 (§4.라)
- **프로세스 (골격)**: 연락처 입력 + 전송 동의 → 임시 저장 → 외부 서비스로 사진 전송 (SMS 링크 또는 이메일, §4.라) → 발송 후 즉시 파기
	- 전송 단계는 사용자 확정 (콘셉트 "사진으로 제공"을 전송 Step으로 구체화). 전송 채널(SMS/이메일)은 **확인 필요** ([[콘셉트 정리#가. 키오스크]] 출력 = SMS/이메일)
	- 실패 분기 처리는 에러/fallback 공용 기능 ([[덜미 - 전자책 변환 기획서#바) S6. 결과물 전송]] 준용)
- **입력**: 연락처, 전송 동의
- **출력**: 전송 결과
- **분기**: 거부 시 전송 생략, S7로
- **다음**: S7

### 7) S7. 종료 / 리셋

- **트리거**: 사진 전송 완료 또는 미동의 또는 타임아웃 또는 유저 이탈
- **시스템**: 클라이언트 UI (§4.마), 백엔드 (§4.다)
- **프로세스 (골격)**: 마무리 인사 → 세션 종료 + 임시 데이터 파기(연락처/영상 피드) → 시작 화면 복귀
- **다음**: 다음 유저용 S1 대기

## 다. 운영 파라미터

무응답 타임아웃, 채점 임계, AI 변환 재시도/폴링 주기 등 운영 파라미터는 구현/운영 단계에서 확정 (작성 예정). 잠정값은 임의 추정 금지, 근거 확보 후 기재 ([[CONVENTIONS#바. 수치/목표 인용 원칙 (엄격)]]).

# 3. 콘텐츠 설계

본 콘텐츠의 정체성(진행 호스트, 탈/춤사위 고증, 채점 체계, 가드레일, 자산)을 정의. §4 기술 구성은 본 절에서 정의된 것의 구현/배치를 다룸.

## 가. 진행 호스트 (말뚝이)

본 콘텐츠의 진행 안내자. 탈춤 풍자의 화자 말뚝이가 전 Step을 잇는 목소리로 등장, 탈 디자인부터 춤사위 따라하기, 기념 촬영까지 안내하고 추임새로 호응함.

- **역할**: 양반을 놀리는 탈춤 풍자의 화자. 관객과 대거리하는 전통 기능을 진행 안내/추임새로 계승 (덜미 박첨지의 해설자/길잡이에 대응, [[덜미 - 전자책 변환 기획서#가. 박첨지 페르소나]])
- **화법**: 재담과 추임새. 춤사위 채점 피드백을 추임새로 전달 (§3.라 채점 체계와 연동)
- **시각 정체성**: 말뚝이 탈/의상 고유 양식 유지 (고증 §3.나)
- **고증 주의**: 말뚝이 배역 해석은 일반 탈춤 문헌 수준(L5 추론, [[CONVENTIONS#사. 외부 근거의 권위 계층]]). [[덧뵈기]] 문서 작성 후 검증 (확인 필요)
- 세부 페르소나(말투, 어휘, 반응 패턴 등) 작성 예정

## 나. 탈/춤사위 고증

- **탈**: 덧뵈기 탈놀음의 배역 탈(말뚝이/양반/먹중/샌님 등) 양식을 디자인 레퍼런스로 활용 (목록/종수 **확인 필요**, [[덧뵈기]] 문서 작성 후 보강)
- **춤사위**: 따라 추기 대상 춤사위 동작과 풍물 장단의 고증 매핑 (작성 예정, 고증 자문 연계)
- **시각 정체성**: 탈 양식/질감의 전통 정합성 유지 방향 (작성 예정)

## 다. 탈 디자인

- 사용자가 탈을 직접 디자인하는 도구의 입력 방식과 제약 (템플릿/조합/드로잉 중 택, **확인 필요**)
- 디자인 결과가 3D 변환(§4.가.1) 입력으로 연결되는 형식 규격 (작성 예정)

## 라. 채점 체계 (신명 게이지)

본 콘텐츠 핵심 루프. 실시간 동작을 채점해 신명(興) 게이지로 시각화하고 달성 시 보상.

- **채점 입력**: 포즈 추정 기반 자세 일치도 + 풍물 장단 대비 타이밍 (S4), 정지 포즈 일치도 (S5)
- **게이지/보상**: 채점 누적 → 신명 게이지 상승, 달성 시 환호 사운드(군중 추임새/박수) 보상, 미달 시 마무리 처리
- **세부 설계 (작성 예정)**: 채점 가중치, 게이지 임계, 난이도 곡선, 미달 시 처리 정책

## 마. 가드레일

콘텐츠 안전 정책. 구현은 §4.가 AI 가드레일 모듈에서. [[덜미 - 전자책 변환 기획서#라. 가드레일]]의 3지점 적용 원칙을 준용하되 본 콘텐츠 입출력에 맞춰 재정의.

- **적용 지점 (골격)**:
	- 입력: 탈 디자인 도안 검사 (S2) — 부적절 이미지 차단
	- 출력: 3D 변환물(S3) / 기념 사진(S5) 검사 — 부적절 생성물, 전통 정체성 왜곡 차단
- **세부 정책 (작성 예정)**: 부적절 도안 분류, 전통 왜곡 판정, 동의 약관(카메라 촬영 포함) 항목 구체화

## 바. 콘텐츠 자산

> 본 콘텐츠 제작에 필요한 자산 목록(발주/견적 입력). 산출 방식은 §4 기술 구성에서. (골격, 작성 예정)

| 자산 | 분류 | 비고 |
|---|---|---|
| 탈 디자인 템플릿/프리셋 | 디자인 입력 자산 | 배역 탈 양식 기반, 종수 확인 필요 |
| 춤사위 레퍼런스 (모션) | 채점 기준 데이터 | 따라하기 대상 동작 + 채점 기준 |
| 풍물 장단 음원 | 음향 자산 | 춤사위 타이밍 기준 |
| 환호/추임새 사운드 | 음향 자산 | 게이지 달성 보상 |
| 기념 사진 프레임/스탬프 | 출력 양식 자산 | 점수/등급 스탬프 디자인 |

# 4. 기술 구성

본 콘텐츠 구현에 필요한 시스템을 6개 영역으로 정리. 구조는 [[덜미 - 전자책 변환 기획서#4. 기술 구성]]을 준용하되 본 콘텐츠 고유 모듈(3D 변환, 포즈 추정 채점)로 재구성. (골격, 작성 예정)

## 가. AI 시스템

- **탈 3D 변환 모델**: 2D 탈 도안 → 3D 탈 모델 변환 (S3)
- **포즈 추정/채점**: 카메라 영상에서 자세 추정, 자세 일치도/타이밍 채점 (S4/S5)
- **AI 가드레일 (횡단)**: 탈 디자인 입력 + 3D 변환물 + 기념 사진 출력 검사 (§3.마)

## 나. 하드웨어 (키오스크)

- 9:16 세로형 디스플레이 (터치 인식)
- 카메라 (얼굴 추적 AR + 포즈 추정용)
- 음향 출력 (풍물 장단, 환호 사운드)
- 마이크 (필요 시)
- 네트워크 연결 (AI 서버 통신, 사진 전송)

## 다. 백엔드

- 키오스크 ↔ AI 서버 API
- 세션 관리 (세션별 진행 상태, §2.가)
- 체험 진행 제어 (탈 디자인 → 3D 변환 → 춤사위 채점 → 기념 촬영)
- 결과물 저장소 (3D 모델, 기념 사진)
- 개인정보 처리: 연락처 + 영상/사진, 상세 정책은 §4.다.1)

### 1) 개인정보 처리 정책

- **개인정보 범위**: 연락처(전송용) + **얼굴/신체 영상 및 기념 사진** (덜미와 달리 영상 처리 포함, 민감도 높음)
- **영상 피드**: 포즈 추정용 실시간 영상의 처리/비보관 원칙 (작성 예정, 법무 검토)
- **기념 사진**: 전송 후 보관 기간 정책 (작성 예정, 법무 검토)
- **연락처**: 임시 저장 후 발송 직후 즉시 파기 ([[덜미 - 전자책 변환 기획서#1) 개인정보 처리 정책]] 준용)
- **세부 정책 (작성 예정)**: 보관 기간 잠정값은 근거 확보 후 기재, 임의 추정 금지

## 라. 외부 서비스 연동

- 사진 전송 서비스 (SMS 또는 이메일, 채널 확인 필요)
- AI API (3D 변환, 포즈 추정 등 외부 모델 사용 시)
- 결과물 호스팅 (전송 링크 방식 사용 시, 설계 미정)

## 마. 클라이언트 UI (키오스크 앱)

- 말뚝이 진행 호스트 렌더링 (전 Step 진행 안내/추임새, §3.가)
