> 기획서 [[덧뵈기 - 나만의 탈춤 기획서#다. 탈 디자인]] 보강을 위한 임시 작업 문서. 참조 자료를 모아 검토한 뒤 기획서에 반영하고 삭제 예정. MOC 미등록.

# 1. 이 문서의 용도

- **성격**: 임시 작업 문서. 정본 아님, 검토용 자료 모음
- **흐름**: 자료 정리 → 검토 → 기획서 [[덧뵈기 - 나만의 탈춤 기획서#다. 탈 디자인]] 반영 → 본 문서 삭제
- **현재 자료**: 모여봐요 동물의 숲(ACNH) 마이 디자인 페이스 페인트 기능 (L4 외부 자료, §6 출처)

# 2. ACNH 마이 디자인 페이스 페인트 개요

- **마이 디자인(Custom Designs)**: 닌텐도 스위치 게임 ACNH의 도트 그림 그리기 기능. 게임 내 폰 앱에서 사용자가 직접 디자인을 그림
- **페이스 페인트**: 마이 디자인으로 그린 도안을 캐릭터 얼굴에 입히는 착용 방식. 옷, 우산 등 다른 대상에도 같은 도안을 입힐 수 있음
- **참조 이유**: 사용자가 도트 캔버스에 그린 2D 도안을 3D 표면(얼굴, 옷)에 입히는 흐름이, 본 콘텐츠의 "사용자 탈 도안 → 3D 탈" 흐름과 구조가 같음

# 3. 핵심 기능 (참조 대상)

## 가. 캔버스와 그리드

- **그리드**: 32x32 픽셀 (기본 디자인 슬롯 기준)
- **저해상도 고정**: 도트 단위라 진입 장벽이 낮고, 키오스크 터치 입력에 유리

## 나. 색과 팔레트

- **디자인당 색 수**: 한 디자인이 쓰는 색은 최대 15색
- **기본 에디터**: 미리 정의된 팔레트(15종, 각 16색)에서 색을 고름
- **Pro 에디터**: 각 색을 HSV(색상, 선명도, 밝기) 슬라이더로 자유 조정
- **투명도**: 지원. 칠하지 않은 영역은 투명, 페이스 페인트에서는 피부가 비침

## 다. 그리기 도구

- **펜**: 굵기 조절
- **도형**: 직선, 사각형, 원
- **채우기**: 영역 채우기(버킷)
- **스탬프**: 원형, 별, 하트 (크기 조절)
- **스포이트**: 캔버스의 색을 집어옴 (L과 R 동시)

## 라. 대칭(미러) 모드

- **좌우 대칭 그리기**: 미러 모드(ZR)로 한쪽을 그리면 반대쪽이 따라 그려짐
- **탈에 특히 유리**: 탈은 좌우 대칭 형태가 많아 대칭 모드가 디자인 효율과 완성도를 높임

## 마. 미리보기 (스왑 프리뷰)

- **대상별 미리보기**: 같은 도안을 옷, 페이스 페인트, 캔버스 등 대상별로 바꿔 미리 봄
- **실시간 확인**: 그린 도안이 실제 대상에 어떻게 보이는지 즉시 확인

## 바. 페이스 페인트 착용과 매핑

- **착용 경로**: 마이 디자인 앱에서 도안을 골라 페이스 페인트로 착용, 또는 거울의 "체인지 잇 업"에서 커스텀 디자인 탭 선택
- **매핑 범위**: 페이스 페인트는 이마와 양 볼만 덮음. 도안이 위에서 갈라져 이마와 볼에 배치됨
- **매핑 한계**: 얼굴 전체가 아니라 정해진 영역(이마, 볼)에만 입혀짐

## 사. 제거

- **제거 경로**: 주머니의 옷 탭에서 페이스 페인트를 골라 제거, 또는 거울/서랍의 페이스 페인트 탭에서 "없음" 선택

# 4. 탈 디자인 적용 시사점 (분석, L5)

기획서 반영 전 검토용 제안. 정본 아님.

- **저해상도 고정 캔버스**: 도트 그리드로 진입 장벽을 낮춰 키오스크 단시간 체험에 맞춤
- **제한 팔레트**: 색 수를 제한하면 빠른 디자인과 전통 색감(오방색 등) 통일에 유리
- **대칭 모드 우선**: 탈의 좌우 대칭 특성상 미러 모드가 핵심 후보 기능
- **도형과 스탬프**: 전통 문양 스탬프(눈, 코, 이마 무늬 등)를 제공하면 비숙련자도 빠르게 탈다운 결과를 냄
- **실시간 3D 프리뷰**: 그린 도안을 3D 탈에 입힌 모습을 즉시 보여주면 만족도와 완성도가 오름 (기획서 Step 2 → Step 3 흐름과 연결)
- **배역 탈 템플릿 시작점**: ACNH가 빈 캔버스에서 시작하는 것과 달리, 본 콘텐츠는 배역 탈 프리셋을 시작점으로 두면 전통 정합성과 속도를 함께 잡음 (기획서 [[덧뵈기 - 나만의 탈춤 기획서#1) 탈 디자인 템플릿과 프리셋]])
- **검토 필요**: ACNH 도트 방식 그대로 갈지, 템플릿 조합형으로 갈지, 드로잉형으로 갈지는 기획서에서 미확정(확인 필요)인 부분과 직접 연결됨

# 5. 검토 메모 (사용자 결정, 2026-06-15)

중재자 결정. §4 시사점과 다를 때는 본 절이 우선이며, 기획서 반영 기준이 됨.

## 가. 시사점별 결정

| 시사점 | 결정 | 근거와 보완 |
|---|---|---|
| 저해상도 고정 캔버스 (32x32) | 반려 | ACNH는 데포르메 캐릭터라 저해상도 픽셀 아트가 자연스럽지만, 본 콘텐츠 탈은 32x32가 너무 낮음. 도트 그리드를 버리고 드로잉형 캔버스로 전환 |
| 제한 팔레트 | 수용 | 전통 색감(오방색 등) 통일과 빠른 디자인 |
| 대칭(미러) 모드 우선 | 수용 (보완) | 기본 제공하되 해제 토글 필요. 좌우 비대칭 표현도 허용 |
| 도형과 스탬프 | 수용 | 전통 문양 스탬프로 비숙련자 보조 |
| 실시간 3D 프리뷰 | 수용 | Step 2 도안 → Step 3 3D 변환 흐름과 연결 |
| 배역 탈 템플릿 시작점 | 수용 | 빈 캔버스 대신 배역 탈 프리셋에서 시작 |
| 디자인 방식 (도트/템플릿/드로잉) | 드로잉형 확정 | 드로잉형으로 가되 배역 탈 템플릿을 함께 제공 |

## 나. 기획서 반영 방향

기획서 [[덧뵈기 - 나만의 탈춤 기획서#다. 탈 디자인]]의 "입력 방식과 제약", "디자인 방식 미확정(확인 필요)"을 아래로 확정함.

- **디자인 방식**: 드로잉형. 배역 탈 템플릿을 시작점으로 제공하고 그 위에 자유 드로잉
- **캔버스와 해상도**: 드로잉형 캔버스. ACNH식 32x32 도트 그리드는 쓰지 않고 충분히 높은 해상도로 함 (구체값은 디자인 단계 확정)
- **색**: 제한 팔레트 (전통 색감 통일)
- **대칭**: 미러(좌우 대칭) 모드 기본 제공 + 해제 토글 (비대칭 허용)
- **보조 도구**: 도형, 전통 문양 스탬프
- **프리뷰**: 실시간 3D 탈 프리뷰
- **시작점**: 배역 탈 템플릿과 프리셋 (기획서 [[덧뵈기 - 나만의 탈춤 기획서#1) 탈 디자인 템플릿과 프리셋]])
