> 대한민국 정부 차원의 남사당놀이 공식 아카이브를 데이터셋 구축 관점에서 검토함. 핵심 원천은 국립무형유산원 무형유산지식새김(2000년 기록화 영상, 도서, 사진)이고, 공공데이터포털 OpenAPI로 메타와 검색을 기계 수집할 수 있음. 다만 API가 주는 메타까지 포함해 자료 전반이 공공누리 제4유형(출처표시, 비상업적, 변경금지)이라, 열람과 비상업적 참고는 가능해도 AI 학습용 가공은 자료이용신청과 별도 허가가 필요함. 접촉처는 [[남사당놀이 데이터 보유 단체]] 참조.

# 1. 검토 기준

데이터셋 소스 적합성을 아래 축으로 판정함. 공개 열람 가능과 데이터셋 재이용 허용은 별개이므로 라이선스를 핵심 축으로 둠.

- **보유 자료 유형과 규모**: 영상, 사진, 도판, 음원, 기록도서. 분량과 해상도(파악되면)
- **접근과 이용 조건**: 공개 열람 가능 여부, 이용 허락(저작권, 초상권) 절차, 비용
- **라이선스**: 재이용, 2차 가공, AI 학습 허용 여부 (공공누리 유형 등)
- **포맷과 기계 가독성**: 디지털 원본 제공 여부, API나 일괄 내려받기 가능성
- **데이터셋 적합성 판정**: 활용 가능 / 조건부 / 보조 + 사유

# 2. 아카이브별 활용성

각 정부 아카이브를 §1 기준으로 평가함. 핵심 원천을 먼저, 보조 포털을 뒤에 둠. 평가 범위는 정부가 직접 제작하거나 개방한 아카이브임. [[남사당놀이 데이터 보유 단체]]에 있는 국립민속박물관, 한국민족문화대백과사전, 문화콘텐츠닷컴, 한국민속극박물관은 아직 활용성 평가 전이며 후속 보강 대상임.

## 가. 국립무형유산원 무형유산지식새김 (핵심 아카이브)

남사당놀이 공식 기록화 자료를 보유한 핵심 아카이브임. 국가유산청과 국립무형유산원 계열이 운영하는 전자정부 누리집임.

- **보유 자료**: 남사당놀이 기록영상, 기록도서, 사진. 2000년 박계순 보유자와 남기환 보유자, 남사당놀이보존회의 실연을 바탕으로 제작된 국가무형유산 기록화 자료임
	- 기록 내용: 역사적 유래, 남사당패 구성, 여섯 종목, 전승 현황, 실연 영상
	- 영상 목차: 역사와 구성, 길놀이, 비나리, 풍물놀이, 버나, 땅재주, 어름, 덧뵈기, 덜미, 의의
	- 메타: 소장기관 국가유산청 무형유산기록관, 생산기관 국립문화재연구소 예능민속연구실, 생산년도 2000년. 자료 한 건(박첨지 항목) 기준 사진 약 160건, 영상 1건, 도서 1건이 연결됨
- **접근과 이용**: 누리집 온라인 열람 가능. 자료 이용은 자료이용신청서 제출(처리 5일, 공휴일 제외). 출처는 국가유산청 무형유산기록관으로 표시
- **라이선스**: 공공누리 제4유형(출처표시, 비상업적, 변경금지). 제3자 권리 포함 자료는 추가 제한
- **포맷과 기계 가독성**: 웹 열람 중심. 일괄 수집과 메타 조회는 공공데이터포털 API로 보완함 (§2.나)
- **적합성 판정**: 조건부. 열람과 고증 참고는 가능하나, 변경금지와 비상업적 조건이라 AI 학습용 가공은 자료이용신청과 별도 협의가 필요함

## 나. 공공데이터포털 OpenAPI (기계 활용 경로)

무형유산 기록화 자료를 기계로 수집하는 경로임. 두 OpenAPI 모두 국가유산청 국립무형유산원 제공, XML 형식, 무료임.

- **보유 자료**: 제공 API 2종
	- 무형유산 기록화 정보: 국가무형유산 기록화 자료의 영상, 도서, 사진 메타 정보 제공
	- 무형유산 기록화 영상 정보 목록 조회 서비스: 검색어(자료명, 종목명)로 영상 정보 조회. 반환 항목은 자료명, 썸네일 URL, 자료구분명, 자료 페이지 이동 URL
- **접근과 이용**: 공공데이터포털 활용신청(인증키 발급)
- **라이선스**: API가 제공하는 메타 정보 자체도 공공누리 제4유형(출처표시, 비상업적, 변경금지)이고, 제3자 권리 포함분은 추가 제한됨. 원자료(영상, 사진)도 무형유산지식새김 제4유형 조건이 그대로 적용됨
- **포맷과 기계 가독성**: 높음. XML API로 검색, 메타, 썸네일, 이동 URL을 제공해 메타데이터 수집과 인덱싱에 적합
- **적합성 판정**: 조건부. 비상업적 메타데이터 수집과 참고 인덱싱은 가능하나, 메타와 원본 모두 제4유형이라 AI 학습, 상업적 이용, 2차 가공은 별도 허가가 필요함

## 다. 국가유산포털 (기본 정보)

원자료 아카이브가 아니라 지정 정보와 설명을 제공하는 포털임.

- **보유 자료**: 남사당놀이 지정 기본 정보
	- 명칭: 남사당놀이
	- 지정 구분: 국가무형유산
	- 분류: 무형유산 > 전통 공연예술 > 연희
	- 지정일: 1964년 12월 7일
	- 관리단체: 사단법인 국가무형유산 남사당놀이보존회
- **라이선스**: 포털 게시 지정 정보는 공공 정보. 사진과 영상 검색물은 무형유산지식새김 제4유형 조건과 연계됨
- **적합성 판정**: 지정 정보와 메타 참조용. 데이터셋 원천으로는 보조임

## 라. 국가유산채널 (대중 영상)

- **운영**: 국가유산진흥원. 접촉처는 [[남사당놀이 데이터 보유 단체]] §3.나
- **보유 자료**: 남사당놀이 대중용 영상 콘텐츠
- **라이선스**: 이용 시 확인 필요
- **적합성 판정**: 대중 영상 참고용. 보조 경로임

# 3. 종합 판정

아카이브를 데이터셋 활용도 기준으로 정리함. 핵심 제약은 라이선스임. 공공 아카이브라도 공공누리 제4유형은 변경금지와 비상업적 조건이라, 열람과 달리 AI 학습용 가공에는 자료이용신청과 별도 협의가 필요함.

| 아카이브 | 데이터셋 활용도 | 핵심 제약 |
|---|---|---|
| 국립무형유산원 무형유산지식새김 | 조건부 (핵심 원천) | 제4유형 변경금지, 비상업적. 자료이용신청 필요 |
| 공공데이터포털 OpenAPI | 조건부 (비상업적 메타 인덱싱) | 메타와 원본 모두 제4유형. AI 학습, 상업, 2차 가공은 별도 허가 |
| 국가유산포털 | 보조 (지정 메타) | 원자료 아님 |
| 국가유산채널 | 보조 (대중 영상) | 라이선스 확인 필요 |

- 활용 순서: 메타데이터와 검색은 공공데이터포털 API로 수집하되 비상업적 참고로 한정하고, 원천 미디어 확보와 데이터셋 가공은 국립무형유산원 자료이용신청과 허가 절차를 거침
- 라이선스 유의: AI 학습용 가공은 제4유형 변경금지에 저촉될 소지가 있어, 데이터셋 구축 전 이용 조건 확인과 협의가 필수임
