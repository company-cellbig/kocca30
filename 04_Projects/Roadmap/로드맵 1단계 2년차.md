> 2차연도(12개월) 핵심: 고도화된 4D 상호작용 플랫폼 + 글로벌 실증을 통한 상용 수준(TRL 7) 시스템 완성. 5 그룹 18개 마일스톤 + 국내외 3개소 실증 + 사업화 패키징. 1차연도 Phase Gate 통과를 전제로 진입.

# 1. 2차연도 핵심 목표

- 고도화된 4D 상호작용 플랫폼 + TRL 7 달성 (수요처 현장 실증 검증 완료)
- 2인 상호작용(맞대거리) 전승 교육 시스템
- 지능형 4D 콘텐츠 생성 + LLM 기반 AI 사부 + 시스템 최적화
- 미디어 케이브(공간형) + 키오스크(모듈형) 패키지 이원화
- 국내(서울랜드) + 해외(태국/필리핀) 실증 3개소 운영
- 사업화 패키징 완료 (정량 목표 §9)

# 2. 분기별 진행 계획

- **Q1 (2027.01 ~ 2027.03): 고도화 착수**
	- [27.01] 페르소나 매칭, 맞대거리 분석, 생성형 서사 고도화, 4D 콘텐츠 생성 모델, 평균 fps 고도화, 플랫폼/CX 관리 일제히 착수
	- [27.03] AI 기반 4D 편집/변형, 사실적 모션 생성, 고실감 4D 콘텐츠 제작, 4DGS 렌더링/햅틱, 다중 참여 시뮬레이션 착수
- **Q2 (2027.04 ~ 2027.06): 핵심 고도화 + 국내 실증 시작**
	- [27.04] 생성형 서사 고도화 종료, LLM 기반 AI 사부 착수, AI 동작 인식/의미 분석 착수
	- [27.05] 페르소나 매칭 종료, 2차연도 심화 콘텐츠(6종) 착수, **서울랜드 실증 시작** (~27.08)
	- [27.06] 4DGS 렌더링/햅틱 종료, **오차 감소 및 요약 교정 고도화 착수** (27.06~27.12)
- **Q3 (2027.07 ~ 2027.09): 통합 + 해외 실증 본격화**
	- [27.07] 다중 참여 시뮬레이션 종료
	- [27.08] 참여자 동작 동기화 착수, AI 동작 인식 종료, 수요처 현장 실증 착수, **태국 실증 시작** (~27.10), 서울랜드 실증 종료
	- [27.09] 글로벌 실증 패키징 착수, **필리핀 실증 시작** (~27.12)
- **Q4 (2027.10 ~ 2027.12): 글로벌 실증 + 패키징 완성**
	- [27.10] 사실적 모션 생성 종료, 플랫폼/CX 관리 종료, 태국 실증 종료
	- [27.11] LLM AI 사부 종료, 참여자 동기화 종료, 4D 콘텐츠 모델 종료, 심화 콘텐츠 종료
	- [27.12] 잔여 마일스톤 종료, 필리핀 실증 종료, **2차연도 KPI 검증** (분류 95% / FID 4.0 / MPJPE 35mm / CSAT 85점 / 서울랜드 400명), **TRL 7 달성** 선언, **AI 검증위원회 최종 검토**

	- 점검: 동작 스타일 매칭 + 교정 지시문 생성 확인
- 1.2 LLM 기반 AI 사부 및 경량화 [27.04~27.11, 큐랩]
	- 산출물: AI 사부 통합 엔진, 경량화 모델(SLM)
	- 점검: 엔진 + 경량화 모델 동작 + 문화 맥락 질의응답 안정성
- 1.3 2인 상호작용(맞대거리) 분석 및 평가 [27.01~27.12, **큐랩**/용인대]

	- 산출물: 참여자 동작 동기화 기술

	- 산출물: 고도화 버전, 전/후 fps 비교 리포트, 장시간 테스트 리포트

	- 산출물: 개선 버전 모듈, 요약 교정 예시, 최종 통합 데모/보고서
	- 점검: 2차년도 오차/fps 동시 충족 + **LMA 의미 기반 요약 교정 적용**
	- 비고: 변환본([[4. 마일스톤 체계 및 수행계획]]) 원본 표 상 일정이 `26.06~26.12`로 적혀있었으나 2차연도 마일스톤이므로 27년이 맞음: 작성 오기 정정 권고 (§11 별도 메모 참조)

- 4.1 고실감 4D 콘텐츠 제작 [27.03~27.12, **큐랩**/셀빅]
	- 산출물: 콘텐츠 SW (실감콘텐츠)
- 4.2 플랫폼 고도화 및 CX 관리 시스템 [27.01~27.10, 셀빅]
	- 산출물: 운영 관리 플랫폼 SW, CX 관리 서버, 데이터 대시보드
	- 점검: 자동 부하 분산 + 장애 예측 + 시각화 기능 안정성
- 4.3 수요처 현장 실증 및 상용화 검증 [27.08~27.12, **큐랩**/셀빅]
	- 산출물: 실증 결과 보고서, 사용자 만족도 조사
	- 점검: 수요처 실증 + TRL 7 단계 도달 + 국내외 수요처 2개소 이상 현장 적용

## 마. 그룹 5. 시범서비스 시나리오 기반 실증 및 기술검증/고도화

- 5.1 초고속 4D 렌더링 및 햅틱/VR 핵심 기술 개발 [27.03~27.06, 셀빅]
	- 산출물: 4DGS 렌더링 엔진, 햅틱 연동 모듈
	- 점검: 렌더링 프레임(80fps) + 햅틱 반응 지연시간
- 5.2 다중 참여형 시뮬레이션 및 AI 합주/대련 기술 개발 [27.03~27.07, 셀빅]
	- 산출물: 군중 시뮬레이터, 멀티 싱크 엔진
	- 점검: 다중 사용자 동기화 + 군중 렌더링 효율
- 5.3 2차년도 심화 서비스 콘텐츠(6종) 개발 [27.05~27.11, 셀빅]
	- 산출물: 살판/어름/군중/풍물/대련 콘텐츠 SW
	- 점검: 미디어 케이브 + VR 환경 최적화
	- 비고: 라벨 "(6종)"은 RFP 정량 요건([[rfp_제안요청서]] L56: "문화전승 가능한 무형문화유산 선정 및 6종 이상의 적용 시범 시나리오 제시")의 수치 인용. "6종 이상"은 사업 전체 목표이며 연차별 독립 카운트가 아님. 1종은 시나리오 1개이지 종목 1개가 아님. 1차연도 남사당놀이 5종([[로드맵 1단계 1년차]] §8) + 2차연도 심화 콘텐츠로 전체 목표 충족.
- 5.4 글로벌 실증 및 상용화 패키징 [27.09~27.12, 셀빅]
	- 산출물: 상용화 패키지, 최종 결과 보고서
	- 점검: 국내/해외 실증 성공 + 사업화 목표 달성

- 실감형 미디어 케이브 + 햅틱 연동 4D 시범 콘텐츠 + 상용 수준 패키지
- 맞대거리(2인) 동작 멀티모달 데이터 + 평가/교정 피드백 시스템
- 글로벌 서비스 플랫폼 적용 가능한 실시간 인터랙션 모듈
- 동작 단위(Action-level) 평가 + 자동 피드백 시스템
- 무형문화유산 특화 동작 평가 프레임워크 기술 검증
- 국내외 수요처 2개소 이상 현장 실증 + TRL 7단계 달성
- **국내특허 출원 2건, 기술문서 1건, 플랫폼 완성용 시제품 1건, SW 저작권 등록 2건**
- 공인인증기관 성능 시험 (20fps + 각도 오차 10° 미만)

# 8. 2차연도 시범서비스 콘텐츠 (남사당놀이 미디어 케이브)

> 종목 4종(살판/어름/덧뵈기/풍물)으로 구성된 미디어 케이브 콘텐츠 상세. RFP "시나리오 6종 이상" 전체 목표 충족 논리는 §3.마 그룹 5의 5.3 비고 참조.

- **살판(땅재주)**: 4DGS 렌더링 미디어 케이브 4면 고실감 투사
- **어름(줄타기)**: 체험형(롤러 보드 연동) + 관람형(인터랙티브 곡예) 이원화
- **덧뵈기(탈놀이)**: 사용자 디자인 탈 아바타 참여형 공연
- **풍물(농악)**: XR 앙상블(가상 악기 합주) + 빛의 상모놀이

# 11. 별도 메모: 작성 오류 / 후속 조치

> 컨소시엄 회의 자료로 별도 정리 예정. 본 로드맵은 정상 값을 기재하되, 변환본 정정이 필요한 항목을 참고용으로 명시.

- **3.2 일정 오기 (변환본 정정 권고)**: [[4. 마일스톤 체계 및 수행계획]] 1단계(2차연도) 표 안 3.2의 일정이 `26.06~26.12`로 적혀있으나 2차연도 마일스톤이므로 `27.06~27.12`로 정정 필요. 본 로드맵은 정정 값을 기재.
