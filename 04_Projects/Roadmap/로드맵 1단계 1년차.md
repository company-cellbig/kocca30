# 개발 로드맵 - 1단계 1년차 (2026.04 ~ 2026.12)

> 1차연도 핵심: 무형문화유산 4D 핵심 엔진 + 1인 동작(혼자익히기) 기반 디지털 도제 프로토타입 완성. 9개월간 4 그룹 16개 마일스톤 수행.

## 1. 1차연도 핵심 목표

- 무형문화유산 4D 핵심 엔진 및 서비스 프로토타입 개발 (TRL 4~5)
- 무형문화유산 서비스 시나리오 및 플랫폼 설계
- 실시간 3D 포즈 추적 및 정량 평가 기술 개발
- 4D 콘텐츠 생성을 위한 기초 AI 모델 구축
- 1인 동작(혼자익히기) 분석 및 피드백 엔진 구현

## 2. 분기별 진행 계획

- Phase 1 (2026.04 ~ 2026.06) — 데이터 수집 시작 + 설계
	- [26.04] 1인 동작 데이터 확보 (용인대), 멀티모달 데이터 수집 (KETI), 실시간 동작 인식 (큐랩/셀빅) 착수
	- [26.05] 시나리오 정의(6종) 시작 (큐랩), 통합 플랫폼 아키텍처 설계 (큐랩/셀빅)
	- [26.06] 키오스크 프로토타입, 스코어링 엔진, 정량 오차 산출, 교정 피드백, 4D 복원, 처리 파이프라인 일제히 착수
- Phase 2 (2026.07 ~ 2026.09) — 핵심 개발
	- [26.07] 시나리오 정의 종료, 아바타 제어, 생성형 서사/텍스처, 시범 콘텐츠 프로토, 통합 실증 시작 (셀빅)
	- [26.08] 통합 플랫폼 아키텍처 종료
	- [26.09] 아바타 제어 종료, 통합 플랫폼 안정화 시작 (셀빅)
- Phase 3 (2026.10 ~ 2026.12) — 통합 및 1차연도 KPI 검증
	- [26.10] 1인 학습 데이터 확보 종료, 플랫폼 안정화 종료
	- [26.11] 실시간 동작 인식, 생성형 서사/텍스처, 시범 콘텐츠 프로토 종료
	- [26.12] 잔여 마일스톤 종료, 1차연도 KPI(분류 85%, FID 6.0, MPJPE 45mm) 검증

## 3. 마일스톤 그룹별 활동

### 그룹 1. 서비스 시나리오 및 플랫폼 구축

- 1.1 전승 교육 시나리오 및 서비스 설계 [26.05~26.07, 큐랩]
	- 산출물: 시나리오 정의서(6종)
- 1.2 통합 플랫폼 아키텍처 및 인프라 구축 [26.05~26.08, 큐랩/셀빅]
	- 산출물: 시스템 설계서, 아키텍처 설계서, CMS/API 서버
- 1.3 하드웨어 인터페이스 및 키오스크 프로토타입 [26.06~26.12, 큐랩/셀빅]
	- 산출물: 통합 미들웨어, 키오스크 UI 모듈, 키오스크 시제품 SW
- 1.4 통합 플랫폼 최적화 및 안정화 [26.09~26.10, 셀빅]
	- 산출물: 플랫폼 통합 패키지, 안정화 결과서

### 그룹 2. AI 기반 동작 분석 및 코칭 기술

- 2.1 실시간 동작 인식 및 분석 [26.04~26.11, 큐랩/셀빅]
	- 산출물: 동작분석 SW, 사용자 행동 인식 AI
	- 점검: 전문가 데이터 대비 분석 정확도 85% 이상
- 2.2 스코어링 엔진 및 평가 알고리즘 [26.06~26.12, 큐랩/용인대]
	- 산출물: 스코어링 엔진, 1인 동작 평가 알고리즘
	- 의존: 2.1 실시간 동작 인식의 출력 spec를 입력으로 활용 (병행 진행 시 spec 합의 선행 필요)
- 2.3 정량 오차 산출 및 검증 체계 [26.06~26.12, 연세대]
	- 산출물: 기준 동작 정의서, 검증 데이터, 오차 산출 모듈
	- 점검: 1차연도 각도/말단 오차 목표 충족
- 2.4 오차 기반 교정 및 피드백 시스템 [26.06~26.12, 연세대]
	- 산출물: 교정 안내 규격, 실시간/요약 교정 데모
	- 의존: 2.3 오차 산출 모듈의 인터페이스 spec를 입력으로 활용 (병행 진행 시 spec 합의 선행 필요)
- 2.5 1인 학습용 동작 데이터 확보 [26.04~26.10, 용인대]
	- 산출물: 멀티모달 데이터셋(영상, 포즈 등)

### 그룹 3. 생성형 AI 및 아바타 멀티모달 기술

- 3.1 무형문화유산 멀티모달 데이터 수집 및 증강 [26.04~26.12, KETI]
	- 산출물: 수집 절차서, 수집/증강 데이터셋
- 3.2 4D 콘텐츠 복원 및 특징 추출 [26.06~26.12, KETI]
	- 산출물: 멀티모달 엔코더, 특징 추출/형상 복원/4D 복원 SW 엔진
- 3.3 아바타 제어 및 인터랙션 기술 [26.07~26.09, 셀빅]
	- 산출물: 아바타 표현 제어 AI, 손 관절 추적 모듈, 물리 시뮬레이션 엔진
- 3.4 생성형 전통 서사 및 텍스처 기술 [26.07~26.11, 셀빅]
	- 산출물: 전통 서사 생성 AI, AI 텍스처 생성기, LMA 분석 알고리즘

### 그룹 4. 시스템 최적화 및 통합 실증

- 4.1 실시간 처리 파이프라인 및 최적화 [26.06~26.12, 연세대]
	- 산출물: 실시간 처리 모듈, 병목 분석 리포트, 최적화 버전
	- 점검: 평균 fps 1차연도 목표치 달성
- 4.2 시범 서비스 콘텐츠 프로토타입 [26.07~26.11, 셀빅]
	- 산출물: 덜미/버나/덧뵈기/택견 콘텐츠 SW
- 4.3 통합 실증 및 기술 검증 [26.07~26.12, 셀빅]
	- 산출물: 실증 결과 보고서, 사용자 피드백 분석서

## 4. 기관별 핵심 역할 (1차연도)

- ㈜큐랩 (주관)
	- 전승 지식 온톨로지 설계 및 멀티모달 데이터 파이프라인 구축
	- 무형문화유산 특화 실시간 동작 분석/스코어링 엔진(Core) 개발 (기초)
	- 디지털 도제(택견) 시나리오 6종 수립 및 플랫폼 프로토타입 구축
- ㈜셀빅
	- 몰입형 인터랙션 기반 아바타 제어 및 생성형 전통 서사 통합 기술
	- 무형문화유산 실감 체험 통합 플랫폼 (1차) 구축
	- 시범서비스(남사당놀이 - 덜미/버나/덧뵈기) 시나리오 기반 실증
- 한국전자기술연구원
	- 멀티모달 데이터(영상/음성/동작/문헌) 전처리
	- 영상 → 3D 형상(메쉬) 생성 기술 개발
	- 영상 → 4D 콘텐츠 복원 인공지능 모델 개발
	- 4D 생성 사전학습용 파운데이션 모델 구축
	- 멀티모달 → 무형문화유산 고유 특징 추출 AI 모델 개발
- 연세대학교
	- 단일 RGB 기반 사용자 포즈 인식/추적 파이프라인 구축
	- 3D 스켈레톤 기반 정량 동작 평가 지표 정의 및 초기 평가 모델 개발
	- 초기 단계 실시간 교정 피드백 생성 구조 설계
- 용인대학교
	- 1인(전문가/초보자/수련생) 혼자익히기 멀티모달 데이터 획득
	- 혼자익히기 동작 평가 및 교정 피드백 알고리듬/엔진 개발
	- 택견 표준수련체계 (기본동작 5/홀새김 1/연무동작 2) 정리

## 5. 1차연도 KPI 목표

- 무형문화유산 특성 분류 정확도: 85%
- 무형문화유산 4D 콘텐츠 생성 정확도(FID): 6.0
- 동작 분석 정확도(MPJPE): 45mm

## 6. 1차연도 산출물 목표

- 실시간 1인 동작 분석 및 스코어링 엔진
- 무형문화유산 전승 교육용 시나리오 및 체험형 시범 콘텐츠
- 무형유산 멀티모달 데이터셋
- 혼자익히기(1인) 동작 평가 및 교정 피드백 시스템
- 실시간 사용자 포즈 추적 및 단일 뷰 3D 재구성 핵심 알고리즘
- 국내특허 출원 3건, 기술문서 1건, 시제품 제작 2건, SW 저작권 등록 2건

## 7. 1차연도 멀티모달 데이터 수집 종목

- 택견
	- 기본동작: 품밟기, 활갯짓, 딴죽, 차기, 손질
	- 홀새김: 첫단~일곱단
	- 연무동작: 본때 앞엣거리 8마당, 연단18수
- 남사당놀이
	- 덜미(인형극), 버나(대접돌리기), 살판(땅재주), 어름(줄타기), 덧뵈기(탈춤), 풍물(농악)

## 8. 1차연도 시범서비스 시나리오 6종 (택견)

> RFP 단계별 정량 요건([[ref_제안요청서]] L56 — "문화전승 가능한 무형문화유산 선정 및 6종 이상의 적용 시범 시나리오 제시")의 수치(6종 이상)를 1차연도 택견 시나리오로 충족. RFP는 시나리오 수만 명시하며 산출물 항목과 일대일 대응되는 셈법은 아님.

- 품밟기 리듬 동기화
- 활개짓 궤적 추적 가이드
- 혼자 익히기 (독습)
- 맞대거리 (가상 대련)
- 택견 굴신 호흡 가이드
- 택견 온톨로지 (AI 도슨트)
