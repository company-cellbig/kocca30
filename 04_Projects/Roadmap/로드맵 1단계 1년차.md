> 1차연도(9개월) 핵심: 무형문화유산 4D 핵심 엔진 + 1인 동작(혼자익히기) 디지털 도제 프로토타입 완성. TRL 4~5. 4 그룹 16개 마일스톤. 종료 시 Phase Gate를 통해 2차연도 진입 Go/NoGo 결정.

# 1. 1차연도 핵심 목표

- 무형문화유산 4D 핵심 엔진 + 1인 동작(혼자익히기) 프로토타입 (TRL 4~5)
- 시나리오 정의서 6종 작성 (사업 전체 분량, §3.가 1.1: RFP 정본) + 1차연도 시범서비스 시나리오 5종 구현 (남사당놀이, §8) + 통합 플랫폼 설계
- 실시간 3D 포즈 추적 + 정량 평가(각도/말단 오차) + 평균 fps 기준선 확보
- 4D 콘텐츠 생성 기초 AI 모델 + 멀티모달 온톨로지 1차 구축 + 검증
- LMA(Laban Movement Analysis) 기반 동작 분석/정량화 1차 적용
- 종료 시 Phase Gate 통과 → 2차연도 진입

- 1.3 하드웨어 인터페이스 및 키오스크 프로토타입 [26.06~26.12, **큐랩**/셀빅]

# 5. 1차연도 KPI 목표 + Phase Gate

**RFP 명시 KPI**:

| KPI | 목표 |
|---|---|
| 무형문화유산 특성 분류 정확도 | 85% |
| 4D 콘텐츠 생성 정확도 (FID) | 6.0 |
| 동작 분석 정확도 (MPJPE) | 45mm |

**4대 트랙 기준선** (Medium-5 반영):

| 트랙 | 1차연도 기준선 |
|---|---|
| 평균 fps | 측정 기준선 확보 (Latency 100ms 이하 1차 검증) |
| 관절 각도 오차 | 1차연도 기준선 산출 (2차 10° 미만 목표 대비) |
| 말단 위치 오차 (MPJPE) | 45mm |
| 교정 안내 | 실시간 즉시 + 동작 후 요약 2단 구조 prototype |

**Phase Gate (2026.12 종료 시점)**:

- 위 RFP KPI 3종 + 4대 트랙 기준선 + 온톨로지 정합성 검증(§9) + LMA 평가 축 1차 검증(§10) 통과 여부
- AI 검증위원회(§11) 자문 → 2차연도 진입 Go/NoGo 결정 및 2차연도 계획 조정

# 10. LMA 평가 축 (독립 명시)

> LMA(Laban Movement Analysis)는 4대 트랙(속도/각도/말단/교정 안내) 중 "교정 안내" 트랙의 의미 기반 평가 축으로 작동. 3.4 산출물(텍스처/서사)에 묻힌 부수 알고리듬이 아닌 **독립 평가 축**.

- **이론적 기반**: 무용/동작 분석 표준 LMA: Effort/Shape/Space/Time 4 축으로 동작 의미 정량화
- **1차연도 적용 범위**
	- 2.3 정량 오차 산출 점검 기준에 LMA 의미 평가 지표 반영
	- 2.4 교정 안내: 동작 완료 후 요약 교정에 LMA 4축 기반 의미 안내 적용
	- 2.5 데이터 수집: LMA 라벨 동반
	- 3.4 LMA 분석 알고리듬 개발 (알고리듬 자체)
- **목표**: 단순 관절 오차 비교를 넘어 "수행 의도/완성도" 정량화: 무형문화유산 동작의 핵심 특성(연속성/리듬성/수행 완성도) 평가
