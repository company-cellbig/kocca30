> 덧뵈기 기획서에 적용했으나 [[덜미 - 나만의 유람기 기획서]]에 아직 적용 안 한 공통 사양 표준 항목 목록. 정합 대상 정본은 [[시범콘텐츠 공통 사양]], 적용 예시는 [[덧뵈기 - 나만의 탈춤 기획서]]. (2026-06-08 기준). **2026-06-26 마이그 완료**: 나/다/라 적용, 가 해소, 마 보류, 바 외래어 적용(나머지 가독성 전수는 별건 잔여). 항목별 현황은 §2.

# 1. 배경

2026-06-08 작업에서 덧뵈기 기획서에 공통 사양 표준 여러 개를 적용함. 덜미는 일부만 따라가, 미적용 항목을 모아 나중에 일괄 정리하려고 둠. 이미 정합된 항목(프로세스 순차 sub-step 번호 형식, 행위자 표준, 분기/실패 sub-step 하위)은 제외하고, 남은 것만 적음.

# 2. 항목별 정합 현황

## 가. 화면 필드 (Step별 스크린 목록 + 전환)

- 내용: 각 Step에 `화면` 필드로 풀스크린 목록 + 전환 트리거 기재
- 상태: 해소(2026-06-26). 덧뵈기 기획서도 Step에 화면 필드 없음(별도 UI 문서 소관)이라, 덧뵈기 준용 결정으로 덜미도 기획서에 필드 안 둠. 화면 정체성은 나(UI 태그)와 동작 인라인 화면명으로 충족
- 정본: [[시범콘텐츠 공통 사양]] 화면 필드

## 나. UI 화면 태그 (프로세스)

- 내용: 프로세스 UI sub-step을 `UI(화면명): 동작`으로 표기해 동작이 어느 화면 건지 연결
- 상태: 적용(2026-06-26, 배치 1). 덧뵈기 준용해 페르소나 박첨지 태그 `UI(박첨지)`(S3) 적용. 덧뵈기는 특수 surface와 페르소나만 괄호 태그하고 일반 화면은 동작에 화면명 인라인 기재인데, 덜미도 동형이라 일반 화면 추가 괄호는 불요
- 정본: [[시범콘텐츠 공통 사양]] 프로세스 정의

## 다. AI 모듈 명세 템플릿

- 내용: AI 모듈을 역할/입출력/모델 확보/판정/성능/적용/데이터/평가 항목으로 명세 (한 줄 라벨 금지)
- 상태: 적용(2026-06-26, 배치 2, 커밋 9d939c7). 덜미 §4.가 4개 모듈(마당 플롯 LLM, 유저 입력 가공 LLM, 이미지 생성, AI 가드레일)을 공통 §7.가 템플릿(역할/입력과 출력/동작과 규칙/기술 요건/자산 요구/가드레일과 실패/의존) 풀세트로 확장. 미정 정량(모델 확보 후보, 판정 임계)은 확인 필요 표기, 정의분만 인용
- 정본: [[시범콘텐츠 공통 사양]] AI 모듈 명세 항목

## 라. 세션 데이터 표 형식 (확인 필요)

- 내용: 세션 데이터를 분류/값/처리 보관/파기 단일 표로 정리
- 상태: 적용(2026-06-26, 배치 1). 공통 §2.나 형식 맞춰 `수명` 열 추가, 헤더 슬래시 제거. 콘텐츠 입력 3종(캐릭터 정보, 선택 마당, 거리별 응답) 수명은 정본 모순(§2.가.3 S7 임시 데이터 파기 vs §4.다.1/S7 콘텐츠 데이터 보관)으로 "확인 필요" 표기. 사용자 확인 대상
- 정본: [[시범콘텐츠 공통 사양#2. 세션]]

## 마. 절참조 기호 정리 (워드 이관 시)

- 내용: 자기 문서 절참조 기호(예: 4장 마절을 가리키는 § 표기)를 사람용 표현(N장 X. 제목)으로 전환
- 상태: 보류 결정(2026-06-26). 백로그 최초의 "덧뵈기 전환 완료"는 stale(덧뵈기 기획서 § 자기참조 104회, 사람용 0회). §는 워드 평탄화에서 평문 "§3.나"로 정상 표시되고, 실제 워드 걸림돌은 위키링크임. 덜미만 변환 시 덧뵈기와 어긋나므로 사용자 결정으로 보류
- 조건: 워드 이관 정리가 필요해지면 덜미와 덧뵈기를 함께 별건으로 처리

## 바. 가독성 표준 (슬래시 절제, 두괄식 라벨, 쉬운 말)

- 내용: 덧뵈기에 적용한 가독성 정비. (1) 슬래시 절제: 3항목 이상 `A/B/C`는 쉼표로, 2항목은 진짜 대안만 유지 (2) 모든 불릿에 두괄식 볼드 라벨, 다항목은 sub-bullet 분리 (3) 표 셀 경량화, 반복 조건은 표 아래 불릿으로 (4) 전문용어 이중부정 금지, 쉬운 말(외래어 한글화 포함, 덧뵈기 예: 폴링→상태 조회, 횡단→공통, 스택→구현 기술)
- 상태: 외래어 적용(2026-06-26, 배치 1과 3). 폴링→상태 조회 7곳(§2.나 S4, §2.다 운영 파라미터), §4.가.4 "AI 가드레일 (횡단)"→"(전 단계 공통)"으로 교체. §1.가 "콘텐츠 횡단 누적"은 플랫폼 사양 정본 용어라 유지. 세션 표 헤더 슬래시도 제거
- 잔여(별건): 본문 3항목 이상 슬래시 전수 절제(예: `시작/진행/마무리`, `도입/전개/절정/마무리` 등), 두괄식 볼드 라벨 통일, 표 셀 경량화, 쉬운 말 전체 점검. 가운뎃점, em-dash는 없음
- 정본: [[CONVENTIONS#4) 읽기 쉬운 개조식]], [[CONVENTIONS#2) 쉽게 쓰기]]. 적용 예시 [[덧뵈기 - 나만의 탈춤 기획서]]
