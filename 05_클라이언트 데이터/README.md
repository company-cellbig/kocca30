> 클라 개발자가 앱에 직접 로드하는 프로덕션 데이터 폴더. 기획서 삽화(`assets/`)나 위키 문서(`04_Projects/`)와 분리함. 개발자는 이 폴더만 받으면 됨.

# 1. 폴더 목적

시범콘텐츠 클라이언트가 런타임에 로드하는 데이터(로컬라이제이션 텍스트, 이름 풀, 설정 등)를 둠. 위키 독자가 아니라 개발자가 소비 대상임.

- **소비자**: 클라 개발자 (앱 빌드/런타임)
- **삽화(PNG)와 분리**: 화면 도안 이미지는 `assets/시범콘텐츠/`에 있음. 여기는 데이터만
- **문서/검수와 분리**: 각 데이터의 용도 문서화와 번역 검수는 `04_Projects/시범콘텐츠/`의 위키 문서(.md)에서 하고, 그 문서가 이 폴더 파일을 상대경로로 참조함

# 2. 폴더 구성

| 경로 | 범위 | 내용 |
|---|---|---|
| `공통/` | 5종 시범콘텐츠 공유 | 여러 콘텐츠가 함께 쓰는 데이터 |
| `유람기/` | 덜미 - 나만의 유람기 전용 | 유람기에서만 쓰는 데이터 |

콘텐츠가 늘면 콘텐츠명 폴더를 추가함.

# 3. 파일 목록

## 3.1 공통/localization.json

- **용도**: 시범콘텐츠 5종 공통 UI 텍스트 (버튼, 라벨, 팝업, 안내 문구)
- **구조**: 최상위가 `key → { ko, en }` 평면 맵. key는 화면 코드 접두(예: `3_6_title`)를 씀
- **키 접두 범위**: `1_x`(공통 버튼/타임아웃), `3_x`(유람기), `5_x`(덧뵈기), `13_x`(그만두기/종료 확인), `14_x`(실패 처리 팝업)
- **플레이스홀더**: `{0}`, `{1}` 형식으로 런타임 값 치환 (예: `"{0}초 후 이동"`)
- **검수**: 한국어→영어 번역 정확성, 용어 일관성, UI 길이 제약을 위키 문서에서 검수함
- **상태**: 값 입력됨(초안). 번역 검수 미착수. 아래 확인 필요 참고

## 3.2 유람기/character_name_pool.json

- **용도**: 덜미 - 나만의 유람기 이름 랜덤 입력에 쓰는 이름 풀
- **구조**: `인덱스 → { ko, en }` 평면 맵. `ko`는 한국어 이름, `en`은 대응 창작 영문명(로마자 음역 아님, 뜻을 살린 각색)
- **상태**: 20개 항목 입력됨(초안)

# 4. 번역 검수 상태

한국어→영어 검수 결과. 상세 발견과 키 목록은 검수 노트(`06_작업노트/시범콘텐츠 공통/클라이언트 데이터 번역 검수.md`)에 있음.

- **반영 완료(2026-07-22)**: `5_x` en 플레이스홀더 오류 7건(`5_4_title`~`5_9_title`, `5_5_dialogue`) 실제 번역, 대소문자 2건(`Malttugi's`, `QR Code`)
- **사용자 직접 수정 예정**: 서술문 39키의 Title Case를 문장 케이스로 전환(버튼과 짧은 명사 라벨은 유지)
- **결정으로 종결**: 이름 풀 창작 영문명 유지, 이중 공백은 줄바꿈 의도라 유지, 키 번호 결번(`3_9`, `14_5`, `14_6`)은 의도적
- **미결**: 아포스트로피(`’`/`'`) 통일, "유람기" 역어(Story/E-Book/Travelogue) 통일, `5_10_title` 위치 확인

# 5. 규약

- **실제 구조 보존**: JSON은 클라가 로드하는 정본이라 구조(평면 맵)를 임의로 바꾸지 않음. 메타 래퍼(`_meta` 등)를 덧씌우지 않음
- **가독성 검토 면제**: 이 폴더의 JSON은 기계 대상이라 낯선 독자 가독성 검토를 하지 않음. 값의 정합(번역 정확성, 용어 일관성, 스키마)만 검수함
- **원본 정본**: 값의 단일 정본은 이 JSON 파일임. 위키 문서(.md)는 이 값을 중복 나열하지 않고 문서화와 검수 기록만 담음
