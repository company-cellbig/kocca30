> [[풍물]]의 판굿 단계를 구조화하기 전에 원자료의 동작 단위를 순서대로 추출한 작업 기록임. 결과 개수를 먼저 정하지 않고 원자료 범위 안의 단위를 모두 남김.

# 1. 분석 범위와 분절 기준

- 분석 범위: 윤범하 「안성남사당패의 어제와 오늘」 중 판굿 순서 전체. 인쇄면 65쪽의 1번 인사굿부터 인쇄면 66쪽의 27번 마당걷이까지임 (PDF 67~68쪽)
- 분절 기준: 원자료가 붙인 번호 하나를 근거 단위 하나로 삼음. 대형, 참여자, 행동, 놀이 종류 중 하나가 다음 번호에서 바뀌므로 번호 사이를 합치지 않음
- 대조 범위: 국립국악원 국악사전 「남사당놀이」의 판굿 27개 판제 순서와 한국민족문화대백과사전 「안성 남사당 풍물놀이」의 일반 판제 목록을 함께 확인함
- 근거 등급: 세 자료 모두 외부 공공 기관과 전문 기관 자료인 L4임. 전승 현장의 유일한 고정 순서로 격상하지 않음

# 2. 최초 근거 단위 추출표

원자료의 번호, 위치와 동작을 일대일로 대응함. 이 단계에서는 사용자 제시 개수에 맞춰 단위를 합치거나 제외하지 않음.

# 3. 근거 단위와 25단계 구조 대응

설명 편의를 위해 25단계를 다섯 흐름으로 묶음. 이 묶음은 원자료의 명칭이 아니라 문서 설계 추가임.

| 분석 묶음 | 사용자 단계 | 근거 단위 | 처리 |
|---|---:|---|---|
| A01 판 열기 | 1~3 | U01~U03 | 순서를 유지해 묶음 |
| A02 대형 전개 | 4~9 | U04~U07, U09~U10 | U08을 제외하고 순서를 유지해 묶음 |
| A03 집단 기예와 대형 변환 | 10~17 | U11~U18 | 순서를 유지해 묶음 |
| A04 개인놀이와 시나위 | 18~23 | U19~U24 | 순서를 유지해 묶음 |
| A05 마무리 기예 | 24~25 | U25~U26 | 순서를 유지해 묶음 |

- **합치기와 나누기**: 원자료 번호 단위 자체는 합치거나 나누지 않음. 상위의 다섯 묶음만 설명을 위해 추가함
- **제외 U08 당산돌림벅구**: 공공 자료의 27개 판제에는 있으나 사용자 제시 목록에는 없어 25단계 본표에서 제외함. 누락 사실은 [[풍물]]에 별도로 표시함
- **제외 U27 마당걷이**: 공공 자료의 마지막 군무이나 사용자 제시 목록에는 없어 25단계 본표에서 제외함. 누락 사실은 [[풍물]]에 별도로 표시함
- **명칭 정규화**: 사용자 표기의 `무등서기`는 세 자료에 공통으로 나타난 기본명 `무동서기`로 바로잡음
- **이형 표기**: PDF는 `무동서기, 새미받기`, 국립국악원은 `무동서기(새미받기)`, 한국민족문화대백과사전은 `무동서기와 동리받기`로 적음. [[풍물]]에서는 국립국악원 표제를 대표명으로 씀
- **이형 표기**: PDF는 `마당일채`, 국립국악원은 `마당일체(쩍쩍이굿)`, 한국민족문화대백과사전은 `마당일채 쩍쩌기굿`으로 적음. [[풍물]]에서는 국립국악원 표제를 우선하고 이형을 병기함
- **설계 추가**: A01~A05의 흐름 이름임. 전승 판제의 정식 구분으로 간주하지 않음
