> 꼭두각시 거리에서 유저가 수행할 동작과 오브젝트별 반응 초안을 정리함.

# 1. 유저 행동

## 1.1 유저가 할 수 있는 동작

- 이동
- 기울이기
- 팔 움직이기

## 1.2 유저가 취해야 하는 동작

- 오브젝트 획득
	- 오브젝트 근처로 이동 시 획득 가능 안내 표시가 뜨고 유저가 팔을 아래에서 위로 올리면 해당 오브젝트가 손에 붙음
- 오브젝트 던지기
	- 오브젝트 획득한 상태에서 팔을 위에서 수평까지 뻗으면 해당 오브젝트가 날아감
- 오브젝트 패대기치기
	- 오브젝트 획득한 상태에서 팔을 위에서 아래로 내리면 해당 오브젝트가 막 아래로 사라짐
- 오브젝트 챙기기
	- 오브젝트 획득한 상태에서 손을 맞잡으면 해당 오브젝트가 막 아래로 사라짐
- 오브젝트 전달
	- 오브젝트 획득한 상태에서 해당 오브젝트가 일정 거리 이상 이동하여 다른 인형과 충돌했을 경우 해당 인형의 뒤로 이동
- 오브젝트 쥔 손 교체
	- 유저가 몸을 기울인 방향의 손으로 오브젝트 배치
- 인형 위로하기
	- 꼭두각시 거리 4번째 단계인 박첨지 울음에서 유저가 박첨지에게로 다가가 팔을 천천히 흔듦
- 인형 때리기
	- 꼭두각시 거리 4번째 단계인 박첨지 울음에서 유저가 박첨지에게로 다가가 팔을 빨리 흔듦


# 2. 꼭두각시 거리

## 2.1 꼭두각시 덜머리집 싸움

- 찬물

| 행동             | 처리                                                          |
| -------------- | ----------------------------------------------------------- |
| 획득             | 산받이가 찬물 집어들었음을 알리고 그걸 어떻게 할 것인가 물음                          |
| 던지기            | 산받이가 그 무슨 놀부 심보냐고 어이없어함                                     |
| 패대기치기          | 산받이가 물 안 마실거면 안 마시지 왜 애먼 바가지까지 깨트리냐고 물음                     |
| 챙기기            | 산받이가 이 와중에 갈증이 나냐고 어이없어함                                    |
| 전달하기<br>(박첨지)  | 박첨지가 체신머리 없이 물을 마시고 산받이가 지금 자기때문에 이 난리가 났는데 <br>물이 넘어가냐며 비꼼 |
| 전달하기<br>(덜머리집) | 유저에게 넌 또 뭐하는 놈이냐며 성냄                                        |
| 전달하기<br>(꼭두각시) | 유저에게 지금 자기가 물이 넘어가겠냐며 성냄                                    |
