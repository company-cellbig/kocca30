> 꼭두각시 거리의 유저 동작과 소품별 반응, 실제 선택한 행동으로 개입도와 해결도를 산출하는 기준을 정리함.

# 1. 유저 행동

## 1.1 유저가 할 수 있는 동작

- 이동
- 기울이기
- 팔 움직이기

## 1.2 유저가 취해야 하는 동작

- 오브젝트 획득
	- 오브젝트 근처로 이동 시 획득 가능 안내 표시가 뜨고 유저가 팔을 아래에서 위로 올리면 해당 오브젝트가 손에 붙음
- 오브젝트 던지기
	- 오브젝트 획득한 상태에서 팔을 위에서 수평까지 뻗으면 해당 오브젝트가 날아감
- 오브젝트 패대기치기
	- 오브젝트 획득한 상태에서 팔을 위에서 아래로 내리면 해당 오브젝트가 막 아래로 사라짐
- 오브젝트 챙기기
	- 오브젝트 획득한 상태에서 손을 맞잡으면 해당 오브젝트가 막 아래로 사라짐
- 오브젝트 전달
	- 오브젝트 획득한 상태에서 해당 오브젝트가 일정 거리 이상 이동하여 다른 인형과 충돌했을 경우 해당 인형의 뒤로 이동
- 오브젝트 쥔 손 교체
	- 유저가 몸을 기울인 방향의 손으로 오브젝트 배치
- 인형 위로하기
	- 꼭두각시 거리 4번째 단계인 박첨지 울음에서 유저가 박첨지에게로 다가가 팔을 천천히 흔듦
- 인형 때리기
	- 꼭두각시 거리 4번째 단계인 박첨지 울음에서 유저가 박첨지에게로 다가가 팔을 빨리 흔듦

# 3. 유저 행동별 성향 평가 초안

유저가 실제로 선택한 행동마다 맥락과 반응을 기록함. 선택 행동의 횟수로 개입도를, 각 행동의 효과를 종합해 해결도를 정함. 장면은 행동을 해석하는 맥락으로 사용함.

## 3.1 선택 행동의 기록과 집계

유저가 실제로 한 행동을 1건씩 집계함. 소품은 획득부터 조작이 끝날 때까지를 1건으로 세고, 박첨지를 다독이거나 때린 행동도 1건으로 셈.

행동마다 장면, 소품이나 인물, 실제 한 행동, 전달 대상과 반응을 기록함.

이동, 기울이기와 손 교체는 집계에서 제외함. 선택하지 않은 소품은 평가에 넣지 않음.

## 3.2 개입도 산출

개입도는 체험 중 실제 선택한 행동의 누적 횟수로 정함. 돕는 행동과 혼란을 더하는 행동 모두 개입 횟수에 포함함.

**선택 행동 수 `N` = [[#3.1 선택 행동의 기록과 집계]]에 따라 센 행동 건수**임.

등급 경계는 기존 초안의 횟수 경계를 이어받은 설계 제안임. 기획서에 명시된 기준이나 검증된 성향 판정 기준은 아니며, 체험 기록을 보고 조정할 값임.

| 개입도 | 선택 행동 수 `N` |
| --- | --- |
| 소극 | 0~3건 |
| 중간 | 4~6건 |
| 적극 | 7건 이상 |

재산 분배에서 소품 하나만 전달하고 나머지 다섯 소품을 지나쳤다면 선택 행동 1건임. 다른 장면에서 한 행동도 같은 방식으로 더함. 분수나 소수점 계산은 사용하지 않음.

## 3.3 행동별 해결도

해결도는 선택한 행동의 효과를 분류한 값임. 해결은 싸움을 누그러뜨리거나 물건을 주인에게 돌려주는 행동, 요청을 돕거나 인물을 위로한 행동임. 혼란은 반감을 더하거나 소품을 훼손하는 행동, 필요한 재산이나 노잣돈을 버리거나 챙기는 행동임. 중립은 해결과 혼란 어느 효과도 확인되지 않는 행동임.

같은 전달 동작이라도 소품과 대상, 당시 요청과 반응에 따라 분류가 달라짐.

| 장면과 소품 | 해결 행동 | 혼란 행동 | 중립 행동 |
| --- | --- | --- | --- |
| 싸움: 찬물이 담긴 그릇 | 덜머리집 또는 꼭두각시에게 전달 | 패대기치기 | 던지기, 챙기기, 박첨지에게 전달 |
| 싸움: 노리개 | 덜머리집에게 전달 | 패대기치기, 꼭두각시에게 전달 | 던지기, 챙기기, 박첨지에게 전달 |
| 재산 분배: 오동 장롱 반다지, 자개 함롱 귀다지, 천석지기 땅문서 | 꼭두각시에게 전달 | 던지기, 패대기치기, 챙기기 | 박첨지 또는 덜머리집에게 전달 |
| 재산 분배: 깨진 매운독, 부적가리, 세마지기 땅문서 | 없음 | 덜머리집 또는 꼭두각시에게 전달 | 던지기, 패대기치기, 챙기기, 박첨지에게 전달 |
| 노잣돈: 엽전 꾸러미 | 꼭두각시에게 전달 | 던지기, 패대기치기, 챙기기 | 박첨지 또는 덜머리집에게 전달 |
| 박첨지 울음 | 다독이기 | 때리기 | 없음 |

획득만 한 행동은 중립 1건임. 획득 후 전달이나 처분을 했다면 전달이나 처분의 결과로 분류함.

해결 행동은 싸움 2건, 재산 분배 3건, 노잣돈 1건과 박첨지 다독이기 1건으로 총 7건까지 선택할 수 있음.

## 3.4 해결도 산출

선택 행동마다 해결, 중립과 혼란 중 하나를 기록하고 각 건수를 더함.

집계값은 다음과 같으며 모두 정수임.

| 집계값 | 의미 |
| --- | --- |
| `R` | 해결 행동 수 |
| `M` | 중립 행동 수 |
| `H` | 혼란 행동 수 |
| `N` | 전체 선택 행동 수. `R + M + H`와 같음 |

해결 행동과 혼란 행동의 건수를 비교해 최종 해결도를 정함. 중립 행동은 개입도에만 포함함.

| 최종 해결도 | 정수 비교 조건 |
| --- | --- |
| 해결 | `R > H` |
| 혼란 | `H > R` |
| 중립 | `R = H` |

해결 5건과 중립 5건이면 `R = 5`, `H = 0`이므로 해결임. 해결과 혼란이 각각 3건이면 중립이며, 두 종류의 행동 기록은 그대로 남김.

체험을 마쳤는데 선택 행동이 없으면 `N = 0`으로 기록하고 소극과 중립을 적용함. 결과 설명에는 판정 근거가 되는 선택 행동이 없었음을 표시함.

| 개입도 | 해결 | 중립 | 혼란 |

## 3.6 판정 예시와 결과 설명

아래 행동만 선택하고 체험을 마친 경우의 예시임. 전달이나 처분을 위한 획득 동작은 별도로 더하지 않음.

| 선택 행동 기록 | 행동 수 `N` | 개입도 | 최종 해결도 | 최종 성향 |
| --- | --- | --- | --- | --- |
| 오동 장롱 반다지만 꼭두각시에게 전달함. 재산 분배의 다른 다섯 소품은 지나침 | 1건 | 소극 | 해결: `R = 1` | 조용한 수습꾼 |
| 찬물을 꼭두각시에게, 노리개를 덜머리집에게 전달함. 오동 장롱 반다지, 자개 함롱 귀다지, 천석지기 땅문서와 엽전 꾸러미를 꼭두각시에게 전달하고 박첨지를 다독임 | 7건 | 적극 | 해결: `R = 7` | 적극 해결사 |
| 위의 일곱 행동에 더해 깨진 매운독, 부적가리와 세마지기 땅문서를 던짐 | 10건 | 적극 | 해결: `R = 7`, `M = 3` | 적극 해결사 |
| 해결 1건, 중립 4건과 혼란 5건을 선택함 | 10건 | 적극 | 혼란: `R = 1`, `M = 4`, `H = 5` | 천둥 벌거숭이 |
| 해결 3건, 중립 4건과 혼란 3건을 선택함 | 10건 | 적극 | 중립: `R = H = 3`, `M = 4` | 오지랖쟁이 |
| 소품 9개를 획득만 하고 조작을 마침 | 9건 | 적극 | 중립: `M = 9` | 오지랖쟁이 |
| 아무 행동도 선택하지 않음 | 0건 | 소극 | 중립: 선택 행동 없음 | 태평한 구경꾼 |

마무리 화면에는 최종 성향, 선택 행동 수, 해결과 중립 및 혼란 행동 수와 근거 행동을 함께 표시함. 중립 결과는 중립 행동만 했는지, 해결과 혼란 행동 수가 같았는지, 선택 행동이 없었는지를 실제 기록에 맞춰 설명함.
