> 꼭두각시 거리의 유저 동작과 소품별 반응, 행동에 따른 성향 평가 초안을 정리함.

# 1. 유저 행동

## 1.1 유저가 할 수 있는 동작

- 이동
- 기울이기
- 팔 움직이기

## 1.2 유저가 취해야 하는 동작

- 오브젝트 획득
	- 오브젝트 근처로 이동 시 획득 가능 안내 표시가 뜨고 유저가 팔을 아래에서 위로 올리면 해당 오브젝트가 손에 붙음
- 오브젝트 던지기
	- 오브젝트 획득한 상태에서 팔을 위에서 수평까지 뻗으면 해당 오브젝트가 날아감
- 오브젝트 패대기치기
	- 오브젝트 획득한 상태에서 팔을 위에서 아래로 내리면 해당 오브젝트가 막 아래로 사라짐
- 오브젝트 챙기기
	- 오브젝트 획득한 상태에서 손을 맞잡으면 해당 오브젝트가 막 아래로 사라짐
- 오브젝트 전달
	- 오브젝트 획득한 상태에서 해당 오브젝트가 일정 거리 이상 이동하여 다른 인형과 충돌했을 경우 해당 인형의 뒤로 이동
- 오브젝트 쥔 손 교체
	- 유저가 몸을 기울인 방향의 손으로 오브젝트 배치
- 인형 위로하기
	- 꼭두각시 거리 4번째 단계인 박첨지 울음에서 유저가 박첨지에게로 다가가 팔을 천천히 흔듦
- 인형 때리기
	- 꼭두각시 거리 4번째 단계인 박첨지 울음에서 유저가 박첨지에게로 다가가 팔을 빨리 흔듦

# 3. 유저 행동별 성향 평가 초안

[[덜미 - 나만의 꼭두각시 기획서#4.3 유저 성향 평가 시스템]]의 판정표를 아래 네 장면의 유저 행동과 대조함. **행동별 문제 해결도와 그 해석은 이번에 제안하는 설계 추가임.** 기획서에 이미 확정된 행동별 점수나 최종 판정으로 보지 않음.

## 3.1 평가 기준과 결과 연결

4.3의 인포그래픽은 개입 적극도와 문제 해결도를 조합해 다음 성향명을 표시함.

| 개입 적극도 | 해결 | 중립 | 혼란 |
| --- | --- | --- | --- |
| 적극 개입 | 적극 해결사 | 오지랖쟁이 | 천둥 벌거숭이 |
| 중간 개입 | 은근한 조력자 | 유유자적 유람객 | 장난꾸러기 |
| 소극 개입 | 조용한 수습꾼 | 태평한 구경꾼 | 슬쩍 사고뭉치 |

행동별 평가표는 문제 해결도에 반영할 방향을 제안함. 최종 성향명은 세션 전체의 개입 적극도와 종합한 문제 해결도가 정해진 뒤 위 표에서 찾음.

- **개입 적극도**: 기획서에는 적극, 중간과 소극을 구분할 횟수, 비율과 임계값이 없음. 행동 한 번만으로 개입 수준을 확정하지 않음.
- **해결**: 해당 장면의 요구에 부합하는 도움을 주거나 인물을 달래는 행동으로 해석함.
- **중립**: 행동은 했지만 해당 장면의 요구나 갈등을 해결하거나 악화했다는 근거가 부족함.
- **혼란**: 상대를 더 화나게 하거나 분배할 재산을 훼손하고 빼돌리는 등 문제를 어렵게 만드는 행동으로 해석함.
- **획득**: 모든 소품에서 후속 행동을 준비하는 동작임. 획득만으로 문제 해결도를 판정하지 않고 던지기, 챙기기나 전달 같은 후속 행동을 확인함.
- **점수 합산**: 행동별 가중치, 반복 행동 처리, 해결과 혼란이 섞인 경우의 합산 기준은 기획서에 미명시임. 아래 표로 최종 점수나 유형을 자동 확정하지 않음.

같은 전달 동작도 장면과 소품, 받는 인물에 따라 다르게 해석함. 산받이의 농담이나 칭찬 자체를 해결 판정으로 삼지 않음.

## 3.2 꼭두각시와 덜머리집 싸움

[[덜미 - 나만의 꼭두각시 기획서#6.3.2 꼭두각시와 덜머리집 싸움]]의 반응을 기준으로, 싸움이 가라앉는지 또는 더 격해지는지를 봄. 두 소품의 획득은 위의 공통 획득 기준을 적용함.

### 3.2.1 찬물이 담긴 그릇

물을 주는 대상과 물을 다루는 방식별 판정 방향을 정리함.

| 행동 | 문제 해결도 초안 | 평가 근거와 해석 |
| --- | --- | --- |
| 던지기 | 중립 | 던진 대상과 싸움에 미친 영향이 미명시임. 물을 던졌다는 행동만으로 싸움을 진정시켰거나 악화했다고 판정하지 않음. |
| 패대기치기 | 혼란 | 산받이가 애먼 바가지를 깨뜨렸다고 반응함. 싸움과 별개로 소품을 파손하는 행동으로 해석함. |
| 챙기기 | 중립 | 산받이가 갈증이 나느냐고 반응함. 자신의 필요를 챙겼지만 싸움 해결에 기여한 근거는 없음. |
| 박첨지에게 전달 | 중립 | 박첨지는 물을 마시고 산받이는 이를 비꼼. 박첨지의 갈증을 해소하는 것과 싸움을 해결하는 것은 구분함. |
| 덜머리집에게 전달 | 혼란 | 덜머리집이 유저에게 성냄. 싸움 중인 인물의 반감을 더하는 행동으로 해석함. |
| 꼭두각시에게 전달 | 혼란 | 꼭두각시가 지금 물이 넘어가겠느냐며 유저에게 성냄. 상대가 원하지 않는 도움으로 반감을 더하는 행동으로 해석함. |

### 3.2.2 노리개

| 행동 | 문제 해결도 초안 | 평가 근거와 해석 |
| --- | --- | --- |
| 던지기 | 중립 | 산받이가 자신에게 주지 그랬느냐며 아쉬워함. 노리개를 버리는 행동이 싸움을 바꿨다는 근거는 없음. |
| 패대기치기 | 혼란 | 산받이가 비싼 물건을 부순다고 반응함. 싸움과 별개로 재산을 파손하는 행동으로 해석함. |
| 챙기기 | 중립 | 산받이가 손장난을 하느냐고 반응함. 노리개를 챙긴 행동만으로 싸움의 변화를 확인할 수 없음. |
| 박첨지에게 전달 | 중립 | 박첨지가 자기 뒤로 옮김. 전달은 이뤄지지만 싸움이 가라앉거나 격해지는 반응은 미명시임. |
| 덜머리집에게 전달 | 혼란 | 덜머리집이 자기 물건을 함부로 만지지 말라며 성냄. 상대의 반감을 더하는 행동으로 해석함. |
| 꼭두각시에게 전달 | 혼란 | 꼭두각시가 덜머리집에게 더 성내며 달려듦. 원래의 싸움을 더 격하게 만드는 행동으로 해석함. |

## 3.3 재산 분배

[[덜미 - 나만의 꼭두각시 기획서#6.3.3 재산 분배]]에서는 꼭두각시가 재산 분배를 요구함. 같은 행동에 같은 반응이 나오는 소품을 묶되, 기획서가 표현한 수용과 거절을 실제 재산 가치의 절대 기준으로 보지 않음. 모든 소품의 획득은 공통 획득 기준을 적용함.

### 3.3.1 전달 시 수용되는 소품

오동 장롱 반다지, 자개 함롱 귀다지와 천석지기 땅문서는 전달 대상별 반응이 같음. 아래 행동별 판정은 세 소품 각각에 적용함.

| 행동 | 문제 해결도 초안 | 평가 근거와 해석 |
| --- | --- | --- |
| 던지기 | 혼란 | 산받이가 버리는 것을 아쉬워하거나 값어치를 강조함. 분배할 재산을 버려 분배를 어렵게 만드는 행동으로 해석함. |
| 패대기치기 | 혼란 | 산받이가 파손을 지적하거나 자신이 챙길 테니 두라고 반응함. 분배할 재산을 훼손하거나 분배에서 빼는 행동으로 해석함. |
| 챙기기 | 혼란 | 산받이가 손장난을 지적하거나 자신과 나누자고 반응함. 다른 인물에게 분배할 재산을 유저가 챙기는 행동으로 해석함. |
| 박첨지에게 전달 | 중립 | 박첨지가 자기 뒤로 옮김. 재산이 박첨지에게 돌아가 꼭두각시의 분배 요구에 응한 결과는 확인되지 않음. |
| 덜머리집에게 전달 | 중립 | 덜머리집은 당연하다는 듯 반응함. 덜머리집의 수용만으로 꼭두각시의 요구까지 해결했다고 보지 않음. |
| 꼭두각시에게 전달 | 해결 | 재산을 요구한 꼭두각시에게 전달하고 꼭두각시가 기뻐함. 요구에 응하는 도움으로 해석하되, 전체 분배가 공평하다는 판정까지 확장하지 않음. |

### 3.3.2 전달 시 거절되는 소품

깨진 매운독, 부적가리와 세마지기 땅문서는 박첨지가 버리고, 꼭두각시와 덜머리집은 성내거나 상대에게 던지는 반응을 보임. 아래 행동별 판정은 세 소품 각각에 적용함.

| 행동 | 문제 해결도 초안 | 평가 근거와 해석 |
| --- | --- | --- |
| 던지기 | 중립 | 산받이는 쓸모나 날아가는 모습에 대해 말함. 버리는 행동만으로 분배 갈등이 해소되거나 악화한 결과는 확인되지 않음. |
| 패대기치기 | 중립 | 산받이는 더 부술 것이 없거나 자신이 가져가겠다고 반응함. 기획서에 추가 파손이나 갈등 악화가 명시되지 않아 혼란으로 단정하지 않음. |
| 챙기기 | 중립 | 산받이는 곤궁함, 엿바꿔먹기나 땅의 가치를 소재로 농담함. 유저가 챙기는 행동이 분배 갈등을 바꿨다는 근거는 없음. |
| 박첨지에게 전달 | 중립 | 박첨지가 화면 밖으로 던짐. 전달한 재산이 수용되지 않아 분배 요구를 돕는 결과로 보지 않음. |
| 덜머리집에게 전달 | 혼란 | 덜머리집이 성내거나 꼭두각시에게 던짐. 원하지 않는 분배로 반감을 더하는 행동으로 해석함. |
| 꼭두각시에게 전달 | 혼란 | 꼭두각시가 성내며 덜머리집에게 던짐. 분배 요구에 응하기보다 상대에 대한 분노를 더하는 행동으로 해석함. |

## 3.4 노잣돈

[[덜미 - 나만의 꼭두각시 기획서#6.3.4 노잣돈]]에서는 금강산으로 떠나려는 꼭두각시가 노잣돈을 요구함. 엽전 꾸러미의 획득은 공통 획득 기준을 적용함.

| 행동 | 문제 해결도 초안 | 평가 근거와 해석 |
| --- | --- | --- |
| 던지기 | 혼란 | 산받이가 버릴 거면 자신에게 주지 그랬느냐고 반응함. 필요한 노잣돈을 버려 요구에 응하기 어렵게 만드는 행동으로 해석함. |
| 패대기치기 | 혼란 | 산받이가 자신이 챙기겠다고 반응함. 엽전을 처분해 노잣돈을 요청한 꼭두각시에게 전달하지 않는 행동으로 해석함. |
| 챙기기 | 혼란 | 산받이가 손장난을 하느냐고 반응함. 꼭두각시에게 필요한 노잣돈을 유저가 챙기는 행동으로 해석함. |
| 박첨지에게 전달 | 중립 | 박첨지가 자기 뒤로 옮김. 꼭두각시의 노잣돈 요구에 응한 결과는 확인되지 않음. |
| 덜머리집에게 전달 | 중립 | 덜머리집은 당연하다는 듯 반응함. 돈을 전달했지만 노잣돈을 요구한 인물은 꼭두각시임. |
| 꼭두각시에게 전달 | 해결 | 노잣돈을 요구한 꼭두각시에게 엽전을 전달하고 꼭두각시가 기뻐함. 떠날 준비를 돕는 행동으로 해석함. |

## 3.5 박첨지 울음

[[덜미 - 나만의 꼭두각시 기획서#6.3.5 박첨지 울음]]의 두 행동을, 울고 있는 인물에게 유저가 어떻게 반응했는지로 해석함.

| 행동 | 문제 해결도 초안 | 평가 근거와 해석 |
| --- | --- | --- |
| 다독이기 | 해결 | 박첨지를 위로하는 행동으로 해석함. 슬픔을 달래는 도움을 평가하며, 박첨지의 잘못까지 용서했다는 의미로 확장하지 않음. |
| 때리기 | 혼란 | 울고 있는 박첨지에게 폭력을 더하는 행동으로 해석함. 산받이가 맞아도 싸다고 반응해도 해결 행동으로 바꾸지 않음. |

## 3.6 마무리 결과 연결 예시

아래는 행동 방향과 판정표를 연결하는 조건부 예시임. 실제 세션의 개입 수준과 문제 해결도 합산 기준은 따로 정해야 함.

- 꼭두각시에게 수용되는 재산과 노잣돈을 전달하고 박첨지를 다독인 행동은 해결 방향의 근거로 남김. 세션 종합 결과가 해결이면 개입 수준에 따라 적극 해결사, 은근한 조력자 또는 조용한 수습꾼으로 연결함.
- 상대의 반감을 더하는 전달, 전달 시 수용되는 재산을 버리거나 챙기는 행동과 박첨지를 때린 행동은 혼란 방향의 근거로 남김. 세션 종합 결과가 혼란이면 개입 수준에 따라 천둥 벌거숭이, 장난꾸러기 또는 슬쩍 사고뭉치로 연결함.
- 갈등에 미친 영향이 확인되지 않는 행동은 중립 방향의 근거로 남김. 세션 종합 결과가 중립이면 개입 수준에 따라 오지랖쟁이, 유유자적 유람객 또는 태평한 구경꾼으로 연결함.
