# 1. 입력 준비

씨댄스에 넣을 영상과 이미지의 짝을 아래 표에서 찾음. 영상 파일명의 번호는 한 자리부터 쓰고, 이미지 파일명의 번호는 두 자리로 씀.

복원에 쓰는 자료의 위치와 역할을 구분함.

- **동작 참조 영상**: `assets/영상/덜미/원본영상/박첨지거리_1.mp4`부터 `박첨지거리_22.mp4`까지임

- **컬러 입력 이미지**: `assets/영상/덜미/컬러복원 v2/박첨지거리_01.png`부터 `박첨지거리_23.png`까지임

현재 컬러 v2의 일부 이미지에는 원본과 다른 중앙 구도, 얼굴 형태와 글자 배치가 남아 있음. 사용할 시작과 종료 이미지는 아래 입력 전 대조를 거쳐 원본 구도에 맞춘 뒤 사용함. 파일이 존재하는 것만으로 입력 준비가 끝난 것으로 판단하지 않음.

## 1.3 입력 순서와 사용 방법

입력 전에 시작과 종료 컬러 이미지를 같은 번호의 원본 기준 이미지 및 해당 영상의 실제 첫 프레임과 마지막 프레임에 대조함. 원본 중앙 영역의 대상 수, 위치, 크기, 자세, 얼굴 윤곽, 천 윗선과 글자 배치를 확인함. 원본 기준 이미지와 영상 프레임이 다르면 실제 영상의 해당 프레임을 우선함. 컬러 이미지에 차이가 있으면 원본에 맞춰 정정한 뒤 입력함. 구도가 다른 시작과 종료 이미지는 프롬프트 수정만으로 원본과 맞게 된 것으로 판단하지 않음.

한 영상의 프롬프트를 사용할 때 아래 순서로 입력함.

1. 표의 시작 컬러 이미지를 **첫 번째 이미지**로 넣음
2. 표의 종료 컬러 이미지를 **두 번째 이미지**로 넣음
3. 같은 행의 원본 영상을 동작 참조로 넣음
4. 무대 밖 장면이 있는 영상에는 공간과 실사 레퍼런스를 필요에 따라 추가함. 추가 이미지에는 시작이나 종료 역할을 부여하지 않음
5. 공통 프롬프트와 해당 영상의 개별 프롬프트를 한국어 원문 그대로 이어 붙임. 영문 재작성이나 원문에 없는 동작 시작 시각을 추가하지 않음

제출 기록에는 실제 입력 파일의 경로와 해시, fps와 길이, 생성 설정 및 제출 프롬프트를 남김. 제출 직전에 프롬프트가 공통과 해당 개별 코드 블록을 이어 붙인 문자열과 같은지 대조함. 길이는 생성 도구의 설정에서 지정하며, 지원 길이는 실제 도구에서 확인함.

표의 길이는 원본 길이이며 생성 도구의 지원 길이를 뜻하지 않음. 지원 길이를 넘으면 실제 동작과 카메라 전환을 확인해 나누며, 원본 동작을 임의로 빠르게 압축하지 않음.

이 문서의 영상별 코드 블록은 원본 파일 전체에 대응함. 분할 입력은 해당 구간의 영상 파일명, 시작과 종료 컬러 이미지 및 동작과 카메라 흐름을 반영한 한국어 개별 코드 블록을 이 작업 노트에 먼저 기록한 뒤 사용함. 제출 문자열은 공통 코드 블록과 해당 구간의 개별 코드 블록을 그대로 이어 붙인 내용과 대조함. 전체 영상용 개별 프롬프트를 나눈 영상에 그대로 적용하지 않음.

# 2. 공통 프롬프트

모든 영상의 개별 프롬프트 앞에 아래 문장을 붙임. 인형과 실사 사람의 움직임을 구분하며, 각 영상에 들어 있는 카메라 확대, 축소와 이동을 함께 따름.

```text
입력한 첫 번째 이미지는 이 영상의 시작 컬러 이미지이고, 두 번째 이미지는 이 영상의 종료 컬러 이미지다. 원본 참조 영상의 첫 프레임에서 시작해 마지막 프레임으로 끝내며, 해당 시점의 컬러 이미지에서 색과 재질을 적용한다. 두 이미지의 입력 순서를 뒤집지 않는다. 추가로 넣은 이미지는 공간과 색 및 재질을 위한 레퍼런스이며 시작 이미지나 종료 이미지가 아니다.

인형과 사람의 수, 위치, 크기, 얼굴 방향, 자세, 가려짐과 무대 천의 높이는 원본 참조 영상의 해당 프레임을 따른다. 동작, 등장과 퇴장, 카메라 확대와 축소, 이동 방향, 장면 순서와 타이밍은 원본 참조 영상을 따른다. 컬러 이미지의 위치나 크기에 맞추려고 원본의 대상을 옮기거나 늘이거나 동작 시점을 바꾸지 않는다.

시작과 종료 컬러 이미지 및 추가 컬러 레퍼런스는 색, 재질과 조명의 기준으로 사용한다. 중간에 나타나는 대상도 원본 참조 영상의 외형과 움직임을 유지하고 해당 컬러 레퍼런스의 색과 재질을 적용한다.

전체 결과는 가로 16:9 컬러 화면으로 만든다. 원본 중앙 시야의 구도와 대상 크기를 유지하고 좌우에 필요한 공간을 확장한다. 컬러 이미지의 기와, 목재, 단청, 검은 무대 천과 의상 색을 장면 전체에서 일관되게 유지한다. 원본의 좌우 검은 여백, 흠집, 먼지, 필름 끊김, 노출 깜박임과 잔상을 새 화면에 복제하지 않는다. 카메라가 이동할 때 건물, 무대 천, 고정 줄과 난간이 하나의 공간 안에서 연결되게 한다. 배경 구조가 휘거나 새 구조로 바뀌지 않게 한다.

인형 장면에서는 원본의 얼굴 윤곽과 눈, 코, 수염의 상대 위치를 유지하고 단단한 목각 얼굴과 천 의상을 표현한다. 조종하는 인형의 짧은 상하 움직임과 고개 기울기, 순간적인 멈춤을 참조 영상의 박자로 표현한다. 불분명한 밝은 형태는 원본에 보이는 윤곽과 움직임을 유지하고, 손으로 단정해 손바닥, 개별 손가락이나 관절을 새로 만들지 않는다. 인형 얼굴을 사람의 피부처럼 움직이게 하지 않고, 눈과 코, 수염이나 의상이 다른 인형과 섞이지 않게 한다. 서로 겹칠 때는 가려짐으로 처리하고 얼굴이 합쳐지는 효과를 만들지 않는다. 실사 사람 장면에서는 실제 사람의 피부와 얼굴, 손과 관절을 유지하고 원본의 자세 변화와 악기 동작을 따른다.

‘남 사 당’ 글자가 보이는 화면에서는 원본 참조 영상에 보이는 글자 모양, 위치, 간격과 크기를 유지한다. 카메라 확대와 이동에 따라 글자가 커지거나 화면 밖으로 빠지는 모습도 참조 영상을 따른다. 다른 글자, 자막, 로고, 테두리, 현대 물건과 원본에 없는 인물을 추가하지 않는다.

원본에 있는 카메라 이동과 컷 전환은 그대로 따르고, 새 장면 전환이나 겹쳐 녹는 효과를 만들지 않는다. 마지막 화면의 인물과 인형 수, 위치, 크기, 자세와 배경 구도는 원본 참조 영상의 마지막 프레임을 따른다. 종료 컬러 이미지의 색과 재질을 적용하되 그 이미지에 맞추려고 마지막 순간에 위치나 크기를 바꾸거나 불필요한 정지 시간을 덧붙이지 않는다. 새 대사나 음악은 생성하지 않는다. 인형의 입을 임의로 대사에 맞춰 움직이지 않는다.
```

# 3. 영상별 프롬프트

각 절은 원본 영상 한 파일에 대응함. 인형의 배역명과 대사의 뜻을 추정하지 않고 화면에 보이는 외형, 동작과 전환을 지시함.

## 3.1 `박첨지거리_1.mp4`


```text
첫 번째 이미지인 ‘박첨지거리_01.png’는 시작 이미지이고, 두 번째 이미지인 ‘박첨지거리_02.png’는 종료 이미지다. 동작과 카메라 흐름은 ‘박첨지거리_1.mp4’를 따른다.

넓은 정면 무대의 빈 화면에서 시작한다. 참조 영상의 순서와 박자에 맞춰 작은 머리들이 검은 무대 천 위로 낮게 나타났다가 내려가고, 좌우로 짧게 움직인다. 중간에는 인형의 몸을 크게 드러내지 않고 머리가 천 뒤에 가려지는 높이를 유지한다. 후반에는 왼쪽의 둥근 머리 형태와 오른쪽의 가늘고 긴 얼굴 형태가 함께 보이게 한다.

끝부분에서 참조 영상처럼 무대 입구를 향해 화면을 확대한다. 인형의 크기를 변형하지 말고 카메라 확대에 따라 천과 건물도 함께 커지게 한다. 종료 시에는 원본 영상의 마지막 프레임에 보이는 머리 높이, 좌우 위치, 무대 천의 글자 크기와 구도에 맞춘다.
```

# 4. 결과 확인과 연결

생성 결과를 원본 영상과 나란히 확인하고 다음 항목을 점검함.

- 첫 화면과 마지막 화면의 중앙 구도, 대상 수, 위치, 크기와 자세가 원본의 해당 프레임과 맞는지 확인함. 색과 재질은 해당 컬러 입력과 대조함
- 인형의 교대 순서, 서로 가려지는 순간과 천 뒤로 내려가는 동작을 확인함
- 카메라 확대와 축소에 따라 배경도 함께 움직이는지 확인함
- 무대 밖 장면의 사람, 북과 관악기 동작이 누락되지 않았는지 확인함
- 무대와 마당 사이의 이동에서 천의 측면, 고정 줄과 난간이 연결되는지 확인함
- 마지막 영상의 천 글자 화면과 ‘남 사 당’ 표기가 맞는지 확인함

음향은 참조 영상의 원본 트랙을 보존해 영상 편집 단계에서 연결함. 앞 영상의 종료 이미지와 다음 영상의 시작 이미지는 같은 파일이지만, 이것만으로 생성 결과의 연속성이 보장되지는 않음. 실제 생성본의 끝과 다음 생성본의 시작을 이어지는 원본 프레임과 함께 대조하고, 인형의 위치와 얼굴 크기, 천 윗선과 배경이 갑자기 바뀌지 않는지 확인함.
