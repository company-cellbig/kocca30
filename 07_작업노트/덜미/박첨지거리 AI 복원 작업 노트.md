> `assets/영상/박첨지거리.mp4`를 무대와 인형만 보이는 컬러 영상으로 재구성하기 위한 결정 사항, 제작 원칙과 검수 기준을 정리함.

# 1. 작업 목표

- **화면 구성**: 산받이와 악사 등 연희자가 나오는 실사 화면을 무대와 인형 중심 화면으로 교체함. 산받이의 대사와 추임새는 공연 음향의 일부로 유지함
- **복원 방식**: 현재 제공된 자산에는 같은 순간을 다른 각도에서 찍은 영상이 확인되지 않으므로 AI를 이용한 재구성 방식을 적용함. 앞뒤 무대 화면, 인형 사진과 동작 자료를 함께 사용해 비어 있는 무대 장면을 재구성함
- **품질 우선순위**: 기록 영상의 원본성보다 장면의 시각적 자연스러움과 연속성을 우선함. 다만 실제 촬영 장면과 AI 재구성 장면은 작업 기록에서 구별함
- **화면 복원**: 전체 영상을 진단해 실제로 확인되는 흔들림, 노이즈, 깜빡임, 명암 불균형과 선명도 저하를 보정하고 컬러화함
- **출력 규격**: 16:9 화면과 1080p 출력을 우선함. 좌우 화면 생성이나 재구도가 인형과 무대를 부자연스럽게 만들면 4:3에 가까운 원본 화면비를 유지함
- **음향 복원**: 잡음을 줄이고 음량과 대사 명료도를 높임. 과도한 처리로 목소리가 금속성으로 변하거나 추임새와 악기 소리가 손상되면 처리 강도를 낮춤

# 2. 영상 제작 원칙

## 2.1 화면 재구성

1. 원본을 장면 단위로 나누고 무대 장면, 산받이 장면과 전환 장면으로 구분함
2. 산받이 장면의 음향은 원래 시간축에 유지함
3. 산받이 장면의 화면은 앞뒤 무대 장면과 인형 사진을 참고해 짧은 구간으로 나누어 생성함
4. 생성 장면의 인형 외형과 움직임, 무대 구조와 조명 방향을 앞뒤 실제 장면에 맞춤
5. 생성 장면의 시작과 끝을 실제 장면에 연결하고, 경계에서 위치나 색이 튀면 전환 길이와 생성 구간을 다시 조정함

인형 움직임은 [[덜미 영상 인형 동작 분석]]과 [[박첨지 장대 인형 조종법]]을 참고함. 원본에 없는 복잡한 몸짓을 새로 만들기보다 고개, 몸통과 팔의 움직임, 등퇴장 동작을 공연의 기존 움직임에 맞춰 제한함.

## 2.2 안정화와 화질 복원

- **흔들림 보정**: 인형의 고유 움직임과 카메라 떨림을 구분해 무대 틀을 기준으로 안정화함
- **화면 손상 보정**: 실제로 확인되는 노이즈, 깜빡임, 먼지와 명암 변화를 장면별로 보정함
- **선명도 복원**: 얼굴과 의상의 경계가 뭉개지지 않는 범위에서 선명도를 높임. 없는 무늬나 표정을 만들어 내는 과도한 복원은 피함
- **컬러화**: 출처와 생성 이력을 확인한 인형 사진의 색만 근거로 사용함. 확인할 수 없는 무대와 의상 색은 추정임을 기록하고 장면 안에서 일관되게 유지함
- **해상도 향상**: 안정화, 화면 복원, 컬러화와 생성 장면 연결을 마친 뒤 최종 출력 단계에서 적용함

## 2.3 화면비 결정

- **우선안**: 원본의 위아래를 과도하게 자르지 않고 좌우를 생성해 16:9로 확장함
- **대체안**: 생성한 좌우 공간이 흔들리거나 무대 구조가 달라지면 4:3에 가까운 원본 화면비를 유지함. 이 경우 1080p 프레임 안에 원본 화면비를 보존하고 남는 좌우 영역을 단색 또는 무대와 어울리는 배경으로 처리함
- **판정 기준**: 인형 비율, 무대 틀, 배경 소품과 조명 방향이 장면 사이에서 안정적으로 이어지는지를 기준으로 화면비를 결정함

# 3. 음향 복원

음향은 영상 재구성과 별도 경로로 복원한 뒤 원래 시간축에 다시 맞춤.

1. 원본 음향을 재인코딩하지 않고 분리하며 원본 사본을 보존함
2. 지속 잡음, 저역 울림과 순간 잡음을 구분해 필요한 항목만 줄임
3. 대사 대역을 정리하고 장면별 음량 차이를 완화함
4. 큰 소리가 찌그러지지 않도록 최종 음량을 정리함
5. 산받이의 대사와 추임새, 악기 소리와 공연장 잔향이 자연스럽게 남는지 원본과 비교함

대사가 악기나 관객 소리와 겹친 구간은 완전히 분리하기 어려울 수 있음. 이때는 잡음을 모두 없애는 것보다 대사의 자연스러움과 공연 현장감을 우선함.

# 5. 검수 기준

## 5.1 영상

- 산받이의 모습이 최종 화면에 남지 않음
- 산받이 구간에서도 무대와 인형의 움직임이 멈추거나 부자연스럽게 반복되지 않음
- 실제 장면과 생성 장면 사이에서 인형 얼굴, 의상, 크기와 위치가 갑자기 바뀌지 않음
- 무대 틀과 배경 소품이 프레임마다 휘거나 새로 생기고 사라지지 않음
- 안정화 과정에서 인형의 의도된 흔들림과 빠른 동작을 지우지 않음
- 컬러가 장면 사이에서 튀지 않음
- 인형에 피부처럼 보이는 잘못된 질감이 생기지 않음
- 16:9 확장이 위 기준을 충족하지 못하면 원본 화면비를 유지하는 대체안을 사용함

## 5.2 음향

- 대사와 추임새가 원본보다 알아듣기 쉬움
- 음량이 장면마다 크게 튀지 않음
- 잡음 감소 뒤 목소리에 금속성 울림이나 물결치는 왜곡이 생기지 않음
- 악기와 공연장 잔향이 지나치게 사라지지 않음
- 생성 화면의 동작 시점이 원본 음향과 어긋나지 않음
