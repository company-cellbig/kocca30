> 저화질 흑백 기록영상은 동작, 연출, 음향과 시간축의 근거로 사용함. 최종 화면은 고정된 16:9 컬러 무대, 별도로 생성한 인형 동작 전경과 복원한 원본 음향을 합성해 1920×1080 컬러 영상으로 재구성함.

# 1. 제작 목표와 표시 원칙

- **결과물**: 박첨지거리 기록영상의 장면 순서와 공연 시간축을 따르는 1920×1080, 16:9 컬러 영상을 만듦
- **재구성 방식**: 원본 픽셀을 확대하거나 흑백 화면에 색을 입히지 않고, 원본에서 읽은 동작과 연출을 새 시각 자산으로 다시 제작함
- **표시 원칙**: 결과물을 사실적 복원본으로 부르지 않고 `원본 기록영상을 바탕으로 한 AI 생성 재구성 영상`으로 표시함
- **원테이크 정의**: 한 번의 생성으로 만든 영상을 뜻하지 않음. 여러 생성 클립을 연결하되 관객에게 컷이 두드러지지 않는 연속 화면을 뜻함
- **품질 우선순위**: 인형의 정체성, 조종 구조, 무대 일관성, 움직임의 자연스러움과 원본 음향 동기화를 우선함

# 2. 우선 제작 구조

최종 영상은 서로 독립적으로 교체할 수 있는 세 층으로 제작함.

| 층 | 역할 | 제작 원칙 |
|---|---|---|
| 고정 무대 | 전편의 공간, 조명과 구도 기준 | 승인한 16:9 컬러 무대를 반복 사용하고 생성 구간마다 다시 그리지 않음 |
| 인형 동작 전경 | 배역, 소품과 동작 표현 | 원본 동작 영상과 인형 기준 이미지를 함께 참조해 짧은 묶음으로 생성함 |
| 음향과 시간축 | 대사, 추임새, 장단과 전체 진행 고정 | 원본 음향을 복원하고 생성 영상의 동작을 이 시간축에 맞춤 |

## 2.1 고정 무대를 우선하는 이유

- 전체 화면을 매번 생성하면 무대 폭, 기둥, 포장막, 조명과 배경색이 구간마다 달라질 수 있음
- 무대를 고정하면 실패한 인형 동작 중심으로 다시 만드는 범위를 줄일 수 있을 것으로 예상함. 실제 절감 범위는 시제품에서 확인함
- 연결부에서 배경이 바뀌지 않으므로 인형의 자세와 이동만 맞추면 됨
- 배경과 전경을 따로 보정할 수 있어 색, 선명도와 합성 흔적을 구분해 고칠 수 있음

## 2.2 전체 화면 생성의 위치

- 전체 화면 생성은 우선 제작안이 아니라 시제품 비교 대상임
- 같은 시험 구간을 `전체 화면 생성`과 `고정 무대 및 인형 전경 분리 생성`으로 각각 만들어 품질과 재작업 비용을 비교함
- 전체 화면 생성이 무대와 인형의 일관성, 연결성 및 수정 효율에서 더 나은 결과를 보일 때만 예외적으로 채택함

# 3. 원본과 분석 마커의 역할

## 3.1 원본에서 가져올 정보

`assets/영상/박첨지거리.mp4`는 최종 화면의 픽셀 원본이 아니라 다음 정보를 판독하는 근거임.

- 대사, 추임새, 장단과 전체 재생 시간
- 인형과 소품의 등장 및 퇴장 순서
- 배역별 위치, 이동 방향, 동작과 속도
- 대사에 반응하는 고개, 몸통, 팔과 장대의 움직임
- 원본 카메라가 보여 주는 무대 범위와 시선 방향
- 연희자 실사 구간의 대사, 극적 기능과 앞뒤 장면 관계

인형 동작은 [[덜미 영상 인형 동작 분석]]의 관찰과 [[박첨지 장대 인형 조종법]]의 구조 및 조종 원리를 함께 대조함. 기록영상만으로 식별하기 어려운 배역과 동작은 추정으로 표시하고 생성 전에 다시 확인함.

## 3.2 기존 61개 구간의 사용법

- [[박첨지거리 분석 마커]]의 61개 구간은 원본의 장면, 동작과 음향을 찾는 내부 색인으로 유지함
- 61개 마커를 독립 생성 클립 수로 고정하지 않음
- 실제 생성 단위는 동작이 자연스럽게 이어지고 하나의 프롬프트로 지시할 수 있는 연속 묶음으로 다시 정함
- 하나의 분석 마커를 여러 생성 묶음으로 나누거나 여러 마커를 하나의 생성 묶음으로 합칠 수 있음
- 마커 ID와 실제 생성 묶음 ID를 별도로 두고 대응 관계를 생성 기록에 남김

## 3.3 연희자 실사 구간의 처리

- 연희자의 외형이나 신체 동작을 인형으로 직접 변환하지 않음
- 해당 구간의 대사, 장단, 극적 기능과 앞뒤 인형 장면의 흐름을 먼저 확인함
- 같은 시간 동안 무대에서 수행할 새 인형 행동을 스토리보드나 애니매틱으로 설계함
- 승인한 배역과 무대 기준을 사용해 새 인형 동작을 생성함
- 원본 음향의 대사와 추임새에 맞춰 인형의 시선, 고갯짓과 반응 시점을 조정함

# 4. 고정 기준 자산

영상 생성 전에 무대와 배역의 정지 기준을 먼저 승인함.

## 4.1 16:9 컬러 무대

- 1920×1080 정면 무대 이미지를 기본 합성 배경으로 만듦
- 원본의 핵심 공연 영역을 중앙에 두고 좌우 공간은 확인 가능한 무대 구조를 바탕으로 설계함
- 무대 틀, 포장막, 바닥, 배경 소품, 조명 방향, 재질과 색을 고정함
- 카메라 높이, 화각, 무대가 화면에서 차지하는 비율과 렌즈 느낌을 고정함
- 원본에서 확인되지 않는 좌우 구조와 색은 `설계 추가`로 기록함

## 4.2 배역별 인형 기준 묶음

배역의 구조 유형을 먼저 확인하고 해당하는 정지 기준을 마련함.

- 정면과 좌우 3/4 방향
- 좌우 측면
- 전신 비율과 배역 간 크기 비교
- 대표 표정과 가동 부위의 기본 상태
- 얼굴, 의상과 소품의 색상표
- 장대 인형, 막대 인형, 포대 인형과 기타 소품의 유형별 조종 구조

박첨지의 사각 장대, 입끈, 어깨끈과 팔 구조는 [[박첨지 장대 인형 조종법]]을 기준으로 확인함. 입이 열리고 닫히는 표현과 입끈 및 어깨끈 묘사는 박첨지처럼 해당 구조가 확인된 장대 인형에만 적용함. 다른 배역의 구조를 박첨지와 같다고 추정하지 않음.

## 4.3 색의 근거 수준

- **실물 근거 색**: 같은 개체나 같은 계통임이 확인된 실물 사진에서 가져온 색임
- **설계 색**: 흑백 원본과 확인되지 않은 자료만 있어 제작자가 정한 색임
- **생성 후보 색**: 생성형 이미지에서 나온 색으로, 역사적 사실의 근거로 사용하지 않음

색의 근거 수준을 배역 및 무대 색상표에 표시함. 정지 이미지 승인 뒤에는 장면마다 색을 새로 결정하지 않음.

## 4.4 승인 순서

1. 무대 기준 이미지의 구조, 구도와 색을 승인함
2. 배역별 외형, 크기와 조종 구조를 승인함
3. 배역 및 무대 색상표를 승인함
4. 공통 프롬프트, 배역별 프롬프트와 금지 프롬프트를 승인함
5. 승인된 자산만 영상 생성 시험에 사용함

# 5. 생성 방식 시험

## 5.1 도구 기능과 적용 경계

ByteDance는 Seedance 2.5가 한 번에 최대 30초를 생성하고 이미지, 영상과 음향을 함께 참조할 수 있다고 설명함. 모션 참조, 타임스탬프 단위 지시와 그린스크린 편집도 지원한다고 밝힘. 다만 복잡한 동작의 물리성과 여러 주체가 상호작용하는 장면의 안정성에는 개선 여지가 있다고 밝힘 ([ByteDance Seedance 2.5](https://seed.bytedance.com/en/seedance2_5), [ByteDance 공식 소개](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)).

Higgsfield의 2026-09-17 안내 기준으로 Seedance 2.5는 4초부터 30초까지 생성할 수 있고, Seedance 2.5 Edit는 기존 입력 영상 길이를 따르는 별도 모델임. 지원 길이와 기능은 플랫폼 변경 가능성이 있으므로 본편 생성 전에 다시 확인함 ([Higgsfield 도움말](https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-seedance)).

이 기능 설명은 제작 가능성의 근거일 뿐 박첨지거리에서의 성공을 보장하지 않음. 고정 무대와 인형 전경 분리, 모션 추종, 배경 제거와 길이별 안정성은 실제 시제품으로 판정함.

## 5.2 길이별 반복 시험

난도가 높은 한 장면을 다음 길이로 반복 시험함. 아래 길이와 반복 횟수는 모델의 안정성을 비교하기 위한 잠정 설계값임.

| 시험 길이 | 목적 |
|---:|---|
| 8초 | 짧은 기본 단위에서 외형과 동작 유지 여부를 확인함 |
| 15초 | 대사와 동작이 이어지는 중간 길이의 안정성을 확인함 |
| 20초 | 복수 행동과 장면 내 전환의 유지 여부를 확인함 |
| 30초 | 모델의 최대 생성 길이에서 형태와 시간 제어의 한계를 확인함 |

- 각 길이를 같은 입력 조건으로 2회 이상 생성하되 반복 횟수는 잠정값으로 둠
- 우연히 잘 나온 한 번의 결과가 아니라 반복 결과의 안정성을 비교함
- 길이가 늘어날수록 실패가 증가하면 최장 길이를 목표로 삼지 않고 통과율이 높은 짧은 단위를 선택함
- 단순한 독백과 느린 이동은 길게, 여러 인형의 상호작용과 빠른 동작은 짧게 나눌 수 있음

## 5.3 입력 묶음

생성 묶음마다 다음 자료를 준비함.

- 승인한 무대 또는 전경 생성용 단색 배경
- 등장 배역의 기준 이미지
- 원본에서 자른 동작 참고 클립
- 원본 음향에서 확인한 대사 및 반응 시점
- 시작 자세 이미지
- 시간대별 동작, 위치와 시선 지시
- 나타나면 안 되는 사람 신체, 현대 장비, 문자, 추가 인형과 임의 소품을 적은 금지 프롬프트

종료 자세 이미지는 모든 묶음에 의무로 만들지 않음. 다음 클립과 연결하기 어렵거나 특정 자세로 끝나야 하는 묶음에만 사용함. 중간 기준 프레임도 복잡한 동작의 경로를 고정할 필요가 있을 때만 추가함.

## 5.4 시험 평가 기준

| 평가 항목 | 통과 기준 |
|---|---|
| 배역 정체성 | 얼굴, 의상, 재질, 크기와 조종 구조가 클립 안에서 유지됨 |
| 동작 구조 | 팔, 장대와 몸통이 합쳐지거나 사람 신체로 바뀌지 않음 |
| 위치 제어 | 인형이 지시한 무대 위치와 이동 방향을 유지함 |
| 시간 제어 | 주요 동작과 반응이 지정한 시점에 나타남 |
| 화면 안정성 | 깜박임, 형태 붕괴, 임의 소품과 추가 배역이 없음 |
| 연결 가능성 | 마지막 자세와 이동 속도를 다음 클립에 이어 붙일 수 있음 |
| 수정 효율 | 실패한 인형 전경 중심으로 교체할 수 있고 무대 수정 범위가 제한됨 |

# 6. 전경 생성과 합성

## 6.1 인형 전경 생성

- 고정 무대를 영상 모델이 다시 그리지 않도록 인형과 필요한 소품만 생성하는 방식을 우선 시험함
- 단색 또는 그린스크린 배경 생성이 인형 윤곽과 반투명 소매를 안정적으로 보존하는지 확인함
- 배경 분리가 불안정하면 정지 마스크, 추적 마스크와 수동 로토스코핑을 함께 사용함
- 원본 모션 참조가 인형의 조종 구조를 무너뜨리면 동작을 더 짧게 나누고 시작 자세와 시간 지시를 보강함

## 6.2 연결 원칙

- 앞 클립의 마지막 자세와 다음 클립의 첫 자세를 맞춤
- 이동 방향, 속도, 시선과 대사 반응을 이어감
- 생성 요청마다 잠정 설계값인 0.5초에서 1초의 연결 여유를 두고 시험한 뒤 결과에 맞춰 확정함
- 인형이 멈추거나 다른 인형 및 소품에 가려지는 순간을 우선 연결점으로 사용함
- 필요한 경우 인형 전경에만 짧은 디졸브, 보간이나 속도 조정을 적용함
- 고정 무대에는 연결용 디졸브를 적용하지 않아 배경이 흐려지거나 이중으로 보이지 않게 함

DaVinci Resolve Studio는 Magic Mask를 이용한 피사체 분리와 추적, 시간 및 공간 노이즈 감소, UltraNR와 Super Scale을 제공함. 이 기능들은 합성 후보를 만드는 데 사용함. 자동 분리 결과는 인형 윤곽, 소매와 장대 가장자리를 프레임 단위로 확인함 ([Blackmagic Design](https://www.blackmagicdesign.com/products/davinciresolve/studio)).

# 7. 원본 음향 복원

음향은 영상 생성과 분리해 처리하고 생성 모델의 임의 음향은 최종본에서 사용하지 않음.

1. 원본 음향과 무처리 사본을 분리해 보존함
2. 지속 잡음, 험, 클릭, 파열음과 과도한 바람 소리를 필요한 범위에서 줄임
3. 대사, 추임새와 배경 소리의 분리 가능성을 시험함
4. 대사 명료도와 구간별 음량 편차를 정리함
5. 악기 소리와 공연장 잔향이 지나치게 사라지지 않았는지 원본과 비교함
6. 손상된 구간만 수동 보정함
7. 복원 음향을 기준 시간축으로 잠그고 생성 화면의 동작을 맞춤
8. 원음과 처리음을 비교해 목소리의 금속성 왜곡과 물결치는 잡음이 늘지 않았는지 확인함

DaVinci Resolve Studio는 Voice Isolation과 Dialogue Separator를 제공하지만 오래된 공연 음원에 적용했을 때 자연스러운지는 별도 시험이 필요함 ([Blackmagic Design](https://www.blackmagicdesign.com/products/davinciresolve/studio)). 필요하면 원음과 처리음을 섞어 현장감을 보존함.

# 8. 시제품 제작

## 8.1 시험 장면 선정

시제품의 잠정 범위를 30초 안팎으로 잡고 다음 조건을 함께 넣음.

- 원본 인형극 무대의 동작을 따라야 하는 구간
- 연희자 실사 화면을 새 인형극 장면으로 바꾸는 구간
- 두 인형 이상이 상호작용하거나 동작이 빠른 구간
- 원본 무대에서 대체 장면으로 넘어갔다가 다시 무대로 돌아오는 연결
- 대사와 인형 반응의 동기화를 확인할 수 있는 구간

## 8.2 비교 시제품

같은 시간 범위와 기준 자산으로 다음 두 시제품을 만듦.

1. 전체 16:9 화면을 생성한 시제품
2. 고정 무대와 인형 전경을 분리 생성해 합성한 시제품

두 결과는 화면 품질뿐 아니라 재생성 횟수, 수정 시간, 연결부 수리 범위와 배경 일관성을 함께 비교함. 고정 무대 방식이 검수 기준을 충족하지 못하면 배경 분리 방법, 전경 생성 배경이나 전체 화면 생성 방식을 다시 시험함.

# 9. 전체 제작 절차

1. 원본 영상과 음향을 분석하고 분석 마커를 대조함
2. 복원 음향을 기준 시간축으로 확정함
3. 16:9 컬러 무대 기준 이미지를 제작하고 승인함
4. 배역별 인형 기준 이미지와 색상표를 제작하고 승인함
5. 비교 시제품의 범위를 잠정 30초 안팎으로 잡고 난도 높은 구간을 선정함
6. 전체 화면 생성과 인형 전경 분리 생성의 결과 및 수정 비용을 비교함
7. [[#5.2 길이별 반복 시험]]에 적은 잠정 길이별로 반복 시험해 생성 단위를 정함
8. 분석 마커와 실제 생성 묶음의 대응표를 만들고 본편을 생성함
9. 고정 무대와 승인한 인형 전경을 합성함
10. 연결부, 색, 인형 윤곽과 음향 동기화를 보정함
11. 1920×1080 무음 영상과 복원 음향을 결합한 마스터를 각각 출력함

# 10. 검수 기준

아래 기준은 시제품 시험을 통과한 방식으로 제작한 전체 최종본에 적용함.

## 10.1 무대와 화면

- 전편에서 무대 틀, 포장막, 바닥, 배경 소품, 조명 방향과 색이 유지됨
- 원본의 핵심 공연 영역이 16:9 화면에서 잘리지 않음
- 좌우에 새로 설계한 공간이 흔들리거나 구간마다 다른 구조로 바뀌지 않음
- 원본의 단순 확대, 흐린 복제 배경과 검은 여백이 최종 화면에 남지 않음

## 10.2 인형과 동작

- 같은 배역의 얼굴, 의상, 재질, 크기와 조종 구조가 유지됨
- 팔, 장대와 소매가 합쳐지거나 사람의 피부 및 신체 형태로 바뀌지 않음
- 인형 수와 소품 수가 임의로 늘거나 줄지 않음
- 등장, 퇴장, 시선, 대사 반응과 주요 동작 순서가 원본 근거와 맞음
- 빠른 동작에서 형태 붕괴, 순간 이동, 역방향 재생과 불필요한 카메라 이동이 없음

## 10.3 연결과 음향

- 클립 경계에서 인형의 위치, 자세, 이동 방향과 속도가 갑자기 바뀌지 않음
- 연결용 디졸브나 보간이 인형의 윤곽을 이중으로 만들지 않음
- 대사, 추임새와 주요 반응 시점이 복원 음향과 맞음
- 대사 명료도가 높아지면서 목소리, 악기와 공연장 잔향의 인공적 왜곡이 늘지 않음
- 생성 모델의 임의 음성, 효과음과 음악이 최종 음향에 섞이지 않음

## 10.4 색과 기록

- 승인한 배역 및 무대 색상표가 전편에서 유지됨
- 실물 근거 색, 설계 색과 생성 후보 색의 구분이 생성 기록에 남음
- 사용 모델, 입력 자산, 프롬프트, 길이, 생성 후보, 선택 사유와 재작업 이력이 생성 묶음마다 기록됨
- 최종본과 작업 기록에 AI 생성 재구성 영상임이 표시됨
