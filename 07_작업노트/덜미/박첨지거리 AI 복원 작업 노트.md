> 저화질 흑백 기록영상 `assets/영상/박첨지거리.mp4`를 동작, 시간축과 음향의 근거로 사용하고, 전체 화면을 생성형 인공지능으로 다시 만들어 1920×1080, 16:9 컬러 영상으로 재구성하기 위한 원칙, 리소스, 제작 단계와 검수 기준을 정리함.

# 1. 작업 목표

- **최종 화면**: 원본의 모든 시각 구간을 생성형 인공지능으로 재구성한 1920×1080, 16:9 컬러 영상을 만듦
- **원본의 역할**: 저화질 흑백 원본은 장면 순서, 인형 동작, 카메라 시점, 대사와 공연 시간축을 판단하는 자료로 사용함. 원본 픽셀을 선명하게 만드는 전통적 복원본을 최종 화면으로 사용하지 않음
- **전체 생성 재구성**: 원래 무대 장면과 연희자 실사 장면을 모두 같은 시각 기준으로 다시 생성함. 연희자 실사 구간은 무대 위 인형과 인형 동작으로 대체함
- **화면비**: 처음부터 16:9 무대 구도를 설계하고 생성함. 654×480, 약 1.36:1인 원본 화면의 좌우만 사후 확장하거나 원본 화면비로 되돌리는 대체안은 최종 계획에 포함하지 않음
- **컬러**: 흑백 원본에 색을 덧씌우는 방식이 아니라, 확정한 인형과 무대 색을 생성 기준 이미지와 프롬프트에 고정해 컬러 장면을 만듦
- **음향**: 생성 모델의 음향은 사용하지 않고, 원본 공연 음향을 복원해 생성 화면의 원래 시간축에 맞춤
- **품질 우선순위**: 기록 영상의 픽셀 보존보다 인형과 무대의 정체성, 장면 연속성, 움직임의 자연스러움과 음향 동기화를 우선함
- **표시 원칙**: 최종본과 작업 기록에서 결과물을 원본의 사실적 복원본이 아니라 원본을 바탕으로 한 `AI 생성 재구성 영상`으로 표시함

# 2. 제작 방식

## 2.1 전체 화면 생성

원본 전체를 장면 단위로 나눈 뒤 각 장면을 16:9 컬러 화면으로 다시 생성함. 원래 무대 장면도 최종본에 그대로 사용하지 않고, 인형의 위치와 동작 및 무대 구도를 참고하는 모션 레퍼런스로 사용함.

- 원래 무대 장면은 원본의 동작과 장면 진행을 유지하면서 고화질 컬러 무대로 다시 생성함
- 연희자 실사 장면은 해당 시간의 대사, 추임새와 극 흐름에 맞는 인형 중심 무대 장면으로 새로 설계함
- 장면마다 시작, 중간과 종료 기준 프레임을 만들고 이를 영상 생성의 시각 기준으로 사용함
- 한 번에 전체 영상을 생성하지 않고, 모델이 외형과 동작을 안정적으로 유지할 수 있는 짧은 구간으로 나누어 생성함
- 생성 구간의 길이는 Seedance 2.5의 실제 입력 및 출력 제한과 시제품 결과를 확인한 뒤 확정함

## 2.2 16:9 무대와 인형 기준 고정

전체 생성에 앞서 모든 장면이 공유할 시각 기준 묶음을 만듦.

- **무대 기준**: 16:9 정면 무대, 무대 틀, 포장막, 바닥, 조명 방향과 배경 소품의 위치
- **인형 기준**: 배역별 얼굴, 체형, 의상, 장대, 색, 크기 비율과 정면 및 측면 모습
- **촬영 기준**: 카메라 높이, 화각, 무대가 차지하는 비율, 시선 방향과 피사계 심도
- **색 기준**: 배역별 색상표와 무대 색상표, 피부처럼 보이는 재질을 피하기 위한 재질 지시
- **생성 제약**: 사람의 얼굴과 신체, 현대적 장비, 임의의 문자, 추가 인형과 소품이 나타나지 않도록 하는 금지 요소

동일한 기준 이미지, 색상표와 핵심 프롬프트를 전 구간에 반복 사용함. 장면마다 임의로 스타일을 바꾸지 않음.

## 2.3 원본 전처리의 범위

원본 전처리는 최종 화면을 만드는 복원이 아니라 생성 입력을 알아보기 쉽게 만드는 준비 작업임.

- 장면 경계와 시간축을 분석하고 구간표를 만듦
- 인형 위치와 움직임을 읽기 어려운 구간만 최소한으로 밝기, 노이즈와 흔들림을 보정함
- 대표 프레임과 동작 참고 클립을 추출함
- 원본에 없는 무늬, 표정과 색을 전처리 단계에서 만들어 내지 않음
- 전처리본은 생성 모델 입력과 내부 검토에만 사용하고 최종 화면에는 포함하지 않음

## 2.4 컬러 재구성

색은 원본 흑백 영상에서 복구할 수 있는 정보가 아니므로 근거 수준을 구분해 설계함.

- 실물 사진에서 확인되는 색은 배역별 기준에 반영함
- 생성형 컬러화 이미지의 색은 역사적 사실이 아니라 시각적 일관성을 시험하는 후보로만 사용함
- 확인할 수 없는 무대와 의상 색은 `설계 색`으로 기록함
- 장면 생성 뒤 색을 새로 결정하지 않고, 승인한 색상표에 맞춰 생성본을 선택하거나 다시 생성함

## 2.5 음향 재사용과 복원

음향은 영상 생성과 별도 경로로 처리하고 원래 시간축을 유지함.

1. 원본 음향을 분리하고 무처리 사본을 보존함
2. 지속 잡음, 저역 울림과 순간 잡음을 필요한 범위에서 줄임
3. 대사와 추임새의 명료도 및 장면별 음량을 정리함
4. 악기 소리와 공연장 잔향이 지나치게 사라지지 않았는지 원본과 비교함
5. 복원 음향을 생성 영상에 다시 맞추고 인형의 반응 및 동작 시점을 조정함

대사와 악기가 겹쳐 분리가 어려운 구간은 완전한 잡음 제거보다 목소리의 자연스러움과 공연 현장감을 우선함.

# 4. 검수 기준

## 4.1 화면 구성과 해상도

- 모든 장면이 1920×1080, 16:9 화면을 채우고 654×480 원본의 단순 확대, 좌우 검은 여백 또는 흐린 복제 배경이 남지 않음
- 원본의 핵심 인형 동작, 등장 순서와 카메라 시점이 식별 가능하게 이어짐
- 연희자 실사 모습이 최종 화면에 남지 않고 해당 구간이 인형 중심 무대 장면으로 대체됨
- 원본의 위아래를 잘라 핵심 인형이나 무대 구조가 사라지지 않음
- 최종 마스터가 1920×1080 해상도와 원본 시간축을 유지함

## 4.2 인형과 무대의 일관성

- 같은 배역의 얼굴, 의상, 크기, 장대와 재질이 장면 사이에서 바뀌지 않음
- 인형의 팔, 얼굴, 장대와 의상에 사람의 신체나 피부 같은 질감이 생기지 않음
- 인형 수가 임의로 늘거나 줄지 않고 배역이 서로 섞이지 않음
- 무대 틀, 포장막, 바닥, 배경 소품과 조명 방향이 프레임마다 휘거나 사라지지 않음
- 생성 구간 경계에서 인형과 무대의 위치, 크기, 색과 조명이 갑자기 바뀌지 않음
- 화면 가장자리에서 새로 생성한 무대 공간이 흔들리거나 녹아내리지 않음

## 4.3 움직임과 시간 연속성

- 고개, 몸통, 팔, 장대와 등퇴장 움직임이 덜미 인형의 조종 방식에 맞음
- 빠른 동작에서 인형의 형태가 무너지거나 장대와 팔이 합쳐지지 않음
- 정지 프레임의 반복, 역방향 움직임, 순간 이동과 부자연스러운 카메라 이동이 없음
- 대사, 추임새와 주요 인형 반응의 시점이 원본 음향과 맞음
- 짧은 생성 구간을 연결한 흔적이 관객에게 두드러지지 않음

## 4.4 색과 화질

- 승인한 배역 및 무대 색상표가 전체 장면에서 유지됨
- 색이 프레임마다 깜빡이거나 흑백으로 되돌아가지 않음
- 인형의 얼굴과 의상에 과도한 샤픈, 플라스틱 질감과 가짜 세부 무늬가 생기지 않음
- 노이즈 제거와 업스케일 과정에서 인형 윤곽과 동작이 뭉개지지 않음
- 실제 근거 색과 설계 색의 구분이 재구성 기록에 남음

## 4.5 음향

- 대사와 추임새가 원본보다 알아듣기 쉽고 장면별 음량이 크게 튀지 않음
- 목소리에 금속성 울림이나 물결치는 왜곡이 생기지 않음
- 악기 소리와 공연장 잔향이 지나치게 사라지지 않음
- 생성 모델의 임의 음성, 효과음이나 음악이 최종 음향에 섞이지 않음
- 생성 화면의 동작 시점이 복원한 원본 음향과 어긋나지 않음

- **영상 무음 마스터**: 생성 화면의 품질과 장면 연결을 확인할 수 있는 무음 영상임
- **음향 복원 마스터**: 원본 시간축을 유지한 별도 고품질 음향 파일임
- **구간표**: 원본 타임코드, 장면 내용, 사용한 기준 프레임, 생성 상태와 승인 상태를 기록함
- **기준 이미지 묶음**: 승인한 16:9 무대, 배역별 인형과 색상표 이미지임
- **생성 기록**: 모델, 프롬프트, 참조 이미지, 설정, 생성본 선택 이유, 실패와 재작업 이력을 기록함
- **검토본**: 원본과 생성 결과를 나란히 보거나 타임코드로 대조할 수 있는 내부 검토 영상임
- **원본 보존**: `assets/영상/박첨지거리.mp4`와 제공된 참고 자산은 수정하거나 덮어쓰지 않음

# 6. 작업 계획

## 6.1 원본 분석과 생성 구간표 작성

- **작업**: 전체 영상을 장면과 동작 단위로 나누고 각 구간의 시작 및 종료 타임코드, 등장 배역, 인형 동작, 카메라 구도와 음향 사건을 기록함
- **구분**: 원래 무대 장면과 연희자 실사 장면을 표시하되 두 종류 모두 생성 대상으로 지정함
- **산출물**: 생성 구간 길이, 기준 프레임과 대체 동작이 포함된 구간표를 만듦
- **통과 조건**: 전체 영상의 모든 시각 구간이 하나 이상의 생성 구간에 대응하고 빈 시간이 없음

## 6.2 기준 이미지와 생성 규칙 확정

- **작업**: 원본 프레임과 인형 사진을 대조해 배역별 기준 이미지를 만들고, 16:9 무대 기준 이미지와 전체 색상표를 설계함
- **검토**: 실물 근거, 흑백 형태 근거와 설계 색을 구분하고 서로 다른 배역의 자료가 섞이지 않았는지 확인함
- **산출물**: 무대 및 배역 기준 이미지, 색상표, 공통 프롬프트, 장면 프롬프트와 금지 프롬프트를 만듦
- **통과 조건**: 구간표에 기록된 모든 배역과 무대의 정지 기준 이미지가 사용자 승인 상태임

## 6.3 생성 모델과 입력 방식 시험

- **우선 경로**: Seedance 2.5가 기준 이미지와 원본 동작 참고 클립의 결합 입력을 지원하는지 먼저 확인하고, 지원할 경우 해당 방식을 시험함
- **비교 시험**: 플랫폼에서 실제 지원이 확인된 입력 방식만 같은 구간에 적용함. 시작 프레임, 시작 및 종료 프레임과 이미지 및 동작 영상의 결합은 지원 여부를 확인할 후보로 관리함
- **확인 항목**: 생성 길이, 출력 해상도, 참조 이미지 반영 정도, 인형 외형 유지, 동작 추종, 음향 생성 여부와 비용을 기록함
- **대체 경로**: 우선 모델이 기준을 충족하지 못하면 같은 기준 이미지와 구간표를 사용할 수 있는 다른 영상 생성 모델을 시험함
- **통과 조건**: 선택한 생성 경로, 한 구간의 표준 길이와 입력 묶음이 시험 기록에 확정되어 있음

## 6.4 대표 구간 시제품 제작

- **선정 기준**
	- 원래 인형 무대 장면을 고화질 컬러로 다시 만드는 구간을 포함함
	- 연희자 실사 화면을 인형 무대 장면으로 바꾸는 구간을 포함함
	- 인형의 빠른 동작, 대사 반응과 장면 전환을 포함함
- **작업**: 선택 구간 전체를 16:9 컬러 영상으로 생성하고 원본 복원 음향을 결합함
- **산출물**: 원래 무대 장면과 연희자 대체 장면이 연속해서 들어간 15~30초 시제품을 만듦
- **통과 조건**: 시제품이 화면 구성, 인형 및 무대 일관성, 움직임, 색과 음향 검수 기준을 충족함

## 6.5 전체 구간 생성

- **작업**: 승인된 기준 이미지, 프롬프트와 표준 입력 묶음을 사용해 구간표 순서대로 전체 영상을 생성함
- **원래 무대 구간**: 원본 동작과 구도를 따라 16:9 고화질 컬러 장면으로 다시 생성함
- **연희자 실사 구간**: 극 흐름과 음향을 유지하면서 인형의 반응, 대화와 무대 동작을 새로 설계해 생성함
- **후보 관리**: 구간마다 여러 후보를 만들고 검수 기준에 따라 승인, 보류와 재생성을 기록함
- **통과 조건**: 전체 타임코드에 승인 후보가 배치되고 원본 화면이 최종 시각 트랙에 남지 않음

## 6.6 연속성 보정과 실패 구간 재생성

- **작업**: 인접 구간의 마지막 및 첫 프레임을 비교해 인형, 무대, 색, 조명과 카메라 구도를 맞춤
- **재생성 조건**: 외형 변화, 화면 가장자리 붕괴, 추가 인형, 사람 신체, 역방향 동작, 순간 이동과 색 깜빡임이 보이면 해당 구간을 더 짧게 나누거나 기준 프레임을 보강해 다시 생성함
- **금지**: 실패한 16:9 구간을 654×480 원본 화면이나 단순 업스케일 화면으로 대체하지 않음
- **통과 조건**: 모든 연결 지점을 정지 화면과 정상 재생 속도로 전수 확인했으며, 위 재생성 조건에 해당하는 발견이 없음

## 6.7 음향 복원

- **작업**: 원본 음향의 지속 잡음, 저역 울림, 순간 잡음과 장면별 음량 차이를 정리함
- **우선순위**: 대사와 추임새의 명료도를 높이되 악기 소리와 공연장 잔향을 보존함
- **산출물**: 원본 길이와 시간축을 유지한 음향 복원 마스터를 만듦
- **통과 조건**: 원본과 비교했을 때 대사가 명료해지고 목소리 및 악기의 인공적인 왜곡이 증가하지 않음

## 6.8 후반 조립과 1080p 마스터링

- **작업**: 생성 구간을 원본 시간축에 배치하고 장면 전환, 색, 밝기와 프레임 속도를 맞춘 뒤 복원 음향을 결합함
- **화질 처리**: 생성 모델의 출력이 1920×1080보다 작으면 승인한 생성본에 한해 업스케일과 약한 선명도 보정을 적용함
- **안정화**: 생성 결과에 불필요한 카메라 흔들림이 생긴 구간만 약하게 보정하며 인형 동작은 안정화하지 않음
- **산출물**: 1920×1080, 16:9 영상 무음 마스터와 AI 생성 재구성 마스터를 만듦
- **통과 조건**: 두 영상이 1920×1080, 16:9, 29.97p이며 AI 생성 재구성 마스터의 음향이 48kHz이고 원본 음향과 같은 길이 및 시간축을 유지함

## 6.9 최종 검수와 기록 정리

- **작업**: 전체 영상을 정상 속도와 구간별 프레임 단위로 확인하고 검수 발견을 구간표에 기록함
- **재작업**: 검수 기준을 벗어난 구간은 후보 교체, 재생성 또는 후반 보정 후 다시 확인함
- **표시**: 최종본과 재구성 기록에 전체 화면이 생성형 인공지능으로 재구성됐음을 명시함
- **완료 조건**: 654×480 원본 화면과 연희자 실사 화면이 남지 않고, 전체가 일관된 16:9 컬러 인형극 영상으로 이어지며, 복원 음향과 주요 동작의 시점이 맞음
