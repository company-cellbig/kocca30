- **분석 범위**: 로컬 원본의 시작부터 끝까지임
- **분절 기준**: 장면 전환, 주요 동작 변화, 음향의 쉼과 연희자 화면 전환을 함께 참고해 분절함

# 3. 생성 묶음 대응 규칙

분석 마커를 실제 생성 묶음과 연결할 때 다음 규칙을 적용함.

- 실제 생성 묶음에는 별도 ID를 부여함
- 생성 묶음 하나가 포함하는 분석 마커 ID를 모두 기록함
- 한 마커를 나누면 각 생성 묶음에 원본에서의 시작 및 종료 시각과 프레임 번호를 적음
- 여러 마커를 합치면 합친 이유와 하나의 프롬프트로 처리할 수 있는 동작 범위를 적음
- 분석 마커 설명이 원본과 다르면 기존 행을 바로 덮어쓰지 않고 수정 이력과 근거를 남김
