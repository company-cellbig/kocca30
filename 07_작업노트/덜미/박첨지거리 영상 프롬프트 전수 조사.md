> 공통 프롬프트와 개별 프롬프트 22개, 이전 실행본 4개를 조사한 수정 전 기록임. 실행 지시 변경 1건, 손 형태 단정 1건, 이미지와 영상의 구도 기준 충돌 가능성 1건, 입력 설명의 오래된 정보 2건을 발견함. 후속 사용자 요청에 따라 작업 노트의 지시와 입력 안내를 정정했으며, 현재 지시는 [[박첨지거리 AI 복원 작업 노트]]를 따름. 실제 컬러 이미지의 구도 정정은 별도 작업으로 남음.

# 1. 조사 범위와 방법

[[박첨지거리 AI 복원 작업 노트]]의 입력 안내, 공통 코드 블록 1개와 영상별 코드 블록 22개를 끝까지 읽음. 빈 줄로 구분한 원문 단락 74개에 ID와 원문 행 위치를 부여한 최초 추출표를 먼저 저장하고, 이후 대조 결과와 보고서의 대응 위치를 별도로 기록함. 원문 단위의 합치기와 나누기와 제외는 없음.

| 대상 | 조사 범위 | 보존 근거 |
|---|---|---|
| 원문 지시 | 공통 6단락과 개별 지시 68단락, 총 74단락 | `최초 추출표.json` |
| 원본 영상 | 현재 `원본영상/`의 1~22번, 총 346초 | `원본 대조 자료.json` |
| 기준 이미지 | 원본 23개와 현재 `컬러복원 v2/`의 23개 | 영상별 비교 이미지와 중앙 영역 비교 3장 |
| 보조 레퍼런스 | `레퍼런스_전체.png`, `레퍼런스_산받이.png` | `실행 프롬프트와 입력 점검.json`의 경로와 해시 |
| 실제 실행 지시 | 최초 테스트 1번과 2번과 24fps 참조 재생성 1번과 2번, 파일 4개 | 실행 TXT와 각 실행 기록 JSON |

영상 22개의 8,304프레임을 모두 디코딩하여 파일 읽기를 확인함. 육안 대조는 첫 프레임과 마지막 프레임과 1초 간격 대표 프레임 368개를 기본으로 하고, 1, 2, 4, 11, 19, 22번의 의심 동작과 전환에 상세 프레임 150개를 추가함. 겹치는 프레임을 제외한 육안 대조 대상은 499개임. 2번 상세 자료는 인형이 있는 위쪽 영역을 원래 해상도로 보여 줌.

프롬프트는 전수 조사했으나, 영상의 모든 프레임을 육안 검수한 것은 아님. 원본에 흐릿하게 보이는 손과 천과 짧은 동작의 의미는 이 대조만으로 확정하지 않음. 생성 모델 내부의 원인 분석이나 조건별 재생성 실험도 수행하지 않음.

근거 파일은 모두 `assets/영상/덜미/프롬프트 전수 조사/`에 보존함. 원본 영상과 이미지, 작업 노트 및 이전 실행 기록의 해시를 기록하여 조사 중 변경 여부를 대조할 수 있게 함.

# 2. 발견과 수정 제안

## 2.1 F1. 실제 실행 프롬프트를 영문으로 재작성하고 시간을 추가함

최초 테스트와 24fps 참조 재생성의 실행 TXT 4개를 각 실행 기록의 `params.prompt`와 대조함. 각 파일은 기록된 제출 지시와 같으며, 두 실행에서 같은 번호의 영문 본문도 같음. 서로 다른 실행 본문은 1번과 2번의 2개임. 작업 노트의 한국어 공통과 개별 프롬프트를 그대로 제출한 실행은 이 4개 안에 없음.

| 대상 | 작업 노트의 지시 | 실제 제출본의 차이 |
|---|---|---|
| 1번 동작 시간 | 참조 영상의 순서와 박자에 맞춤 | 빈 무대 `0–0.5초`, 머리 움직임 `0.5–8.5초`를 추가함 |
| 1번 확대 | 끝부분에서 참조 영상처럼 확대함 | `From about 8.5 seconds`로 확대 시작 시각을 추가함 |
| 2번 동작 시간 | 확대 → 물체 움직임 → 인형 등장과 겹침 → 오른쪽 이동 | `0–3.5`, `3.5–8.8`, `8.8–10.1`, `10.1–11초`로 구간을 지정함 |
| 전체 길이 | 대응표에서 1번 10초, 2번 11초로 안내함 | 본문에 `exactly 10 seconds`, `exactly 11 seconds`를 추가함. 길이 자체는 원본과 같음 |
| 중앙 구도 | 시작과 종료 컬러 이미지를 구도 기준으로 삼고 중간 카메라는 원본을 따름 | 원본 중앙 시야를 유지하면서 좌우를 확장한다는 지시를 추가함 |
| 불명확한 형태 | 2번 직사각형 물체에 보이지 않는 몸과 팔다리를 붙이지 않음 | 불명확한 모든 형태에 손바닥, 손가락, 관절, 몸통 등을 만들지 말라는 공통 제한으로 확대함 |
| 2번 뺨 옆 형태 | 손을 뺨 가까이에 둔다고 지시함 | 손을 새로 만들거나 뺨을 만지는 동작을 만들지 말라는 지시로 바꿈. 앞선 이미지의 손 정정은 사용자 요청에 따른 작업이었음 |
| 목각 얼굴 | 얼굴을 사람 피부처럼 움직이지 않음. 입을 임의로 대사에 맞춰 움직이지 않음 | 새 표정, 입 움직임과 독립적인 눈 움직임을 모두 금지하는 지시를 추가함 |
| 공통 지시 일부 | 추가 이미지의 역할 구분, 실사 사람의 피부, 손, 관절 유지, 글자 모양과 간격 및 실제 컷 유지 등을 명시함 | 해당 문장을 생략하거나 더 짧게 재서술함. 1번과 2번에는 실사 사람 장면과 추가 레퍼런스 입력이 없었음 |
| 종료 화면 | 이미 종료 이미지의 위치, 크기, 자세, 배경에 맞추고 정지 시간을 덧붙이지 말라고 지시함 | 같은 조건을 영문으로 재서술함. 종료 이미지에 맞추라는 조건 자체는 새로 추가한 것이 아님 |

작업 노트의 공통과 개별 코드 블록에는 동작을 절대 초 단위로 나누는 지시가 없음. 따라서 8.5초 등은 원문에 있던 지시를 번역한 것이 아니라 작성자가 추가한 실행 지시임. 영문이 더 잘 작동한다는 비교 실험 근거도 없음.

현재 1번 원본의 8.25~9.92초 상세 자료에서는 8.5초 전후의 무대 구도가 거의 유지되고 끝부분에 확대가 나타남. 8.5초부터 확대하라는 별도 시간 지시를 추가한 근거가 부족함. 이전 생성본의 겹침과 위치 전환은 이미 실행 기록에 관찰되어 있으나, 이 지시가 그 현상을 일으켰다고 확정하지 않음.

**수정 제안**: 다음 제출은 작업 노트의 한국어 공통과 개별 코드 블록을 그대로 이어 붙이고, 제출 직전 문자열 동일 여부를 확인함. 발견 F2와 F3에 대한 사용자 판정 없이 원문을 임의로 고쳐 제출하지 않음.

## 2.2 F2. 2번의 뺨 옆 형태를 손으로 단정함

작업 노트 3.2절의 마지막 단락에는 콧수염 인형이 오른쪽으로 이동해 손을 뺨 가까이에 둔다는 지시가 남아 있음. 현재 컬러 03번 이미지에서는 앞서 문제 된 별도의 손을 제거한 상태임. 이미지의 정정과 문서 지시가 함께 갱신되지 않음.

원본 2번의 9~10.96초 상세 프레임에는 얼굴 옆과 어깨 쪽에 밝은 형태가 보이지만, 손바닥, 개별 손가락, 손목 구조와 특정한 뺨 접촉 동작을 분명하게 식별하기 어려움. 원본에 손이 전혀 없다고 단정하는 것도 이 자료가 뒷받침하지 않음. 현재 지시는 흐릿한 형태에 구체적인 신체와 동작을 부여함.

**수정 제안**: 해당 손 지시의 삭제 또는 보이는 밝은 형태와 움직임만 따르는 표현으로 변경할지를 사용자가 결정함. 손을 없애라는 지시도 원본에 보이는 윤곽을 지워도 된다는 뜻으로 확대하지 않음.

근거: `02번_상세_프레임.jpg`, 원본과 컬러 03번 이미지 및 `clip02-P03`임. 다른 영상의 팔과 천 지시도 함께 점검함. 4번에는 양쪽의 짧은 밝은 돌출부가 실제로 움직이며, 7번과 8번은 소매 또는 의상 천으로 불확실성을 남겨 표현하고 있어 같은 이유로 오류라고 판정하지 않음.

## 2.3 F3. 원본 움직임과 컬러 이미지 구도가 달라 기준이 충돌할 수 있음

공통 지시는 시작과 종료 컬러 이미지를 구도 기준으로 삼고, 두 이미지 사이의 동작과 카메라는 원본 영상을 따르도록 함. 마지막에는 컬러 종료 이미지의 위치, 크기, 자세, 배경에 맞추게 함. 입력 이미지가 원본의 구도를 바꾸었다면 두 기준을 그대로 동시에 만족시키기 어려울 수 있음.

원본 23장과 컬러 v2 23장을 전체 화면과 중앙 영역으로 대조함. 중앙 영역 비교는 컬러 이미지의 높이를 유지한 채 원본의 종횡비에 해당하는 중앙 폭을 잘라 동일한 크기로 보여 주는 분석 방법임. 모델이 실제로 이 방법으로 두 입력을 대응시킨다는 뜻은 아님.

| 예시 이미지 | 중앙 영역 대조에서 보이는 차이 | 관련 영상 |
|---|---|---|
| 02번 | 천 윗선의 높이, 두 머리의 위치와 글자 간격이 원본과 다름 | 1번 종료, 2번 시작 |
| 16번 | 얼굴 윤곽과 눈과 수염의 상대 위치 및 고개 방향이 원본과 다름 | 15번 종료, 16번 시작 |
| 23번 | ‘남 사 당’의 위치와 간격과 천 주름이 원본과 다름 | 22번 종료 |

이 차이는 좌우 확장 외에도 원본 중앙 영역의 형상과 배치가 다시 그려졌음을 보여 줌. 다만 어느 차이가 기존 생성본의 특정 프레임 튐을 일으켰는지는 확인하지 않음.

**수정 제안**: 원본 중앙의 인형 위치, 크기, 가려짐과 카메라 구도를 보존하는 이미지로 입력을 다시 맞출지, 현재 컬러 구도를 허용할지 먼저 결정함. 전자를 택하면 원본에 맞춰 이미지를 정정한 뒤 사용함. 충돌하는 이미지를 유지한 채 시간 지시만 추가해 해결됐다고 판단하지 않음.

## 2.4 F4. 현재 원본은 24fps인데 입력 설명은 30fps로 남음

작업 노트 1.2절 아래에는 원본이 654×480px, 30fps이며 음향 트랙이 있다고 적혀 있음. 현재 참조 영상 22개는 모두 654×480px, 24fps이고 음향 트랙이 있음. 재생 시간 22개는 대응표의 값과 같음.

30fps 문장은 입력 안내에 있으며 공통과 개별 생성 코드 블록에는 없음. 따라서 이 문장을 읽었다는 사실만으로 실제 생성 요청에 30fps 설정이 전달되었다고 판단하지 않음. 이 오래된 설명만으로 현재 입력이 30fps였다고 판단하거나, 현재 재생성본의 튐을 30→24fps 차이로 설명할 수 없음.

**수정 제안**: 현재 파일의 메타데이터에 맞춰 24fps로 갱신하고, fps와 재생 시간은 실제 제출 파일을 읽은 값으로 기록함.

## 2.5 F5. 컬러 입력 경로가 현재 파일 위치와 다름

작업 노트 1.1절의 컬러 입력 위치는 `assets/영상/덜미/박첨지거리_01.png`부터 23번까지임. 조사 시점에는 이 경로의 23개가 모두 없고, `assets/영상/덜미/컬러복원 v2/`에는 같은 번호 23개가 모두 있음. 공간과 실사 레퍼런스의 안내 경로는 실제 파일과 일치함.

영상별 시작과 종료 파일명의 번호 연결은 22개 모두 맞음. 문제는 같은 파일명의 컬러본을 어디에서 가져오는지에 대한 폴더 안내임. 원본 기준 이미지와 컬러본을 구분하는 지시 자체는 맞음.

**수정 제안**: 컬러 입력 폴더를 현재 v2 위치로 갱신함. 백업과 수정 전 이미지를 같은 파일명만 보고 선택하지 않도록 제출 기록에 실제 경로와 해시를 남김.

# 3. 공통 프롬프트 단락 대조

| 원문 ID | 지시 내용 | 대조 결과 |
|---|---|---|
| common-P01 | 시작과 종료 입력 순서와 추가 이미지 역할 | 영상과 이미지 번호 연결은 맞음. 실제 실행본의 역할 설명은 축약됨(F1) |
| common-P02 | 이미지의 외형, 색, 구도와 영상의 동작과 카메라 | 구도가 다른 입력 사이의 기준 충돌 가능성 있음(F3) |
| common-P03 | 16:9 컬러, 결함 제거, 공간 연결 | 작업용 설계 지시임. 원본의 실제 색을 증명하는 문장으로 쓰지 않음. 무대와 마당 이동 11, 12, 19, 21, 22번을 대조함 |
| common-P04 | 목각과 천의 움직임, 가려짐, 실사 사람 | 큰 동작 순서는 개별 지시와 대체로 맞음. 2번의 손 단정은 개별 단락에 남음(F2) |
| common-P05 | 글자 모양과 간격과 카메라에 따른 변화 | 원본과 컬러 이미지의 글자 배치가 다를 때 기준 충돌 가능성 있음(F3) |
| common-P06 | 실제 컷 유지, 종료 이미지 일치, 정지 시간과 새 음향 금지 | 22번 원본의 실제 컷과 양립함. 종료 구도 일치는 F3, 영문 실행본과의 차이는 F1에 해당함 |

원본의 결함을 제거하고 컬러로 재구성하는 요구와, 원본에 실제로 있는 빠른 이동, 가려짐, 컷을 지우는 요구는 구분해야 함. 22번의 실제 컷은 새로 만들어 낸 전환에 해당하지 않음.

# 4. 영상별 프롬프트 22개 대조

아래 판정은 개별 한국어 지시의 큰 등장과 퇴장 순서와 카메라 흐름에 대한 것임. ‘유지 후보’는 이번 대표와 상세 프레임 범위에서 큰 흐름의 모순을 발견하지 못했다는 뜻이며, 모든 미세 동작이나 생성 성공을 확인했다는 뜻이 아님. 모든 영상은 공통 F3 및 입력 안내 F4와 F5의 영향을 따로 검토해야 함.

| 19 | 19→20 | 초반 축소와 오른쪽 이동, 관악기 상승과 연주 자세, 끝부분 무대 복귀 | 큰 흐름 유지 후보. ‘잠시 내렸다 다시 올림’의 동작 폭은 추가 확인 필요 |

19번의 4~6.5초 상세 자료와 원래 크기의 추가 프레임에서는 악기를 올리는 과정과 손과 머리의 작은 높이 변화가 보임. 이를 크게 내렸다 다시 올리는 별도 동작으로 해석할지는 이번 자료만으로 확정하지 않음. 기존 문장을 검증된 상세 동작으로 단정하거나 새로운 초 단위 구간을 만들지 않음.

컬러 12번과 22번, 원본에는 뒤쪽에 일부 가려진 세 번째 사람이 있음. 12, 19, 21번 지시의 뒤쪽 사람 유지 요구는 원본에 근거함. 보조 레퍼런스에서 잘 보이지 않는다는 이유로 이 사람을 지우지 않음. 19번과 22번의 관악기 동작도 보조 레퍼런스의 북 장면만으로 대신하지 않음.
