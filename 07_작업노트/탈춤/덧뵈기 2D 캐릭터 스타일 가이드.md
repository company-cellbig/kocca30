> 덧뵈기 캐릭터를 새로 만들 때 실제 탈과 복식은 보존하고, 정돈된 셀 애니메이션 표현과 비대칭 희극 실루엣을 결합하는 공통 제작 기준임. 원형 자료, 캐릭터별 차이, 마스터 이미지 규격, 생성 프롬프트와 검수 절차를 한곳에서 관리함.

# 1. 적용 범위와 승인 방향

이 가이드는 꺽쇠, 말뚝이, 취발이, 옴탈, 샌님, 먹중과 진행 호스트 장쇠의 기본 전신 이미지와 상태별 파생 이미지에 적용함. 동작의 시간, 방향과 반복 횟수는 이 문서가 아니라 배역별 애니메이션 프롬프트가 정함.

- **[사용자 승인] 공통 방향**: A안의 정돈된 선과 셀 채색에 C안의 비틀린 자세와 과장된 실루엣을 결합함
- **A안에서 채택함**
	- 굵기가 변하는 깨끗한 외곽선
	- 형태를 흐리지 않는 제한된 단계의 셀 명암
	- 탈, 짚, 천을 구분하는 재질 표현
	- 후속 동작 이미지에서도 되풀이하기 쉬운 단순하고 안정된 형태
- **C안에서 채택함**
	- 정면 대칭을 피한 무게중심
	- 머리 장식, 소매, 옷자락과 신발이 만드는 배역 고유의 덩어리
	- 탈의 표정을 바꾸지 않고 몸의 기울기와 관절 각도로 만드는 웃음
	- 상대 공간을 침범하거나 버티는 성격이 한눈에 드러나는 자세
- **그대로 복제하지 않음**: C안의 옴탈 자세를 모든 배역에 반복하지 않음. 같은 조형 원칙을 각 배역의 성격과 소품에 맞게 다르게 적용함

승인에 사용한 비교 이미지는 다음 두 파일임.

| 역할 | 파일 | 사용 범위 |
|---|---|---|
| 선, 셀 채색 기준 | `assets/이미지 생성 테스트/2026-08-28_옴탈_2D스타일_A_셀애니메이션.png` | 선 굵기, 명암 단계, 재질 구분과 제작 안정성을 참고함 |
| 실루엣, 자세 기준 | `assets/이미지 생성 테스트/2026-08-28_옴탈_2D스타일_C_희극캐리커처.png` | 비대칭 무게중심, 몸의 비틀림과 희극적 거리감을 참고함 |

두 비교 이미지는 스타일 시안이며 캐릭터 정본이 아님. 체크보드가 실제 픽셀로 들어간 RGB 이미지이므로 투명 배경 에셋이나 영상 입력으로 직접 사용하지 않음.

# 2. 원형 자료와 적용 우선순위

생성 결과가 서로 충돌하면 다음 순서로 판단함.

1. `prototype/assets/`의 해당 배역 이미지에서 탈, 복식, 소품과 대표 색을 확인함
2. 이 가이드의 공통 조형과 배역별 실루엣을 적용함
3. 사용자가 승인한 배역별 마스터 이미지가 생기면 얼굴과 의상 일관성은 그 마스터를 따름
4. `assets/이미지 생성 테스트/`의 과거 시험 이미지는 명시적으로 채택한 A안과 C안 외에는 정본으로 사용하지 않음

원형 이미지는 다음과 같이 역할을 나눔.

| 캐릭터 | 사실 참조 이미지 | 게임 역할 |
|---|---|---|
| 꺽쇠 | `prototype/assets/배역_꺽쇠.png` | 옴탈잡이 유저배역 |
| 말뚝이 | `prototype/assets/배역_말뚝이.png` | 샌님잡이 유저배역 |
| 취발이 | `prototype/assets/배역_취발이.png` | 먹중잡이 유저배역 |
| 옴탈 | `prototype/assets/상대_옴탈_대기.png` | 옴탈잡이 상대배역 |
| 샌님 | `prototype/assets/상대_샌님_대기.png` | 샌님잡이 상대배역 |
| 먹중 | `prototype/assets/상대_먹중_대기.png` | 먹중잡이 상대배역 |
| 장쇠 | `prototype/assets/호스트_장쇠_기본.png` | 진행 호스트 |

사실 참조 이미지는 촬영 상태와 자세를 복제하기 위한 자료가 아님. 탈의 형태와 색, 복식의 층과 색, 소품의 종류와 착용 관계를 확인하는 자료로 사용함. 원형에 없는 장식, 무기, 문양과 복식은 추가하지 않음.

# 3. 공통 조형 기준

## 3.1 탈과 얼굴

- 탈의 비대칭 윤곽, 눈구멍, 코, 입, 수염, 채색과 표면 무늬를 사실 참조 이미지에 맞춤
- 탈은 표정이 변하지 않는 단단한 물체로 표현함. 살아 있는 눈동자, 눈썹 움직임, 입 모양 변화와 사람 피부 표정을 넣지 않음
- 감정은 고개 각도, 어깨 높이, 척추의 기울기, 팔과 손, 무릎과 발의 방향으로 전달함
- 옴탈의 외형은 환자의 신체나 질병 증상처럼 사실적으로 바꾸지 않음. 탈의 돌기는 원형 탈의 조형으로만 다룸 ([[덧뵈기 탈놀음 한바탕 재설계 방향#4.6 연출 원칙]])

## 3.2 선과 형태

- 외곽선은 한 굵기의 벡터선 대신 시작과 끝이 가늘어지는 붓선을 사용함
- 얼굴과 손의 세부선은 외곽선보다 가늘게 두어 멀리서도 큰 형태가 먼저 보이게 함
- 검은 실루엣으로 바꿔도 머리 장식, 몸통, 소매, 소품과 발의 조합으로 배역을 구분할 수 있어야 함
- 인체를 사실 비례로 복사하지 않음. 탈, 손, 발과 대표 소품은 알아보기 쉬울 만큼 키우고 몸통은 배역 성격에 맞게 압축하거나 늘림
- 손가락과 발은 후속 동작 생성에서 형태가 무너지지 않도록 겹침을 줄이고 윤곽을 분명히 함

## 3.3 색과 명암

- 대표 색은 사실 참조 이미지에서 가져오며, 배역을 바꾸기 위한 임의의 색 교체를 하지 않음
- 명암은 기본색, 그림자와 필요한 소량의 밝은 면으로 제한함. 부드러운 입체 그라데이션보다 명확한 셀 경계를 우선함
- 검은 옷 안에서도 몸통, 겉소매와 안쪽 옷자락이 붙어 보이지 않게 명도와 질감을 조금씩 구분함
- 탈과 허리띠처럼 배역을 알아보게 하는 색은 화면이 작아져도 탁해지지 않게 유지함

## 3.4 재질

- 나무탈은 붓자국과 조각 면, 삿갓과 짚신은 엮인 결, 옷은 무광 천의 접힘으로 구분함
- 한지 섬유, 분채와 마른 붓 질감은 색면 안쪽에 약하게 사용함. 외곽을 흐리거나 낡은 종이 효과가 캐릭터보다 먼저 보이면 줄임
- 광택이 강한 플라스틱, 3D 렌더와 매끈한 기업용 벡터 질감을 사용하지 않음

## 3.5 자세와 희극성

- 기본 자세도 완전한 정면 대칭으로 세우지 않음. 어깨, 골반, 무릎과 발 가운데 둘 이상에 서로 다른 방향을 줌
- 재미는 얼굴 변형보다 기대, 버티기, 들이밀기, 뽐내기, 움츠리기처럼 배역의 행동 성격에서 만듦
- 과장은 한 장면의 주된 방향 하나에 모음. 머리, 손, 발과 소매를 모두 같은 세기로 키우지 않음
- 큰 화면에서 자세가 바로 읽히도록 손과 소품을 몸통 뒤에 숨기지 않음

# 4. 배역별 실루엣

| 배역 | 주된 덩어리 | 기본 자세와 희극 방향 | 반드시 보존할 인식 요소 |
|---|---|---|---|
| 꺽쇠 | 짧고 탄력 있는 몸, 머리 장식과 허리의 색 띠 | 몸을 조금 앞으로 기울이고 언제든 튀어나갈 수 있게 손발을 열어 둠 | 흰 바탕 복식, 머리 장식, 허리에서 늘어지는 여러 색 천 |
| 말뚝이 | 넓은 하체, 긴 팔과 막대가 만드는 가로선 | 다리를 벌리고 상체를 비껴 세워 상대를 건드리거나 시험하는 태도를 보임 | 어두운 윗옷, 흰 바지, 머리 장식과 긴 막대 |
| 취발이 | 큰 소매, 긴 옷자락과 팔다리의 대각선 | 한쪽 팔이나 무릎을 높여 흥이 몸 밖으로 뻗는 자세를 만듦 | 붉은 탈, 푸른 계열 옷과 붉은 계열 띠 |
| 옴탈 | 넓은 삿갓과 검은 장삼이 만드는 큰 어두운 덩어리 | 머리와 어깨가 먼저 상대 공간에 들어가고 골반과 발이 뒤늦게 따라오는 엇박 자세를 만듦 | 붉은 탈, 넓은 삿갓, 검은 장삼, 붉은 허리띠와 흰 바지 |
| 샌님 | 세로로 길고 좁은 몸, 부채와 지팡이 | 턱과 가슴을 들고 관절을 굳혀 권위를 세우며, 무너질 때 수직선이 꺾이게 함 | 흰 복식, 검은 머리와 목 부분, 부채와 지팡이 |
| 먹중 | 머리 장식과 겉옷이 만드는 위쪽으로 무거운 형태 | 처음에는 중심을 세우고, 폭로가 쌓이면 어깨와 무릎이 단계적으로 무너지게 함 | 머리 장식, 붉고 회색인 겉옷, 막대 형태 소품 |
| 장쇠 | 장구를 중심으로 한 안정된 삼각형 | 몸을 열고 한 손으로 화면의 다음 행동을 안내하되 유저배역보다 앞서 행동하지 않음 | 흰 복식, 붉은 탈과 검은 수염 부분, 장구 |

배역별 표는 생성 방향을 구분하기 위한 설계 기준임. 탈과 복식의 세부 형태가 글의 요약과 다르면 사실 참조 이미지가 우선함.

# 5. 마스터 이미지 규격

## 5.1 기본 마스터

- **파일 형식**: 실제 알파 채널이 있는 PNG
- **화면비와 크기**: 세로 3:4, 1080 × 1440을 기본으로 함 ([[꺽쇠 애니메이션 프롬프트#1. 입력 이미지]])
- **구도**: 머리 장식과 신발을 포함한 전신, 사방에 동작 여백을 둔 단독 캐릭터
- **시점**: 정면에 가까운 3/4 시점. 몸의 앞뒤 관계는 보이되 강한 원근과 카메라 쪽 돌출은 피함
- **기본 자세**: 배역별 실루엣을 드러내는 비대칭 대기 자세. 손과 대표 소품이 몸통에 가려지지 않게 함
- **그림자**: 캐릭터에 붙은 셀 명암만 사용하고 바닥 그림자, 후광과 배경 효과를 넣지 않음

## 5.2 파생 파일

- 투명 PNG를 마스터로 보관함
- 영상 모델이 투명 입력을 받지 못할 때만 크로마 그린 `#00B140` 파생본을 만듦 ([[꺽쇠 애니메이션 프롬프트#1. 입력 이미지]])
- 16:9 장면은 캐릭터를 다시 그리지 않고 마스터를 장면 안에 배치하는 것을 우선함. 둘 이상의 인물이 접촉하는 자세처럼 단독 마스터로 해결되지 않는 장면만 별도 생성함
- 상태별 이미지는 기본, 행동 준비, 행동 절정, 성공 반응과 실패 반응을 같은 마스터에서 파생함. 필요한 상태의 종류와 이름은 기획서와 배역별 애니메이션 문서가 정함

## 5.3 알파 확인

화면에 체크보드가 보인다는 이유만으로 투명하다고 판정하지 않음.

- 파일에 알파 채널이 실제로 있는지 확인함
- 빈 모서리 픽셀의 알파값이 0인지 확인함
- 흰색이나 회색 체크보드가 RGB 픽셀로 들어가 있으면 실패로 판정함
- 삿갓, 수염, 옷자락과 짚신 가장자리에 흰 테두리가 남지 않았는지 어두운 배경과 밝은 배경에서 각각 확인함

# 6. 이미지 생성 프롬프트

참조 이미지를 넣을 때 각 파일의 역할을 프롬프트 안에서 명시함.

```text
Use case: stylized-concept
Asset type: production-ready full-body 2D game character

Input images:
- Image 1: factual reference for the exact mask, costume, props and colors
- Image 2: style reference for clean tapered outlines, restrained cel shading and material separation
- Image 3: style reference for asymmetric theatrical posture and comic silhouette

Primary request:
Redesign the referenced Korean Namsadang Deotboegi performer as a premium hand-drawn 2D cel-animation character. Preserve the exact character identity from Image 1. Combine the clean production finish of Image 2 with the crooked, body-driven comic energy of Image 3. Adapt the posture to this character's own role instead of copying Omtal's pose.

Style and medium:
Confident tapered brush outlines, bold readable shapes, restrained cel shading, subtle hanji fiber and dry-brush texture inside the color areas, polished feature-animation quality.

Pose and composition:
One character only, full body including headwear and footwear, near-front three-quarter idle pose, clear hands and props, asymmetric shoulders and hips, generous margins, portrait 3:4 framing.

Mask rule:
The mask is a rigid carved object with a fixed expression and dark eye openings. Emotion comes only from head angle, shoulders, torso, arms, hands, knees and feet.

Background:
Genuine transparent background with clean alpha edges. No checkerboard pixels, floor, shadow plate or scenery.

Constraints:
No invented costume pieces, ornaments, weapons or patterns. No costume recoloring. No extra character. No text, logo or watermark.

Avoid:
Anime face, living cartoon eyes, moving eyebrows or mouth, chibi mascot, photoreal person, 3D render, glossy corporate vector art, perfect frontal symmetry, mannequin pose, plastic materials.
```

캐릭터별로 `Primary request` 뒤에 [[#4. 배역별 실루엣]]의 기본 자세와 보존 요소를 덧붙임. 옴탈은 질병이나 환자의 신체를 연상시키는 사실적 묘사를 금지하는 문장을 추가함.

# 7. 제작 절차

1. 사실 참조 이미지에서 탈, 복식, 소품, 대표 색과 착용 관계를 글로 먼저 적음
2. 참조 역할을 사실 이미지, A안 스타일과 C안 스타일로 나눠 프롬프트에 명시함
3. 기본 마스터 후보를 만들고 탈과 복식의 보존 여부를 먼저 확인함
4. 실루엣, 자세, 선, 명암과 재질을 확인한 뒤 사용자 승인을 받음
5. 승인한 기본 마스터에서 상태별 이미지와 영상 입력용 크로마 파생본을 만듦
6. 모든 배역을 같은 크기로 놓고 외곽선 굵기, 명암 단계, 재질 강도와 화면 점유율을 한 번에 비교함

첫 마스터를 승인하기 전에 다른 배역의 정본을 연속 생성하지 않음. 배역마다 독립 프롬프트로 처음부터 다시 만들지 않고 승인한 마스터와 이 가이드를 공통 스타일 참조로 사용함.

# 8. 검수 목록

- 사실 참조 이미지의 탈, 복식, 소품과 대표 색이 유지됐는가
- 원형에 없는 장식, 무기, 문양과 옷이 추가되지 않았는가
- 탈의 표정 대신 몸의 자세로 성격과 감정이 드러나는가
- 검은 실루엣으로 보아도 다른 배역과 구분되는가
- A안의 정돈된 선과 명암, C안의 비대칭 희극성이 함께 보이는가
- 나무, 짚과 천의 재질이 구분되면서 질감이 외곽을 흐리지 않는가
- 손, 발과 소품의 형태가 분명하고 불필요하게 겹치지 않는가
- 머리 장식과 신발이 잘리지 않고 동작 여백이 남았는가
- 파일에 실제 알파 채널이 있고 체크보드가 픽셀로 들어가지 않았는가
- 같은 캐릭터의 파생 이미지에서 탈, 옷, 몸 비례와 선 굵기가 유지되는가
