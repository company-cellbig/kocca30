# 3. anchor 참조 기준선

- **집계 방법**
	- 추출 범위: 기준 커밋 스냅샷의 모든 마크다운 파일에서 표의 문서 10개를 가리키는 `[[문서명]]`, `[[문서명#anchor]]`와 별칭형 링크를 정규식으로 추출함
	- 링크 수: 같은 줄의 복수 링크도 각각 셈
	- 고유 대상: 별칭을 제외한 문서명과 anchor 원문 문자열의 고유 조합임. anchor가 없는 문서 자체 링크도 하나의 대상으로 포함함
	- 활성: 이력 보존 대상인 `99_Logs/`와 `_archive/`를 제외한 값임

| 대상 문서 | 전체 링크 | 전체 고유 대상 | 활성 링크 | 활성 고유 대상 |

# 4. 자동 검사 기준선

세 자동 검사는 2026-09-08에 기준 커밋의 문서 상태를 대상으로 실행함.

| 검사 | 결과 | 잔류 항목 |
|---|---|---|
| `node scripts/wiki_number.mjs --write` | 마크다운 68개 스캔, 넘버링 어긋남 0건 | 없음 |
| `node scripts/wiki_lint.mjs` | 마크다운 68개 스캔, 오류 0건 | 경고 28건: 미작성 링크 6건, 참조 순서 위반 22건 |
| `node scripts/quote_check.mjs` | 행 번호 인용 어긋남 0건 | 전사본을 정하지 못해 건너뜀 7건 |

경고 28건은 이번 역할 분리 작업의 변경에서 생긴 오류가 아니며 단계별 비교를 위해 그대로 기록함. 완료 기준은 오류 0건을 유지하고, 변경한 anchor와 파생 텍스트에 새 경고를 만들지 않는 것임.

# 5. 선결 정책 결정

사용자의 계획 실행 지시를 [[CONVENTIONS와 HowTo 역할 분리 계획#8. 선결 정책 판단]]의 권장안 4건을 채택한 것으로 해석함.

| 정책 | 결정 | 소유 관계 |
|---|---|---|
| 변환본 프론트매터 | `02_References/converted/`를 일반 프론트매터 규칙의 명시적 예외로 둠 | 예외 원칙은 `CONVENTIONS.md`, 정확한 스키마는 [[docx 변환 파이프라인]]이 소유함 |
| 변환본 문체 | 원문 영역은 충실 전사를 우선하고 작성자가 덧붙이는 설명은 일반 문체를 따름 | 우선순위는 `CONVENTIONS.md`, 변환 방법은 [[docx 변환 파이프라인]]이 소유함 |
| 수치 근거 | 외부 및 과제 사실, 코드 상수와 내부 시험 집계의 근거 종류를 구별함 | 공통 근거 요건은 `CONVENTIONS.md`, 작업별 재현 방법은 해당 HowTo가 소유함 |
| 파생 규칙 | 규칙 복제본에 파생 관계를 표시하고 원본 anchor가 바뀔 때의 동기화 책임을 명시함 | 원본은 `CONVENTIONS.md` 또는 [[문서 작성 세부 규칙]], 파생본은 해당 검수 문서가 소유함 |
