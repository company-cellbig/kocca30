# 2. 분류 원칙

## 2.1 대분류 기준

- **문서**: 사람이 읽는 글, 표와 발표 내용이 중심인 결과물임. Markdown뿐 아니라 DOCX, PPTM과 PDF 원자료도 실행보다 읽기와 전달이 중심이면 문서로 분류함
- **이미지**: 정지된 한 화면의 시각물이 중심인 결과물임. 캐릭터, 배경, 소품, UI 시안과 인포그래픽을 포함함
- **영상**: 시간축을 따라 재생되는 시각물이 중심인 결과물임. 생성 영상과 분석용 기록영상을 포함함
- **소프트웨어**: 실행, 상호작용과 자동 처리가 중심인 코드 결과물임. HTML 프로토타입, 변환기, 검사기, 훅과 자동화 스크립트를 포함함
- **데이터**: 프로그램이 읽고 쓰는 구조화 값이 중심인 결과물임. 실행 상태 객체와 JSON 전달 패키지를 포함함
- **3D 자산**: 입체 형상이나 공간 데이터가 중심인 결과물임. 렌더링한 정지 화면은 이미지로, 재생 영상은 영상으로 분류해 3D 자산과 구별함
- **음원과 음성**: 소리 재생 자체가 중심인 독립 결과물임. 이번 조사에서는 확인되지 않음

## 2.2 결과물 통합 기준

여러 파일로 이뤄진 결과물은 과제에서 맡는 중심 기능 하나로 대분류함.

## 2.3 인공지능 활용 포함 기준

인공지능이 처음부터 만들지 않았더라도 내용 생성, 구조 설계, 분석, 코딩, 수정, 검수 중 하나에 실질적으로 기여했으면 포함함. 기여 범위는 `인공지능 활용 방식` 항목에서 구별함.

# 6. 보고할 때의 해석

- 결과물 187건은 파일 수가 아니라 같은 결과물의 생성, 수정, 이동 이력을 하나로 합쳐 센 수임
- 폐기 42건과 대체 20건도 시행착오와 의사결정 이력을 보여 주므로 목록에서 제거하지 않음
- 문서 131건에는 기획서뿐 아니라 조사서, 원전 변환본, 검수 기록, 회의록, 지침과 채팅 보고가 포함됨
- 이미지 묶음과 영상 묶음은 같은 생성 목적과 세션으로 만든 여러 파일을 결과물 하나로 셈
- 제외 사건 28건은 개인 설정, 단순한 파일 이동이나 삭제, Git 조작처럼 별도의 콘텐츠 결과물을 만들지 않은 작업임
