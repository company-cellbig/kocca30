# 1. 기록 원칙

- **범위 정본**: [[인공지능 활용 내역 처리 현황]]을 따름
- **근거 약호**
	- `운영`: 에이전트가 작성과 편집을 맡는 저장소 운영 흐름과 로그의 작업 내용으로 확인함
	- `명시`: 로그에 인공지능 도구나 생성 행위가 직접 적힘
- **현재 경로 `대조 전`**: 당시 경로는 로그에서 옮겼으나 현행 경로와 이름 변경 이력은 원시 목록 완성 뒤 Git으로 전역 대조한다는 뜻임
- **관련 사건**: 같은 결과물 키의 앞선 사건만 기록함. 전체 연결 관계는 결과물 통합 단계에서 다시 계산함
