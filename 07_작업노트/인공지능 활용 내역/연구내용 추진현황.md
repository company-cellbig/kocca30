# 1. 연구내용 추진현황

## 1.1 인공지능 기반 프로젝트 위키 구축 및 운영 체계화

### 1.1.1 무형문화유산 남사당놀이 프로젝트 위키 구축

- 인공지능으로 프로젝트 관련 자료 수집하고 정리하여 기획 및 개발에 활용할 위키 구축
- 정보의 중요도 순으로 폴더 위계와 참조 순서를 설계하여 순환 참조와 오류 누적 방지
- 핵심 문서를 MOC(Map of Contents)에 등록 후 참조 시 위키 링크로 연결하여 자료 탐색과 근거 추적 체계 구축

### 1.1.2 위키 운영 체계화

- 위키 작성 규칙과 인공지능 운영 절차를 분리하여 사람과 인공지능의 역할과 적용 범위 명확화
- 작성과 검수를 서로 다른 인공지능 도구에 맡겨서 같은 모델의 오류가 반복되는 위험 방지
- 공유 전 문서 구조를 자동 검사하여 구조상에서의 오류 차단
- 반복 결함을 데이터화하여 작성과 검수 기준으로 재사용

## 1.2 위키 기반 자료 조사, 기획서 및 번역 검수

### 1.2.1 자료 조사 및 정리

- 인공지능으로 남사당놀이 관련 자료와 보유 단체 조사 후 출처, 접근 방법과 활용 조건 정리
- 이미지, PDF, HWPX를 OCR(광학 문자 인식) 후 변환하여 검색 및 인용할 수 있는 자료로 구조화
- 기록 영상의 장면, 배역, 동작을 프레임 단위로 분석하여 기획용 참고 자료로 구조화

### 1.2.2 기획서 검수

- 기획서 작성과 검수에 서로 다른 인공지능 도구를 사용하여 사실성, 정합성, 견고성과 가독성을 독립 검토
- 기획서 작성 후 모순, 불필요하거나 누락된 내용 등 내부 검수 진행
- 내부 검수와 별도로 연구개발 계획서, 참고 자료, 회의록 등 프로젝트 결정 사항과 대조하는 외부 검수 진행

### 1.2.3 번역 검수

- 클라이언트 데이터와 사용자 인터페이스 문구의 한국어 원문과 영어 번역을 화면 기능과 기획 의도에 맞춰 대조
- 남사당놀이에서 쓰이는 고유 명사와 전통 용어의 로마자 표기, 대소문자, 문장 부호, 명령문 형식과 대사 어조의 일관성 점검
- 내용 오류(오역, 미번역, 입력 오류, 중복 표현)와 구조 오류(텍스트 데이터의 키와 해당 내용의 불일치)를 찾고 수정안 제시
- 반복된 번역 문제와 사용자 결정을 공통 규칙으로 정리해 이후 데이터 제작과 검수에 재사용

## 1.3 인공지능을 활용한 2D 자산 제작

### 1.3.1 인공지능 기반 2D 이미지 자산 제작

- 여러 화풍 시험 후 승인된 시안을 바탕으로 시각 스타일 기준을 위키에 정리
- 남사당놀이 배역, 배경, 체험 단계별 장면과 생성형 이야기 삽화 등 2D 이미지 자산 제작
- 사용자 인터페이스용 동작 픽토그램, 유형 아이콘, 소품 이미지 자산 제작
- 이미지 자산 제작 시 위키의 캐릭터와 화풍 기준으로 얼굴, 복식, 소품과 장면의 일관성을 검토하고 재생성하거나 보정하여 최종 결과물 산출

### 1.3.2 인공지능 기반 2D 애니메이션 자산 제작

- 기존 2D 캐릭터 이미지를 바탕으로 동작 속도와 시작 및 종료 자세를 지정하여 여러 동작 영상 생성
- 캐릭터 외형, 복식과 소품 유지 여부, 카메라 고정, 동작 속도, 신체 변형과 프레임별 움직임을 검토하여 문제가 있을 경우 수정하거나 재생성하여 최종 결과물 산출
- 후처리로 생성한 영상의 배경을 제거하고 프레임을 추출하여 투명 배경의 연속 이미지로 가공
- 추출한 프레임을 스프라이트 애니메이션으로 구성하여 캐릭터별 애니메이션 상태에 연결

## 1.4 인공지능을 활용한 3D 자산 제작

### 1.4.1 2D 이미지 기반 3D 모델 및 유니티 프리팹 제작

- 남사당놀이의 탈와 인형 이미지로 형상과 텍스처를 갖춘 3D 모델 생성
- 수작업 모델링 없이 2D 이미지를 개발 엔진에서 불러올 수 있는 표준 3D 파일 형식으로 변환
- 3D 자산을 이용하여 개발 엔진인 유니티에서 재사용 가능한 오브젝트인 프리팹 제작
- 2D 이미지로 개발용 3D 자산을 빠르게 제작하는 공정의 실적용 가능성 확인

## 1.5 인공지능을 활용한 소프트웨어 프로토타입 및 업무 자동화 도구 개발

### 1.5.1 남사당놀이 덜미 나만의 유람기 콘솔 프로토타입 제작

- 이야기 유형과 주인공 설정부터 4개 문답, 서사와 삽화 생성까지 핵심 과정만 인공지능과의 콘솔 대화로 실행
- 기획 단계에서 빠르게 실행하고 검증하기 위해 외부 API 연동 없이 인공지능 대화 환경과 로컬 프로그램의 결합만으로 구동할 수 있는 프로토타입 구현
- 결과물 확인을 위해 생성된 서사를 텍스트 이미지로 변환하고 삽화와 결합해 이미지로 저장

### 1.5.2 남사당놀이 덧뵈기 탈놀음 한바탕 HTML 프로토타입 제작

- 인공지능으로 웹 브라우저에서 실행되는 HTML과 JavaScript 기반 프로토타입 제작
- 옴탈잡이, 샌님잡이, 먹중잡이의 마당별 진행 과정과 사용자 입력에 따른 성공, 실패, 무입력 분기 구현
- 동작 인식이 아닌 진행 과정상의 재미 검증이 우선이었으므로 동작 인식 장비 대신 버튼 입력으로 인식 결과와 재시도 과정 재현

### 1.5.3 구글 스프레드시트 데이터 JSON 변환 도구 제작

- 인공지능으로 C# 코드와 데이터 변환 로직 설계
- 구글 스프레드시트 데이터를 개발에 필요한 내용만 정리하고 가공하여 개발 엔진용 JSON 파일로 변환 후 저장
- 수작업 데이터 가공 및 파일 저장 자동화
