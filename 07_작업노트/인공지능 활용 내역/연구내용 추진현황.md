# 1. 연구내용 추진현황

## 1.1 인공지능 기반 프로젝트 위키 구축 및 운영 체계화

### 1.1.1 무형문화유산 남사당놀이 프로젝트 위키 구축

- 인공지능을 활용해 프로젝트 관련 자료를 분류하고 정리하여 기획과 개발 과정에서 활용할 수 있는 프로젝트 지식 기반 위키를 구축함
- 규칙, 원자료, 개념, 설계 산출물 순으로 폴더 위계와 참조 순서를 설계하여 순환 참조와 오류 누적을 방지함
- 주제별 핵심 문서를 MOC에 등록하고 위키링크로 연결하여 자료 탐색과 근거 추적이 가능한 지식 구조를 구축함

### 1.1.2 위키 운영 체계화

- 위키 작성 규칙과 AI 운영 절차를 분리하여 사람과 AI의 역할과 적용 범위를 명확히 함
- 같은 모델의 표현 습관과 누락이 반복될 가능성을 줄이기 위해 작성과 외부 검토를 서로 다른 AI 도구로 분리함
- 자료 수집, 질의 결과의 문서 환원과 유지 보수를 반복 가능한 위키 운영 절차로 정립함
- 헤딩 번호, 링크, 앵커, 인용과 수정일을 자동으로 검사하여 커밋 전에 오류를 차단함
- 반복되는 결함을 데이터화하여 이후 작성과 검수의 기준으로 재사용함

## 1.2 위키 기반 자료 조사, 기획서 및 번역 검수

### 1.2.1 자료 조사 및 정리

- 인공지능을 활용해 남사당놀이 관련 학습자료, 기록영상, 공공 아카이브와 자료 보유 단체를 조사하고 출처, 접근 방법과 활용 조건을 정리함
- 스캔 이미지, PDF와 HWPX 원자료를 광학 문자 인식(OCR), 전사와 마크다운 변환을 거쳐 검색하고 인용할 수 있는 자료로 구조화함
- 남사당놀이 기록영상의 장면, 배역, 인형 조종과 춤사위를 프레임 단위로 분석하여 기획에 활용할 수 있는 동작 자료로 구조화함
- 수집한 자료의 출처와 원문 위치를 기록하고 관련 개념, 기획서와 프로젝트 문서에 위키링크로 연결함

### 1.2.2 기획서 검수

- 기획서의 내용을 연구개발 계획서, 전통 연희본, 프로젝트 결정 사항과 대조하여 사실과 근거를 검수함
- 문서 내부와 기획서 사이의 모순, 논리적 비약, 누락된 사용자 흐름, 예외 상황과 운영 조건을 점검함
- 작성과 검수를 서로 다른 인공지능 도구로 분리하여 사실성, 정합성, 견고성과 가독성을 독립적으로 검토함
- 인공지능이 발견 사항과 수정안을 제시하고 사용자 판정에 따라 수용된 항목만 기획서와 관련 문서에 반영함

### 1.2.3 번역 검수

- 클라이언트 데이터와 사용자 인터페이스 문구의 한국어 원문과 영어 번역을 실제 화면 기능과 기획 문맥에 맞춰 대조함
- 배역명과 전통 용어의 로마자 표기, 대소문자, 문장 부호, 명령문 형식과 대사 어조의 일관성을 점검함
- 오역, 미번역, 복사 오류, 중복 표현과 데이터의 키와 값의 불일치를 찾아 수정안을 제시함
- 반복해서 발견된 번역 문제와 사용자 결정을 공통 규칙으로 정리하여 이후 데이터 제작과 검수에 재사용함

## 1.3 인공지능을 활용한 2D 자산 제작

### 1.3.1 인공지능 기반 2D 이미지 자산 제작

- 인공지능으로 여러 화풍과 표현 방식을 시험하고 승인된 시안을 바탕으로 캐릭터 형태, 색상, 선화와 질감의 시각 스타일 기준을 프로젝트 위키에 정리함
- 남사당놀이 배역, 배경, 체험 단계별 장면과 생성형 이야기 삽화 등 콘텐츠에 필요한 2D 이미지 자산을 제작함
- 사용자 인터페이스에 사용하는 동작 픽토그램, 유형 아이콘, 증거 소품과 진행 흐름 이미지를 제작함
- 프로젝트 위키에 정리한 캐릭터와 화풍 기준에 따라 얼굴, 복식, 소품과 장면 사이의 일관성을 검토하고 재생성하거나 보정함

### 1.3.2 인공지능 기반 2D 애니메이션 자산 제작

- 기존 2D 캐릭터 이미지를 참조 이미지로 사용하고 동작 속도와 시작 및 종료 자세를 지정하여 일관성 있는 여러 동작의 영상을 인공지능으로 생성함
- 캐릭터 외형, 복식과 소품의 유지 여부, 카메라 고정, 동작 속도, 신체 변형과 프레임별 움직임을 검토하고 문제가 있는 영상을 수정하거나 재생성함
- 후처리로 생성 영상의 배경을 제거하고 필요한 프레임을 추출하여 투명 배경의 연속 이미지로 가공함
- 추출한 프레임을 개발 엔진에서 재생할 수 있는 스프라이트 애니메이션 자산으로 구성하고 캐릭터별 애니메이션 상태에 연결함

## 1.4 인공지능을 활용한 3D 자산 제작

### 1.4.1 2D 이미지 기반 3D 모델 및 유니티 프리팹 제작

- 남사당놀이의 탈과 인형 이미지를 입력 자료로 사용하여 인공지능으로 입체 형상과 텍스처를 갖춘 3D 모델을 생성함
- 별도의 수작업 모델링 없이 2D 이미지를 개발 엔진에서 불러올 수 있는 GLB 형식의 3D 자산으로 변환함
- 후처리한 3D 자산을 유니티 엔진으로 옮기고 프로젝트에서 반복 사용할 수 있는 프리팹으로 제작함
- 기존 2D 이미지로부터 개발에 활용할 수 있는 3D 자산을 빠르게 제작하는 작업 방식의 적용 가능성을 확인함

## 1.5 인공지능을 활용한 소프트웨어 프로토타입 및 업무 자동화 도구 개발

### 1.5.1 남사당놀이 덜미 나만의 유람기 콘솔 프로토타입 제작

- 마당 유형과 주인공 설정, 4거리 문답, 서사와 삽화 생성까지 핵심 부분만 인공지능과의 콘솔 대화로 실행함
- 외부 API를 직접 연동하지 않고 인공지능 대화 환경과 로컬 프로그램을 결합하여 기획 단계에서 신속하게 실행할 수 있는 형태로 구현함
- 생성된 서사를 텍스트 이미지로 변환하고 삽화와 결합하여 거리별 최종 페이지 이미지로 저장함

### 1.5.2 남사당놀이 덧뵈기 탈놀음 한바탕 HTML 프로토타입 제작

- 인공지능을 활용하여 브라우저에서 실행할 수 있는 HTML과 JavaScript 기반 체험 화면을 제작함
- 옴탈잡이, 샌님잡이, 먹중잡이의 마당별 진행 과정과 사용자 입력에 따른 성공, 실패, 무입력 분기를 구현함
- 실제 동작 인식 장비 대신 버튼 입력으로 인식 결과와 재시도 과정을 재현함

### 1.5.3 구글 스프레드시트 데이터 JSON 변환 도구 제작

- 인공지능을 활용하여 C# 코드와 데이터 변환 로직을 설계함
- 구글 스프레드시트 데이터를 개발에 필요한 내용만 정리하고 가공하여 개발 엔진에서 사용할 수 있는 JSON 파일로 변환하고 저장함
- 수작업으로 수행하던 데이터 가공과 파일 저장 절차를 도구로 자동화함
