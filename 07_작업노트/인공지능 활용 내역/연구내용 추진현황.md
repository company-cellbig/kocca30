# 1. 연구내용 추진현황

## 1.1 인공지능 기반 프로젝트 위키 구축과 활용

### 1.1.1 프로젝트 위키 구축 및 운영

- 인공지능으로 프로젝트 자료를 수집하고 정리해 기획과 개발에 활용할 위키를 구축함
- 원자료에서 개념과 설계 산출물로 이어지는 참조 구조를 만들고 콘텐츠 지도(Map of Content, MOC)와 위키링크로 연결함
- 작성과 검수에 서로 다른 인공지능 도구를 사용하고 문서 정합성을 자동 점검해 품질을 관리함

### 1.1.2 자료 조사 및 구조화

- 인공지능으로 남사당놀이 자료와 보유 단체를 조사해 출처와 활용 조건을 정리함
- 이미지와 문서는 검색과 인용이 가능하게 변환하고 기록 영상은 장면과 동작 단위의 기획 자료로 구조화함

### 1.1.3 기획서 및 번역 검수

- 연구개발계획서와 프로젝트 근거 자료를 기준으로 기획서의 정확성과 완결성을 점검함
- 한국어 원문과 영어 번역을 화면 기능에 맞춰 대조하고 표현과 데이터 구조의 일관성을 점검함

## 1.2 인공지능을 활용한 2D 자산 제작

### 1.2.1 인공지능 기반 2D 이미지 자산 제작

- 여러 화풍 시험 후 승인된 시안을 바탕으로 시각 스타일 기준을 위키에 정리
- 남사당놀이 배역, 배경, 체험 단계별 장면과 생성형 이야기 삽화 등 2D 이미지 자산 제작
- 사용자 인터페이스용 동작 픽토그램, 유형 아이콘, 소품 이미지 자산 제작
- 이미지 자산 제작 시 위키의 캐릭터와 화풍 기준으로 얼굴, 복식, 소품과 장면의 일관성을 검토하고 재생성하거나 보정하여 최종 결과물 산출

### 1.2.2 인공지능 기반 2D 애니메이션 자산 제작

- 기존 2D 캐릭터 이미지를 바탕으로 동작 속도와 시작 및 종료 자세를 지정하여 여러 동작 영상 생성
- 캐릭터 외형, 복식과 소품 유지 여부, 카메라 고정, 동작 속도, 신체 변형과 프레임별 움직임을 검토하여 문제가 있을 경우 수정하거나 재생성하여 최종 결과물 산출
- 후처리로 생성한 영상의 배경을 제거하고 프레임을 추출하여 투명 배경의 연속 이미지로 가공
- 추출한 프레임을 스프라이트 애니메이션으로 구성하여 캐릭터별 애니메이션 상태에 연결

## 1.3 인공지능을 활용한 3D 자산 제작

### 1.3.1 2D 이미지 기반 3D 모델 및 유니티 프리팹 제작

- 남사당놀이의 탈와 인형 이미지로 형상과 텍스처를 갖춘 3D 모델 생성
- 수작업 모델링 없이 2D 이미지를 개발 엔진에서 불러올 수 있는 표준 3D 파일 형식으로 변환
- 3D 자산을 이용하여 개발 엔진인 유니티에서 재사용 가능한 오브젝트인 프리팹 제작
- 2D 이미지로 개발용 3D 자산을 빠르게 제작하는 공정의 실적용 가능성 확인

## 1.4 인공지능을 활용한 소프트웨어 프로토타입 및 업무 자동화 도구 개발

### 1.4.1 남사당놀이 덜미 나만의 유람기 콘솔 프로토타입 제작

- 이야기 유형과 주인공 설정부터 4개 문답, 서사와 삽화 생성까지 핵심 과정만 인공지능과의 콘솔 대화로 실행
- 기획 단계에서 빠르게 실행하고 검증하기 위해 외부 API 연동 없이 인공지능 대화 환경과 로컬 프로그램의 결합만으로 구동할 수 있는 프로토타입 구현
- 결과물 확인을 위해 생성된 서사를 텍스트 이미지로 변환하고 삽화와 결합해 이미지로 저장

### 1.4.2 남사당놀이 덧뵈기 탈놀음 한바탕 HTML 프로토타입 제작

- 인공지능으로 웹 브라우저에서 실행되는 HTML과 JavaScript 기반 프로토타입 제작
- 옴탈잡이, 샌님잡이, 먹중잡이의 마당별 진행 과정과 사용자 입력에 따른 성공, 실패, 무입력 분기 구현
- 동작 인식이 아닌 진행 과정상의 재미 검증이 우선이었으므로 동작 인식 장비 대신 버튼 입력으로 인식 결과와 재시도 과정 재현

### 1.4.3 구글 스프레드시트 데이터 JSON 변환 도구 제작

- 인공지능으로 C# 코드와 데이터 변환 로직 설계
- 구글 스프레드시트 데이터를 개발에 필요한 내용만 정리하고 가공하여 개발 엔진용 JSON 파일로 변환 후 저장
- 수작업 데이터 가공 및 파일 저장 자동화
