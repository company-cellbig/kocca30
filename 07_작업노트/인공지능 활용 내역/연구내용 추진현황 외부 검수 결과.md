## 3.2 R-01 인공지능과 AI 표기의 혼용

- **위치**: 추진현황.md:21, 22, 40, 41, 79, 80, 85, 91
- **문제**: 같은 대상을 두 표기로 부름. 변경 전에는 인공지능이 11불릿, AI가 2불릿이었으나 변경 후 인공지능 2불릿, AI 8불릿으로 뒤집힘. 반면 문서 제목과 H2, H3 제목은 `1.3 인공지능을 활용한 2D 자산 제작`처럼 전부 인공지능으로 남아 제목과 본문이 어긋남
- **근거**: 이번 변경에서 새로 전환된 자리는 여섯 곳임. `인공지능 도구`가 `AI 도구`로(추진현황.md:40), `인공지능이 발견 사항과`가 `AI가 제시한`으로(추진현황.md:41), `인공지능과의 콘솔 대화`가 `AI와의 콘솔 대화`로(추진현황.md:79), `인공지능 대화 환경`이 `AI 대화 환경`으로(추진현황.md:80), `인공지능을 활용하여`가 `AI로`로(추진현황.md:85, 추진현황.md:91) 바뀜. 추진현황.md:21과 추진현황.md:22의 AI는 변경 전부터 있었음
- **영향**: 외부 심사자가 서로 다른 도구나 범주로 오해할 수 있음. 3.3 가독성 발췌의 `정의 안 된 용어` 항목에 해당함
- **제안**: 제목 표기에 맞춰 본문을 인공지능으로 통일함. 예를 들어 추진현황.md:40을 `작성과 검수에 서로 다른 인공지능 도구를 사용해`로, 추진현황.md:91을 `인공지능으로 C# 코드와 데이터 변환 로직을 설계함`으로 고침. 반대로 AI로 통일한다면 제목 여덟 곳도 함께 바꿔야 함
- **근거 등급**: 해당 없음

## 3.3 R-02 수식어 삭제로 생긴 지시 대상 모호

- **위치**: 추진현황.md:54, 64, 80, 81, 92
- **문제**: 한정 명사를 지워 남은 일반 명사가 무엇을 가리키는지 문장 안에서 확정되지 않음
- **근거**: 다섯 자리의 변경 전후가 각각 다음과 같음
	- `캐릭터 형태, 색상, 선화와 질감의 시각 스타일 기준`이 `형태, 색상, 선화와 질감 기준`이 되어 무엇의 형태이고 무슨 종류의 기준인지 사라짐
	- `캐릭터별 애니메이션 상태에 연결함`이 `캐릭터별 상태에 연결함`이 되어 엔진의 애니메이션 상태라는 개념이 막연한 상태가 됨
	- `신속하게 실행할 수 있는 형태로 구현함`이 `신속히 실행하도록 구현함`이 되어 무엇을 실행하는지 목적어가 없음
	- `거리별 최종 페이지 이미지로 저장함`이 `거리별 최종 페이지로 저장함`이 되어 저장 산출물의 형식이 사라짐
	- `개발 엔진에서 사용할 수 있는 JSON`이 `엔진용 JSON`이 됨. 문서의 다른 자리는 유니티로 특정하는데 여기만 엔진으로 남음
- **영향**: 처음 읽는 심사자가 대상을 특정하지 못함. 3.3 가독성 발췌의 `막연한 이 기능, 해당 값` 항목에 해당함
- **제안**: 다섯 자리에 각각 `캐릭터 형태`와 `시각 스타일 기준`, `캐릭터별 애니메이션 상태`, `프로토타입을 신속히 실행하도록`, `최종 페이지 이미지로`, `유니티용 JSON 파일로`를 되살림
- **근거 등급**: 해당 없음

## 3.4 R-03 관형절을 명사로 붙인 임의 조어

- **위치**: 추진현황.md:54의 `승인 시안`, 추진현황.md:63의 `생성 영상`, 추진현황.md:81의 `생성 서사`
- **문제**: `승인된 시안`, `생성한 영상`, `생성된 서사`의 관형형 어미를 떼어 명사 두 개를 이어 붙임. 표준 표현이 아니고 능동과 피동이 구분되지 않음
- **근거**: 세 자리 모두 변경 전에는 어미가 있었음. 참고로 추진현황.md:25의 `반복 결함`은 저장소 정본 문서명 [[반복 결함 카탈로그]]와 같은 표기라 이 지적에서 제외함
- **영향**: 3.3 가독성 발췌의 `임의 조어` 항목에 해당함. 두 글자를 아끼고 가독성을 잃는 교환임
- **제안**: `승인된 시안을 바탕으로`, `생성한 영상의 배경을 제거하고`, `생성한 서사를 텍스트 이미지로 변환하고`로 고침
- **근거 등급**: 해당 없음

## 3.5 R-04 H3 제목과 불릿 내용의 어긋남

- **위치**: 추진현황.md:52와 추진현황.md:54, 추진현황.md:68과 추진현황.md:73
- **문제**: 제목이 제작인데 해당 불릿은 제작이 아니라 기준 수립과 사후 평가임
- **근거**: `1.3.1 인공지능 기반 2D 이미지 자산 제작` 아래 첫 불릿은 `기준을 위키에 정리함`으로 끝나 자산 산출이 아님. `1.4.1 2D 이미지 기반 3D 모델 및 유니티 프리팹 제작` 아래 네 번째 불릿은 `적용 가능성을 확인함`으로 끝나 제작이 아님. [[CONVENTIONS#4.1 헤딩 레벨 사용 규칙]]은 제목이 가리키기만 하고 주장하지 않게 함
- **영향**: 제목만 보고 불릿 수를 실적 건수로 읽으면 과대 계상됨. 두 건 모두 변경 전에도 있던 상태이며 이번 축약으로 악화되지는 않음
- **제안**: 제목을 `2D 이미지 자산 제작 및 기준 수립`과 `3D 모델과 유니티 프리팹 제작 및 적용성 검증`으로 넓히거나, 두 불릿을 성격에 맞는 절로 옮기는 방안 중 택일함
- **근거 등급**: 해당 없음

## 3.6 R-05 같은 사실의 반복 서술

- **위치**: 추진현황.md:22, 추진현황.md:40
- **문제**: `작성과 외부 검토를 서로 다른 AI 도구에 맡겨`와 `작성과 검수에 서로 다른 AI 도구를 사용해`가 같은 운영 방식을 서술함
- **근거**: 변경 전에도 두 문장이 있었으나 각각 `서로 다른 AI 도구로 분리함`과 `서로 다른 인공지능 도구로 분리하여`라 표기가 갈렸음. 이번 축약으로 두 문장의 구조가 더 비슷해져 중복이 두드러짐. [[CONVENTIONS#3.4.3 읽기 쉬운 개조식]]의 동어반복 제거 항목에 해당함
- **영향**: 적용 대상이 위키 운영과 기획서 검수로 달라 완전 중복은 아니지만, 연달아 읽으면 같은 말을 두 번 하는 것으로 보임
- **제안**: 추진현황.md:40을 대상 특정형으로 차별화함. 예를 들어 `기획서 작성과 검수에 서로 다른 인공지능 도구를 배정해 사실성, 정합성, 견고성과 가독성을 검토함`으로 고침
- **근거 등급**: 해당 없음

## 3.7 R-06 남은 축약 여지

- **위치**: 추진현황.md:40, 추진현황.md:16과 추진현황.md:17
- **문제**: 축약이 이미 충분히 진행되어 더 줄일 자리는 두 곳뿐임
- **근거**: 추진현황.md:40의 `독립적으로`는 앞의 `서로 다른 도구를 사용해`가 이미 담고 있어 지워도 뜻이 같음. 추진현황.md:16의 `참조 체계`와 추진현황.md:17의 `추적 체계`는 인접 불릿에서 `체계`를 반복함. 두 번째 항목은 M-01의 제안대로 추진현황.md:16이 `참조 순서`가 되면 함께 풀림
- **영향**: 경미함. 다만 40개 불릿 중 15곳에서 한정어와 근거가 함께 사라졌으므로, 남은 여백은 압축이 아니라 복원에 쓰는 편이 문서 목적에 맞음
- **제안**: 추진현황.md:40을 `작성과 검수에 서로 다른 인공지능 도구를 사용해 사실성, 정합성, 견고성과 가독성을 검토함`으로 고침. R-05의 제안과 함께 적용할 경우 한쪽만 반영함
- **근거 등급**: 해당 없음
