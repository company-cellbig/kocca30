> 위키 마크다운 문서를 셀빅 발표문 자동화 양식(`assets/셀빅_템플릿1_16b9_매크로_v.1.0.0.pptm`) 기반 파워포인트로 변환하는 절차. `scripts/pptx_author.ps1`이 슬라이드 생성과 본문 채움을 맡고, 넘버링/목차/헤더/텍스트 스타일은 템플릿 내장 매크로가 마무리함.

# 1. 역할

- 마크다운 문서(H1=챕터, H2=슬라이드)를 읽어 표지, 간지, 내지, 뒷표지로 구성된 `.pptm`을 생성함
- 첫 적용 사례는 [[무형문화유산 AI 과제 킥오프]] 문서의 발표본 변환임
- 문서 변환의 반대 방향(외부 문서 → 위키)은 [[docx 변환 파이프라인]]이 담당함

# 2. 사용법

PowerPoint가 설치된 Windows에서 실행함. 산출물은 git 미추적 폴더 `export/`에 생김.

```powershell
powershell -ExecutionPolicy Bypass -File scripts\pptx_author.ps1 `
  -InputMd "04_Projects\킥오프\무형문화유산 AI 과제 킥오프.md" `
  -ExportPngDir "C:\temp\검증png"   # 선택: 슬라이드별 PNG 내보내 검증
```

- **-InputMd** (필수): 변환할 마크다운 경로
- **-OutputPptm**: 출력 경로. 생략 시 `export/<입력 파일명>.pptm`
- **-TemplatePptm**: 템플릿 경로. 생략 시 `assets/` 표준 템플릿
- **-CoverOrg, -CoverDept, -CoverDate**: 표지 기관/부서/일자. 생략 시 (주)셀빅, 빈 값, 오늘
- **-ExportPngDir**: 지정 시 전체 슬라이드를 PNG로 내보냄 (검증용)

# 3. 입력 문서 규약

- **H1** (`# n. 제목`) = 간지(챕터). 헤딩 번호는 떼고 제목만 씀
- **H2** (`## n.n 제목`) = 내지 슬라이드 1장
- **H3**: H2 아래 H3가 있으면 이름이 "슬라이드"로 끝나는 H3의 본문만 쓰고 나머지 H3(프롬프트 등)는 건너뜀. H3가 없으면 H2 본문 전체를 씀
- **발표자 노트**: `> **발표 노트**: ...` 인용블록은 슬라이드 본문이 아니라 발표자 노트로 들어감
- **본문 요소**: 그 외 인용블록은 도입 문장으로, 표는 표 도형으로, 불릿(탭 중첩, 최대 5수준)은 템플릿 글머리 양식으로, 일반 문단은 서술 문단으로 변환함. 코드 펜스 블록과 이미지는 건너뜀
- **인라인 정리**: wikilink는 표시 텍스트만 남기고, 볼드/이탤릭/백틱 마커는 벗김

# 4. 템플릿 계약 (수정 시 주의)

스크립트는 템플릿의 다음 구조에 의존함. 템플릿 개정판을 받으면 이 계약이 유지되는지 확인함.

- **레이아웃 이름**: 표지, 간지, 내지 기본, 뒷표지. 내장 매크로가 레이아웃 이름 앞 2글자("간지"/"내지")로 대상을 식별함
- **placeholder 순서**: 간지 1=제목, 2=번호, 3=목차. 내지 1=제목, 2=헤더. 2와 3은 스크립트가 비워 두고 내장 매크로 `MainManager.Main`이 채움
- **글머리 스타일**: 수준별 글꼴 크기/색/들여쓰기 값은 템플릿 VBA `TextBoxCustom.ApplyBulletStyle`과 동일 값을 스크립트에 복제함. 템플릿 쪽 값이 바뀌면 스크립트도 맞춰 고침
- **매크로 실행**: 스크립트가 저장 전에 `MainManager.Main`을 자동 실행함(간지 넘버링, 목차 수집, 내지 헤더, 자간/줄간격). 실행이 실패하면 콘솔 경고가 나오며, 그때는 PowerPoint에서 우클릭 후 "자동화 실행"으로 수동 보완함

# 5. 한계

- **본문 넘침**: 슬라이드당 담기는 분량 판단은 하지 않음. 하단 기준선을 넘으면 콘솔에 "본문 넘침 의심" 경고를 내며, 해당 슬라이드는 사람이 분할하거나 축약함
- **이미지 미배치**: 문서 속 이미지와 이미지 생성 프롬프트는 변환하지 않음. 인포그래픽은 생성 후 사람이 배치함
- **매크로 보안**: 출력이 매크로 포함(.pptm)이라 처음 열 때 콘텐츠 사용 허용이 필요할 수 있음(템플릿 가이드 슬라이드의 안내와 동일)
