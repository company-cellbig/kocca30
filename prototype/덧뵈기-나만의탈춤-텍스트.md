# 덧뵈기 - 나만의 탈춤 프로토타입 텍스트

`덧뵈기-나만의탈춤-프로토타입.html` 화면에 나오는 문안을 한자리에 모은 대조본임. 문안을 고칠 때는 이 문서에서 먼저 고치고 HTML에 옮김.

- **원문**: 2장과 3장 배역 대사는 전사본 「남사당놀이 - 덧뵈기」 5) 연회본 발췌임. 행 번호를 함께 적었고 고칠 때는 원전과 대조해야 함. 화면에는 「연회본 원문」 꼬리표가 붙음
- **임시 문안**: 장쇠 대사, 화면 라벨, 판정 문구는 전부 임시 문안임. 기획서가 「문안 작성 예정」으로 둔 자리이며 화면에 「임시 문안」 꼬리표가 붙음
- **범위**: 콘텐츠 화면에 나오는 텍스트만 담음. 검토용 오른쪽 패널과 프로토타입 입력부는 실제 콘텐츠에 없으므로 「프로토타입 전용 문구」 절에 목록만 둠

## 4. Step 2 배역 확인

화면 라벨은 이 배역이 할 일, 맞설 상대, 배울 동작임. 배역 이름 밑에는 「{마당 이름}의 배역」이 붙음.

### 4.1 꺽쇠 (옴탈잡이)

- 소개: 꽹과리를 든 남사당패의 앞잡이. 판을 열고 훼방꾼을 몰아내는 놈.
- 맞설 상대: 옴탈, 슬금슬금 기어드는 옴쟁이
- 장쇠 탈 해설: 이 낯을 보아라. 엷은 자줏빛 바탕에 상모를 얹고 꽹과리를 든 꺽쇠다. 나와 한 패로 판을 여는 놈이지.
- 장쇠 다짐: 탈을 쓰면 너는 네가 아니라 꺽쇠다. 서툰 건 꺽쇠가 서툰 것이니 마음 놓고 놀아라.

### 4.2 말뚝이 (샌님잡이)

- 소개: 벙거지 쓰고 말채찍 든 하인. 주먹이 아니라 말로 주인을 이기는 놈.
- 맞설 상대: 샌님, 거드름 피우는 양반
- 장쇠 탈 해설: 이 낯을 보아라. 이마에 혹이 돋은 자줏빛 바탕에 벙거지 쓰고 말채찍을 든 말뚝이다. 제 주인 샌님을 말로 이기는 하인이지.
- 장쇠 다짐: 탈을 쓰면 너는 네가 아니라 말뚝이다. 양반 앞에서도 기죽지 말고 놀아라.

### 4.3 취발이 (먹중잡이)

- 소개: 상투 꽂고 붉은 띠 두른 장정. 흥이 오르면 누구 앞에서도 물러서지 않는 놈.
- 맞설 상대: 먹중, 행패 부리는 파계승
- 장쇠 탈 해설: 이 낯을 보아라. 꽃자줏빛 바탕에 상투를 꽂고 붉은 띠를 두른 취발이다. 흥이 오르면 누구 앞에서도 물러서지 않는 놈이지.
- 장쇠 다짐: 탈을 쓰면 너는 네가 아니라 취발이다. 물러서지 말고 크게 놀아라.

## 10. 프로토타입 전용 문구

실제 콘텐츠에 없는 검토용 영역이라 문안 검토 대상이 아님. 자리와 대표 문구만 남김.

- **프로토타입 입력부**: 실제 콘텐츠에서는 카메라 동작 인식이 이 자리를 대신함. 자세는 번호, 타이밍은 누른 시점, 홀드는 누른 시간으로 치환함
	- 상태 표기: 대기 중 / 응수 대기 중 / 절정 응수 대기 / 따라 하기
	- 조작 안내: 판에 뜬 그림에 맞는 번호를 누르십시오 / 그림에 맞는 번호를 빠르게 누르기 / 그림에 맞는 번호를 N초 넘게 누르고 있기 (홀드 동작)
	- 판정 요소 표기: 자세 / 홀드 / 타이밍 / 진폭 (실기기 전용) / 속도 (실기기 전용)
	- 실기기 동작 설명 9종은 동작마다 따로 있음 (예: 팔을 앞으로 힘껏 뻗어 찌름)
- **오른쪽 검토 패널**: 세션 데이터, 이벤트 로그, 체험 리포트, 리소스 상태, 튜닝값, 진행 도구, 에러 케이스 발동, 기획서 대조에서 걸린 것
