> `덜미-나만의유람기-3지선다-0918` 버전에서 덜미의 원초적 욕망과 일탈을 웃음으로 다루기 위한 3지선다 생성 설정임. `작성 예정`으로 표시한 항목은 사용자가 해당 값을 바꾸기 전까지 생성 입력과 검사에서 제외함.

# 1. 진행 전제

- 선택지는 모두 문제 해결책일 필요가 없음
- 욕심, 편들기, 속임, 난장과 새 문제도 이야기를 진행하는 유효한 선택임
- 선택의 잘잘못을 즉시 훈계하지 않고 사건과 웃음으로 결과를 보여 줌
- 연령에 따라 소재와 표현 수위를 바꾸되 선택의 주도성과 장난기는 유지함
- 이야기는 발단, 전개, 절정, 위기, 결말 순서로 진행함
- 발단, 전개, 절정과 위기에서는 인물의 직접 대사가 한 차례 이상 들어간 300자 이상 400자 이내 서사를 먼저 보여 준 뒤 선택지 세 개를 제시함. 직접 대사 뒤에는 다른 인물의 대사뿐 아니라 행동, 표정이나 반응을 서술해도 됨
- 결말은 위기에서 고른 선택까지 반영한 300자 이상 400자 이내 서사만 보여 주고 선택지를 제시하지 않음

# 2. 선택지 유형

한 행동에 여러 성향이 겹치면 장면을 가장 크게 바꾸는 효과 하나를 주 유형으로 기록함.

| ID | 유형 | 적용 거리 | 기능 |
| --- | --- | --- | --- |
| `SOLVE` | 수습, 해결 | 발단, 전개, 절정, 위기 | 중재, 구조, 조사와 복구로 문제를 줄이거나 남은 갈등을 정리함 |
| `SIDE` | 한쪽 편들기 | 발단, 전개, 절정, 위기 | 인물 한 명이나 한 집단의 이익을 택해 관계와 결과를 바꿈 |
| `STIR` | 부추기기 | 발단, 전개, 절정, 위기 | 경쟁, 허세, 질투와 싸움을 키우며 그 대가가 다음 서사나 결말에 나타나게 함 |
| `TRICK` | 속이기, 이간질 | 발단, 전개, 절정, 위기 | 거짓말, 꾀와 오해로 판을 움직이며 선택의 결과를 뒤에서 회수함 |
| `DESIRE` | 자기 욕망 따르기 | 발단, 전개, 절정, 위기 | 먹을 것, 재물, 체면, 애정과 권력을 좇아 사건의 우선순위를 바꿈 |
| `RAMPAGE` | 난장, 힘쓰기 | 발단, 전개, 절정, 위기 | 쫓기, 몸싸움, 물건 뒤엎기와 과장된 몸개그로 상황을 밀어붙임 |
| `NEW_TROUBLE` | 다른 문제 만들기 | 발단, 전개, 절정 | 제삼자, 물건이나 사건을 끌어들여 갈등의 방향을 바꿈. 결말 직전인 위기에는 쓰지 않음 |
| `AVOID` | 회피, 떠넘기기 | 발단, 전개, 절정, 위기 | 달아나거나 NPC에게 책임을 떠넘겨 대응을 일으킴. 단순 무행동은 제외함 |
| `EXPOSE` | 폭로, 조롱 | 발단, 전개, 절정, 위기 | 숨은 욕망과 위선을 드러내 관계나 승패를 바꾸고 재담으로 망신시킴 |

결말은 선택 단계가 아니므로 별도의 결말 전용 선택지 유형을 두지 않음. 자랑, 남 탓, 농담, 후회와 소회는 앞선 네 선택에서 드러난 태도와 결과에 맞을 때 결말 서사 안에서만 사용함.

# 3. 세 선택지 구성

1. 현재 연령과 장면에서 허용되는 유형만 후보로 삼음
2. 서로 다른 유형 세 개를 뽑음
3. 발단, 전개, 절정과 위기는 `SOLVE`를 `solve_max` 이하로 두고 `STIR`, `TRICK`, `RAMPAGE`, `NEW_TROUBLE`을 합해 `complication_min` 이상 넣음
4. 위기에서는 `NEW_TROUBLE`을 제외하고 어떤 선택을 골라도 다음 결말에서 중심 갈등을 닫을 수 있게 함
5. 어느 선택도 즉시 막다른 길이나 정답 표시가 되지 않게 함
6. 결과와 벌을 선택지 문안에서 미리 밝히지 않음
7. 선택된 행동만 다음 서사의 사실로 만들고 나머지는 폐기함
8. 결말에서는 선택지를 만들지 않고 위기까지 누적된 네 선택으로 이야기를 마침

| 거리 | 선택지 기능 |
| --- | --- |
| 발단 | 첫 상황에서 주인공이 끼어드는 동기, 욕망, 편과 태도를 고름 |
| 전개 | 진행형 유형 중에서 판을 움직임 |
| 절정 | 주인공이 직접 행동해 갈등을 최고조로 밀고 그 결과로 위기 상황을 만듦 |
| 위기 | 절정의 결과로 생긴 마지막 문제에 대응해 결말의 방향을 확정함 |
| 결말 | 선택지 없음. 위기까지의 선택과 결과를 회수해 완결된 서사를 보여 줌 |

| 연령대 | 기본 허용 범위 | 제한 | 결과 강도 | 사용자 추가 |

| 청소년 | 반항, 허세, 또래 편들기, 속임, 위험한 도전 | 성적 대상화, 잔혹한 상해, 실제 집단 대상 비하 제외 | 관계와 체면의 손해까지 허용하되 회복 가능 | 작성 예정 |
| 어른 | 불륜 암시, 탐욕, 부패, 권력 남용과 거친 다툼 | 노골적 성행위, 잔혹한 폭력, 실제 인물과 단체 공격 제외 | 오래 남는 재산, 관계와 체면의 손해 허용 | 작성 예정 |

- **어른 수위 상한**: `insult_level=2`, `predation_level=3`, `nonsexual_nudity=traditional_only`, `relationship_transgression=adult_only`

# 7. 제어값

`0~3` 강도값은 `0` 없음, `1` 약함, `2` 보통, `3` 강함을 뜻함.

| 키 | 기본값 | 범위와 규칙 | 효과 |
| --- | --- | --- | --- |
| `story_stage_count` | 5 | 고정 | 발단, 전개, 절정, 위기, 결말의 전체 단계 수 |
| `choice_stage_count` | 4 | 고정 | 선택지를 제시하는 발단, 전개, 절정과 위기의 단계 수 |
| `choice_count` | 3 | 고정 | 각 선택 단계의 서사 뒤에 제시할 선택지 수 |
| `distinct_type_min` | 3 | 고정 | 서로 다른 선택지 유형의 최소 수 |
| `narrative_char_min` | 300 | 고정 | 각 단계 서사의 최소 글자 수 |
| `narrative_char_max` | 400 | 고정 | 각 단계 서사의 최대 글자 수 |
| `dialogue_required` | `true` | 고정 | 각 단계 서사에 인물의 직접 대사를 한 차례 이상 넣음. 이어지는 반응은 대사나 서술 모두 허용함 |
| `ending_choice` | `false` | 고정 | 결말에는 선택지를 제시하지 않음 |
| `solve_max` | 1 | 0~1 | 발단, 전개, 절정과 위기 한 세트의 수습, 해결 선택지 상한 |
| `complication_min` | 1 | 1~2 | 발단, 전개, 절정과 위기 한 세트의 `STIR`, `TRICK`, `RAMPAGE`, `NEW_TROUBLE` 합계 하한 |
| `chaos_level` | 2 | 0~3 | 난장, 우연과 새 문제의 강도 |
| `moralizing_level` | 0 | 고정 | 즉시 훈계하거나 특정 선택을 정답으로 표시하지 않음 |
| `npc_autonomy` | 2 | 0~3 | NPC가 자기 욕망으로 사건을 일으키는 강도 |
| `deception_level` | 2 | 0~3 | 거짓말, 속임과 이간질의 강도 |
| `power_abuse_level` | 2 | 0~3 | 신분과 권력을 사적으로 휘두르는 강도 |
| `insult_level` | 1 | 0~3 | 가상 인물끼리 주고받는 욕설과 조롱의 강도 |
| `predation_level` | 2 | 0~3 | `0` 없음, `1` 위협이나 화면 밖 실종, `2` 과장된 삼킴, `3` 반복되는 삼킴. 잔혹 묘사는 쓰지 않음 |
| `consequence_delay` | 1 | 0~2개 거리 | 선택 결과가 다시 돌아오기까지 미룰 거리 수 |
| `comic_recovery` | 2 | 0~3 | 손해와 망신을 웃음으로 회수하는 강도 |
| `seed_binding` | 1 | 0~3 | 이야기 씨앗의 거리 방향을 따르는 강도 |
| `age_gate` | `hard` | 고정 | 연령대 제한을 다른 설정보다 우선함 |
| `selected_fact_only` | `true` | 고정 | 고른 선택만 다음 이야기의 사실로 사용함 |
| `relationship_transgression` | `adult_only` | 고정 | 불륜과 관계 일탈은 어른 런에서 암시로만 다룸 |
| `nonsexual_nudity` | `traditional_only` | 고정 | 전통 인형의 맨몸은 비성적 익살로만 쓰고 미성년 캐릭터에는 적용하지 않음 |
| `explicit_sex` | 0 | 고정 | 노골적 성적 묘사를 생성하지 않음 |
| `graphic_violence` | 0 | 고정 | 잔혹한 상해 묘사를 생성하지 않음 |
| `real_target` | 0 | 고정 | 실제 인물과 단체를 풍자나 욕설 대상으로 쓰지 않음 |
