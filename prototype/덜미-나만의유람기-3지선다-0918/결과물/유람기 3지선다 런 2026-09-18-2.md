- **씨앗에서 달라진 지점**: 물길을 막은 위협을 이시미로 구체화하고 빈 물동이 유인, 둑 붕괴와 이시미를 이용한 임시 복구를 런타임에서 추가함. 결말은 마을 사람들이 물동이를 채워 집으로 돌아가는 작별로 마침.

## 4.1 발단

<img src="유람기%203지선다%20런%202026-09-18-2/1_발단_페이지.png" width="500">

들길의 흙먼지가 발목까지 피어오르자 박첨지가 빈 물동이를 두드렸다. 논바닥은 거북등처럼 갈라졌고, 볏잎은 누렇게 말려 고개를 숙였다. 아무개가 마른 도랑을 내려다보는 사이, 아이 하나가 물지게를 끌며 다가왔다.

“나그네 양반, 물 한 바가지만 찾아 주시오. 사흘째 우물 밑바닥만 긁고 있소.” 뒤따라온 마을 사람들은 서로 윗마을 탓을 하며 삿대질했다. 박첨지는 수염을 쓸며 “물보다 성미가 먼저 끓었구먼. 이러다 사람 속이 터지겠네” 하고 혀를 찼다.

아무개는 도랑 가장자리에서 아직 젖은 짚 한 오라기를 발견했다. 물길이 완전히 마른 것은 아닌 듯했지만, 위쪽 굽이 너머에는 쓰러진 나무와 돌무더기가 길을 가리고 있었다. 사람들은 삽을 들고도 누구 말부터 따라야 할지 몰라 아무개의 입만 바라보았다.

| 번호 | 제시한 선택지 | 선택 |
| --- | --- | --- |
| 1 | 사람들을 나눠 돌무더기를 치운다 | 선택 |
| 2 | 물을 찾으면 값을 받겠다고 나선다 |  |
| 3 | 삽을 빼앗아 막힌 도랑을 내리친다 |  |

## 4.2 전개

<img src="유람기%203지선다%20런%202026-09-18-2/2_전개_페이지.png" width="500">

아무개가 사람들을 셋씩 나누자 삽과 괭이가 한 박자로 움직였다. 박첨지는 돌 나르는 시늉을 하며 “허리는 하나인데 입은 열이니, 오늘은 입도 품삯을 해야겠구먼!” 하고 장단을 맞췄다. 해가 중천에 닿을 무렵 마지막 돌무더기가 무너져 내렸다.

그러나 물 대신 축축하고 찬 바람이 도랑 안쪽에서 불어왔다. 아이가 어둑한 굴을 가리키며 “저 안에서 큰 숨소리가 나요”라고 속삭였다. 아무개가 횃불을 비추자, 샘 어귀를 칭칭 감은 이시미가 가느다란 물줄기를 받아 삼키고 있었다.

이시미는 누런 눈을 뜨고 “내가 먼저 차지한 물인데 누가 돌을 치웠느냐?”라며 꼬리로 둑을 후려쳤다. 금이 간 둑 사이로 흙탕물이 새자 사람들이 물러섰다. 그대로 두면 샘은 마르고, 성급히 건드리면 약해진 둑이 한꺼번에 터질 판이었다.

| 번호 | 제시한 선택지 | 선택 |
| --- | --- | --- |
| 1 | 주민들을 물리고 새 물길을 판다 |  |
| 2 | 빈 물동이 소리로 이시미를 유인한다 | 선택 |
| 3 | 삽으로 꼬리 아래 둑을 먼저 허문다 |  |

## 4.3 절정

<img src="유람기%203지선다%20런%202026-09-18-2/3_절정_페이지.png" width="500">

아무개는 빈 물동이마다 자갈을 넣고 사람들을 굴 양옆에 세웠다. 신호에 맞춰 항아리를 흔들자 달그락거리는 소리가 골짜기 위로 이어졌다. 이시미가 목을 빼며 “물이 저리도 넘치는데, 나만 빼놓고 잔치를 벌이느냐?” 하고 샘 어귀를 풀었다.

아무개가 소리를 조금씩 멀리 옮기게 하자 이시미의 긴 몸이 굴 밖으로 미끄러졌다. 막혔던 샘물이 흐르기 시작했지만, 냄새를 맡은 이시미는 물동이가 빈 것을 알아챘다. 놈이 입을 쩍 벌리고 돌아서자 박첨지는 모자까지 벗어 던지며 달아났다.

그때 홍동지가 둑 위로 뛰어올라 꼬리 끝을 붙잡았다. “아무개, 머리는 자네가 맡게. 이 긴 국수 가락은 내가 붙들지!” 아무개 앞에서 이시미가 몸을 세우자 굴 천장의 흙이 쏟아지고 샘물이 거세졌다. 이제 놈과 물길을 한꺼번에 다뤄야 했다.

| --- | --- | --- |
| 1 | 굴 입구를 파서 샘물로 이시미를 민다 |  |
| 2 | 더 큰 샘이 있다며 골짜기로 꾀어낸다 |  |
| 3 | 이시미 등에 올라 꼬리를 둑 밖으로 돌린다 | 선택 |

## 4.4 위기

<img src="유람기%203지선다%20런%202026-09-18-2/4_위기_페이지.png" width="500">

아무개는 이시미의 등을 밟고 목덜미까지 기어올랐다. 뿔을 붙잡고 몸을 틀자 홍동지도 꼬리를 둑 밖으로 잡아당겼다. “물은 네 배 속에 가둘 것이 아니다!” 아무개가 외치자 이시미는 몸을 뒤집었고, 마침내 샘 어귀에서 떨어져 나갔다.

풀려난 물은 굉음을 내며 도랑으로 쏟아졌지만, 몸부림에 약해진 둑 한쪽이 무너졌다. 물살은 논으로 가지 못하고 마을길로 번졌고, 물동이와 삽이 둥둥 떠내려갔다. 홍동지는 바위틈에 낀 이시미의 꼬리를 붙든 채 버티고 있었다.

박첨지가 높은 돌 위에서 “샘은 살렸는데 마을이 떠내려가면 물고기만 농사짓겠구나!” 하고 소리쳤다. 아무개 앞에는 갈라진 물길, 무너진 돌과 붙잡힌 이시미가 놓였다. 지금 방향을 바로잡지 않으면 말라붙은 논 대신 집들이 물을 뒤집어쓸 판이었다.

| 번호 | 제시한 선택지 | 선택 |
| --- | --- | --- |
| 1 | 주민들과 새 물꼬를 논 쪽으로 낸다 |  |
| 2 | 이시미에게 둑을 막으면 풀어 주겠다고 한다 | 선택 |
| 3 | 홍동지와 바위를 밀어 물살을 가른다 |  |

## 4.5 결말

<img src="유람기%203지선다%20런%202026-09-18-2/5_결말_페이지.png" width="500">

아무개는 바위틈에 낀 이시미에게 다가갔다. “네 몸으로 둑을 막아라. 물이 논으로 돌아가면 풀어 주마.” 이시미는 이를 드러냈지만 물살에 제 몸도 휩쓸릴 판이었다. 놈이 마지못해 몸을 둥글게 말자 홍동지가 꼬리를 놓았다.

사람들은 아무개의 지시에 따라 이시미 둘레에 돌을 쌓고 물꼬를 논 쪽으로 냈다. 굴을 막았던 돌을 함께 치운 손들이 둑을 단단히 다졌다. 미끼로 흔들었던 물동이마다 맑은 물이 차오르자 아이는 “이제 우물 밑을 긁지 않아도 돼요!”라며 웃었다.

약속대로 아무개가 길을 터 주자 이시미는 비늘을 털며 먼 골짜기로 달아났다. 박첨지는 “용마보다 길고 성질 고약한 탈것이었네” 하고 너스레를 떨었다. 저녁빛 아래 물은 갈라진 논을 적셨고, 사람들은 찬 물동이를 들고 집으로 돌아갔다.
