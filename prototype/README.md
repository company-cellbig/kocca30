# 덧뵈기 - 나만의 탈춤 프로토타입

키오스크 콘텐츠 「덧뵈기 - 나만의 탈춤」의 Step 2~5 진행을 브라우저에서 돌려 보는 프로토타입임. 개발 리뷰와 기획 검토용이며 실제 제품 코드가 아님.

## 1. 여는 법

`덧뵈기-나만의탈춤-프로토타입.html`을 브라우저로 열면 됨. 설치도 서버도 필요 없음.

- 이 폴더를 통째로 풀어야 함. `assets/` 폴더가 같은 자리에 있어야 그림이 나옴
- 크롬이나 엣지 권장. 음성(TTS)은 브라우저 내장 음성을 씀
- 화면이 넓을수록 잘 맞음. 1920x1080 이상 권장 (좁으면 판 위 말풍선이 상대 배역을 가림, 아래 「알려진 한계」 참조)

## 2. 조작

실제 키오스크는 뎁스 카메라로 몸동작을 읽지만 프로토타입에는 카메라가 없음. 그래서 화면 아래 **프로토타입 입력부**가 그 자리를 대신함.

| 실기기가 재는 것 | 프로토타입에서 |
|---|---|
| 자세 (어느 동작인가) | 판에 뜬 그림에 맞는 번호를 누름 |
| 타이밍 (장단에 맞췄나) | 대사가 끝난 뒤 얼마나 빨리 눌렀나 |
| 홀드 (끝을 맺었나) | 번호를 누르고 있는 시간 |
| 진폭, 속도 | 키패드로 못 잼. 요소 표시에 「실기기 전용」으로만 남김 |

## 3. 진행 흐름

1. **시작** → 마당 선택 (옴탈잡이, 샌님잡이, 먹중잡이)
2. **배역 확인** → 탈 쓰기
3. **1장 기초 수업**: 장쇠가 그 마당의 동작 3개를 가르침
4. **2장 앞대목**: 상대 배역이 원전 대사를 하면 유저가 동작으로 응수함
5. **3장 뒷대목(절정)**: 같은 방식에 장단과 게이지가 붙음
6. **배역 인정** → 종료

2장과 3장 대사는 「남사당놀이 여섯 가지」 덧뵈기 장의 연회본에서 발췌한 원문임. 화면 오른쪽 진행 목록에 원전 행 번호가 함께 표시됨. 장쇠 대사와 안내 문구는 임시 문안임.

## 4. 오른쪽 패널

화면 오른쪽은 검토용 패널임. 실제 콘텐츠에는 없음. 오른쪽 위 「패널」 버튼으로 접고 펼 수 있음.

- **세션 데이터, 이벤트 로그**: 판정 결과와 서버 호출 지점을 그대로 보여 줌
- **체험 리포트**: 종료 시 집계
- **그래픽 자산**: 그림 확보 여부. 「없음」은 아직 안 그린 것이고 자리표시가 대신 나옴
- **조정값**: 응답 대기, 타이핑 속도, 얼쑤 기준 등을 바로 바꿔 볼 수 있음
- **에러 케이스, 진행 도구**: 실패 상황 재현과 장 건너뛰기
- **기획서 대조에서 걸린 것**: 기획서와 어긋나 프로토타입에서 달리 처리한 항목과 미해결 사항

## 5. 알려진 한계

- **작은 창에서 말풍선이 상대 배역을 가림**: 1920 화면은 문제없으나 1600에서 일부, 1366에서는 전부 가림. 배치 변경이 필요한 사안임
- **긴 대사의 음성이 끊김**: 화면 표시가 끝나면 다음으로 넘어가므로 긴 사설은 음성이 중간에 잘림. 패널의 「음성 끝까지 기다림」을 켜면 온전히 나오지만 그만큼 느려짐
- **미확보 그림**: 상대 배역의 과장/중립/결말 포즈, 배경, 동작 시범 클립이 아직 없음. 대기 전신과 자리표시로 대체 중
- **동작 시범**: 모션 레퍼런스 확보가 미정이라 1장 시범 자리는 비어 있음

## 6. 폴더 구성

```
prototype/
├── 덧뵈기-나만의탈춤-프로토타입.html   ← 이 파일 하나가 전부 (CSS와 JS 내장)
├── README.md
└── assets/                          ← 그림 28개
```

`assets/`의 `탈_먹중`, `탈_샌님`, `탈_옴탈` 3개는 현재 코드가 쓰지 않음(상대 배역은 전신 그림을 씀). 뒤에 쓸 수 있어 남겨 둠.

동작 픽토그램 9개는 `scripts/make_pictograms.py`로 생성함(저장소에 있음). 그림을 고치려면 그 스크립트를 고쳐 다시 돌리면 됨.
