> 3지선다 콘솔이 유형별로 무작위 배정할 이야기 씨앗 80개를 담음. 각 씨앗은 질문과 확정 사건이 아니라 도입, 전개, 절정, 마무리의 느슨한 방향만 제공함. 박첨지 질문과 선택지 세 개 및 실제 사건은 런타임에 생성함.

# 1. 사용 규칙

## 1.1 추출 범위와 기준

- **분석 범위**: 원본 마당 플롯 풀의 위협-구원형, 권력 풍자형, 위선 폭로형과 욕심과 다툼형 P01~P20을 사용함
- **분절 기준**: 플롯 하나를 이야기 씨앗 하나로 보고 제목과 4거리 괄호 안 사건 방향을 간추림. 원본 용어인 `유저`는 방향 데이터에 유지하고, 명백히 빠진 조사와 잘못 쓰인 어휘만 바로잡음
- **대응 결과**: 원본 플롯 80개를 전용 씨앗 80개에 일대일 대응함. 제외한 플롯과 새로 만든 이야기는 없음
- **제외 정보**: 원본의 박첨지 질문 320개는 런타임 각색 대상이라 본 문서에 싣지 않음

## 1.2 구속 강도

- **강하게 지킴**
	- 사용자가 고른 마당 유형을 세션 끝까지 유지함
	- 배정된 이야기 씨앗 하나를 도입, 전개, 절정, 마무리 순서로 진행함
	- 사용자가 실제로 고른 응답만 다음 질문과 서사의 사실로 사용함
	- 안전 규칙과 주인공의 절정 주도권을 지킴
- **약하게 지킴**
	- 거리별 방향은 다음 장면을 만드는 출발점으로만 사용함
	- 앞선 선택이 자연스럽게 다른 전개를 요구하면 장소, 행동, 조연과 해결 방식을 바꿀 수 있음
	- 씨앗의 표현을 그대로 되풀이하거나 정해진 결말로 강제하지 않음
	- 4거리 안에서 선택 결과를 회수하되 원본 방향과 다른 결말도 허용함

## 1.3 런타임 사용

1. 사용자가 고른 유형에서 이야기 씨앗 하나를 무작위로 배정함
2. 현재 거리 방향, 누적 이야기 상태와 앞서 고른 응답을 입력으로 박첨지 질문을 생성함
3. 생성한 질문에 직접 답하는 선택지 세 개를 만듦
4. 사용자가 고른 응답으로 이야기 상태를 갱신하고 다음 거리로 넘어감
5. 테스트 재현이 필요할 때만 이야기 ID를 지정하고 일반 실행에서는 ID를 사용자에게 고르게 하지 않음

| 유형 | 이야기의 중심 방향 | 등장 가능한 조연 | 홍동지 활용 예시(약한 가이드) |
| --- | --- | --- | --- |

| 위선 폭로형 | 겉과 속이 다른 위선을 사용자가 드러내고 망신이나 축출로 잇는 방향 | 상좌, 홍백가, 피조리, 묵대사 | 폭로된 위선자를 몰아내는 일을 거들 수 있음 |
| 욕심과 다툼형 | 재산, 명예, 기회와 분배를 둘러싼 다툼을 사용자의 선택으로 가르는 방향 | 무명 이웃, 동무, 형제, 사돈 | 전개에 따라 등장하거나 등장하지 않음 |
