> 덜미의 원초적 욕망과 일탈을 웃음으로 다루기 위한 3지선다 생성 설정. `작성 예정`은 사용자가 바꾸기 전까지 생성 입력과 검사에서 제외함.

# 1. 진행 전제

- 선택지는 모두 문제 해결책일 필요가 없음
- 욕심, 편들기, 속임, 난장과 새 문제도 이야기를 진행하는 유효한 선택임
- 선택의 잘잘못을 즉시 훈계하지 않고 사건과 웃음으로 결과를 보여 줌
- 연령에 따라 소재와 표현 수위를 바꾸되 선택의 주도성과 장난기는 유지함

# 2. 선택지 유형

한 행동에 여러 성향이 겹치면 장면을 가장 크게 바꾸는 효과 하나를 주 유형으로 기록함.

| ID | 유형 | 적용 거리 | 기능 |
| --- | --- | --- | --- |
| `SOLVE` | 수습, 해결 | 도입, 전개, 절정 | 중재, 구조, 조사와 복구로 문제를 줄임 |
| `SIDE` | 한쪽 편들기 | 도입, 전개, 절정 | 인물 한 명이나 한 집단의 이익을 택함 |
| `STIR` | 부추기기 | 도입, 전개, 절정 | 경쟁, 허세, 질투와 싸움을 더 키움 |
| `TRICK` | 속이기, 이간질 | 도입, 전개, 절정 | 거짓말, 꾀와 오해로 판을 움직임 |
| `DESIRE` | 자기 욕망 따르기 | 도입, 전개, 절정 | 먹을 것, 재물, 체면, 애정과 권력을 좇음 |
| `RAMPAGE` | 난장, 힘쓰기 | 도입, 전개, 절정 | 쫓기, 몸싸움, 물건 뒤엎기와 과장된 몸개그로 밀어붙임 |
| `NEW_TROUBLE` | 다른 문제 만들기 | 도입, 전개, 절정 | 제삼자, 물건이나 사건을 끌어들여 갈등을 바꿈 |
| `AVOID` | 회피, 떠넘기기 | 도입, 전개, 절정 | 달아나거나 NPC에게 책임을 떠넘겨 새 대응을 일으킴. 단순 무행동은 제외함 |
| `EXPOSE` | 폭로, 조롱 | 도입, 전개, 절정 | 숨은 욕망과 위선을 드러내 재담으로 망신시킴 |
| `BOAST` | 자랑, 공치사 | 마무리 | 자기 선택과 결과를 과장해 자랑함 |
| `BLAME` | 남 탓 | 마무리 | 결과의 책임을 다른 인물이나 운수에 돌림 |
| `JOKE` | 농담, 조롱 | 마무리 | 벌어진 일을 재담과 조롱으로 맺음 |
| `REGRET` | 후회 | 마무리 | 자기 선택의 대가를 인정하거나 아쉬워함 |
| `REFLECT` | 소회 | 마무리 | 하루의 의미나 마음에 남은 것을 말함 |

# 3. 세 선택지 구성

1. 현재 연령과 장면에서 허용되는 유형만 후보로 삼음
2. 서로 다른 유형 세 개를 뽑음
3. 도입, 전개와 절정은 `SOLVE`를 `solve_max` 이하로 두고 `STIR`, `TRICK`, `RAMPAGE`, `NEW_TROUBLE`을 합해 `complication_min` 이상 넣음
4. 마무리는 `BOAST`, `BLAME`, `JOKE`, `REGRET`, `REFLECT` 중 서로 다른 세 개를 뽑음
5. 절정의 모든 선택은 중심 갈등을 끝내거나 뒤집음. 갈등을 키우는 선택도 미해결 새 중심 사건을 남기지 않음
6. 어느 선택도 즉시 막다른 길이나 정답 표시가 되지 않게 함
7. 결과와 벌을 선택지 문안에서 미리 밝히지 않음
8. 선택된 행동만 사실로 만들고 나머지는 폐기함

| 거리 | 선택지 기능 |
| --- | --- |
| 도입 | 끼어든 동기, 욕망, 편과 태도를 고름 |
| 전개 | 진행형 유형 중에서 판을 움직임 |
| 절정 | 주인공이 직접 실행하며 갈등을 끝내거나 다른 결말로 뒤집음 |
| 마무리 | 자랑, 남 탓, 농담, 후회와 소회를 고르되 새 사건은 시작하지 않음 |

# 4. 연령대 진행 콘셉트

| 연령대 | 기본 허용 범위 | 제한 | 결과 강도 | 사용자 추가 |
| --- | --- | --- | --- | --- |
| 아이 | 장난, 욕심, 편들기, 작은 거짓말, 과장된 몸개그 | 성적 소재, 잔혹한 폭력, 지속적인 모욕 제외 | 즉시 회복 가능한 손해와 망신 | 작성 예정 |
| 청소년 | 반항, 허세, 또래 편들기, 속임, 위험한 도전 | 성적 대상화, 잔혹한 상해, 실제 집단 대상 비하 제외 | 관계와 체면의 손해까지 허용하되 회복 가능 | 작성 예정 |
| 어른 | 불륜 암시, 탐욕, 부패, 권력 남용과 거친 다툼 | 노골적 성행위, 잔혹한 폭력, 실제 인물과 단체 공격 제외 | 오래 남는 재산, 관계와 체면의 손해 허용 | 작성 예정 |

- **아이 수위 상한**: `insult_level=0`, `predation_level=1`, `nonsexual_nudity=off`, `relationship_transgression=off`
- **청소년 수위 상한**: `insult_level=1`, `predation_level=1`, `nonsexual_nudity=off`, `relationship_transgression=off`
- **어른 수위 상한**: `insult_level=2`, `predation_level=3`, `nonsexual_nudity=traditional_only`, `relationship_transgression=adult_only`

# 7. 제어값

`0~3` 강도값은 `0` 없음, `1` 약함, `2` 보통, `3` 강함을 뜻함.

| 키 | 기본값 | 범위와 규칙 | 효과 |
| --- | --- | --- | --- |
| `choice_count` | 3 | 고정 | 한 질문의 선택지 수 |
| `distinct_type_min` | 3 | 고정 | 서로 다른 선택지 유형의 최소 수 |
| `solve_max` | 1 | 0~1 | 도입, 전개와 절정 한 세트의 수습, 해결 선택지 상한 |
| `complication_min` | 1 | 1~2 | 도입, 전개와 절정 한 세트의 `STIR`, `TRICK`, `RAMPAGE`, `NEW_TROUBLE` 합계 하한 |
| `chaos_level` | 2 | 0~3 | 난장, 우연과 새 문제의 강도 |
| `moralizing_level` | 0 | 고정 | 즉시 훈계하거나 특정 선택을 정답으로 표시하지 않음 |
| `npc_autonomy` | 2 | 0~3 | NPC가 자기 욕망으로 사건을 일으키는 강도 |
| `deception_level` | 2 | 0~3 | 거짓말, 속임과 이간질의 강도 |
| `power_abuse_level` | 2 | 0~3 | 신분과 권력을 사적으로 휘두르는 강도 |
| `insult_level` | 1 | 0~3 | 가상 인물끼리 주고받는 욕설과 조롱의 강도 |
| `predation_level` | 2 | 0~3 | `0` 없음, `1` 위협이나 화면 밖 실종, `2` 과장된 삼킴, `3` 반복되는 삼킴. 잔혹 묘사는 쓰지 않음 |
| `consequence_delay` | 1 | 0~2개 거리 | 선택 결과가 다시 돌아오기까지 미룰 거리 수 |
| `comic_recovery` | 2 | 0~3 | 손해와 망신을 웃음으로 회수하는 강도 |
| `seed_binding` | 1 | 0~3 | 이야기 씨앗의 거리 방향을 따르는 강도 |
| `age_gate` | `hard` | 고정 | 연령대 제한을 다른 설정보다 우선함 |
| `selected_fact_only` | `true` | 고정 | 고른 선택만 다음 이야기의 사실로 사용함 |
| `relationship_transgression` | `adult_only` | 고정 | 불륜과 관계 일탈은 어른 런에서 암시로만 다룸 |
| `nonsexual_nudity` | `traditional_only` | 고정 | 전통 인형의 맨몸은 비성적 익살로만 쓰고 미성년 캐릭터에는 적용하지 않음 |
| `explicit_sex` | 0 | 고정 | 노골적 성적 묘사를 생성하지 않음 |
| `graphic_violence` | 0 | 고정 | 잔혹한 상해 묘사를 생성하지 않음 |
| `real_target` | 0 | 고정 | 실제 인물과 단체를 풍자나 욕설 대상으로 쓰지 않음 |
