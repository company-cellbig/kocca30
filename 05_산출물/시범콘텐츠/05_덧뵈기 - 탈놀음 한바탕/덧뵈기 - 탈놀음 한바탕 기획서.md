# 1. 개요

- **콘텐츠 정의**
	- 남사당놀이 덧뵈기 3개 마당(옴탈잡이, 샌님잡이, 먹중잡이) 중 옴탈잡이 마당을 체험하는 키오스크 콘텐츠
		- 1차년도 개발 대상으로 옴탈잡이 우선 개발 진행
- **소재**
	- 남사당놀이의 덧뵈기는 여타 탈 관련 무형문화재에 비해 춤사위보다 마임과 재담 및 사회 풍자가 두드러지는 특징을 지님
	- 마당씻이 -> 옴탈잡이 -> 샌님잡이 -> 먹중잡이로 진행되나 각 마당은 독자적인 구성이며 마당씻이는 오프닝 성격이어서 본 체험에서는 제외함
	- 각 마당은 희극이라는 카테고리에 묶일 수 있으나 웃음을 유발하는 요인은 각자 다름 (옴탈잡이: 기괴한 존재 퇴치, 샌님잡이: 권위 전복, 먹중잡이: 위선 폭로)
- **개발 목적**
	- 유저에게 덧뵈기의 각 마당 별 재미 요소 체험 수단을 제공하여 마당 별 특성을 체험 및 학습할 수 있도록 함

# 3. 공용 시스템

## 3.1 세션 데이터

### 3.1.1 개요

- **정의**
	- 세션 진행 중 필요한 상태, 선택 및 수행 기록 등을 통합 관리하는 데이터
- **목적**
	- 콘텐츠 진행에 필요한 데이터를 체계화하여 **진행 상태 관리 및 데이터 관리 편의성 향상**

### 3.1.2 구성

| 데이터   | 유형  | 값                                                   |
| ----- | --- | --------------------------------------------------- |
| 세션 ID | 시스템 | 세션마다 부여되는 고유 식별자                                    |
| 현재 언어 | 시스템 | 세션에 적용 중인 언어<br>(기본값: 한국어)                          |
| 현재 단계 | 시스템 | 현재 진행 중인 단계<br>(시작, 가이드, 이용 동의, 마당 선택, 탈놀음 체험, 마무리) |
| 에러 유형 | 시스템 | 에러 발생 시 확인된 에러 유형<br>(기본값: None)                    |
| 동의 내역 | 시스템 | 약관 버전, 동의 시각 기록                                     |
| 선택 마당 | 콘텐츠 | 유저가 선택한 마당의 식별자<br>(기본값: 옴탈잡이)                      |
| 체험 단계 | 콘텐츠 | 유저가 선택한 각 마당의 진행 단계                                 |
| 수행 기록 | 콘텐츠 | 탈놀음 체험 진행 점수                                        |

- **목적**
	- 비한국어권 유저에게도 원활한 콘텐츠 참여 기회 제공

- **목적**
	- 유저의 장시간 키오스크 체류를 방지하여 키오스크 회전율 제고

## 3.4 중도 종료

### 3.4.1 개요

- 정의
	- 유저의 자발적 이탈 또는 비정상적인 세션 중단 시 세션을 정상 종료하는 시스템
- 목적
	- 비정상적인 상황에서 세션이 종료되지 않은 채 유지되는 것을 방지하여 키오스크 회전율 제고

### 3.4.2 동작 방식

#### 1) 진행 중 종료 선택 시 처리

##### (2) 처리 방식

- 종료 팝업 생성 후 확인 버튼 터치 시 종료 처리

#### 2) 미입력 타임아웃 시 처리

##### (1) 적용 조건

- 세션 진행 중 일정 시간 동안 화면 터치 입력이 없는 경우 적용

##### (2) 처리 방식

- 각 단계 화면 진입 시 미입력 타이머 시작
- 화면 터치가 발생하면 타이머 초기화
- 안내 시점까지 입력이 없으면 미입력 안내 표시
- 안내 중 화면을 터치하면 안내를 닫고 타이머 초기화 후 현재 단계 계속 진행
- 안내 후 제한 시간까지 입력 없을 시 미입력 안내 닫고 종료 처리

#### 3) 세션 진행 실패 시 처리

##### (1) 적용 조건

- 세션 등록 실패
	- 서버에 클라이언트의 세션 데이터를 전송 실패
	- 서버에서 세션 ID 부여 실패
- 체험 진행이 불가능한 오류 발생
	- 체험 콘텐츠 리소스 로드 실패, 카메라 및 인식 계통의 지속적 장애 발생

##### (2) 처리 방식

- 재시도(2회) 후 계속 오류 상태일 경우 오류 안내 팝업 표시 후 체험 종료 처리
	- 오류 안내 팝업은 3초간 유지 후 다음 단계 유지
- 세션 등록 실패 시 종료할 세션이 없으므로 체험 종료 처리 없이 시작 화면으로 복귀

## 3.5 유저 기반 모션 인식 시스템

### 3.5.1 개요

- **정의**
	- 카메라로 등록된 유저의 신체와 양손을 추적하고 손 움직임을 게임 입력으로 변환하는 시스템
- **진행**
	- 양손 중 지정 움직임 기준을 먼저 충족한 손을 입력 손으로 지정
	- 입력 손의 화면 위치에 손 위치 포인터 표시 후 원으로 충돌 영역 지정
	- 손 위치 포인터 영역과 관심 영역(ROI)의 충돌 판정
	- 현재 입력 종료 시 입력 손 해제 후 양손 다시 비교
- **목적**
	- 유저가 별도 컨트롤러 없이 직관적인 신체 동작으로 콘텐츠를 조작하게 함
	- 카메라 영상을 화면에 표시하지 않아도 유저가 자신의 입력 위치를 확인하게 함

### 3.5.2 레퍼런스

	- 화면 중앙의 플레이어를 향해 여러 방향에서 등장하는 적을 신체 움직임으로 타격함

	- 카메라 영상을 대신하는 손 위치 포인터로 입력 위치 표시

### 3.5.3 동작 방식

<img src="../../../assets/시범콘텐츠/탈놀음/플로우_모션인식.png">

#### 1) 유저 식별과 추적

- 화면의 가이드라인을 기준으로 체험 위치에 선 유저 식별
- 식별된 유저를 현재 세션의 추적 대상으로 등록
	- 주변 인원과 구분하여 추적
- 등록 유저의 신체 영역에서 양손만 입력 후보로 사용
-
- ==등록 유저 추적 끊길 경우 입력 판정과 포인터 표시 중지==
- ==추적 실패가 허용 시간 초과 시 현재 입력 취소 후 입력 손 해제==
- ==추적 실패가 재식별 전환 시간 초과 시 유저 재식별 실행==

#### 2) 양손 위치와 움직임 추적

- 등록 유저의 양손 위치를 개별 추적
- 양손 위치를 화면 좌표로 변환
- 각 손의 이동 방향, 이동 거리, 이동 속도와 ==추적 신뢰도== 산출
- 입력 손 지정되지 않은 경우 양손 움직임 비교 유지

#### 3) 입력 손 지정과 해제

- 지정 조건
	- 현재 입력 손이 없음 and 손 추적 신뢰도가 기준 이상
	- 입력 손 지정 움직임 기준을 먼저 충족한 손을 입력 손으로 지정
		- 조건 동시 충족 시 오른손을 입력 손으로 지정
- 유지
	- 입력 손 지정 시점부터 ==현재 입력 종료 시점==까지 입력 손 유지
- 해제
	-
- 다음 입력

- 양손마다 유효 움직임 조건과 현재 활성 ROI  접근 조건 개별 확인
- 양손에서 **유효 움직임 조건**이나 현재 **활성 ROI 접근 조건**이 처음 성립한 시점 비교
- 두 조건 중 먼저 성립한 손을 입력 손으로 지정
	- 조건이 같은 시점에 성립했을 경우 오른손을 입력 손으로 지정
- 입력 손 지정 시 현재 입력이 끝날 때까지 다른 손으로 전환하지 않음
- 입력 손 지정은 손 선택 시부터 게임 입력 성공, 또는 현재 단계가 끝날 때까지 유지
	- 현재 단계: 옴탈잡이 조우, 잡아채기, 채검하기, 몰아내기
- 게임 입력이 성공, 또는 현재 단계가 끝날 시 입력 손 해제
	- 목표 소멸, 입력 취소 또는 입력 손 추적 실패 시에도 입력 손 해제
- 입력 손 해제 후 양손을 다시 비교해 다음 입력 손 지정






- 화면의 가이드라인을 기준으로 체험 위치에 선 유저 식별
- 식별된 유저를 현재 세션의 추적 대상으로 등록
	- 주변 인원과 구분하여 추적할 기준으로 사용

#### 4) 유저 추적 및 영역 추출

- 등록된 유저의 신체 영역을 카메라 영상에서 계속 추적
- 등록된 유저의 왼손과 오른손의 위치를 각각 추적
- 양손의 위치를 화면 좌표로 변환
- 양손마다 위치, 이동 방향, 이동 거리, 이동 속도와 추적 신뢰도 산출
- 각 손의 화면 좌표를 해당 손 위치 포인터와 원형 충돌 영역의 중심점으로 사용

#### 5) 입력 손 지정

-
- 양손마다 유효 움직임 조건과 현재 활성 ROI  접근 조건 개별 확인
- 양손에서 **유효 움직임 조건**이나 현재 **활성 ROI 접근 조건**이 처음 성립한 시점 비교
- 두 조건 중 먼저 성립한 손을 입력 손으로 지정
	- 조건이 같은 시점에 성립했을 경우 오른손을 입력 손으로 지정
- 입력 손 지정 시 현재 입력이 끝날 때까지 다른 손으로 전환하지 않음
- 입력 손 지정은 손 선택 시부터 게임 입력 성공, 또는 현재 단계가 끝날 때까지 유지
	- 현재 단계: 옴탈잡이 조우, 잡아채기, 채검하기, 몰아내기
- 게임 입력이 성공, 또는 현재 단계가 끝날 시 입력 손 해제
	- 목표 소멸, 입력 취소 또는 입력 손 추적 실패 시에도 입력 손 해제
- 입력 손 해제 후 양손을 다시 비교해 다음 입력 손 지정

#### 6) 손 위치 포인터 표시와 갱신

- 입력 손을 지정 시 해당 손의 화면 좌표에 손 위치 포인터 표시
- 입력 손의 움직임에 따라 포인트 위치 갱신
- 손 떨림과 인식값의 작은 변화는 보정 뒤 포인터에 반영
- 유효 입력으로 판정되지 않은 움직임도 현재 손 위치를 알려주기 위해 포인터 이동에 반영
- 입력 손 추적 끊기거나 유저가 체험 영역 벗어날 시 포인터 숨김

#### 7) ROI(관심 영역 / 판정 영역) 입력 판정

- ROI는 입력 판정을 위해 화면상에 설정하는 가상의 영역임
- 현재 단계에서 활성화된 ROI와 손 위치 포인터의 위치 비교

| 적용 단계   | 목표 ROI         | 판정 기준                               |
| ------- | -------------- | ----------------------------------- |
| 옴탈 조우   | 화면 좌우에 나타난 옴탈  | - 포인터와 옴탈 중첩<br>- 입력 손 수평 움직임 > 기준값 |
| 옴탈 잡아채기 | 옴탈 머리 영역       | - 포인터와 ROI 중첩                       |
| 옴탈 채검하기 | 화면 가득 채운 옴탈 얼굴 |                                     |
| 옴탈 몰아내기 | 날아오는 옴탈 얼굴     |                                     |

- 손 위치 포인터와 현재 활성화된 ROI의 위치 및 중첩 여부 확인
- 손 위치 포인터가 ROI 안에 있고 움직임 검출값이 판정 기준을 충족하면 유효 판정
	- ROI 안에 있더라도 움직임이 없으면 무효 판정

#### 8) 게임 입력 변환

- 유효 판정 ROI에 연결된 입력 정보를 게임 입력으로 변환
- 각 ROI에 설정된 행동 실행

## 3.6 키워드 조합 시스템 (2차 연도 개발 예정)

- 소재 키워드 선택 상태에서 다른 소재 키워드 선택 시 소재 키워드 변경

- 소재 키워드와 방식 키워드가 모두 선택 시 바로 판정 실행
- 조합 확정 후 키워드 선택 종료하고 조합 결과로 재담 진행

### 3.7.1 개요

- 정의
	- 먹중잡이 진행 시 화면에 표시된 증거 중 2개를 선택하고 조합하여 먹중의 위선을 판정하는 시스템
	- 유효한 조합 성공 시 신분, 향락, 여색, 폭력, 사기 중 해당 내용을 폭로하고 관련 재담과 먹중의 반응 동작 진행
- 목적
	- 먹중잡이의 핵심 재미인 위선 폭로에 증거를 조합하는 추리의 재미를 더함

### 3.7.2 동작 방식

- 증거 2개 선택 시 바로 판정 실행

#### 3) 조합 성공

#### 4) 조합 실패

- 조합 실패에 해당하는 재담 진행
- 증거 선택값 초기화 후 새로운 증거 조합 진행

#### 2) 데이터 테이블 기반 제어

- 관리 및 진행을 데이터 테이블로 제어할 수 있어야 함
	- 재담 진행과 증거 조합 시스템 실행할 위치

# 7. 마무리 진행

## 7.1 개요

마무리 진행은 결과 안내 및 종료로 구성되어 세션을 마무리하는 단계임

## 7.2 진행

### 7.2.1 결과 안내 및 종료

<img src="../../../assets/시범콘텐츠/탈놀음/플로우_마무리.png"  width=500 >

#### 1) 결과 데이터 집계 및 확정

- 세션 데이터에서 현재 언어, 선택 마당 및 수행 기록 로드
- 선택 마당의 단계 별 수행 기록을 결과 화면에 표시할 항목으로 집계
	- 모션 체험: 성공 횟수 누적
	- 키워드 조합: 조합 별 획득 점수 누적
	- 증거 조합: 조합 성공 개수 누적
- 집계 결과를 최종 결과 데이터로 확정
- 기록 없는 항목은 미수행 상태로 처리

#### 2) 결과 화면 표시

- 선택한 마당의 명칭과 최종 결과 요약을 현재 언어로 표시
- 확정된 결과 데이터를 마당별 결과 항목에 맞춰 표시

#### 3) 체험 종료 처리

- '처음으로' 버튼 터치 or 화면 타임아웃 or 미입력 타임아웃 실행 시 체험 종료 처리  진행
- 결과 화면의 추가 입력 차단하고 진행 중인 타이머와 대사 출력을 종료
- 서버에 해당 세션의 체험 종료 상태 기록
	- 2차년도 개발 사양
- 종료 처리 완료 시 세션 데이터 초기화 진행

#### 4) 세션 데이터 초기화

- 종료된 세션의 임시 데이터를 초기값으로 변경
- 키워드 및 증거 선택값, 진행 인디케이터와 타이머 상태 초기화
- 초기화 완료 후 시작 화면으로 이동
