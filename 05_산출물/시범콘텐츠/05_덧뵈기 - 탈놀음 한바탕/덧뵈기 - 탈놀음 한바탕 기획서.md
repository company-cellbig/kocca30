# 1. 개요

- **콘텐츠 정의**
	- 남사당놀이 덧뵈기 4개 마당 중 3개 마당(옴탈잡이, 샌님잡이, 먹중잡이)을 체험하는 키오스크 콘텐츠
- **소재**
	- 남사당놀이의 덧뵈기는 여타 탈 관련 무형문화재에 비해 춤사위보다 마임과 재담 및 사회 풍자가 두드러지는 특징을 지님
	- 마당씻이 → 옴탈잡이 → 샌님잡이 → 먹중잡이로 진행되나 각 마당은 독자적인 구성이며 마당씻이는 오프닝 성격이어서 본 체험에서는 제외함
	- 각 마당은 희극이라는 카테고리에 묶일 수 있으나 웃음을 유발하는 요인은 각자 다름 (옴탈잡이: 기괴한 존재 퇴치, 샌님잡이: 권위 전복, 먹중잡이: 위선 폭로)
- **개발 목적**
	- 유저에게 덧뵈기의 각 마당 별 재미 요소 체험 수단 제공하여 마당 별 특성을 학습할 수 있도록 함

# 3. 공용 시스템

## 3.1 세션 데이터

### 3.1.1 개요

- **정의**
	- 세션 진행 중 필요한 상태, 선택 및 수행 기록 등을 통합 관리하는 데이터
- **목적**
	- 콘텐츠 진행에 필요한 데이터를 체계화하여 **진행 상태 관리 및 데이터 관리 편의성 향상**

### 3.1.2 구성

| 데이터      | 유형  | 값                                                   |
| -------- | --- | --------------------------------------------------- |
| 세션 ID    | 시스템 | 세션마다 부여되는 고유 식별자                                    |
| 현재 언어    | 시스템 | 세션에 적용 중인 언어<br>(기본값: 한국어)                          |
| 현재 단계    | 시스템 | 현재 진행 중인 단계<br>(시작, 가이드, 이용 동의, 마당 선택, 탈놀음 체험, 마무리) |
| 에러 유형    | 시스템 | 에러 발생 시 확인된 에러 유형<br>(기본값: None)                    |
| 동의 내역    | 시스템 | 약관 버전, 동의 시각 기록                                     |
| 선택 마당    | 콘텐츠 | 유저가 선택한 마당의 식별자<br>(기본값: 옴탈잡이)                      |
| 체험 단계    | 콘텐츠 | 유저가 선택한 각 마당의 진행 단계                                 |
| 수행 기록    | 콘텐츠 | 탈놀음 체험 진행 점수                                        |
| 베스트샷     | 콘텐츠 | 탈놀음 체험 중 정리한 정지 화상 1장                               |

## 3.5 유저 기반 모션 인식 시스템

### 3.5.1 개요

- **정의**

### 3.5.2 레퍼런스

#### 1) EyeToy: Play - Kung Foo

<img src="../../../assets/시범콘텐츠/탈놀음/레퍼_모션인식.png">

- **게임 정보**
	- 타이틀: _EyeToy: Play_
	- 미니게임: **Kung Foo**
	- 장르: 체감형/파티 미니게임
	- 플레이 영상: https://youtu.be/0h1EKk6JpK8?si=GEQY9L-9jSdw3drs
- **게임 개요**
	- 카메라를 이용하여 **신체 움직임으로 화면상의 오브젝트와 상호작용하는 체감형 콘텐츠**
	- Kung Foo에서는 화면 중앙의 플레이어를 향해 여러 방향에서 등장하는 적을 **신체를 움직여** 타격하는 방식으로 진행
- **주요 특징**
	- 별도의 컨트롤러 없이 **신체 자체를 입력 수단으로 사용**
	- **자신의 움직임과 결과를 즉각 확인**
	- 복잡한 조작법 없이 화면상의 대상의 위치에 맞춰 신체를 움직이는 것만으로 플레이 가능
- **레퍼런스 적용 요소**
	- 유저의 **신체 움직임을 직접 콘텐츠 입력으로 활용하는 조작 방식**
	- 화면상의 캐릭터, 오브젝트 위치와 유저의 실제 움직임을 연결하는 **공간 기반 상호작용**
	- 별도 입력 장치 없이 쉽게 이해하고 참여할 수 있는 **낮은 조작 진입장벽**
### 3.5.3 동작 방식

<img src="../../../assets/시범콘텐츠/탈놀음/플로우_모션인식.png">

#### 1) 유저 식별 및 등록

- 화면의 가이드라인을 기준으로 체험 위치에 선 유저를 식별
- 식별된 유저를 현재 세션의 추적 대상으로 등록
- 주변 인원과 구분하여 추적할 기준으로 사용

#### 2) 유저 추적 및 영역 추출

- 등록된 유저를 카메라 영상에서 지속적으로 추적
- 유저의 신체 영역을 추출하여 모션 입력 판정 대상으로 사용
- 등록되지 않은 주변 인원 및 배경 영역은 입력 판정에서 제외

#### 3) 움직임 검출

- 추출된 유저 영역 내에서 발생하는 움직임 검출
- 검출된 움직임의 **화면상 위치와 범위** 산출
- 검출 결과는 ROI 입력 판정에 사용할 수 있도록 **화면 좌표 기준 데이터**로 전달

#### 4) ROI(관심 영역 / 판정 영역) 입력 판정

- ROI는 입력 판정을 위해 화면상에 설정하는 **가상의 판정 영역**으로 **화면 좌표 기반 영역**으로 관리
- 현재 탈놀음 체험 진행 단계에서 활성화된 ROI와 검출된 움직임의 위치 및 중첩 정도 비교
- 설정된 판정 기준 충족 시 해당 ROI 입력 유효 판정

#### 5) 게임 입력 변환

- 유효 판정 ROI에 연결된 입력 정보를 게임 입력으로 변환
- 각 ROI에 설정된 행동 실행

### 3.5.4 설정 및 예외 처리

#### 1) 주요 설정값

- 모션 인식 및 입력 판정에 필요한 값으로 데이터 테이블화하여 JSON 파일로 관리
- 구체적인 수치는 실제 설치 환경과 테스트 결과에 따라 조정

| 항목               | 설명                                  |
| ---------------- | ----------------------------------- |
| 유저 식별 영역         | 최초 유저 식별 및 등록에 사용하는 화면상의 위치 및 영역 정보 |
| 유저 식별 <br>신뢰도 기준 | 유저 식별 성공 여부를 판단하는 최소 기준             |
| 유저 추적 <br>신뢰도 기준 | 등록된 유저의 추적 상태를 정상으로 판단하는 최소 기준      |
| 움직임 검출 <br>임계값   | 영상 변화를 유효한 움직임으로 인정하는 최소 기준         |
| 최소 움직임 <br>영역 비율 | 미세 움직임이나 영상 노이즈를 제외하기 위한 최소 범위      |
| 입력 쿨다운           | 동일 움직임으로 인한 연속, 중복 입력 방지 시간         |
